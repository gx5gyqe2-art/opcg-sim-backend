## 0. 動機（P0 実測・`tests/scripts/macro_p0_probe.py`）

慎重型（手単位の木探索）は**読みの解像度が細かすぎる場所で浪費**している:

- 全判断の **42.3%** が細部窓（カウンター選択24.9%・効果サーチ/選択6.1%・任意確認4.4%・ブロッカー2.5%…）
- メイン窓の判断も最頻手は**ドン1枚付与**（メイン判断の46%）
- ドン付与の**順序重複**（同一配分に至る原始経路の倍率）: 中央値 5.3x・最大 **9756x**

→ 細かい手を**意味のまとまり（箱）**に畳めば、同じ探索量で読める未来が桁で増える。
箱の列はそのままターンプランなので、**慎重型（木）とプラン型（プラン読み出し）は
「箱空間の探索」という同一物**になる——適応的に伸ばすか（木）、先に描いて出口で比べるか
（プラン）の違いでしかない。プランA6の敗因（狭い採点係の誤りをターン単位で固定実行）も、
箱の木なら**1箱ごとに読み直す自己修復性**を保ったまま意図を扱える。

## 1. 行動の層の全体像（4段）

```
方針   … ターンを跨ぐ姿勢（攻め/受け/伸ばし・受け方針箱）        ←最上位
プラン … 箱の列（ターン箱）＝「このターンをどう使うか」
箱     … 意味のまとまり＝探索・プラン提案の語彙（本計画の対象）
原始手 … エンジンとの接点（記録/再生/APIの単位。探索からは見えなくなるだけで存続）
```

- 実対局への出力は常に**原始手**（箱→先頭原始手変換。DON_BOX で確立済みの規約
  ＝`cpu_ai.don_box_first_primitive`。プラン経路の素通し事故 2026-08-23 の教訓:
  **箱を導入したら全ての出力経路に変換を通すこと**）。
- **見送りは第一級**: 各箱には必ず「しない」相棒（温存・素通し・不発動）を候補に残す。
  「やる変種」だけ並べると見送りが消える事故が起きる（構造化提案の hold/空集合と同じ原則）。

## 3. 永続効果の位置づけ

永続効果（相手ターン常在・レスト時常在等）は発動判断が無い＝**行動の層の住人ではない**
（状態の層＝収支の修飾子）。ただし行動の層への必須入力が2つ:

1. **箱の候補生成**: 「レスト済みへの付与は死に」の例外が相手ターン常在の持ち主
   （チョッパー型＝守備的付与に意味）。V1族の教師生成で実装済みの除外規則と同根。
2. **採点係**: ターン末/戦闘後盤面の評価は常在の存在を織り込む必要がある
   （現在はカードID埋め込み経由の暗黙学習のみ・陽な特徴化は将来課題）。

## 4. 箱と並列の観点（行動以外の思考要素・参考）

箱=行動の抽象化。並列に: **収支**（状態の抽象化＝ライフ/手札/盤面/ドンの通貨と交換レート。
各箱は通貨の交換）／**レース**（時間の抽象化＝あと何ターンか・伸ばすか縮めるか。通貨の価値は
レース状況で変わる—「盤面アドは長いゲームで効き、ドン圧力はゲームを縮める」）／**読み合い**
（情報の抽象化＝相手手札の想像。挙動からの逆推定は未実装の伸びしろ）。
