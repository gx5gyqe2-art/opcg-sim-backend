# 第 I 部 このゲームは何であるか

## 1. 定義

ONE PIECE カードゲームは**有限・二人・零和・不完全情報・完全記憶の展開型ゲーム**である。

- **有限**: 盤面・手札・デッキは有限で、手数に上限がある。
- **二人零和**: 終局の利得は勝ち／負けの二値で、両者の利得の和は常に 0。
- **不完全情報**: 分からないのは**相手の手札の中身・伏せたライフの中身・両者の山の順**。
  見えるのは公開情報（場・ライフ枚数・手札枚数・トラッシュ・ドン）と自分の私的情報。
- **完全記憶**: 各プレイヤーは自分の観測と行動をすべて覚えている。
- **手番は交互**だが、**相手のターン中にも自分の決定点がある**（カウンター窓・ブロッカー宣言）。
  同時手番ではなく、すべての決定点は一列に並ぶ。

**情報集合**＝自分が区別できない状態の集まり。カウンター窓での情報集合は
「相手の手札と伏せライフの中身だけが違う盤面」の束であり、**その束の大きさが打ち回しの難しさ**。

## 2. 零和から出てくること（前提として使っていい）

1. **ミニマックス値が存在し一意**（有限零和・完全記憶）。だから「正しい評価」という言葉に意味がある。
2. **値は反対称**: 同じ盤面を自分から見た値と相手から見た値は `V_me(s) = −V_opp(s)`。
3. **相手は最善応手を打つと仮定してよい**。零和では「相手が間違えてくれる」ことに期待する戦略は、
   正しく打つ相手に対して損。**相手の選択は最善で畳む**のが正しく、
   「相手が下手を打つ確率」を混ぜるのは保険ではなく歪み。
4. **自分の利得最大化 ＝ 相手の損失最大化**。だから攻めの物差しを
   **「相手に払わせた量」**で書いてよい（第 II 部）。

## 3. 不完全情報から出てくること

1. **最適戦略は一般に混合（確率的）**。決定論的な打ち手は、**適応する相手に読まれる**。
2. ただし**固定の相手に対しては純戦略の最善応手で足りる**。
   ＝**同じ打ち方同士の対戦では、この弱点は原理的に現れない**。損が出るのは
   **打ち方を変えてくる相手（人間）と打つときだけ**。
3. **読まれやすさは量になる**: 公開状態から行動がどれだけ当てられるか
   ＝条件付きエントロピー `H(行動 | 公開状態)`。0 に近ければ完全に読める。
4. **しかし「読める」と「搾取できる」は別**。読まれても、相手の最善応手が
   自分の選択によって変わらないなら取り分は無い。搾取の上限は

```
G* = E_s[ max_a （私の手を知った上での相手の最善応手の値） − （知らないときの値） ]
```

   ＝**応手の感度**。`G*` が小さいゲームでは、決定論でもほとんど損をしない（§5 に続く）。
5. **情報を与える／隠す行動がある**（カウンターを切れば手札の中身が 1 枚分わかる・
   伏せライフのトリガーは公開される）。シグナリングの利得は**未定式化**（第 V 部）。

## 4. 何を見てよいか（公平性の規約）

**相手の手札の中身は使わない**。**未見プール**（相手の手札∪山∪伏せライフの合計）は
「人間がデッキリストから知りうる範囲」なので使う。相手の山の順・実際の手札は使わない。
＝打ち手は**情報集合の上で**打つ（ユーザ決定 2026-09-04）。

## 5. このゲームの情報構造（実測）

不完全情報ゲームは「隠れ情報がどう振る舞うか」で性質が大きく変わる。3 つの尺度で見る:

| 尺度 | 意味 | このゲームでの実測 |
|---|---|---|
| **disambiguation** | 隠れ情報がどれだけ速く公開情報になるか | **高い**——手札は打てば公開・トリガーは公開・カウンターは切れば公開。終盤へ向かうほど情報集合は小さくなる |
| **leaf correlation** | 「どの隠れ手札でも同じ側が勝つ」度合い | **高い**——ほとんどの局面ではどの世界でも勝敗が同じ。**低いのは接戦帯だけ**（実測§18） |
| **bias** | 構造的にどちらかに偏っているか | 先後の非対称はあるが小さい（**未整理**） |

**含意 1**: 隠れ情報の当て方（相手の手札を何通り想定するか）が効くのは**接戦帯だけ**。
`K` 通り想定して「その線が通る世界」が割合 `p` なら、1 度でも当たる確率は

```
1 − (1 − p)^K        K=1: p        K=4: p=0.2 → 59%        K=8: p=0.2 → 83%
```

**「2 割の世界でしか通らない線」は、1 通りしか読まなければ 8 割見落とす**。
そういう線が要るのは**負けが濃厚なとき**（§17）なので、**最も無茶が要る局面で最も読みが要る**。

**含意 2**: leaf correlation が高いことは、**§3-4 の `G*` が小さいこと**と同じ性質である
——自分の手が変わっても勝つ側が変わらないなら、読まれても相手の応手は変わらない。
つまり**このゲームでは決定論の罰が小さい**という説明が立つ（検査可能な含意・第 V 部）。

# 第 II 部 資源と価格——打ち回しの本体

## 6. 交換の恒等式（ここを間違えるとすべて狂う）

超過パワー `x`（攻撃側のパワー − 自リーダーのパワー）の攻撃に対して:

| | ライフ | 手札 | その他 |
|---|---|---|---|
| **受ける** | −1 | **+1**（ライフカードが手札に入る） | トリガーの期待 `+τ` |
| **守る** | ±0 | **−c(x)** | — |

**受けるのは「ライフを失う」のではなく「ライフ 1 枚を手札 1 枚に両替する」**。
ここを「受ける＝損」と置くと、以降の判断がすべて守り過ぎに寄る。

`c(x)` は**止めるのに要る枚数**＝手札のカウンター値の合計が `x` 以上になる最小の組。

## 7. 予算——「あと何回守らなければならないか」

- `L` 今のライフ（0 になった次の被弾で負け＝**受けられるのは残り `L` 回**）
- `T` 自分が決めるまでのターン数・`A` 相手の 1 ターンの攻撃回数・`N ≈ A·T` これから来る攻撃数
- `B` ブロッカーで止める回数・`H` 手札・`D ≈ T` これから引く枚数・`K_atk` 攻めに要る枚数

```
必ず守る回数   G = max(0, N − L − B)
余裕           S = H + (N − G) + D − K_atk − Σ_{安い G 本} c
```

`N − G` が足されるのは**受けた回数だけ手札が増える**から（§6）。

## 8. 価格——この窓の判断は 1 つの符号で決まる

受けた場合と守った場合の `S` を比べると `H` と `(N−G)` が打ち消えて

```
S(受ける) − S(守る) = c(x) − Θ
```

`Θ` は「**この先まだ守る、最も高い攻撃の費用**」＝経済学でいう**シャドー価格（双対価格）**。
「`G` 回は守らねばならない」という制約に紐づく**手札 1 枚の機会費用**である。したがって

> **安い攻撃を守り、高い攻撃を受ける**。境目は `c(x)` と `Θ` の大小だけ。

**記号を混同しないこと**（混同すると必ず誤る）:

| 記号 | 何か | 性質 |
|---|---|---|
| **`c(x)`** | **費用曲線**＝`x` を止める枚数 | **デッキで決まる**（中身を数えれば出る） |
| **`Θ`** | **無差別点＝価格** | **盤面で決まる**（`L`・`T`・`A`・`B` から） |
| `c̄_mean` | 実際に守った窓の平均費用 | 観測量。定義上 `c̄_mean < Θ`（安い側だけ守るので） |

3 つの領域に分かれる:

| 領域 | 条件 | 最適 |
|---|---|---|
| **1** | `G = 0`（全部受けても死なない） | **守るのは純粋な無駄**（トリガーも取りに行ける） |
| **2** | `G > 0` かつ `S ≥ 0` | **`c(x) < Θ` なら守り・`c(x) > Θ` なら受ける** |
| **3** | `S < 0` | どう守っても足りない＝**別の出口**（トリガー・相手の事故）を狙う（§17） |

## 9. 価格は限界価値から計算できる

`λ` をライフ 1 枚の価値、`μ` を手札 1 枚の価値（どちらも勝率の単位）とすると、§6 の表は

```
ΔV(受ける) = −λ + (1 + τ_value)·μ            ΔV(守る) = −c(x)·μ
⇒  受ける ≽ 守る  ⟺  c(x) ≥ λ/μ − 1 − τ_value
⇒  Θ = λ/μ − 1 − τ_value
```

**価格は「ライフと手札の交換レート」から、受けること自体の利得を引いた量**である。
`λ`・`μ`・`τ_value` はすべて測れる量（§18）。実測を入れると

```
λ/μ ≈ 2.5〜2.7  （ライフ 1 枚 ≈ 手札 2.5 枚）      Θ ≈ 0.8〜1.5 枚
```

`c(x)` 曲線（§18）に当てると**切れ目は x = 2000 と 3000 の間**＝

> **2000 までの攻撃は守り、3000 以上は受ける**のが平均的な最適。

`τ_value` の不確かさ（0〜0.67）の幅の中で、**この切れ目は動かない**。

## 10. 整数性（lumpiness）——「7000 に積む」の正体

`c(x)` は**整数**（カードは割れない）で、カウンター値は 1000／2000 と離散。
だから `c(x)` は**階段関数**であり、**段の位置に価値がある**。実測（§18）:

```
c(1000)=1.00  c(2000)=1.28  c(3000)=2.25  c(4000)=2.78  c(5000)=3.63
段の高さ:        +0.28        +0.97         +0.53        +0.85
```

平均すれば「+1000 ごとに +0.66 枚」だが、**`2000→3000` の段が +0.97 で最大**
——2000 カウンター 1 枚では 3000 を止められないため。

> **「リーダー 5000 に +2000 して 7000 を作る」は、1 枚で足りない高さへ跨ぐ段を買う行為**。
> 1000 刻みの線形な足し算ではない。**超過パワーを線形に数えると、この段差が平らに潰れる**。

攻め側から見れば、ドン 1 本を付けて超過を 1000 上げる価値は

```
Δpressure(1000) = c_opp(x + 1000) − c_opp(x)        （段の上なら ≈ 1 枚・段でなければ 0）
```

**過剰盛り**（既に段を越えているのに足す）は `Δpressure = 0` ＝ 純粋な無駄。

## 11. しきい値は状態の関数（「ライフ 3 で守り始める」は誤り）

```
θ(deck, state) = A·T − B        （L < θ から守りが必須になり始める）
```

- 速いデッキ（`T` 小）→ θ 小＝**守り始めが遅くて正しい**
- 相手が横に並べる（`A` 大）→ θ 大＝**早くから守るのが正しい**
- ブロッカーが多い（`B` 大）→ θ 小

さらに `Θ` は `λ/μ` を通じて盤面に依り、`c(x)` はデッキに依る。実測で
**同じ `x` でも `c(x) − Θ` の符号がリーダーによって逆になる**（`c(3000)` が 2.09〜3.00・§18）。

> **固定のライフしきい値は「平均だから」ではなく「価格が状態とデッキの関数だから」誤り**。

## 12. 守りは二重通貨（手札とドン）

- **キャラのカウンター**＝手札を 1 枚捨てるだけ＝**手札だけ**
- **【カウンター】イベント**＝**手札 1 枚 ＋ ドン `m` 個**（コストを払わないと打てない）

だから守りの費用は 1 次元では書けない:

```
guard(x) = min { (枚数, ドン) : 合計の上げ幅 ≥ x }       払えるか＝ドン ≤ （相手ターン中のドン）
```

**相手ターン中に使えるドンは、自分のターンの打ち回しで決まる**（使い切ればゼロ）。
＝**「ドンを残す」が守りの予算に前借りで効く**。

## 13. ドンは 2 段の決定である（窓では埋没費用）

ドンは自分の開始時に**全部アクティブに戻る**。したがって

> **相手ターンに使い残したドンは、次の自分のターンには何の損にもならない**
> ＝**窓の時点でドンは埋没費用（価格 0）**。価格が付くのは**1 ターン前**である。

### 段 1（自分のターン）——残すか、攻めに使うか

```
攻めに使う価値 = Δpressure(1000) · μ        （相手に払わせた枚数＝零和なので自分の利得）
残す価値       = p_need · μ · E[Θ − c_paid]  （p_need＝相手ターンにイベントでしか止まらない窓が来る確率）

残すべき  ⟺  p_need · E[Θ − c_paid] ≥ Δpressure(1000)
```

**実測値を入れると成立しない**: 右辺は平均 0.66 枚、左辺は `Θ ≤ 1.5`・`c_paid ≥ 1` なので
`p_need ≤ 1` でも 0.5 以下。したがって

> **平均的な局面では、【カウンター】イベントのためにドンを残すのは損**。攻めに使う方が良い。
> **例外はライフが薄い帯**——リーサル圏では「そのライフ 1 枚＝敗着」なので `λ` が跳ね、
> `Θ` が 2 枚を超えると成立しうる。**ドンを残すのは、自分が殺されかけている時だけ正しい。**

### 段 2（相手のターン・窓ごと）——使うか、後の窓に取っておくか

```
守る ⟺ c_free(x) ≤ Θ                                          （手札だけで止まる）
     または c_paid(x) ≤ Θ かつ m(x) ≤ d_res かつ m(x)·δ̄ ≤ Θ − c_paid(x)
```

`d_res` は残したドン、`δ̄` は**同じターンの後の窓のための機会費用**（最後の攻撃では 0）。
`Θ` と同じ型の価格が、ターンの内側にもう一段ある。

## 14. 手札は攻めにも使える——価格は 1 つでは足りない

同じ 1 枚を守りにも攻めにも使える。**窓の判断には価格 1 つで足りる**——`μ` を
実測の限界価値として使うなら、`μ` は「**最良の用途に使ったときの**価値」を既に含むので、
`Θ = λ/μ − 1 − τ_value` は攻めの用途を折り込んだ無差別点である。

**2 つ要るのは別の決定**＝**自分のターンに、この札を出すか残すか**:

```
守りの用途 c̄_use = E[ μ·(Θ − c(x_next)) ]        … 次に来る窓で節約できる量
攻めの用途 k̄_use = Δpressure·μ + P(通る)·λ_opp    … 相手に払わせる量＋ライフを取る量
札を攻めに出す ⟺ k̄_use ≥ c̄_use                   μ = max(c̄_use, k̄_use)
```

**`μ` を測っても内訳は出ない**（データは用途を区別しない）。どちらが支配的かは
**未測定**で、これは実務的に大きい——**`k̄_use` が支配的なら「守れるのに受ける」打ち回しの
多くは正しい**ことになる（第 V 部）。

## 15. ターンの中は逐次決定——攻撃順序に価値がある

リーサルの試行は**攻撃 1 本ごとの逐次決定**。1 本ごとに (a) 相手がカウンターを吐いたか＝
相手の予算の情報が更新され、(b) 自分の残り攻撃回数が減る。したがって

- **打ち切れるかの再計算**: 残りの攻撃で相手の予算を割れなければ、そこで「ゲームを伸ばす」へ移る。
  **ターンの最初は①（押し切る）でも、途中から②（伸ばす）に移る**のが正しい。
- **順序に option value がある**: 安い攻撃を先に通して相手の予算を測り、重い攻撃を後に残す
  （逆も戦術としてある）。量は `V(最良の順序) − V(最悪の順序)`。
  **記録を眺めても出ない**——打たなかった順序は棋譜に無いので、
  同じ盤面を別の順序で打ち直す反事実でしか測れない。

## 16. 中盤の 3 方針は「相手の時計のどの項を攻めるか」

自分が決めるまでのターン数 `T_me` と相手の `T_opp` の競争で、勝ち筋は `T_me < T_opp`。

| 方針 | 買うもの | 式の項 |
|---|---|---|
| 純粋な殴り合い | 相手のライフ | `T_me` の分子を削る |
| シーソー（キャラ攻撃を混ぜる） | **相手の手札**（カウンターを吐かせる）・相手のキャラ | 相手の予算 `S_opp` を削る・`A_opp` を減らす |
| 手札切れ待ち | 相手の手札 → 0（そこから `c` が払えない＝全部通る） | `S_opp < 0` を作る |

**キャラへの攻撃は「手札を使わない除去」**＝自分の手札コスト 0 で、相手に
「カウンターを吐く」か「キャラを失う」の二択を強いる。選択の基準は**交換レートの最大化**。

# 第 III 部 時間

## 17. 時計とハザード

勝率は「いつ決着するか」を潰した量である。潰さない形は

```
P(win | s) = Σ_t P(T = t | s) · P(win | s, T = t)
h(t) = P(T = t | T ≥ t)        （ハザード＝「今が勝負か」の形）
```

**実測: `h(t)` には形が在る**（盤面の帯ごとに振れ幅 0.26〜0.63・§18）。さらに
**同じ帯の中で `P(win|T=t)` が大きく動く**（決着が遅い方が勝ちやすい帯がある）＝
**上の分解は実際に働いており、「平均何ターンで決まるか」1 個では足りない**。

## 18 の前に——負けているときの危険選好は零和では最適

利得が勝率（確率）なので、**資源に対しては危険選好が正しい**:
領域 3（`S < 0`）では期待値を積む手より**分散の大きい手**（トリガー・相手の事故・
2 割しか通らない線）の方が勝率を上げる。

> **「どちらにしろ負け濃厚なら、最初から無茶をする」は正しい**。
> そしてその線を見つけるには**隠れ情報を何通りも読む**必要がある（§5 の `1−(1−p)^K`）
> ——理論上いちばん無茶が要る局面が、いちばん読みを要求する。

# 第 IV 部 このゲームの実測値

## 18. 実測値の一覧（本書が参照する数字の正本）

> **重要な留保**: 以下は**自己対戦の棋譜から測った**量である。したがって
> 「このゲームの定数」であると同時に**「その打ち手が作る局面の分布の上での値」**でもある。
> 打ち方が大きく変われば `λ`・`μ`・領域の内訳は動きうる（`c(x)` 曲線と `τ` 密度は
> デッキの中身だけから出るので、打ち方に依らない）。

### デッキから直接出る量（打ち方に依らない）

| 量 | 合成 800 デッキ | 実デッキ 240 |
|---|---|---|
| **`c(x)`**（x=1000…5000） | **1.00 / 1.28 / 2.25 / 2.78 / 3.63** | 1.00 / 1.40 / 2.38 / 2.97 / 3.84 |
| 止められない確率 | 0.005 / 0.024 / 0.080 / 0.187 / 0.353 | 0.008 / 0.057 / 0.170 / 0.328 / 0.503 |
| 段の高さ（1000 あたり） | 平均 **+0.66 枚**・**2000→3000 が +0.97** | 同傾向 |

**実デッキは合成より守りが重い**（`c` が高く止められない確率がほぼ 2 倍・イベントが 1.7 倍）
＝**ドンを要する守りが多い**（§12）。

### 価格（限界価値・自己対戦 1,041 局の holdout）

| 量 | 自分のターン | 相手のターン |
|---|---|---|
| **`λ`（ライフ 1 枚）** | **+0.1158** ±0.0042 | **+0.1362** ±0.0045 |
| **`μ`（手札 1 枚）** | **+0.0433** ±0.0025 | **+0.0551** ±0.0026 |
| **`λ/μ`** | **2.674** | 2.473 |
| `Θ + τ_value = λ/μ − 1` | 1.674 | 1.473 |
| **`Θ`**（`τ_value ∈ [0, 0.67]`） | **0.8〜1.5 枚** | 同 |

`λ` は帯ごとに **0.05〜0.18** と 3〜4 倍動く（＝1 つの定数として使えない・§11）。
**相手ターンの `λ` は自分のターンより 18% 高い**——受けるかを決めるのは相手ターンなので、
**判断に使うべきは高い方**。

### 実プレイで観測される分布（自己対戦 13 万窓）

| 量 | 実測 |
|---|---|
| 領域の内訳（1／2／3） | **4.8% / 67.3% / 27.9%**（判断の 2/3 は価格で決まる領域 2） |
| 攻撃 1 回ごとの最小枚数 | 1.00 / 1.31 / 2.22 / 2.64 / 3.85（**デッキ側の `c(x)` と一致**） |

**`c(x)` がデッキ側と実プレイ側で一致した**ことは重要で、

# 第 V 部 このゲームについて、まだ分かっていないこと

1. **`τ_value`（トリガーの期待値）を直接測っていない**。今あるのは密度 0.17（枚数比）と、
   §9 の恒等式から逆算した 0.37〜0.67 だけ。直接測るには
   「トリガーが出た／出なかった」の反事実が要る。**密度は「引けば必ず役に立つ」を仮定した上限**。
2. **`k̄_use` の符号**（§14）——手札を攻めに使う価値と守りに残す価値のどちらが支配的か。
   **これが分かると「守れるのに受ける」の評価が変わる**（支配的なら受けるのが正しい打ち回し）。
3. **`λ` は逆因果に弱い**。「ライフが低い＝既に負けている」経路があるので、
   実測の `λ/μ = 2.67` は**過大の可能性**がある（過大なら無差別点はさらに下がる）。
4. **bias（先後の非対称）が未整理**。
5. **シグナリングの利得**（§3-5）——カウンターを切ることは情報を渡す行為でもある。未定式化。
6. **`G*`（読まれたときの取り分）が未測定**（§3-4）。`G*` が小さいなら決定論でよく、
   大きいなら混合が要る。**leaf correlation が高いこと（§5）から小さいと予想**されるが、
   **予想が外れたら §5 の含意 2 は誤り**。
7. **攻撃順序の全順列の価値**（§15）——測れているのは「入口 1 手の選択」の価値まで。
