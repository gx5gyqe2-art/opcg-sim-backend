## 1. 問い・定義・予告（数を見る前に固定）

### 1.1 問い

ターンを終える手の点で、理論がターンを終えた盤面から見込んだ「相手の次のターン」と、記録で実際に起きた相手のターンを、項ごとに比べる。「相手の時計が実際より約 1 ターン短い」の主な項はどれか。

### 1.2 腕と点

- 腕: 今の既定（既定の表・並びを知らない形・1 回殴ってから読む切替は切・`OPCG_CLOCK_VALUE_END` は切）＋`OPCG_HAND_STOP=survive`（明示）。
  - 写しの切替: `OPCG_CLOCK_PARTS_DUMP=1`＋`OPCG_DEF_TRACE_DUMP=1`＋`OPCG_OPP_TURN_DUMP=1`（新しい診断・§1.3）。300 局（w41・実デッキ）。
- 点: `foresee_all` のターンを終える手の点（記録で打った手がターンを終える手・候補 2 本以上の行）。
  - 実際の次の自分のメインの行があり写しがある点が本体。`foresee_all` では 1,382 点。
  - 相手のターンで局が終わった点（98 点）は、本体から外し、別に数える。

### 1.3 見込み（コードの場所・新しい式なし）【コード】

ターンを終える候補の後続（`end_of_turn`）を読むとき、相手の時計は鏡の読み（`MIRROR_ME`・既定で入）で「相手の次のターン」を読む。
その読みは、相手の攻め手の計画（`attacker_ctx` → `rule_don_term` → `plans::attempt`）と、守る側（自分）の動的計画（`defender.rs`）を通る。

診断の切替 **`OPCG_OPP_TURN_DUMP=1`**（既定は切・値は変えない）を足す。相手の時計の読みの直後に、次の 3 つを候補の部品に写す。
- 計画の 1 段目（相手の次のターン）の攻め手の並び
- 計画が出す札の枚数（`play` の組）
- 守る側（自分）の辿り（`OPCG_DEF_TRACE_DUMP=1` と同じ `trace_first`）

見込みの量（相手の次のターン 1 回ぶん）:

| 項 | 見込みの取り方 |
|---|---|
| 相手の攻撃の本数 | 辿りの「届く攻撃の数」（1 段目の攻め手の超過 + 1000 × 付けるドン が届くもの） |
| 付けるドン | 計画の 1 段目の付けるドンの和 |
| 出す札 | 計画の出す札の組の枚数（攻撃のために出す札＝速攻のキャラ・パワーを上げる札など。展開のための登場は計画に入らない） |
| 自分が受けるライフ | 辿りの期待値 |
| 自分が切る札 | 辿りの期待値 |
| 自分のブロック数 | 辿りの期待値 |
| 自分が倒される確率 | 辿りの期待値 |
| 自分の体の減り | **枚数の見込みは出さない**（守る側の動的計画は体の減りを数えない）。耐久の体の項（値）の、見込み（ターンを終えた後続）と実際（次の自分の行）の差だけを読む |

### 1.4 実際（記録の相手のターン）

ターンを終える手の行から、次の自分のメインの行までの記録の行（相手のターンと、その中の守りの窓）で数える。

| 項 | 実際の数え方 |
|---|---|
| 相手の攻撃の本数 | 相手のメインの行で `ATTACK`／`DON_BOX` の対象が自分のリーダー |
| 付けるドン | 相手の `ATTACH_DON` の行の数（`DON_BOX` を開いた行を含む） |
| 出す札 | **2 本**: 相手の `PLAY` の全部と、そのうちキャラの `PLAY` |
| 自分が受けるライフ | 自分のライフの減りの和 |
| 自分が切る札 | 自分が選んだ `SELECT_COUNTER` の数（`defend_foresee` と同じ・1 回＝札 1 枚） |
| 自分のブロック数 | 自分が選んだ `SELECT_BLOCKER` の数 |
| 自分の体の減り | **2 本**: 自分の場のキャラの数の減り（ターンを終える行 → 次の自分の行）と、耐久の体の項（値）の差 |

### 1.5 相手の時計の縮みの配り方

- 「相手の時計の縮み」＝実際 − 見込みの相手の時計（`foresee_all` の項と同じ）。
- 自分の耐久の 3 項（ライフ・手札・体）の差の比で配る（`own_clock_parts` と同じ流儀・点ごとの 3 項の差の和が μ の 0.01 倍未満の点は配らない）。
- **判定の項への対応**（この報告の約束）:
  - 手札の項 ↔「自分が切る札」（とライフから手札に入る札）
  - ライフの項 ↔「相手の攻撃（自分が受けたライフ）」
  - 体の項 ↔「自分の体の減り」
- 相手の攻撃の本数・出す札は、項ごとの見込みと実際の差（本数）で読む。

### 1.6 出すもの

- 項ごとの見込み・実際・差（平均・中央値・95% 区間〔局ごとの再抽出〕）。
- 相手の時計の縮みの 3 項への配り（割合）。
- 帯別、自分のデッキ別、相手のデッキ別。

### 1.7 予告（司令塔が固定）

- 主は「自分が切る札」（見込みより多い・`defend_foresee` と同じ向き）で、相手の時計の縮みの **5 割以上**がこの項。
- 相手の攻撃の本数は、見込みとほぼ合う（±0.3 本）。
- 出す札は、見込みが少なめ（相手の展開を読み足りない）。キャラの `PLAY` との差で 2〜3 割。

判定:
- 自分が切る札（手札の項）が **5 割以上**なら「守る側（自分）の札の使い方の見込みが本体」。直す場所は守る側の動的計画の 1 か所。
- 相手の攻撃（ライフの項）と出す札（体の項）が合わせて **5 割以上**なら「相手の攻め手の計画の読みが本体」。
- その間は「どちらとも言えない」。

### 1.8 限界（先に書く）

- 見込みの「出す札」は攻め手の計画の出す札の組だけで、実際の `PLAY`（展開を含む）と範囲が違う。
- 見込みは期待値（ライフの札の種類の確率で平均）、実際は 1 回の結果。
- 体の減りの見込みは枚数では出せない（値の差だけ）。
- 理論の攻撃は自分のリーダーへの攻撃だけ。
- 表は並びを知らない形。記録は古いエンジン、理論は新しいエンジン。
- 道具は Rust の診断の写しと `theory_map.py` の副命令（1 回きり・テストなし）。既定の出力が 1 ビット不変であることを 10 局で確かめてから回す。push 前に `make test` と `make audit-cross`（決着しない局 0）。
