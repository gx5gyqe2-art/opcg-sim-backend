# 効果の値を盤面の対象で決めた——**4.4% の候補が動き、そこでは札 1 枚ぶん。橋は動かない**

2026-09-15 実施。**ユーザ指摘「違うか、登場時効果は `ν` ではなくて効果に紐づく価値を
変動させるべきか」**。**整理としてこれが正しい**——`ν`（体の価格）は定数のままで、
**盤面で変わるのは効果の側の値**である。本報告は特定時点のスナップショット。

## 結論を 5 行で

1. **`ν` は 1 つも動かしていない**。動かしたのは**効果が取る対象の価格**——
   `登場時 KO の価値 = Σ（取れる対象のうち価格が高い n 体の ν）`。
2. **対象が居なければ 0**（空振り）。**実測で 406 件が該当**——それまでは
   **相手の場が空でも除去に平均 0.1087 が付いていた**。
3. **絞り込みを尊重する**（「コスト 4 以下」「レストの」「パワー 5000 以下」）。
   **枠から読めない絞り込み**（特徴・カード名・色）は**盤面を使わない**＝平均に落とす。
4. **効いた候補は 4.4%（1,883/43,263）。そこでの変化は中央値 −0.053＝札 1 枚ぶん**で、
   **向きは下**（平均 0.1087 が除去を過大に見積もっていた）。
5. **橋は動かない**（全体 +4.274 → **+4.325**・CI が重なる）。**中盤の判定は
   `bridge_holds` → `no_link` に戻った**が、これは CI の端が 0 を跨いだだけ（前段も [0.07, 3.29]）。

## 1. 何を直したか——**`ν` ではなく効果の値が動く**

| | 前 | **後** |
|---|---|---|
| 相手の体 1 つを KO | **平均 `ν` = 0.1087** 固定 | **取れるうち一番高い体の `ν`**（0.069〜0.211 で 3 倍差） |
| 2 体 KO | 2 × 0.1087 | **上位 2 体の和**（在る数を超えては取れない） |
| 相手の場が空 | 0.1087 | **0**（空振り） |
| 「コスト 4 以下を KO」 | 0.1087 | **コスト 4 以下の中で一番高い体** |
| 特徴で絞る除去 | 0.1087 | **0.1087**（枠から読めないので盤面を使わない） |

**対象の `ν` の定義は攻撃側と同じものを使った**——`attack_stream` の中の
`nu_of(対象のパワー, 自リーダーのパワー, R, is_blocker=…)` と 1 字も違わない。
**違うと「攻撃で倒す価値」と「効果で倒す価値」が食い違う**ので、そこはテストで縛った。

> **読めない絞り込みは決めない**——「当てはまる」と決めれば過大に、「当てはまらない」と
> 決めれば過小になる。**条件の `None` と同じ作法**（`2026-09-14_condition_gate.md`）。
> 枠（トークン）から読めるのは**パワー・コスト・レスト**だけで、
> **特徴 497 件・カード名 172 件・色 68 件は読めない**。

## 2. 実測——**効いた範囲と大きさ**

実デッキ 300 局・登場と起動メインの候補 43,263 件:

| | |
|---|---|
| **値が変わった候補** | **1,883（4.4%）** |
| 変化の平均 | **−0.0393** |
| 変化の中央値 | **−0.0527**（≈ 札 1 枚 `μ` = 0.0551） |
| p10 / p90 | −0.1087 / +0.0437 |
| **0 になった（空振り）** | **406** |

**向きは下**＝**平均を当てていたのは除去の過大評価だった**。
p10 が **−0.1087**（＝平均そのもの）なのは**空振りで丸ごと消えた行**である。

## 3. 橋（§0.5 の受け入れ基準）

| 帯 | 前段（平均 `ν`） | **後（盤面の対象）** |
|---|---|---|
| **全体** | +4.274 [3.39, 5.26]・AUC 0.707 | **+4.325 [3.48, 5.23]・AUC 0.706** |
| 接戦 | −1.546 [−3.16, +0.29] | **−1.514 [−3.05, +0.25]** |
| 　攻め | +0.865 | **+0.786** |
| 中盤 | +1.659 [0.07, 3.29] `bridge_holds` | **+1.313 [−0.28, 3.12] `no_link`** |
| 決着 | +2.055 [1.42, 2.66] | +2.067 [1.43, 2.71] |
| **守り** | −3.754 | **−3.754（不動）** |

**どれも CI が大きく重なる＝動いていない。**
**中盤の判定が戻ったのは「判定が変わった」のではなく、CI の端が 0 を跨いだだけ**
——前段が [0.07, 3.29] とぎりぎりだったので、**前段の `bridge_holds` も強い主張ではなかった**
（罠 22 の形なので、どちらも「動いていない」と読む）。

> **null の読み方が付いた**のがこの測定の値打ち——**4.4% の候補にしか効かない**ので、
> **橋が動かないのは筋が通る**。「効かない直し」ではなく「**効く範囲が狭い直し**」である。
> §0.4 の感度の規則では**優先度が低い穴**に分類される。

## 4. それでも入れた理由

**橋が動かなくても入れる価値がある**ものが 2 つある:

1. **空振りに値段が付いていた**（406 件）——**理論が「相手の場が空でも除去は 0.1087」と
   言っていた**のは明らかな誤りで、**橋の分解能とは無関係に直すべき**。
2. **絞り込みを無視していた**——「コスト 4 以下を KO」に最大の体の価格を当てるのは、
   **カードの読み方そのものの誤り**である。

**＝橋は「動いたか」を見る道具であって、「正しいか」を決める唯一の道具ではない。**
**カードの本文と食い違っている値付けは、橋が黙っていても直す。**

## 限界

- **効いたのは 4.4%**＝残り 95.6% は元から盤面に依らない効果（ドロー・サーチ・付与）。
- **自分の体を数える効果は平均のまま**（`PLAY_CARD(SELF)` で出る体のパワーは判らない）。
- **特徴・名前・色で絞る除去（約 740 件）は平均のまま**——枠から読めない。
  読むには**枠ごとのカード ID から素性を引く**必要がある（`card_idx` に在るので可能・未実装）。
- **「取れるうち一番高い体」は上限**——実際には**相手が守る**ので、必ず最良を取れるとは限らない。
- **観察であって因果ではない**（§0.3 の限界はそのまま）。

## 次

1. **`card_idx` から枠の素性（特徴・色）を引く**——残り 740 件の絞り込みが読めるようになる。
2. **効果の対象選択**（`RESOLVE_EFFECT_SELECTION` 1,924）——**同じ材料**（対象ごとの `ν`）が
   要るので、本作業の続きで届く。
3. **守り側は P8（dump v5）待ち**——**6 段続けて価格では動かない**。
