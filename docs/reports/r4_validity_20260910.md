# r4 の妥当性検討（2026-09-10・分布の不一致と忘却・`claude/arena-r4-roles`）

§20.8.8-2 の 2 本。候補 r4（`nrel_r4b.npz`）vs 基準 r3。

## (a) 旧分布（波 28 holdout・132,821 行）の評価帯＝忘却の有無

| | r3 | r4 |
|---|---|---|
| 全体 v_mse | **0.5348** | 0.5515 |
| v_sign | 0.805 | 0.797 |
| 除去直後の行 | **0.602** | 0.636 |
| 終盤（turn 9+）| **0.440** | 0.452 |

r4 は**全バケットで r3 より悪い**（差 0.017＝ばらつき幅の 20 倍）。波 29 holdout では逆に r4 が 0.013 良かった
（§20.8.7-3）＝**新分布に寄って旧分布を忘れた**。z には波 27・28 も入れていたのに旧分布の予測が落ちたので、
V の表現そのものが動いている（π の教師＝平坦化した波 29 だけ・補助損失は波 29 の行だけ、が V の共有表現を
新分布側へ引いた可能性）。

## (b) 教師と同じデッキ分布（random × synth_roles・両席既定の探索・帯 501000〜508000）

| | 局 | 勝率 | 95% CI | Elo | void |
|---|---|---|---|---|---|
| r4 vs r3・synth_roles | 384 | 0.5182 | [0.465, 0.571] | +13 | 0 |
| 参考: r4 vs r3・synth（主条件・§20.8.8-1）| 382 | 0.4555 | [0.402, 0.509] | −31 | 1 |

分布内では有意差なし（synth の −31 から +13 へ）。**デッキ分布の不一致が主条件の低さの一部を説明する**が、
分布内でも優位にはならない＝**評価帯で見えた z 予測の改善は打ち方の強さに乗っていない**。

## 結論
1. r4 は採用しない（規約どおり・§20.8.8-1）。出荷既定と生成役は r3 のまま。
2. 1 波（6,720 局・新分布・平坦化 π・ε）だけで r3（4 波・30,720 局）を warm-start すると、新分布には寄るが旧分布を
   忘れ、強さは動かない。r2 → r3 も 2 波足して初めて動いた。
3. 物差し: 実デッキには除去が入るので、次の世代からアリーナの主条件を random × synth_roles にし、synth を
   「旧分布への汎化」の副次条件として残すことを提案（判定はユーザ）。r4 は宣言どおり synth で判定済み。
