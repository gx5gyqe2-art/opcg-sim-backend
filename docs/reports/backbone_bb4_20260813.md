## 3. 機序 — ラベル品質は律速ではなかった（仮説の根本棄却）

対照実験（part0 を訓練から除外→part0 の非飽和84行＝**域内・未見**で測定）:

| ネット | 域内・未見の非飽和 r | 実盤面の非飽和41 r |
|---|---|---|
| bb3（±1ラベルのみ） | **+0.436** | +0.047 |
| bb4（EVラベル・part0除外訓練） | +0.443 | +0.013 |

- **±1 の bb3 が既に域内の接戦盤面を読めていた**（+0.436）。1局1勝敗でも局数が
  積めば接戦盤面の期待値は統計的に学習される＝「微差が教師に乗らない」は誤り。
  EV ラベルの上積みは誤差程度（+0.443）。
- つまり欠けているのはラベルでも訓練圧でもなく、**合成世界の接戦力学と実世界の
  接戦力学の対応**。決着盤面の読み（ライフ・盤面素材の算術＝普遍物理）は転移する
  （全150 r≈0.46）が、接戦の帰趨は世界固有の詳細（実カード・実リーダーの能力意味論）
  で決まり、それは現行の ID 無し物理特徴に映っていない。
- 傍証: 接戦 EV 行の線形プローブは**静的70列が線形無信号**（r≈0.00）・Δ3列（リーサル
  距離レース）単独が r=+0.204。bb ネットの域内接戦読み +0.44 は非線形合成の産物。
- bb1 の分離プローブ（実デッキ×バニラリーダー r=0.51 vs 実リーダー 0.20＝落差の主因は
  リーダー効果）と整合: 接戦帯の盲目も同根の可能性が高い。

## 4. 判定と次

- **bb4 は負**。ラベル品質化（Phase 3 の処方 (a)）はこの規模では実盤面の接戦帯を動かさない。
  ラベル品質仮説そのものが対照実験で棄却された以上、増量（コーパス規模つまみ）でも
  同じ壁に当たる公算が大きい。
- 次の切り分け候補: **接戦帯の分離プローブ**（実デッキ×バニラリーダーの接戦盤面に
  EV ラベル→bb が読めるなら「実カード分布は越えられる・リーダー効果が接戦盲目の主因」
  が確定し、リーダー合成の質を上げる投資に根拠が出る。読めないなら特徴不足＝能力意味論の
  静的要約特徴が本命になる）。
- 実費: ワーカー6セッション×約2〜2.5h（ユーザ指揮）＋ローカル生成76分＋訓練評価・対照実験
  〜40分。副産物: 150点評価行列の再構築手順（fixture の ev から復元・再予測一致 0.0005）。
