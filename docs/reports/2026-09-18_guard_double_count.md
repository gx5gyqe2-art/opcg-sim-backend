## 1. 問い（T85 が指した先）

T85 で分かったこと: **攻撃だけなら必要な `κ` は 1.052／1.122**（＝恒等式が立つ）のに、**攻め＋守りにすると 0.637／0.665**。
守りの `g` は帳簿を大きくするのに勝率の動きと揃っていない。T85 と同じやり方（**記録で二重計上を確かめる**）で見る。

## 2. 記録とコードで確かめたこと

**コード**（`guard_step` ＋ `GUARD_COST_MODE=spent`）:

```
price  = min(受ける費用 Θ·μ, 守る費用 c(x_max)·μ)      ← **そのターン最大の攻撃 1 本**
actual = Σ(窓の間に手札から消えた札の価値) + Θ·μ×(受けたなら 1)  ← **札は全部の攻撃ぶん・受けは 1 回だけ**
g      = price − actual
```

**記録**（2026-09-18 実測・攻撃のあったターンごとの攻撃の本数）:

**同じ移転が攻め手の行と守りの窓で二重に数えられていた**（T85・T62 と同じ型）。


## 5. 読み方

- **上手くいった 1: 二重計上は実在した**（記録で確認・7 割のターン）。**両側を揃えると帳簿の膨らみは減る**
  ——`g` の実効値 −14%／−12%・**`ΔG` の傾きは 0.186 → 0.235／0.255 → 0.295 と 1 に近づき**、プール AUC も上がる
  （必要な `κ` は実 0.509 → 0.529 で 1 に寄るが、**合成は 0.508 → 0.482 で逆に下がる**＝記録のセットで向きが違う）。
- **上手くいった 2: 攻撃の `κ = 1.052／1.122` は 1 桁も動かない**（守り側だけを触ったので当然だが、
  **副作用が無いことの検算**になる）。
- **上手くいかなかった: 局所の相関は落ちる**（0.538 → 0.482／0.558 → 0.462）・**接戦帯も落ちる**
  （0.658 → 0.543／0.568 → 0.453）。**だから既定は据え置き**。
- **第 3 のずれが残っている（本 T の一番の収穫）**: 両側を揃えてもなお、**攻め手の価格は守り手が実際に失う額より
  3〜5 割大きく、しかも攻撃の本数とともに開く**（1 本 0.071 対 0.079 ≒ 釣り合う／5 本 0.289 対 0.224）。
  **機構は T64 で測れている**——**守り手は手札の一番安い札から切る**（切った札の価値は `μ` より低い）。
  攻め手の価格は「`c(x)` 枚 × `μ`」で数えるので、**切られた札が安いぶん過大**になる。
  T61 の「攻撃の価格／実現 = 1.19／1.34」と同じものが、ここでは**本数とともに開く形**で出た。
- **したがって守りの窓の `g` を「価格 − 支払い」で作る形そのものに無理がある**——2 つの別の物差し
  （理論の価格と実際の支払い）の差を取っているので、**どちらの誤差も `g` に入る**。

## 6. 次（ユーザ判定）

1. **既定は据え置き**（`max_attack` ＋ `spent`）。両側を直した形は**尺度としては正しい方向**（傾きが 1 に近づく）だが、
   **接戦帯と相関が落ちる**ので、第 3 のずれを直す前に既定にする理由が無い。
2. **第 3 のずれを直す**（最有力・次の T）: **`exercise` の規約を徹底する**——帳簿（`g`・`ΔG`）では
   **攻め手の行の価格を「守り手が実際に失った額」にする**（切られた札は実価値・受けたライフは実数）。
   そうすると**守りの窓の `g` は 0 になり**（移転は攻め手の行に 1 回だけ）、**帳簿は `price_realised` の `F` と同じ物**になる
   ＝交点の橋と線形の橋が**同じ量**を数えることになる（§0.1 が求める整合）。守りの窓は `s`（取りこぼし）専任になる。
   **新定数ゼロ**。**予測: 必要な `κ` が 1 に寄り、守りの型は帳簿から消える**。
3. 速さ `A`（残り 3）。4. 効果の型別と `κ` の形。

- 攻撃の本数は**その行で選ばれた手**から数えた（候補は見ていない）。トリガーで増えた攻撃は含まない。
- 守りの窓は 1 ターンに 1 つ（記録の制約・T28）＝**どの攻撃にどう応じたかは分からない**。本 T は「合計」を揃えただけ。
- `price` は帳簿の価格（`exercise` 規約）で、**攻め手の行と同じ値**を使っている（そこは整合している）。
