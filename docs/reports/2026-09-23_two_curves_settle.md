# T137d: 決着の瞬間に累積の損害は相手の耐久 Θ_opp に届いているか（2026-09-23）

T136（規則だけの決着判定）と T137a〜c（累積の理論 `G(t)`・実現の損害 `R(t)`・状態量 `Θ_opp(t)`）は
**別々に組んだ 2 つの橋**。本 T はそれを初めて直接突き合わせる——**規則が「もう詰んでいる」と宣言した
瞬間**（`t_declare`）、**実現の累積損害 `R(t_declare)` は相手の耐久 `Θ_opp(t_declare)` にどれだけ
近いか**を測る。器は `tests/scripts/two_curves_settle.py`（新規）・`tests/test_two_curves_settle.py`
（新規・11 本）。

**記録**: 実 = `w41`（300 局・300 勝者席）／合成 = `w39 + w42`（900 局・900 勝者席）。

---

## 0. 結論（先に書く）

**予告は外れた**。主の比較（`R(t_declare)` 対 `Θ_opp(t_declare)`・単位は揃っている）は 1 には
遠く届かない:

| | 実 | 合成 |
|---|---|---|
| **比 `R/Θ_opp`（平均）** | **3.78** | **4.66** |
| 比（中央値） | 3.05 | 3.51 |
| 比（第 1／第 3 四分位） | 2.25／4.52 | 2.45／5.71 |
| 差 `R − Θ_opp`（平均） | 0.71 | 0.68 |
| 宣言が見つからなかった勝者 | 37/300 (12.3%) | 177/900 (19.7%) |

**規則が「詰んでいる」と言う瞬間、実現の損害はすでに相手の耐久の 3〜5 倍に達している**——言い換えると、
**`Θ_opp`（`crossing_bridge` が使っている λ·ライフ＋g·手札＋Σν(体) の集計）は、決着の瞬間になっても
0 に収束しない**。実測の `Θ_opp` の平均はこの時点でまだ約 0.26（`R` は約 0.97＝ゲーム終点の `R_end`
〔T137a: 0.9626〕とほぼ同じ水準）——**規則の精密な組み合わせ計算（最小カウンター・ブロッカー横取り順・
ドン予算）が「もう守れない」と確定させた後も、集計式の `Θ_opp` は手札・体の項を通じて「まだ使える
資源」を残り約 0.26 ぶん見積もり続けている**。これは T137c の「理論の過大は相手の残り体力
（`life_opp`／`th_opp`）が大きいときに大きい」を裏側から補強する——**`Θ_opp` は「もう使えない資源」を
最後まで実際より高く見積もる形**になっている。

**副の比較**（`G(t_declare)` 対 `Θ_opp`）はさらに大きい（実 6.01・合成 6.09）——`G` は攻撃だけでなく
出す・効果・付与も全部積んだ理論の総額なので、`Θ` を削らない手（T137b: play 0.21〜0.25・effect
ほぼ無相関）の分だけ `R` より大きく、この比はそもそも 1 に近づく理由が無い（設計どおり）。

## 1. 式（新定数ゼロ・既存の 3 つの器の再利用のみ）

* **`t_declare`**: `lethal_rule.settled_map(dirs)` の `{(seed,w,t): bool}` から、勝った席の自席ターンを
  昇順に見て最初に `True` になった `t`。
* **`R(t_declare)`／`G(t_declare)`**: `two_curves.py --dump` の `(turns, r, g)` から、`t_declare`
  **以下で最後**のターンの累積値（階段関数）。
* **`Θ_opp(t_declare)`**: `two_curves_state.py` の `state_by_turn`（`kappa_vector.state_of_row` の
  そのままの再利用）が返す `th_opp`。

**主従の入れ替えの経緯**（測ってから直した・報告に残す）: 当初 `G` を主に置いて予告を書いたところ
比が **6 前後**で「1 に近いはず」という予告が大きく外れた。**`G` は手の種類を問わず全部を積む値で
`Θ` とは単位が違う**（T137b の型別相関がすでに示していた）ことに気づき、**実現の損害 `R`**
（`crossing_bridge` の `F` と同じ量）を主の比較に差し替えた。差し替えても比は 3.78〜4.66 で、
予告どおりの「1 に近い」には届かなかった——**今回は主従を直した後も予告そのものが外れた**。

## 2. 上手くいったこと／いかなかったこと

**上手くいった**:
* **既存の 3 つの器（`two_curves.py`・`two_curves_state.py`・`lethal_rule.py`）をそのまま組み合わせる
  だけで測れた**——新しい価格式・新しい状態量を 1 つも作っていない。
* **単位の食い違いに気づき、測っている最中に主従を入れ替えられた**——`G` 対 `Θ` の比が異常な大きさ
  だったこと自体が「単位が違う」というバグ（設計ミス）の検出になった。気づかずに「理論は 6 倍も
  外れる」と報告していたら誤った結論だった。
* **実／合成で符号・大きさが揃った**（比 3.78／4.66・中央値 3.05／3.51）——単発の記録のブレではない。
* **`n_no_declare` の割合が T136 の「勝者の最後のターンで宣言 0.863／0.803」と整合**
  （1 − 0.863 = 0.137 ≒ 実測 0.123・1 − 0.803 = 0.197 ＝ 実測 0.197 と一致）——別の器で独立に
  計算した数字が既存の指標と矛盾しなかった。

**いかなかった／自己批判**:
* **予告が 2 回とも外れた**（最初は単位の選び方そのものが誤り・直した後も水準の予告が外れた）。
  **「決着の宣言は相手の体力がほぼ尽きた局面でしか起きない」までは正しかった**（`R` はほぼ `R_end` に
  達している）が、**「だから `Θ_opp` も 0 に近いはず」は誤り**——`Θ_opp` が実際に 0 へ収束する保証は
  どこにもなかった（規則の精密な判定と集計式の粗さは別物という、測る前には見えていなかった論点）。
* **なぜ `Θ_opp` が 0.26 も残るかは本 T では分解していない**——ライフ／手札／体のどの項が主犯かは
  次の T に送る（`th_life`／`th_hand`／`th_body` の内訳を `t_declare` で取り出せば測れる）。

## 3. ユーザ判断をお願いしたいこと

1. **T137d はここで一区切りとする**（推薦）——2 つの橋を初めて直接突き合わせ、`Θ_opp` が決着の瞬間にも
   収束しないという具体的な数字が出た。
2. **次の選択肢**（順位は推薦）:
   a. **`Θ_opp` を `t_declare` で内訳分解**（`th_life`／`th_hand`／`th_body` のどれが 0.26 を作っているか）
      ——最小の追加作業で「次に触る項」が絞れる。
   b. **T138b**（決着前の行だけで `W(D)` の較正）へ進む——4 段階の判定フローの (3) を進める。
