# 探索は π（事前分布）を超えているか（2026-09-12・`tests/scripts/search_vs_prior.py`・波 30／31／32）

問い: π の教師＝探索後の訪問分布は、生成役の事前分布 `pol_p` から実際に動いているか。動いていなければ
π は自分の写しを学ぶだけで、生成役を替えても π の上限は上がらない（`2026-09-12_r7_pi_window.md` の
「上限は 1 世代遅れる」の前提）。v14 の dump は方策点ごとに探索前の P（`pol_p`）・探索後の訪問分布（`pi`）・
各手の Q を持つので、既存データだけで測れる。各波 w01＋w02・**全方策点**（holdout に絞らず）・生成時の
`root_prior_temp` 2.0。成果物 `claude/svp-r7`（6310c73f・`n1_results/svp/svp_w{30,31,32}.json`）。表はコーディネータが
JSON から組み直した。判定はユーザ。

## 結論（先に）

1. **探索は事前分布の写しではない**。探索が答え（argmax）を変えた局面は **51〜57%**、候補 9 手以上では
   **57〜65%**。確率質量は 23〜26% 動く。事前の読み方で置いた「写し」の閾値（一致 0.9）から遠く、
   「先読みを足している」の帯（0.6〜0.75）よりさらに大きく動いている。**π の教師には十分な情報がある。**
2. **ただし動く理由は「事前分布が平ら」だから**。候補 9 手以上での事前分布のエントロピーは 2.53〜2.63
   （14 手で一様なら ln 14 ≈ 2.64）＝**ほぼ一様**。探索はそれを 0.4〜0.5 尖らせるが、訪問分布も 2.1〜2.2 と
   まだ広い。つまり探索は「π の答えを覆す」というより「π がほとんど答えを持っていないところに、160 回の
   読みで薄い答えを付けている」。
3. **生成役を r3 → r5 に替えると事前分布はさらに平らになり、探索の上書きは増えた**（一致 0.490 → 0.427／
   0.432・事前分布のエントロピー 1.89 → 1.98）。r5 の π は r3 の π より探索の指針として弱い。
4. **各世代の π は教師の尖りに届いていない**。r3 の探索出力（波 30 の H_pi）は 1.62 だが、それで学んだ r5 の
   事前分布（波 31／32 の H_p）は 1.98。局面の分布が違うので厳密な比較ではないが、**訓練で 0.3 以上ぼやけ、
   探索で 0.3 尖らせる**のが各世代の収支で、鋭くなる方向に回っていない。π の home-wave top1 が 0.57〜0.63
   に留まること（`2026-09-12_policy_band.md`）と同じ現象。
5. 読み: **環の律速は「教師の情報量」ではなく「π の当てはまり」**。探索は毎世代たっぷり情報を出しているが、
   ネットの π がそれを吸えていない。r7 の実験（π を倍にすると方策は回復し V が譲る）と合わせると、
   **π が飢えている・V と小さな共有部を奪い合っている**という同じ絵になる。探索側（sims・温度・
   dirichlet）を触っても教師はこれ以上要らない。触るべきは訓練側の π の配分。

## 読み

### 1. 教師に情報はある——だから「生成役を替えれば上限が上がる」は前提としては生きている

探索は半分以上の局面で π の答えを覆し、Q がそれを 87% 支持する（PUCT の構造上高くて当然なので弱い根拠）。
写しを学んでいるわけではない。era8 で生成役を r5 にしたことで教師（r5＋探索）は r3＋探索とは別物になった
はずで、r7 のアリーナが上向いた（+25／+16 Elo・未確定）のと矛盾しない。

### 2. だが π は教師を吸えていない

- 事前分布が k≥9 でほぼ一様＝**π は難しい局面でほとんど意見を持っていない**。探索は 160 回の読みを
  14 手前後に薄く配って（1 手あたり 10 回強）、その中で少しだけ尖らせている。
- 各世代の π は教師の尖り（H_pi ≈ 1.6〜1.7）に届かず 1.9〜2.0 に留まる。訓練で 0.3 ぼやける。
- r3 → r5 で事前分布はさらに平らになり（+0.09）、探索の上書きは増えた（一致 −0.06）。**世代を重ねるほど
  π が探索の指針として弱くなっている**。`2026-09-12_policy_band.md` で見た「訪問分布のエントロピーが
  1.45 → 1.70 と上がる」の内訳は、**事前分布が平らになったことが主**（H_p +0.09 に対し H_pi +0.06）。

### 3. 探索側を触っても解けない

sims を増やす・温度を下げる・dirichlet を減らす、はいずれも「教師をもっと尖らせる」操作だが、教師は
既に π より 0.3 尖っていて、π がそこに届いていないのが問題。教師を尖らせても π が吸えなければ同じ。
（sims 増は V の葉評価も深くするので別の利得はあるが、この問題の解ではない。）

### 4. r7 の結果と同じ絵

r7 で π を 2 波→4 波にしたら方策は 3 波とも改善し、V が譲った。π は**飢えている**（点が足りない・
更新回数が V に負けている）。探索は毎世代、π が吸える以上の情報を出している。**律速は訓練側の π の配分。**
