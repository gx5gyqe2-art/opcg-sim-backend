# T18-b/c: 線を引く（案 b）・型を絞る（案 c）——どちらも介入が少なすぎて判定に届かない（2026-09-24）

パイロット（`2026-09-24_t18_pilot.md`）は「理論を方策として使うと探索に負ける（−206 Elo）」という結果で、
介入率 47% が原因だった。ユーザ決定（2026-09-24「dでやりましょう」）で、介入率を下げる 2 つの案を
**それぞれプラセボつきで**測った。

**条件**: 主条件 `synth_roles`・各案 32 ペア×2 腕・seed 帯は新規（案 b: 1310000〜／案 c: 1320000〜）。
**案 b**（`--cutoff-mu 2`）: 逸脱が手札 2 枚ぶんの価値を超える行だけ介入（`2026-09-24_t18_threshold.md` の推薦）。
**案 c**（`--restrict attach:play`）: T155 が「本物の対立」と確認した「付けて殴る vs 手札を出す」だけに絞る。
両方とも `--seq attack_any --attach-static on`（パイロットと同じ読み）は維持。

---

## 0. 結論（先に書く）

**両方とも介入が少なすぎて、理論とプラセボの差を判定できなかった。** ただし**案 b は「大きく負ける」という
パイロットの結果を消した**——これ自体は意味のある前進。

| | パイロット（線なし） | **案 b（線 2μ）** | **案 c（型を絞る）** |
|---|---|---|---|
| 理論の腕・勝率 [95% CI] | 0.234 [0.147, 0.322] | **0.500 [0.438, 0.562]** | 0.484 [0.431, 0.538] |
| プラセボの腕・勝率 | 0.125 | 0.469 [0.381, 0.556] | 0.484（**理論と同値**） |
| 対にした差（理論−プラセボ） | **+0.109 [+0.037, +0.182]**（有意） | +0.031 [−0.044, +0.107]（**0 を跨ぐ**） | 0.000 [−0.062, +0.062]（**0 を跨ぐ**） |
| 介入率（判定できた行のうち） | 47.0% | **3.0%／4.9%**（理論／プラセボ） | **3.0%／4.5%** |
| 1 局あたりの介入数 | 12.9 | 0.78／1.27 | 0.78／1.14 |
| void | 0／32 ペア | 0／32 ペア | 0／32 ペア |

**案 b**: 理論の腕は 0.234 → **0.500** まで戻り、パイロットの CI 上限（0.322）を明確に超えた（予告 P2 の殺す基準は
発火しなかった）。**しかし理論とプラセボの差は消えた**（+0.109 → +0.031・CI が 0 を跨ぐ）——理由は介入率が
47% → 3〜5% まで下がりすぎたこと。「大きく負ける」原因（介入しすぎ）は取り除けたが、「理論の指す先に信号が
ある」ことを言うにはこの規模（32 ペア・介入 50〜81 件）では足りない。

**案 c**: 介入率は 3〜5%（案 b とほぼ同じ水準・型を絞ったら自然とそうなった）。**理論とプラセボの勝率は小数点
以下まで一致**（0.484375）——64 局中 60 局は腕に依らず同じ勝者で、残る 4 局のうち理論が勝ちを増やした局と
プラセボが勝ちを増やした局が 2 対 2 で打ち消し合った（対の表で確認・§4）。「付けて殴る vs 手札を出す」の
対立で理論が正しいかは、この規模では**まったく読めない**（予告 P8 の懸念どおり）。

## 2. 読み

案 b の「大きく負ける」の解消は、パイロットの機構説明（介入率が高すぎて「理論を方策にする」実験になっていた）
と整合する——**線を引けば方策としての害は消える**。しかし同じ理由（介入が少ない）で「理論を信じると得か」も
測れなくなる。これは**トレードオフ**であって矛盾ではない：介入率と検出力は表裏一体で、介入を絞るほど「害は
無い」は言いやすく「益がある」は言いにくくなる。

案 c は型を 1 つに絞った時点で、パイロットの介入率 47% のうち**この型が占める分がそもそも小さい**ことを
示している（T155 の実測: 読み替え後に残る「出す手」との対立は 1 局あたり数行程度）。案 b・c どちらも
最終的な介入率が同じ水準（3〜5%）に落ち着いたのは偶然ではなく、**パイロットの禁じ行の大半が「小さい逸脱」
または「別の型」で、大きく・付けて殴る型に限ると数行しか残らない**ことの帰結。

## 3. 不変量

* 両案とも異常終了 0・引き分け 0（void 0／32 ペア×2）。
* 案 c の理論／プラセボが 60／64 局で同じ勝者になったのは器の欠陥ではない——**介入数がそもそも少なく、
  介入が勝敗を左右しなかった局が大半**（`n_intervened` 0.78〜1.14／局・パイロットの 12.9／局と比べて桁違いに
  少ない）。CRN（同じ seed）で打っているので、介入が効かなければ両腕は同じ進行になる。

## 5. 上手くいったこと／いかなかったこと

**上手くいった**: 案 b がパイロットの「大きく負ける」という結果を確かに解消できることを示せた——理論の価格を
方策として使うのではなく、大きな逸脱だけを縛る形にすれば害はなくなる。これは T18-閾値（`2026-09-24_t18_threshold.md`）
の推薦（`2μ`）が正しい方向だったことの裏付け。

**いかなかった**: 案 b・c とも「理論に価値があるか」を判定するには 32 ペアでは全く足りなかった——両方とも
差が 0 に近く CI が広い。**次に進むなら、案 b（cutoff 2μ）のペア数を大きく増やす**（介入 50〜81 件から
効果を検出するには、パイロット規模の数倍〜十数倍が要る可能性が高い）のが筋——案 b は「害が無い」ことまでは
確認済みで、残る問いは「益があるか」だけになった。
