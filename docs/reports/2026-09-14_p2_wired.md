# P2-1 の配線——**攻め側の反転は「効果に値段が無かったこと」の影**だった

2026-09-14 実施（`effect_value.py` を `theory_order.score_candidate` へ配線し、**橋を回し直した**）。
`cpu_theory_gap.md` **§0.5 の受け入れ基準**——「**穴を埋める → 橋を回し直す → 傾きが正の方へ動いたか**」
の 1 段目。同じ記録・同じ定数・同じ器で**前後を測った**（違いは配線だけ）。
本報告は特定時点のスナップショット（追記・改変しない）。

## 結論を 5 行で

1. **攻め側の反転は消えた**——1 手あたりの傾きが **−6.98 → +4.27**、AUC 0.378 → **0.701**。
   判定は `bridge_inverted` → **`bridge_holds`**。
2. **接戦帯でも攻めの半分は正に転じた**（**−0.78 → +0.45**）。帯の合計は
   **−3.84 → −1.68**（CI が 0 を含むようになった＝`bridge_inverted` → `no_link`）。
3. **残った反転は守り側だけ**（接戦帯 **−3.75・配線の前後で 1 つも動いていない**）
   ——守り側は候補リストを使わないので**配線の影響を受けないのが正しい**＝
   **前後の差が攻め側にしか出ないこと自体が、器の健全性の検算になっている。**
4. **無言の行が 61% 減った**（3,568 → **1,408**）。候補の単位では
   **起動メイン −76%**（6,080 → 1,452）・**登場／イベント −45%**（13,081 → 7,182）。
5. **よって §0.5 の受け入れ基準を満たした**——**P2 は「結論を動かす穴」だったし、
   埋めたら傾きは正の方へ動いた**。台帳の P2 を「攻め側については解消」に更新する。

## 1. 何を配線したか

| | |
|---|---|
| **起動メイン** | `SCORABLE` に追加し、**効果の値そのまま**（カードは既に場に在るので `μ` を引かない。コストは能力の中に在る） |
| **イベント・ステージ** | **体を持たない札**なので `効果の値 − μ − cost·δ`（札 1 枚とドンを払って効果だけを買う形） |
| **キャラの登場** | 変更なし（`play_value`＝`ν − μ − cost·δ`） |

**読めない効果は `None` のまま**——0 にすると「効果が無い」と混ざる（`effect_value.py` の規則を
そのまま持ち上げた）。**イベントの本文は `ACTIVATE_MAIN` として入っていることがある**ので
（実測・EB04-009）、`PLAY` 側の契機集合にもこれを含めた。

> **新しい定数は 1 つも足していない。** 配線は**既にある価格の写し替え**だけで、
> `0.66·μ`（ドン 1 個の価格 `δ`）も `μ` も `ν` も既存の実測値である。

**効果の対象選択（`RESOLVE_EFFECT_SELECTION`）は手を付けていない**——`SCORABLE` に無く、
**「どの対象を選ぶか」は効果の値付けとは別の問題**である（対象ごとの `ν` の帯が要る）。
**登場・イベントの残り 7,182 は、その効果が §3 の 3 系統（情報・テンポ・能力付与）に
落ちているカード**＝**P2-2 以降で減る**。

## 4. なぜこれが「傾きが動いた」と言えるか（§0.5 の作法）

**橋の絶対水準は穴に汚染されている**ので、受け入れ基準は**絶対値ではなく前後の差**に置いてある。
ここで前後は**同じ 300 局・同じ 18,815 行・同じ定数・同じ乱数**で、**違いは配線だけ**である。
さらに:

- **守り側が 1 桁も動いていない**——守り側は候補リストを使わない（状態から助言を出す）ので
  **配線の影響を受けないのが正しい**。**動いていないことが、差が配線に由来する証拠になっている。**
- **母数は増えている**（無言の行を除外する `exclude` なので、配線で行が戻ってくる）。
  **「都合の悪い行を落として良く見せた」の逆向き**である。

> **当てはめてはいない**——`effect_value.py` の写像表に自由なつまみが無く、
> **橋の結果を見て係数を選ぶ余地が無い**（§0.1 の条件 3）。

## 限界

- **接戦帯の CI はまだ 0 を含む**（−1.68 [−3.27, +0.13]）＝**接戦帯で橋が架かったとは言えない**。
  残っているのは**守り側の反転**（−3.75）で、これは **P8（dump v5）が要る**ところ
  （T28-c で対抗仮説が決着しなかった場所）。
- **効果の値は条件を読んでいない**（`ab["condition"]`）＝**過大**の向き。
  過大な値で傾きが正に動いたので、**条件を読めば更に動く可能性も、逆に戻る可能性もある**。
- **対象の `ν` を盤面の帯で渡していない**（カード単体の平均 0.1087 のまま）。
  `effect_value.action_value(nu=)` は既に受け口が在る＝**配線の次の段**。
- **「〜まで」を満額で数えている**ので、値は**上限として読む**。
- **観察であって因果ではない**（§0.3 の限界はそのまま）。
