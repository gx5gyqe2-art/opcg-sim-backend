| 点 | v20 の記述（3 seed） | v21 実測（16 seed・s1600） |

| m2@44 | 選ばない | **0.31**（5/16） |
| m5@7 | 選ばない | **0.62**（10/16） |

**m2@44 と m5@7 は「常に選べない」のではなく、隠れ情報の引き（決定化世界）で結論が割れる点**
だった。v20 の「3点とも深探索でも選ばない」は**誤り**で、正しくは「1点が決定的に選ばない・
2点は世界依存」。SEARCH_AVERSE という分類自体は残るが、該当は m4@12 のみに縮む。

（v20 の測定が悪かったのではなく、3 seed では 0.31/0.62 の点が 0.00 に見えうるという

読み出しでも減衰でも aux でも世界でもない、**探索が積み上げる評価そのもの**が正着を否定している。

## 4. 世界依存という副産物（コーチゲートの読み方に影響）

m2@44（0.31）と m5@7（0.62）は seed で結論が割れる。**コーチゲートの 5 seed 命中率は、
こういう点では標準誤差が ±0.2 前後**あり、単発の 0.00 / 1.00 を「その点の実力」と読めない。
v19 で観測した「ガード m2@12 の 1.0→0.0 反転」も、同種の分散である可能性を排除できていない
（m2@12 は本プローブの対象外＝別途 16 seed で確認する価値がある）。

**運用への含意**: コーチゲート v2 の点別スコアは**傾向**として読み、点別の増減を単独で
「治った/壊れた」と断定しない。合否判定に使わない（v16 で診断計器へ降格済み）方針は妥当。
