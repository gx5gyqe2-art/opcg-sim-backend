## 1. 問い・腕・予告（数を見る前に固定）

### 1.1 問い

守る側の動的計画の比べ方を、「生き延びるターン → 損害の価値の和（受けたライフ × lam_net ＋ 切った札 × μ ＋ 倒れたブロッカー × ν・損害の並びの全段の和）が小さい → 防いだ本数 → 損害の並び」に変える。新しい定数は入れない。合成の記録でも、理論の守りの見込みは実際の守りに近づくか。勝敗の橋はどう動くか。

### 1.2 腕（2 つ・どちらも既定の表〔`<w39>/clock_succ`〕・1 回殴ってから読む切替は切・`OPCG_CLOCK_VALUE_END` は切）

- **基準＝survive**（`OPCG_HAND_STOP=survive`）: `syn_opp_turn_split` の写し（`OPCG_CLOCK_PARTS_DUMP=1`＋`OPCG_DEF_TRACE_DUMP=1`＋`OPCG_OPP_TURN_DUMP=1`・300 局）をそのまま使う。
- **value**（`OPCG_HAND_STOP=value`）: 同じ切替の組で、取り込み後の新しいエンジンで `theory_bridge.py` を 300 局回す。
- 時計の側: どちらの腕も `theory_map.py clocks`（`OPCG_REACH_DUMP=1`）＋`counter` と `crossing_bridge.py` を回す。survive の交点の基準は `syn_hand_stop` の .6682・時計の偏り +0.324。

### 1.3 測るもの（survive を基準に・帯別と全部）

| | 物差し | 道具 |
|---|---|---|
| (i) | 自分のターンの守り（`defend_foresee` の本体）: 切る札・受けるライフ・ブロックの見込み ÷ 実際 | `theory_map.py defend` |
| (i) | 相手のターンの守り（`opp_turn_split`）: 切る札・受けるライフの見込みと実際 | `theory_map.py oppturn` |
| (ii) | ターンを終える手の見込みと実際の差（絶対値の中央値・平均） | `theory_map.py foreseeall` |
| (ii) | 組の差の割合・差の中央値（followup_turn の物差し） | 前の報告の集計の写し |
| (iv) | 交点の橋の的中・時計の偏り・ばらつき | `crossing_bridge.py` |

（(iii) の深い探索との一致は合成には無い。）

### 1.4 不変量

- 切替が切と survive の出力は 1 ビット不変（取り込み後の `make test` の theory golden）。
- value の腕の写しで、守る側の動的計画を通らない候補の部品（付与・出す手の後続のうち守りの読みが入らない部分）は比べない（どの値段にも守る側の読みが入るので、「動く」が正しい）。数えて書くのは、写しの行・候補の並びが同じであることだけ。

### 1.5 予告（司令塔が固定）

- (i) 切る札の比 → **0.8〜1.0**、ライフの比 → **1.0〜1.1**。
- (ii) ターンを終える手の中央値（合成の基準 1.70 μ）は **2〜3 割縮む**。
- (iv) 的中は **±0.005 以内**。

判定（実側と同じ線）:
- (i)（自分のターンの守りの切る札とライフの比）が両方 **0.8〜1.2** に入り、(iv) の的中が下がらなければ（0.01 以上は下がらない）「**採用候補**」。
- (i) が入っても (iv) の的中が **0.01 以上**下がれば「不採用・切替で残す」。
- (i) が動かなければ（切る札の比が基準から 0.1 未満しか動かない）「比べ方は本体でない」。
- それ以外は「どちらとも言えない」。

### 1.6 限界（先に書く）

- 実側 §1.7 と同じ（損害の価値の和は地平の全段の和・値段の 1 回の戦闘の守り〔quiesce〕は変わらない）。
- 合成の記録の守りは生成時の CPU のもので、深い探索が無い。「実際」の守りそのものが粗い可能性がある。
- 記録は古いエンジン（a28ededa）、理論は新しいエンジン。

## 3. 読み【推測】

- 比べ方の順を変えても、守りの見込みは 1% しか動かない。動的計画の中で「生き延びるターン」が同じになる守りの組では、損害の価値の和の順と、survive の「切る札の少ない順」がほぼ同じ守りを選んでいる。温存は、ライフ 1 枚（lam_net）が札 1 枚（μ）より安く読まれることから来る。
- 的中が少し上がる（+0.0055）のは、時計の偏りが増える（+0.07）のと同時。守りを少し悪く見込む分、相手の時計が延び、交点の向きが少しそろうと見る。採用の線（守りの比が 0.8〜1.2）には遠いので、既定は変えない。
- 次に割るなら、ライフ 1 枚の値（lam_net）を残りライフ・W に応じて読むかどうか。`syn_defend_residual` の残りライフ 2 の差（+0.089）と、`syn_tempo_residual` のターンの始まりの読みの振れすぎが、同じ場所を見ている可能性がある。
