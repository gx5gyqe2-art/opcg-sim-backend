# 登場時の利得——**中盤と大型は勘定が閉じた。最弱帯は 43% しか埋まらない**

2026-09-14 実施・判定（ユーザ指示「1 をおねがいします」＝一覧の 1 番目「サーチやドローなどによる
手札の量増加または手札の質の向上」を測る）。`entry_gain.py`（新規・**記録だけ**）を 300 局
（seed 帯 9700〜9999・sims 64・worlds 4・生成役 r3）で**打たれた登場 2,608 件**に。
`coverage` **1.000**（全件測れた）。本報告は特定時点のスナップショット（追記・改変しない）。

## 設計——**勝率に回帰しない**

登場時の利得は**他の通貨の増減として現れる**ので、**実際に動いた量を数えて既知の価格を掛ける**
だけで出る。勝率に回帰すると「除去は対象が居るときに打つ」という**選択交絡**が乗るが、
**通貨の差分は選択交絡と無関係**（何が起きたかを数えているだけ）。

```
利得 = (Δ手札 + 1)·μ + (Δ自場 − 体)·ν + (−Δ相手場)·ν + (−Δ相手ライフ)·λ + (Δ自ライフ)·λ
```

機械的な分（手札 −1・自場 +1）は `play_value` の他の項が持っているので戻す。
差分は**登場を選んだ main 行 → 同じターンの次の main 行**で取る。

## 0. 先に器のバグ——**ステージが最弱帯を汚していた**

`Δ自場` が **+0.885**（1 未満）という不自然な値が出たので調べたら、
**打たれた 2,608 件のうち 124 件がステージ**だった。ステージは**パワー 0** なので
`power_band` が全部「リーダー未満」に入れ、しかも**体を持たない**（`Δ自場 = 0`）ので
`(Δ自場 − 1)·ν` が `−ν` になり、利得を沈めていた。

| | ステージ込み（誤） | ステージを外す（正） |
|---|---|---|
| 最弱帯の `Δ自場` | 0.885 | **1.008** |
| 最弱帯の利得 | **−0.0016** | **+0.0125** |
| 最弱帯の要る額 | 0.0290 | **0.0318** |

**符号が変わるバグ**だった。`Cards.info` に `stage` を足して、両方の器から外した。

**弱いキャラの利得はほぼ全部「札の入れ替え」**——`Δ手札` が −1 ではなく **−0.769** で、
戻した +0.231 枚 × `μ` = **0.0100** が利得 0.0125 の 8 割を占める。
**ユーザ指摘の 1 番目（サーチ・ドロー）が、弱いキャラの価値の主成分だと数字で出た**。
登場時除去の寄与は 0.013 × `ν` = 0.0016 で小さい。

## 3. 判定

| 帯 | 判定 |
|---|---|
| **リーダー〜飽和** | **勘定が閉じた**。式に足すべき項は「登場時の利得」で足りる |
| **飽和超え** | **超過**（1.48 倍）＝この帯は逆に**過払いでは説明しきれない**ほど利得が大きい |
| **リーダー未満** | **43% しか埋まらない。0.0193 が未説明のまま残る** |

**残った 0.0193 の候補**（優先順）:

1. **手札の「質」**——サーチは**無作為な 1 枚を選んだ 1 枚に変える**ので、`μ`（平均の 1 枚）で
   値付けすると過小。ユーザ指摘の「手札の質の向上」がここ。`μ_search > μ` を測れば埋まりうる。
2. **`ν`（最弱帯 0.0690）そのものが過小**——観察された傾きなので、因果より小さく出ている可能性。
3. **CPU が払い過ぎている**——「過払い」は理論が正しいと仮定したときの差で、
   **この CPU は強くない**。最弱帯は弱いプレイヤーがいちばん無駄をする場所でもある。

**1 と 3 は向きが逆なので、反事実でしか分けられない**（理論が純損と言う登場を禁じて勝率を見る）。

## 4. 副産物——**ステージは枠組みに居場所が無い**

ステージは**体を持たない**（`ν` の定義はキャラ）のに、利得 **0.0194** を持ち、
しかも**常在効果は場に在り続ける**。つまり:

- 登場時の利得だけでは説明できない（継続効果が在る）
- `ν` では説明できない（キャラではない）

＝**4 通貨 + `ν` の枠組みに、ステージの継続価値の置き場が無い**。`game_theory.md` の
一覧（§14.1.1）に項を足す必要がある（今回は「測れた」だけを記録し、式は触っていない）。

## 限界

- **`Δ相手場` を相手の `ν` の平均（0.1230）で値付けした**——消したキャラのパワー帯は追っていない。
  除去の寄与は小さいので影響は限定的だが、上振れ／下振れの向きは不明。
- **手札の質を `μ` で値付けしている＝過小**（§3 の候補 1 がまさにこれ）。
- **差分は「同じターンの次の main 行」**で取るので、**その登場の解決以外は入らない**が、
  同じターン内の後続の自分の行動の影響は入らない（入口の差分だけを見ている）。
- 「過払い」は**理論が正しいと仮定したときの差**（§3 の候補 3）。
- 1 設定・1 ネット（r3）・生成時の探索（Dirichlet 雑音と温度が乗っている）。

## 次

1. **`μ_search` を測る**（サーチで入った札とランダムな札の価格差）＝最弱帯の残り 0.0193 の
   第 1 候補。記録から測れるか要検討（入った札の素性を追う必要が在る）。
2. **反事実**（`cpu_theory_gap.md` の宿題）＝「過払いは CPU の漏れか理論の穴か」を分ける。

3. **ステージの置き場**を枠組みに足す（§4）。
4. 式に足すのは **`leader_to_sat` の帯から**——そこは勘定が閉じているので、
   **足した項が正しいかを検算できる唯一の帯**である。
