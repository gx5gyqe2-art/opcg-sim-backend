## 1. 式（実装の前に書いた）

### 1.1 問い

守る側の計算（`defender.rs` の動的計画）は、攻め手の 2 段目以降の攻撃の並び（`later_seq`）を `core/outer.rs::rules_steps` から受け取る。
`rules_steps` は段 `j ≥ 2` で、出す札と付与を財布（`purse_plan_witness`）で選び、体 `i` に `k` 枚付けるのは
`attach_gain(x_i, k) − k·δ > 0` のときだけ。`attach_gain` は `to.rs::attack_value` の `min(止める値段, 受ける値段, ブロッカーの値段)` の差で、
止める値段は「止めるのに要る札の枚数 `c̄` × 守り手の 1 枚の値段 `ḡ`」。手札の厚い守り手（`ḡ` が小さい）が相手だと差が `k·δ` に届かず、
**後の段の攻撃は付与なしで並ぶ**。実際の攻め手は 1 本に 1.40／1.50 枚付ける（切り分け報告 §4）。ドンはターンをまたいで持ち越せない
（ターンの終わりに余ったドンには他の使い道が無い）ので、**出す札に払った後の残りは攻撃に付く**とするのが規則どおり。
これを入れると、地平を生き延びると言う時計（`S` ≥ 1/2）の言い落としと遅れがどれだけ縮むか。

### 1.2 式（段 `j ≥ 2` だけ・新定数ゼロ）

1. **今のまま**: 財布で出す札 `plays_j` と値打ちで決める付与 `k_i`（`attach_gain − k·δ > 0`）を選ぶ。払い `P_j = Σ cost(plays_j) + Σ k_i`。
2. **残り**: `L_j = round(d_j) − P_j`（`d_j` は段 `j` の攻め手のドン＝今の `ds[j−1]`・財布の予算と同じ丸め）。
   出す札は 1 で選び終えている（財布は払える札のうち値打ちが正のものを全部見ている）ので、残りのドンの使い道は規則上付与だけ。
3. **配り方**: 盤面の攻め手 `i`（今の付与の対象と同じ集合＝リーダーと、前の段までに居た体）に `e_i ≥ 0` 枚、`Σ e_i ≤ L_j`、
   `k_i + e_i ≤` 付与の上限（今の `ATTACK_DON_MAX` = 10）で、
   **`Σ_i c̄(x_i + 1000·(k_i + e_i))` を最大にする**——`c̄(x)` は今の値段の止める値段の芯 `to.rs::cof(x)`（＝`c̄(x + 1000)`・
   守り手が止めるのに要る札の枚数・`x < −ε` は 0）。解き方は今の財布 `purse_plan_witness`（群れ＝攻め手ごとの `e` の選択肢・値＝`c̄` の増え）。
   同点は今の財布の割り切りのまま（先に並んだ攻め手・少ない枚数）。
4. **守る側の計算に渡す攻撃の並び**: 段 `j` の `hits_j` = `{ x_i + 1000·(k_i + e_i) }` ∪（その段に出した速攻の体・今のまま）。

**なぜ `c̄` で配るか**（選び方を入れないため）: 今の値段の止める値段は `c̄ · ḡ`（`ḡ` > 0 の倍率）なので、止める値段の順は `c̄` の順と同じで
`ḡ` に依らない。今の式で付与が選ばれないのは**順ではなく大きさ**（`ḡ` が小さいと差が `k·δ` に届かない）のためで、残りのドンには
`δ`（ドン 1 枚の値段＝他の使い道の値）が掛からない（規則: 持ち越せない＝他の使い道が無い）。`min` の残りの 2 つ（受ける値段・ブロッカーの値段）は
「その 1 本を止めずに受ける方が安い」と静的に言う近似で、受けるか止めるかは守る側の計算そのものがライフと手札で解くので、配り方には使わない。
`c̄` は `x ≥ −ε` で狭義に増える（増えは 0.28〜0.97 枚）ので、リーダーに届く攻め手が 1 体でも居れば残りは全部付く。届かない攻め手には
届くまで付けたときだけ `c̄` が 0 から増える（届かない攻撃は守る側の計算でも当たらない＝`hits` の `x ≥ −ε` の篩と同じ規則）。

### 1.3 変えないもの

- **段 1（今のターン）**: 守る側の計算の中で付与を解いている（`caps`）ので触らない。
- **出す札・払い `P_j`**: 段の `paid`（歩きの流入が使う残りのドン `left_of(i, paid_i)`）は今のまま＝**流入には触らない**。
- **`fb`（地平の外の段の値）**: 付与の値打ちは今の `k_i` のまま＝**`fb` には触らない**。
- **`model_horizon`（最初の地平の見積もり）**: `lead_bare`・`chars_bare`・`flow` だけを読むので動かない。
- 値段の表・`KERNEL_FILES`（守る側の解き方の 8 ファイル）。変えるのは `core/outer.rs`（`KERNEL_FILES` の外）だけ。
- 既定（変数なし）では 1 ビットも変えない（golden〔`rd_solve_golden`／`rd_dp_golden`／`theory_*_golden`／`rs_goldens`〕が動かないこと・
  候補を入れる前の wheel と 10 局の時計の行が 1 バイト一致することを確かめる）。

### 1.4 既知の重なり（今の流入との二重）

地平の内の段の値は `harm_j ＋ 流入 ＋ 効果` で、流入（引いた札から出る体）は残りのドン `left_of(j, P_j)` で払えるとして数える。
候補では同じ残りのドンを守る側の計算の中で攻撃に付けるので、**地平の内では残りのドンを 2 回使う**（引いた体に払う・付与に回す）。
規則の順は「引く → 出す → 付ける」なので本来は引いた体が先に払う。流入を触らない条件（司令塔の指示）を守るため直さない。
大きさは小さいと見る【推測】: 引いた札の候補の報告（`2026-10-09_drawn_attackers.md` §4.2）で、地平の内の段の値に流入が占めるのは 0.042 対 損害 0.893。

### 1.5 切替と新定数

- 環境変数 `OPCG_LEFTOVER_DON`（空でも `0` でもない値で入る・1 度だけ読む・採用前の候補）。入れたときは攻め手の財布の dict に印（`leftover_don`）を足す
  （守る側の計算の覚え書き・計画のディスクの鍵に入る＝切替の前後で計画を取り違えない）。
- **新定数ゼロ・選び方ゼロ**: 使うのは規則（ドンは持ち越せない・付与の上限）・今の `c̄` の曲線（止める値段の芯）・今の財布の解き方とその同点の割り切りだけ。
- 試験は 1 本（配り方の手で導ける値: 超過 0 と 2000 の 2 体・残り 1 枚なら 2000 の体へ〔`c̄` の増え 0.53 対 0.28〕・残り 2 枚なら 2000 の体へ 2 枚
  〔1.38 対 0.81 対 1.25〕）。

## 0. 結論（全記録の後に書いた）

1. **推薦は採らない**【実行】。殺す基準に両方の記録で当たった: 実で (b)（`S` < 1/2 の観測 ÷ 予測 0.927 → **0.830**）・(c)（相対の腕の AUC .8076 → **.7969**）・
   (d)（的中 .7051 → **.6964**）、合成で (c)（.7241 → **.7186**）・(d)（.6602 → **.6493**）。(a) 打ち切りはむしろ減った（実 9 → 0・合成 70 → 3）。
2. **問いへの答え: 後の段の付与は芯の一部で、効きは本物だが「全部付ける」は言い過ぎる**【実行】。地平を生き延びると言う時計の残る遅れ（差し引いた後・同じ時計）は
   実 +0.937 → **+0.339**・合成 +1.192 → **−0.145** と縮み、遅れの地平の段数への傾きも寝た（同じ時計で実 +0.60 → +0.36・合成 +0.31 → +0.19）。
   **引いた札の候補と違い、地平の予算による縮みは起きていない**（予算で地平を縮めた計画 21 → 22・266 → 258）＝縮みは付与そのものの効き。
   ただし計画の後の段の攻撃は、実際の半分（超過の和の平均 3,338／2,957 対 実際 6,105／5,721）から**実際の 1.2〜1.6 倍**（8,630／9,678 対 7,082／6,373）へ越え、
   `S` < 1/2 の時計でも 1.4／1.6 倍になった。計画は盤面の体を毎段全部攻撃させる（本数が実際の 1.6 倍）ので、その全部に残りを付けると強過ぎる。
3. **較正の多くは良くなった**【実行】: 合成の σ_T 2.004 → **1.109**・整数の偏り +0.738 → +0.280・±1 以内 .669 → .725・打ち切り 70 → 3・相対の腕の対数損失
   .6314 → .6186・ECE .058 → .035・**絶対の腕の対数損失 .8639 → .6550（コインに勝つようになった）**。実も整数の偏り +0.354 → +0.102・σ_T 1.412 → 1.089・

## 8. 判断事項

### 判断 1: 後の段で余ったドンを全部攻撃に付ける候補を採るか

1. **何を決めるか**: 守る側の計算に渡す「攻め手の 2 ターン目以降の攻撃」に、出す札に払った後の余りのドンを全部付けて読む式を既定にするか。
2. **選択肢**:
   (a) **採らない**（推薦）——測る前に決めた殺す基準に両方の記録で当たる。実: どちらが勝つかの的中 .705 → .696・決着前の勝率の並べる力 .808 → .797・
       地平を生き延びないと言う時計で倒れる数が予測の 0.83 倍（基準は 0.85 以上）。合成: 的中 .660 → .649・並べる力 .724 → .719。
   (b) 採る——時計の較正は大きく良くなる（合成: 勝つ側の時計のばらつき 2.00 → 1.11 ターン・30 ターンで届かない時計 70 → 3 本・決着前の勝率の外れ具合 .058 → .035・
       決着前の勝率の確率としての良さはコインに負けていたのが勝つようになる）。並べる力と的中が両方の記録で約 0.01 下がる。
3. **なぜこの問いが出てきたか**: 生き延びると言う時計に約 1 ターンの遅れが残り（10-09 の終わりの検算）、切り分け（10-08）では計画が後のターンの攻撃を実際の半分の強さで
   読んでいた。原因は「付けた値打ちが付与 1 枚の費用を越えるときだけ付ける」読みで、手札の厚い守り手が相手だと付けない。独立レビュー（10-09）の推測どおり、
   規則「ドンは持ち越せない」で余りを付ける候補を作り、10 局で輪を閉じて予告を書いてから全記録で測った。遅れは縮んだが、攻撃は実際の 1.2〜1.6 倍へ越えた。
4. **推薦とその理由**: (a)。基準は測る前に決めたもので、並べる力が両方で下がった。ただし (b) の較正の良さは今までの候補で最も大きいので、捨てずに判断 2 へ進むのがよい。
5. **決めないとどうなるか**: 候補は切替のまま残る（既定は不変・golden も不変）。次の (2) 出口の再開は今の既定で進められる。
6. **留保**: 合成の線形の橋は 300 局だけで測った。採らない場合も、後のターンの攻撃を半分の強さで読む穴は残る（遅れの半分強はここ）。

### 判断 2: 「付け過ぎ」を、計画が毎ターン全部の体で攻撃する読みと一緒に直す候補を次に試すか

1. **何を決めるか**: 余りのドンを付ける前に、計画の後のターンの攻撃の本数（今は盤面の全部の体が毎ターン攻撃する読み・実際の 1.6 倍）を規則から直す候補を先に試すか。
2. **選択肢**:
   (a) **試す**（推薦）——今回の付け過ぎ（実際の 1.2〜1.6 倍）は「本数が多い」×「全部に付ける」の掛け算で出ている。本数の読みを直せば（たとえば体が相手のターンに倒される分・
       リーダーでなく体を攻撃する分を、規則と既存の実測値から読む形。選び方の入らない形を探す）、付与の効きを残したまま並べる力を戻せる見込みがある【推測】。
   (b) 今回の候補を採ったうえで、並べる力の下がりを既知の限界として出口の再開へ進む。
   (c) どちらもせず、決めた順番どおり出口の再開へ進む。
3. **なぜこの問いが出てきたか**: 候補ありでも `S` < 1/2 の時計の計画の本数は 3.0 本・実際は 1.9 本で、本数の多さは候補の前から在った（切り分け報告の §4）。
   今まで付与が少なかったので目立たなかった（超過の和は実で計画と実際が同じだった）が、付与を足した途端に表に出た。
4. **推薦とその理由**: (a)。今回の候補は芯に当たる（同じ時計で長い地平の遅れの傾きが 4 割寝る・地平の予算の副作用ではない）ので、付け過ぎの元を規則で直せるかを
   先に確かめる価値がある。ただし本数を読む規則が見つからず選び方が入るなら止めて報告する。
5. **決めないとどうなるか**: 今回の効きは切替の中に残るだけで、遅れの芯の半分強に手が付かないまま出口の再開へ進む。
6. **留保**: 本数の読みを直すと、今回と同じく計算の輪で跳ね返る（地平・耐久）。輪を閉じた予告からやり直しになる。

判断 1 と 2 は独立（判断 1 を (a) にしても判断 2 は進められる。判断 2 の (b) は判断 1 の (b) を前提にする）。表（`make theory-table`）は作り直していない（採らない推薦のため）。
