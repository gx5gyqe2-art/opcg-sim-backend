## 1. 式（実装の前に書いた）

### 1.1 問い

守る側の計算（`defender.rs` の動的計画）は、攻め手の 2 段目以降の攻撃の並び（`later_seq`）を `core/outer.rs::rules_steps` から受け取る。
`rules_steps` は段 `j ≥ 2` で、出す札と付与を財布（`purse_plan_witness`）で選び、体 `i` に `k` 枚付けるのは
`attach_gain(x_i, k) − k·δ > 0` のときだけ。`attach_gain` は `to.rs::attack_value` の `min(止める値段, 受ける値段, ブロッカーの値段)` の差で、
止める値段は「止めるのに要る札の枚数 `c̄` × 守り手の 1 枚の値段 `ḡ`」。手札の厚い守り手（`ḡ` が小さい）が相手だと差が `k·δ` に届かず、
**後の段の攻撃は付与なしで並ぶ**。実際の攻め手は 1 本に 1.40／1.50 枚付ける（切り分け報告 §4）。ドンはターンをまたいで持ち越せない
（ターンの終わりに余ったドンには他の使い道が無い）ので、**出す札に払った後の残りは攻撃に付く**とするのが規則どおり。
これを入れると、地平を生き延びると言う時計（`S` ≥ 1/2）の言い落としと遅れがどれだけ縮むか。

### 1.2 式（段 `j ≥ 2` だけ・新定数ゼロ）

1. **今のまま**: 財布で出す札 `plays_j` と値打ちで決める付与 `k_i`（`attach_gain − k·δ > 0`）を選ぶ。払い `P_j = Σ cost(plays_j) + Σ k_i`。
2. **残り**: `L_j = round(d_j) − P_j`（`d_j` は段 `j` の攻め手のドン＝今の `ds[j−1]`・財布の予算と同じ丸め）。
   出す札は 1 で選び終えている（財布は払える札のうち値打ちが正のものを全部見ている）ので、残りのドンの使い道は規則上付与だけ。
3. **配り方**: 盤面の攻め手 `i`（今の付与の対象と同じ集合＝リーダーと、前の段までに居た体）に `e_i ≥ 0` 枚、`Σ e_i ≤ L_j`、
   `k_i + e_i ≤` 付与の上限（今の `ATTACK_DON_MAX` = 10）で、
   **`Σ_i c̄(x_i + 1000·(k_i + e_i))` を最大にする**——`c̄(x)` は今の値段の止める値段の芯 `to.rs::cof(x)`（＝`c̄(x + 1000)`・
   守り手が止めるのに要る札の枚数・`x < −ε` は 0）。解き方は今の財布 `purse_plan_witness`（群れ＝攻め手ごとの `e` の選択肢・値＝`c̄` の増え）。
   同点は今の財布の割り切りのまま（先に並んだ攻め手・少ない枚数）。
4. **守る側の計算に渡す攻撃の並び**: 段 `j` の `hits_j` = `{ x_i + 1000·(k_i + e_i) }` ∪（その段に出した速攻の体・今のまま）。

**なぜ `c̄` で配るか**（選び方を入れないため）: 今の値段の止める値段は `c̄ · ḡ`（`ḡ` > 0 の倍率）なので、止める値段の順は `c̄` の順と同じで
`ḡ` に依らない。今の式で付与が選ばれないのは**順ではなく大きさ**（`ḡ` が小さいと差が `k·δ` に届かない）のためで、残りのドンには
`δ`（ドン 1 枚の値段＝他の使い道の値）が掛からない（規則: 持ち越せない＝他の使い道が無い）。`min` の残りの 2 つ（受ける値段・ブロッカーの値段）は
「その 1 本を止めずに受ける方が安い」と静的に言う近似で、受けるか止めるかは守る側の計算そのものがライフと手札で解くので、配り方には使わない。
`c̄` は `x ≥ −ε` で狭義に増える（増えは 0.28〜0.97 枚）ので、リーダーに届く攻め手が 1 体でも居れば残りは全部付く。届かない攻め手には
届くまで付けたときだけ `c̄` が 0 から増える（届かない攻撃は守る側の計算でも当たらない＝`hits` の `x ≥ −ε` の篩と同じ規則）。

### 1.3 変えないもの

- **段 1（今のターン）**: 守る側の計算の中で付与を解いている（`caps`）ので触らない。
- **出す札・払い `P_j`**: 段の `paid`（歩きの流入が使う残りのドン `left_of(i, paid_i)`）は今のまま＝**流入には触らない**。
- **`fb`（地平の外の段の値）**: 付与の値打ちは今の `k_i` のまま＝**`fb` には触らない**。
- **`model_horizon`（最初の地平の見積もり）**: `lead_bare`・`chars_bare`・`flow` だけを読むので動かない。
- 値段の表・`KERNEL_FILES`（守る側の解き方の 8 ファイル）。変えるのは `core/outer.rs`（`KERNEL_FILES` の外）だけ。
- 既定（変数なし）では 1 ビットも変えない（golden〔`rd_solve_golden`／`rd_dp_golden`／`theory_*_golden`／`rs_goldens`〕が動かないこと・
  候補を入れる前の wheel と 10 局の時計の行が 1 バイト一致することを確かめる）。

### 1.4 既知の重なり（今の流入との二重）

地平の内の段の値は `harm_j ＋ 流入 ＋ 効果` で、流入（引いた札から出る体）は残りのドン `left_of(j, P_j)` で払えるとして数える。
候補では同じ残りのドンを守る側の計算の中で攻撃に付けるので、**地平の内では残りのドンを 2 回使う**（引いた体に払う・付与に回す）。
規則の順は「引く → 出す → 付ける」なので本来は引いた体が先に払う。流入を触らない条件（司令塔の指示）を守るため直さない。
大きさは小さいと見る【推測】: 引いた札の候補の報告（`2026-10-09_drawn_attackers.md` §4.2）で、地平の内の段の値に流入が占めるのは 0.042 対 損害 0.893。

### 1.5 切替と新定数

- 環境変数 `OPCG_LEFTOVER_DON`（空でも `0` でもない値で入る・1 度だけ読む・採用前の候補）。入れたときは攻め手の財布の dict に印（`leftover_don`）を足す
  （守る側の計算の覚え書き・計画のディスクの鍵に入る＝切替の前後で計画を取り違えない）。
- **新定数ゼロ・選び方ゼロ**: 使うのは規則（ドンは持ち越せない・付与の上限）・今の `c̄` の曲線（止める値段の芯）・今の財布の解き方とその同点の割り切りだけ。
- 試験は 1 本（配り方の手で導ける値: 超過 0 と 2000 の 2 体・残り 1 枚なら 2000 の体へ〔`c̄` の増え 0.53 対 0.28〕・残り 2 枚なら 2000 の体へ 2 枚
  〔1.38 対 0.81 対 1.25〕）。

### 2.3 殺す基準（どれか 1 つに当たったら不採用の推薦）

- (a) 打ち切りが +10% を超えて増える。
- (b) 地平を生き延びないと言う時計（`S` < 1/2）の観測 ÷ 予測が 0.85〜1.15 を外れる（どちらかの記録）。
- (c) 決着前の予測力（相対の腕の AUC）がどちらかの記録で下がる。
- (d) 交点の橋の的中がどちらかの記録で下がる。

**見立て**【推測】: 切り出しでは両方の記録で (b)〜(d) に当たっている（実 (b) 0.763・(c) −.008・(d) −.043／合成 (b) 0.842・(c) −.064・(d) −.042）。
動きは 1 局ぶんより大きく、全記録でも (c) と (d) のどちらかに当たる見込みが 8 割を超える。**芯への当たり方**: 残りのドンを全部付けると後の段の攻撃は
実際の半分から**実際の 1.5〜2 倍**へ跳ぶ。言い落としを埋める向きには動くが、計画が毎段全部の体を攻撃させる（本数が実際の 1.5 倍）ことと組み合わさり越える。
