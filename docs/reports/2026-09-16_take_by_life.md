## 結論を 5 行で

1. **守りの規則にも `--theta-mode` を通した**（それまで攻めの行だけ）。生存のシャドー価格 `max`／`board` は**守りの窓の「受けろ」率を動かさない**
   （ライフ 1〜3 で 0.87〜0.99 のまま）——シャドー価格の単位が「枚」で、来る攻撃の `c(x)` を超えられないため（ライフ 0 でも「受けろ」0.93）。
2. **`by_life`（T19 の `λ(L)` の写し・攻撃は相手のライフ・守りは自分のライフ）**: 橋の `ΔG` は **0.728 → 0.880／0.663 → 0.873** と跳ねるが、
   **帯で見ると決着帯だけ**（0.800 → 0.908／0.707 → 0.891・接戦帯 0.334 → 0.318／0.456 → 0.482・中盤 0.579 → 0.569／0.570 → 0.549）。
   **`ΔS` は 0.447 → 0.324／0.501 → 0.369 と落ち**、攻撃の `実現/価格` は動かない（1.05 → 1.06／1.14 → 1.14）。表の L=4 の谷（λ 0.078）が
   守りの規則を「ライフ 4 では必ず受けろ」（1.00）にする＝**雑音を含む表をそのまま使うと規則が壊れる**。**不採用**。
3. **`lethal`（規則だけ＝ライフ 0 で受ければ負け＝勝利の価値 0.5・他は定数）**: 橋は **0.728 → 0.879／0.663 → 0.874** と `by_life` と同じだけ跳ねる
   ＝**跳ね上がりの正体は「相手ライフ 0 への攻撃＝決め手の一撃」が帳簿に入ったこと**で、接戦帯・中盤帯は動かない（0.328／0.585・0.467／0.577）。
   `ΔS` は 0.447 → 0.348／0.501 → 0.396 と落ちる。攻撃の `実現/価格` は x>2000 で 1.14 → 1.05／1.15 → 1.04 と合う向き。
4. **守り側の `ΔG` はどの形でも 0.5 を割ったまま**（0.276〜0.289／0.401〜0.463）。ライフ 1〜3 で「理論は受けろ 87〜99%・実際 58〜80%」は残る。
   受ける費用の水準がライフで変わるのは確かだが、**その形を式から出す材料がまだ無い**（T19 の表は CI が広く谷がある・シャドー価格は単位が違う）。
5. **既定は `const` のまま**（ユーザ判定）。`lethal` は規則として正しい（決め手を 0.5 で数える）が、橋の数字を読むときは**帯で読む**こと。

## 3. 読み方

- **`ΔG` の跳ね上がりは決め手の一撃**: 相手ライフ 0 への攻撃は「打てば勝ち」で、それを 0.5 で数えれば勝った席の帳簿にだけ大きな正が入る。
  帯で読めば接戦・中盤は動いていない。**帳簿としては正しく、手の良し悪しの説明力としては新しい情報ではない**。
- **`ΔS` が落ちる**のは、相手ライフ 0 では理論の最善が「決め手」に固定され、記録の CPU がそれを外した行（ブロッカー・カウンターで通らない
  攻撃を選んだ行）が逸脱として大きく載るため。これは理論の側が正しい可能性が高い（決め手を外す手は悪い手）。
- **守りの半分は残る**。低ライフで受ける費用が高いのは事実（実際の受け率）だが、それを式から出す材料が無い。T19 の表（谷あり）を
  そのまま使うと規則が壊れ、シャドー価格は単位が「枚」で天井がある。**次の材料は交点の橋（T52）の側**——`λ(L)` は「残り何発で負けるか」から
  出る量で、定数でも表でもなく時計で持つべきもの。
