# T46——相手の体を倒せる潜在価値を「今の場」ではなく「分布」で `ν` に入れた

2026-09-16 実施（ユーザ決定「相手の潜在効果は入れない・相手の体を攻撃できる潜在価値は分布で入れる・
相手の体の価値は同じ式を相手の側から評価したパワーの関数・分布はターン数ではなく残りターン `R` で条件付ける」）。
**新しい定数はゼロ**——分布は A 層の実測（`tests/fixtures/opp_boards.json`・合成 900 局・11,086 ターン）。
本報告は特定時点のスナップショット。

## 結論を 6 行で

1. **式**: `ν` の攻撃項 = `lead·R + 選択肢`・`選択肢 = E_盤面[ Σ_{i<R} max(v_(i), lead) ] − lead·R`・
   `v_T = min(c(P − P_T)·μ, ν(T))`・`ν(T)` は相手の体を**同じ `nu_of` で相手の側から**（深さ 1）。
   **盤面 1 つを `R` ターンの池として 1 体は 1 回だけ倒す**（`attack_stream` の盤面モードと同じ規則）。
   lead を超えた分だけを取るので**二重計上にならない**。
2. **初版は単位を誤った**——「毎ターン新しい体が現れる」形（流量）で書いて `ν` が実測の 1.5〜1.75 倍になった
   （#39 が踏んだのと同じ誤り）。**在庫（R ターンで 1 体 1 回）に直した**のが上の式。
3. **12000 の体に、場が空でも価値が付く**——飽和超えの帯の `ν` は 0.232 → **0.283**（合成・実際に居た体の平均）。
   リーダー未満 0.067 → 0.078・中盤 0.203 → 0.211。
4. **検算は「流れ」で見ると支持され、「在庫」で見ると水準の壁に当たる**——飽和超えの体の**1 ターンあたり**の
   攻撃の価値は理論 0.063 → **0.075**（選択肢込み）対 記録の実現 **0.084**（0.095/回 × 率 0.88）＝近づいた。
   一方、回帰で測った `ν`（在庫・0.211）は理論 0.283 の 0.75 倍で、**攻撃だけの実測の組み直し（0.246）より
   さらに低い**＝在庫への換算（`R`・生存・P1 の `w(状態)`）の側の問題で、選択肢の項の問題ではない。
5. **他の器**: `ΔG` は両記録で成立（実 +6.0・AUC 0.64／合成 +4.5・AUC 0.59）・登場の価格 対 実現 0.46／0.52
   （`ν` が上がったぶん比は下がる）・T26 の「出すのは得」91%／88%（行き過ぎのまま）。
6. **`OPTION_MODE`（`dist`／`off`）で戻せる**。テストは既定で `off` にして閉じた代数を固定し（`conftest`）、
   T46 のテストだけ明示的に入れる。

自席ターンの入口で相手の場に居た体（パワー・ブロッカーか）を、`R = clamp(相手ライフ, 1, 5)` ごとに 400 盤面ずつ無作為抽出:

|---|---|---|---|---|---|
| 1 | 1,046 | 3.9% | 2.66 | 5,331 | 10.0% |
| 2 | 1,075 | 3.4% | 2.51 | 5,411 | 7.0% |
| 3 | 1,904 | 6.0% | 2.16 | 5,051 | 7.8% |
| 4 | 3,871 | 29.7% | 1.33 | 4,599 | 8.4% |
| 5 | 3,190 | 51.6% | 0.71 | 4,250 | 5.5% |

**残りが多い（序盤）ほど相手の場は空**——選択肢の価値は自然に `R` で変わる（ターン数を名指ししない）。

## 3. 流れで見た検算（飽和超えの体・合成）

| | 1 ターンあたりの攻撃の価値 |
|---|---|
| 理論（選択肢なし） | 0.063（`Θ·μ` の頭打ち） |
| **理論（選択肢込み）** | **0.075**＝0.063 ＋ 0.050/4.128 |
| **記録の実現** | **0.084**＝0.095/回 × 率 0.88 |

大きい体の攻撃は記録で 1 回 0.095 実現しており（倒したブロッカー等の `ν_meas` が乗る）、**選択肢の項はそこへ向かって
動いた**。残り 0.009/ターンは `ν(T)` の側（相手の体の価値も同じ式＝同じ水準の問題を持つ）か、率 0.88 を 1 と置く差。

## 4. 読み方

- **「12000 を空の場に出しても圧しか無いのは変」は式で解消**——分布の上で倒せる体があるぶん価値が付く。
- **在庫としての `ν` は依然 1.3〜1.4 倍**——ただし**攻撃だけの実測の組み直しでも 1.0〜1.16 倍**なので、
  差の大半は流れ→在庫の換算（`R`・`(1 − ko_p)`・帯の中の回帰が持つ収穫逓減＝P1）。**選択肢の項を削って合わせない**。
- **T45＋T46 で、パワーの軸は `ν` の中に 3 経路で入った**——ドン付きの攻撃（リーダー未満）・頭打ちまでの攻撃・
  倒せる体の選択肢（飽和超え）。

## 限界

- 分布は**合成 900 局**のもの（実デッキの場は別の分布）。実デッキで回すときも同じ分布を使っている。
- 相手の体の `ν(T)` は同じ式（深さ 1）＝式の水準の誤りが `v_T` にも乗る。
- 盤面を `R` ターンの池にする形は**補充を数えない下限**（本当は新しい体が出てくる）——上の流量の形が上限。
- **観察であって因果ではない**。
