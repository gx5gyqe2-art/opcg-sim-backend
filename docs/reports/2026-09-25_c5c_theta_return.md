# C-5c: レスト中のブロッカーを「次の自席ターンから戻る耐久」として通す——正しい形は全帯で帳簿を上げ、機構の残差を消す(2026-09-25)

C-5(`2026-09-25_c5_attack_theta_parts.md`)は、攻撃の残差の機構を「ブロッカーがレストすると`Θ`の体の項
(アクティブなブロッカーだけ)から`ν_meas`1体分が丸ごと消える」と特定し、式の候補4つを並べた。ユーザ決定
「正しい形だけやれば良い」「その場合はdだけ」を受け、**(d)＝レスト中のブロッカーは持ち主の次のリフレッシュで
戻る(規則・`rules/turn.rs`)ので、歩きの2段目から的に戻る耐久として持つ**形だけを作った。(c)(遅れを落とした
近似)は作らない。比較相手は今の既定(a)とC-2の近似(b・`ATTACK_REST_MODE=body`)。

## 式(新定数ゼロ・既存の`THETA_RETURN_MODE=untap`〔T96〕を全器に通す)

* **交点の橋**: `theory`読みは既に`tau_grow(step=th_back)`で2段目から戻る分を足していた(相手側のみ・
  `OPP_CLOCK_MODE=mirror`なら鏡の行で自分側も同じ道)。`curve`読みの`tau_from_profile`に`step`を足し、
  `rows_out`に両歩きの戻る分(`th_back_me`/`th_back_opp`)を持たせて同じ規約で歩かせた。
* **帳簿の状態**(`kappa_vector.state_of_row`): `untap`なら**7つ組** `(Θ_me, Θ_opp, A_me, A_opp, j, 戻る_me, 戻る_opp)`
  ——戻る分は`resting_blocker_term`(札の原本から`blocker`を引く・レスト中の体の`ν_meas`)。`Θ`本体は
  アクティブなブロッカーだけのまま(**既定と同じ数字**・`off`なら5つ組でビット一致)。3本の歩き
  (`tau_from_profile`・`tau_of`・`tau_theory`)はどれも**2段目から**戻る分を的に足す(`tau_grow`と同じ規約)。
* **攻撃の価格**(`ATTACK_REST_MODE=return`): ブロッカーで攻めた`ν_meas`を**`th_me`から`th_me_back`へ移す**
  (総量は不変)。C-2の`body`(消す)と違い「永久の損失」ではない。
* シャープレイ配分は耐久の軸と戻る分を1人の「選手」として動かす(`_mix`)・席の入れ替えは戻る分も
  入れ替える(`_swap_state`・`_swap_dx`)。**`_swap_dx`が戻る分を入れ替えていない誤りを実装中に踏んだ**
  (席1の攻撃で戻る分が守り手に付き、ブロッカー攻め手の残差が−0.126→+0.072に化けた)——テストで固定して直した。
* 帳簿の不変量の検算(`_invariance`)も7つ組を通す(P5は戻る分も同じ通貨・P7はそのまま)。
  **P5(通貨の付け替え)の破れ304/315は既定でも同数**(`curve`読みの既知の患部・T122)で本Tの変更ではない。

テスト15本(`tests/test_theta_return.py`)。`ATTACK_REST_MODE=body`(C-2)は切替として残す。

## 結論

**規則どおりの形(d)は、近似(b)が勝った所(とどめの帯・攻撃行残差)でも勝ち、近似が負けた所
(主に読む帯)でも勝つ**——C-3で符号が割れた原因が「永久」と「1ターン」の差だったという読みが実測で
裏づけられた。機構の残差は両側でほぼゼロ。交点の橋は不動。**採否はユーザ判断**(既定は`off`のまま)。
