## 2. 境界と API

### 2.1 受け渡し（段 1）
* **カード表**: Python がカード DB（パーサ）から 1 度だけ JSON を作る（`theory_rs.card_table_json`）。1 枚 = `PL.Cards.info` の 9 項目

* **効果の木**: `opcg_effects.json` の文字列をそのまま Rust が読む（`PyVal` の木・`json.load` と同じ型）。段 3 の効果の値付けがこれを歩く。
* **fixture**: `harm_profile.json`・`opp_boards.json` を Rust が自分で読む。
* **局の枠**: `theory_rs.frame_of(rows, pol, ex, L, ptr, idx)` → `opcg_engine.TheoryFrame`。行の列（`who`・`turn`・`seed`・`z`・`kind`・`step`・
