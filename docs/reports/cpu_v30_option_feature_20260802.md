# v30 学習: 登場時オプション特徴（v7）で m4@2 を狙う — 方向は動いた・未昇格（2026-08-02）

スナップショット（追記・改変しない）。前提: `cpu_v29`（v7 特徴の実装・本 PR）、
`cpu_v26_cause_analysis_20260801.md`（周辺相関 vs 条件付き対比）、`gen9_adoption_20260801.md`。
標的は m4@2（1ドン・ターン1で「イワンコフを出すか A&S&L を出すか」＝レフェリー唯一合格手は
A&S&L）。v24/v25/v26 が一度も動かせなかった、representation-bound の核心点。

## TL;DR

- **v7 特徴（登場時オプションの make/unmake 実測）は m4@2 の value を初めて正しい方向に動かした**:
  子盤面 value 差「A&S&L − イワンコフ」が gen9 の **−0.140 → v30(α1) −0.047**（66% 縮小・
  符号は未反転＝選択はまだイワンコフ 8/8）。過去 3 手法が 0.00 で不動だった点での初の前進。
- **綺麗なトレードオフ**: distill なし（α1）は標的に最も効くがアリーナ 0.325（弱化）。
  distill0.5 は**アリーナ 0.509（gen9 と同等・800局 CI[0.476,0.542]）× コーチ PASS**だが
  m4@2 の前進は −0.106 へ後退。標的の解決度と一般対局の健全性が直交して交換される。
- **波及**: v7 特徴は m4@2 だけでなく**未解決のドン付与点**も動かした（m2@44 0.00→0.44・
  m5@7 0.19→0.75）。ドン付与＝「オプションを消費せず盤面を作る」手なのでオプション価値が効く。
- **昇格基準では FAIL**（どの腕も 0.55 未満）。distill0.5 は「アリーナ中立＋コーチ +0.4＋
  新機能（v7）搭載」の gen9 型・ユーザ判断採用候補。ただし**標的 m4@2 は解決していない**。

| 項目 | 値 |

**途中で発見・修正した設計欠陥**（本 PR に含む）: v7 実測は当初「今コストを払える PLAY」
だけを走査しており、1ドンの m4@2 では 1 コストを出した子で全札が非合法になり全て (0,0,0) へ
潰れ、**探索が子を比べる唯一の場所で盲目**だった。ドン非依存（コスト分の一時ドンを txn 内で
補い巻き戻す）に修正して初めて子盤面の判別が立った（イワンコフ後 live 2→1・A&S&L 後 2 維持）。

## 2. 判定

| 腕 | コーチ v3（vs gen9・16seed・13点） | アリーナ | m4@2 value差 |
|---|---|---|---|
| gen9（基準） | 4.6 | 0.500（定義） | −0.140 |
| v30 α1 | **PASS 5.3**（m2@44・m5@7 が 2σ超え） | 0.325 reject（40局screen） | **−0.047** |
| v30 distill0.5 | **PASS 5.0**（m5@7 が 2σ超え） | **0.509**（800局・CI[0.476,0.542]・Elo+6.1） | −0.106 |

m4@2 のコーチ点はどの腕も 0.00（選択がイワンコフのまま＝バンド不合格）。動いたのは
value の連続量であって離散選択ではない。「あと一歩で符号が反転する」状態。

## 3. 読み

1. **特徴は効いている**。過去 3 手法（v24 因果ラベル・v25 密再生成・v26 ε強制）が m4@2 の
   value を 1ミリも動かせなかったのに対し、v7 は 66% 詰めた。**representation-bound は
   表現の追加で緩む**ことを実証。「効果の有無を実測で見せる」という設計判断が正しかった。
2. **value 回帰では符号反転に届かない**。教師は平均勝敗（z）で、m4@2 のように 2 つの子が
   僅差で拮抗する点では回帰の勾配が弱い。v26 原因分析 §3 が予告した通り、**条件付き対比**
   （この局面では A&S&L > イワンコフ）を直接教える**ペア順位損失**（v12.1 機構）が符号反転
   には要る。値回帰は「近づける」ことはできるが「順位を確定する」教師ではない。
3. **標的解決とアリーナ健全性は直交して交換される**（distill 掃引で連続確認）。v27/v28 で
   見た「コーチ↔アリーナ」の緊張が、value レベルでも同じ形。distill0.5 が交換の中で最も
   バランスした点（アリーナ中立を保ちつつコーチ +0.4）。

## 4. 選択肢（判断はユーザと）

- **(A) distill0.5 を gen10 として採用**: アリーナ中立（0.509・退行なし）＋コーチ +0.4＋
  v7 オプション特徴を搭載（将来のペア順位学習の土台）。ただし m4@2 は未解決で、
  decide が +77%（309→546ms・1秒予算内）。gen9 と同じユーザ判断採用の性格。
- **(B) ペア順位損失でもう一段（推奨・標的直撃）**: v7 コーパスの防御/選択窓で状態を clone し
  「イワンコフ出し」と「A&S&L 出し」の両子を同一世界で終局まで打ち、**同一グループ ID の
  順位損失**（v12.1 の実装済み機構）で「A&S&L > イワンコフ」を直接教える。value 回帰より
  順位確定に強い＝m4@2 の符号反転を最も狙える。v26 §3 の設計そのもの。
- **(C) α 補間**（v28 方式）: α1 と gen9 の中間で「m4@2 の前進を最大化しつつアリーナ中立」の
  点を掃引。安価だが (A) の distill と本質的に同じ交換曲線上の探索。

推奨は **(A) で v7 特徴を土台として確定（アリーナ中立なのでロールバック不要の純増）→
(B) で標的を直撃**。value 回帰の限界（§3-2）は今回はっきりしたので、次は順位教師へ。
