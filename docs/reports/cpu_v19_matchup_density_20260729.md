# v19 — 対面特化の密ラベルで gen7 超え（800局 0.570・確証つき2連続の前進・2026-07-29）

v17 で「汎用分布の密度は1周で回収済み」と確定した後、**未踏の分布＝ユーザ実デッキの固定対面**
（ナミ vs シャンクス・`user_decks_20260728.json`）へ v16 の密ラベル機構を当てた。
**汎用アリーナで gen7 に +49 Elo（PASS）**＝密度仮説の適用先を「分布の新しさ」で選ぶ方針が
2連続で当たった。スナップショット（追記・改変しない）。

## 1. 方法

- 生成: `dense_selfplay_gen --matchup nami:shanks`（新オプション・`_W["game"]` の new_game 差し替え
  のみ＝生成コア無改修・seed偶奇で席入替）。gen7 自己対戦 **1,536局 → 197,683行**
  （129 行/局・q_root 有限率 1.00）
- 学習: gen7 + 1エポック（lr2e-4・混合ラベル＋残りターン補助・policy凍結）。
  train 0.159 / val 0.165（汎用コーパスより高め＝この対面は難しい局面が多い）
- 判定: 較正済み `arena_gate`（対 gen7・汎用デッキ・seed帯 650000〜）＋ コーチゲート v2 ＋
  アンカー（対 gen5）。撤退基準は事前宣言（汎用 CI下限 < 0.47 で棄却）

## 3. 読み

1. **効くのは「密度そのもの」ではなく「密度 × 分布の新しさ」**。v17（同分布2周目）は +21 Elo
   （未確証）で頭打ち、v19（新分布1周目）は +49 Elo（確証）。次の周回も「まだ踏んでいない分布」
   から選ぶべき（例: 他の対面ペア・ユーザ実デッキ vs 多様リーダー）
2. VERIFIED v2 の改善はカウンター較正系に集中し、展開系（イワンコフ/クマシー）とリーダー付与系は
   未解決のまま残った。これらは value 較正だけでは動かない可能性（policy prior が候補を沈めている）
3. ガード m2@12 の反転（守るべき所で守らない）は「カウンターを切りすぎ→切らなすぎ」への
   全体シフトの兆候。振り子の監視点として次周回でも必ず見る
