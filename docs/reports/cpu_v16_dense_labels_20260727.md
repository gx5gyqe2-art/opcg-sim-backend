# v16 総括 — 密ラベル復元で gen6 超え（800局 0.571・確証つき）と判定器の較正（2026-07-27）

v11〜v15 で12方式を棄却した後に残った構造仮説「**教師密度**」を、v15 §3 の測定方針
（800局・帯層別・計器較正を先に）で検証した。**gen6 採用以降で初めて確証を通った前進**。
スナップショット（追記・改変しない）。

## 1. 仮説と根拠

教師密度は p3期 **102.9 点/局** → v9 レフェリー期 **2.52 点/局** と **40.8倍**崩壊していた。
gen2→gen5 の世代交代は増分 ≈197,600 行の密レジームの上で起きたが、gen6 は 10,159 行の
疎レジームで採用され、以後の12方式（v9〜v15・計1.6万行規模）はすべて**この未検証領域の外**で
棄却されていた。

## 2. 方法（計器3本・いずれも既存経路無改修）

| 計器 | 内容 |
|---|---|
| `dense_selfplay_gen.py` | p3 生成コアを gen6 固定で駆動し**全決定点**の (z, q_root, turns_left) を採取。**2,048局 → 236,387行**（116 行/局・q_root 有限率 1.00・ev5・sims160）。閉ループにしない（v7 の機序を再演しないため） |
| `dense_finetune.py` | 混合ラベル y=0.5·z+0.5·q_root ＋残りターン補助（v4/v5 本走と同一仕様）で gen6 value を追い学習。**policy は凍結**（v12 確定）。1ep 33秒: train 0.094 / val 0.098（過適合なし） |
| `arena_gate.py` | 48ペア一次スクリーン → **400ペア=800局・4帯**（seed 帯を10万ずつ分離）。PASS = 勝率 ≥0.55 **かつ**ペア水準95%CI下限 >0.50 |

## 3. 計器較正が偽陽性バグを検出（本判定の前）

ヌル対照（gen6 vs gen6・80局）が **wr=1.000 CI[1,1] PASS** を返した。原因は `_play_pair` の
ペア勝ち数（0..2）を [0,1] 前提の `_pair_level_ci` へ未正規化で渡していたこと＝**五分の候補が
必ず PASS する**判定器だった。帯表示（2×局数で除算）は正しく総合だけが壊れており、帯の数字を
見ているだけでは気づけない。`normalize_pairs` を切り出して修正・回帰テスト追加。

    修正前  gen6 vs gen6: 総合 40.0/80 → wr=1.000 PASS（偽陽性）
    修正後  同一 seed    : 総合 40.0/80 → wr=0.500 FAIL（正）

**以下の判定はすべて修正後の計器によるもの。**

## 4. 結果

### 本判定（ep1 候補 vs gen6・800局・修正済み計器）

| 帯 | 局数 | 勝率 |
|---|---|---|
| band0 | 200 | 0.555 |
| band1 | 200 | 0.600 |
| band2 | 200 | 0.560 |
| band3 | 200 | 0.570 |
| **通算** | **800** | **457/800 = 0.5713 · CI[0.540, 0.603] · Elo +50 → PASS** |

帯間差 0.045。**4帯すべてが単独でも 0.55 以上**＝v15 の「1帯だけ跳ねて確証で消える」
（帯間 0.442〜0.583）とは形が異なる。事前宣言の撤退基準（800局 wr<0.52 で密度仮説も棄却）に
該当せず、仮説は支持された。

- 一次スクリーン: ep1 0.562/96局 → 確証帯 0.725/0.600（計176局 0.608）
- ep3（3エポック版）もスクリーン通過（0.637/80）＝1エポックで十分・学習量に頑健
- **アンカー（対 gen5・200局）: 110/200 = 0.550**（両帯 0.550）＝非退行 ≥0.5 を満たす。
  gen6 にだけ強い血統過適合ではない

### コーチゲート: FAIL（2.4 vs gen6 3.8）— ただし読み方に注意

退行 @33 1.0→0.4／@64 0.8→0.0／@137 1.0→0.0、改善 @82 0→1.0。

VERIFIED 7点の採録注記を読み直すと、7点は**同一対局 g3 由来の混成標本**だった:
- **勝ち局面**: @33（全攻撃 8/8 勝ち・4手同価値）・@68（正味+3 断定）・@64（薄差 +1）
- **飽和負け局面**: @93（1/6）・@115（1/8）・@137（**1/16** の捲り筋のみ・他0勝）

飽和負け側では勝敗ラベルに正解情報がほぼ無く（どの手でも z=−1）、正解は 1/16 級の細い捲り筋。
密ラベルはまさに「この局面は負け」と value を較正する教師なので、**捲り筋への忠実度と実戦勝率の
間には本物の緊張がある**＝アリーナ↑・コーチ↓が同時に起きた機序として整合する（ユーザ指摘
2026-07-27 を実測で裏取り）。@33 は accept 集合の閉世界問題（検証済み4手以外にも勝つ手があり得る）
も併記する。

**判定方針**: 一次判定は較正済み800局アリーナ（本報告の形）。コーチゲートは**合否ゲートから
診断計器に降格**（どの決定が変わったかを見るレンズ）。後continuation候補として「対面固定 CRN ペアの
**変換率**」計器（両ネットが不利側を持ち、同じ不利スタートを何回勝ちへ変換したか）を記録しておく
—「惜しさ」（ライフ差・粘りターン数）は強さと単調でないため主指標にしない。

## 5. 結論

1. **密度仮説は支持された**。変更は教師の作り方のみ（採掘1.6万決定点 → 全決定点23.6万行）。
   ネット構造・探索・policy・学習仕様（v4/v5 と同一）は不変で、gen2→gen5 を支えたレジームへの
   回帰だけで +50 Elo 相当が出た
2. 候補 = gen6 + 密コーパス1エポック（33秒）。**採用（gen7 同梱・既定切替）はユーザ判断待ち**
3. 「1.6万規模で12方式全滅」の正しい読みは「**教師の質より量（密度）が律速だった**」

## 6. 教訓

1. **測定の前に計器を較正する**。ヌル対照が fail-open バグ（五分でも必ず PASS）を本判定の前に
   検出した。v15 の教訓（検定力）に続き、今回は正しさそのもの
2. 洗練された教師12方式（1.6万行）より、素朴な教師の23.6万行が勝った。**次の一手を選ぶときは
   「何を教えるか」の前に「どれだけ教えるか」が復元されているかを確認する**
3. 7点の局所忠実度と全体強度は乖離しうる。乖離したときは**標本の性格**（勝ち局面か飽和負けか・
   単一対局由来か）を先に確認する
