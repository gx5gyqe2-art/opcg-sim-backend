# T133: `Θ` が席ごとに別の式だった——1 つにした（2026-09-20）

ユーザ提案「**一旦各指標を構成するパラメータを一つづつ丁寧に比較しましょうか**」
（同じ盤面を見ているはずの `Θ` と `A` が、要素ごとに何を読んでいるかを突き合わせる）。

**器**: `crossing_bridge.threshold_parts_side` ＋ `THETA_SIDE_MODE`（`legacy`／`symmetric`）。
`--theta-side`（交点の橋・帳簿）。テスト 86 → 91 本。
**記録**: 実 = `w41`（300 局）／合成 = `w39 + w42`（900 局）。

---

## 0. 結論（先に書く）

1. **欠陥は実在した**——**`Θ` は席ごとに別の式で計算されていた**:

   | | 相手の耐久 `threshold_parts` | 自分の耐久 `threshold_of_me` |
   |---|---|---|
   | ライフ | `λ × 枚数` | `λ × 枚数` |
   | **手札** | **規則が強いる守りで実際に吸える額**（`cuttable_forced`・T100） | **`g × 枚数`** |
   | 体 | アクティブなブロッカー | アクティブなブロッカー |

   **同じ「手札」という要素に 2 つの違う式**が当たっていた。
   **T79 で「1 行の器を完全情報で対称にする」と書いたのに、この項だけ対称になっていなかった。**
2. **実際に効いていた**——実記録 1,522 行（120 局）で:
   **差が出た行 23.1%**・**その行で `Θ_自分` は 13.0% 小さくなる**（最大 −0.190）・全行平均 **−1.6%**。
   **向きは「従来は自分の耐久を過大に見ていた」**（規則が強いる守りで実際に吸える額は枚数 × 平均より少ない）。
3. **直した**（新定数ゼロ・新しい量ゼロ）——**同じ式を鏡に当てるだけ**。
   鏡にするとき入れ替わるのは **5 つ**（全部既にある量）: ライフ・手札の枚数・場の枠・
   **守らされる攻撃**（`own_attackers_of` ↔ `opp_attackers_of`）・**吸う側のブロッカー**。
4. **測った結果は「害が無く、少し良い」**:

   | | 実 | 合成 |
   |---|---|---|
   | 未決着帯 AUC（`rel_flat`） | 0.9384 → **0.9384**（不変） | 0.9462 → **0.9462**（不変） |
   | 同（`rel_K`＝法則の腕） | 0.7446 → **0.7726** | 0.8517 → **0.8586** |
   | 較正 `sep`（`rel_K`） | 0.5652 → 0.4447 | 0.6399 → 0.6361 |
   | **交点の橋（4 指標）** | **完全に不変** | **完全に不変** |

   **交点の橋が動かないのは正しい**——橋の `theory` の読みは**各席の行からその席の相手の `Θ`** を
   `threshold_parts` で読むので**もともと対称**だった。**非対称は 1 行の帳簿の側だけに在った。**
5. **採否の推薦: 採る**。**理由は数字ではなく「1 つの量に 2 つの式がある」ことが欠陥だから**
   ——数字は「害が無い」ことを示しているにすぎない（`rel_flat` 不変・`rel_K` は両記録で改善）。

## 1. 突き合わせ表（本 T の出発点）

**記録が持っている要素**を符号化の定義から出し、**`Θ` と `A` がそれぞれ何を読んでいるか**を並べた:

| ゲームの要素 | `Θ`（的の遠さ） | `A`（削る速さ） | 判定 |
|---|---|---|---|
| 相手のライフ | `λ × 枚数` | 効果の条件としてのみ | — |
| **自分のライフ** | `λ × 枚数` | **見ていない**（受ける費用が定数） | **⚠️ ③** |
| 手札の枚数 | ✓ | ✓（出せる体） | — |
| **手札のカウンター値** | 「切れるか否か」だけ | ✗ | **⚠️ ④** |
| 手札の出す価値 | ✗（既定では平均 `μ`） | ✓ | ⚠️ ④ |
| 場・アクティブなブロッカー | ✓ | ✗（切替はオフ） | 意図的（T129 で二重計上を確認） |
| 場・レストの体 | ✗（避けて通れる） | ✗（殴れない） | 一致 |
| 場・殴れる体 | ✗ | ✓ | 一致（役割が違う） |
| ドン | ✓（守りに払える分） | ✓（財布） | — |
| **山札の中身** | **✗** | **✓**（毎ターンの流入・効果） | **⚠️ ②** |
| トラッシュ | ✗ | ✗ | — |
| ターン番号 | 窓の上限経由で間接的 | ✓（ドンの列・初手の規則） | — |

**見つかった穴 4 つ**（本 T は ① を閉じる）:

* **① `Θ` の式が席で違う**（本 T）
* **② 山札を `A` だけが見ている**——**自分がこれから引く札は速さに入るのに、
  相手がこれから引く札は耐久に入らない**（切替 `RACE_MODE=net/deck` は在るがオフ・T103／T104 で単独では悪化）
* **③ 受ける費用が自分のライフを見ていない**——`theta_take(ライフ)` は**在って**線形の橋・守りの規則・
  実現の帳簿では使われているのに、**交点の橋の `A` だけが定数を渡している**。
  既定（`lethal`）では**ライフ 0 のときだけ値が変わる**ので、**`A` は「これが通れば勝ち」を一度も見ていない**
  ＝**T117（とどめの規則の的中 0.23）と同じ患部**。
* **④ カウンター値と「出したい度」をどちらも使っていない**（T130 で測った量・実記録では効くが合成では効かない）

**負け方の但し書き**: 負け方は 2 つ（ライフ 0・**山札切れ**）で、エンジンは両方持つが
**理論はライフ 0 しか持たない**。ただし**計算で確かめた**——自席ターン平均 6.7・長くて 9 前後、
引く枚数は初手 5 ＋ 毎ターン 1 ＋ ライフ最大 5 で **20 枚前後**、デッキは 50 枚。
**今の記録では絶対に起きない**＝いま直す穴ではなく**範囲の但し書き**。

## 2. 検算の立て方を 2 回間違えた（記録として残す）

**最初に書いた不変量**: 「**左右対称の盤面なら両席の `Θ` は等しい**」。
**これでは差を検出できない**——左右対称でライフに余裕があると、
**リーダーの攻撃は超過 0 で「1 枚で止まる」**ので `hand_absorb_forced` の `c_eff` が 1.0 になり、
**`μ × 枚数` に戻って従来の式と一致してしまう**。

**2 回目**: 守りを強いられる盤面（本数 > ライフ ＋ ブロッカー）にした。**まだ 0 だった**
——**テスト環境の `CBAR_MODE` は `loose`** で `c_of(1000) = 1.0`（出荷は `strict` で 1.28）。
**盤面の選び方が環境の設定に依存していた。**

**3 回目で通った**: **守りを強いられる ＋ 体が 10000**（超過 5000 → どちらのモードでも `c > 1`）。

> **教訓**: **不変量を書くときは「差が出る条件」まで書く。**
> 「破れるはず」と思って書いたテストが通ってしまったら、**式ではなく盤面を疑う。**
> **両方のテストを残した**——「この盤面では従来でも破れない」も、**なぜ最初の設計が外したか**の記録になる。

## 4. 上手くいったこと／いかなかったこと

**上手くいった**:
* **ユーザの提案どおり要素を 1 つずつ並べたら、1 つ目で欠陥が出た**。
  **「同じ盤面を見ているはず」という制約を検算に使う**のは、今日 4 回外した「機構の推測」と違い、
  **測る前に当たり外れが決まっている**。
* **部品が全部在ることを先に確かめた**（`opp_attackers_of`／`_own_active_blockers`）ので、
  **新定数ゼロ・新しい量ゼロ**で直せた。
* **橋が動かないことを予測してから測り、そのとおりだった**（橋はもともと対称）
  ——**どこが影響を受けるかを先に特定できた。**
* **不変量が 2 回とも「通ってしまった」ときに、式ではなく盤面を疑った**（§2）。

**いかなかった／自己批判**:
* **不変量を「差が出る条件」を書かずに設計した**——1 回目は規則（リーダーの超過 0）、
  2 回目は**テスト環境の設定**（`CBAR_MODE=loose`）を見落とした。
  **テストが通ったことを一度「直った」と誤読しかけた。**
* **T79（1 行の器を対称にする）でこの項を見落としていた**。
  **「対称にした」と書いたときに、項ごとに確かめていなかった。**

## 5. ユーザ判断をお願いしたいこと

1. **`THETA_SIDE_MODE=symmetric` を既定にする**（推薦）。
   **理由は数字ではなく欠陥だから**——1 つの量に 2 つの式がある状態を残さない。
   **数字は害が無いことを示している**（`rel_flat` 不変・`rel_K` は両記録で改善・橋は完全に不変）。
2. **次は突き合わせ表の ③**（推薦）——**受ける費用が自分のライフを見ていない**。
   **`theta_take` は既に在り、他の 3 つの器では使われている**ので、**渡していないだけ**。
   **T117（とどめの規則）と同じ患部**なので、**2 つまとめて片付く見込み**。
3. ② と ④ はその後（②は T103／T104 の再測定が要る・④は T130 で「規則から書ける入れ方が無い」と確定済み）。
