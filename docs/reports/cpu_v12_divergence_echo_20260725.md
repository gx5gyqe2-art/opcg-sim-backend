# v12 実験報告 — 乖離診断とエコー教師の発見（2026-07-25）

gen6 採用後、**どんな微調整でも実戦力が上がらない**現象の原因を特定し、対策（対戦相手混合）を
配備するまでの記録。スナップショット（追記・改変しない）。

## 1. 出発点 — コーチ↔アリーナの乖離

v11 で「コーチゲート PASS（4.4 vs 3.8＝歴代最高プロファイル）なのにアリーナ 9/24 で敗退」を初観測。
v12 で教師プールを拡大して再挑戦したが 10/24 で再敗退。**マークのスコアと実戦力が逆行**していた。

## 2. 計器の新設 — divergence_probe

「候補は実戦のどこで gen6 より悪い手を打つのか」を直接測るため、既存基盤（記録対戦・真盤面復元・
プラン列挙レフェリー）を組み合わせた読み取り専用プローブを実装（`tests/scripts/divergence_probe.py`）。

1. **記録対戦**: candidate vs gen6 を同 seed・席入替・decide rng 隔離で録画
2. **分岐点採掘**: 候補が負けた対局の候補手番を真盤面再生し、候補と gen6 に**同条件で decide させて**
   equiv キーが割れた点を検出
3. **裁定**: 乖離点をレフェリー（gen5 錨・プラン列挙＋CRN 実測勝率）で判定し
   cand_bad / best_bad / both_ok / both_out に分類
4. **カタログ化**: cand_bad の行動種遷移と局面相（early/mid/late）を集計

### 初回計測（8局・乖離11点）
cand_bad 5 / best_bad 2 ＝ **分岐点の質の差がアリーナ負けの実体**であることを確認。
cand_bad の 4/5 が中終盤に集中し、内容は「@93 で教えた展開を攻めるべき場面で誤発動」
「@82 で教えたカウンター温存を守るべき場面で誤発動」＝**マークの教訓の文脈外適用**。

## 3. 乖離点の教師化とその失敗

裁定済み乖離点は band-top（正解集合）まで計算済みなので、そのまま教師化できる
（`--out` で kind='diverge' バッチ・学習側は `--extra-dirs` / `--diverge-weight`）。
候補自身の失敗分布から採った文脈つき反例＝過般化の直接矯正を狙った。

| 条件 | コーチ | アリーナ stage1 |
|---|---|---|
| プール単独（対照） | 2.4 | 10/24 = 0.417 |
| ＋乖離教師 35点×16 | 3.8 | 8/24 = 0.333 |
| ＋乖離教師 70点×8 | 3.0 | 9/24 = 0.375 |

**線量を倍にしても改善せず**。乖離教師そのものは正しい情報だが、実戦力を動かさなかった。

## 4. 決定的な観察 — 0.38±0.04 への収束

v11/v12 の全候補の対 gen6 アリーナ成績:

    0.333 / 0.375 / 0.375 / 0.417 / 0.417   （レシピ・線量・教師種を問わず）

コーチスコアは 2.4〜4.4 まで大きく振れるのに、**アリーナは常に 0.38 付近**。
さらに同一レシピ（sd0.9/dw2）がプール 12.6k では 4.2 PASS、13.4k では 2.4 FAIL と反転しており、
**マーク側の成績はプール構成に敏感なノイズ、実戦側は頑健に劣位**という非対称が確定した。

## 5. 仮説 — エコー教師（自己対戦バブル）

gen6 採用後、教師は **gen6 同士の自己対戦**からしか採れていない＝gen6 の均衡分布の内側のデータ。
そこからの微調整は「均衡からの漂流」にしかならず、評価の土俵（対 gen6 アリーナ＝まさに gen6 の
分布）では構造的に不利になる。gen5→gen6 が成功したのは、v10 の特徴拡張が**分布外の情報**
（相手盤面の脅威集約）を与えたからであり、データ量ではなく情報の出どころが効いていた。

この仮説は上記の全観察と整合する:
- レシピ/線量/教師種に不感（＝どれも分布内の操作）
- コーチだけ動く（＝マーク7点はプール構成で暗記できる）
- 乖離教師も効かない（＝候補の失敗も gen6 の均衡内で起きている）

## 6. 対策 — エコー破り（対戦相手混合）

`referee_labeler --opp-mix`（既定 `self:0.5,gen5:0.3,l1:0.2`）を実装・既定ON。
生成対局の相手種を seed 決定論で混合し、**gen5（旧世代）・L1（α-β）という異質な相手**との
対局から教師を採る＝gen6 の均衡の外の局面を教材にする。

- `record_mixed_descriptor`: rng 隔離・記述子形式は既存と同一（scripted 再生は記録が正＝
  相手種は再生可能性に影響しない）
- meta に `opp_mix` を記録＝バッチの出自を後から追跡可能（新旧の分離集計に使用）
- 既定ONのためワーカーは `git pull` だけで移行（20バッチサイクルで自動追従・実測で確認）

## 7. 現状と判定計画

- **gen6 は据え置き**（v12 でも採用候補なし）
- 混合教師の蓄積が進行中（2026-07-25 05:57 時点 593点・5枝稼働）
- **本判定**: 混合教師 1,000点超で再学習し、アリーナが 0.38±0.04 の壁を越えるかを見る
  - 越えれば: エコー仮説の実証＋gen7 への道。以後は混合比の調整が主ノブになる
  - 越えなければ: 「新しい目（特徴拡張）」路線へ軸足を戻す（v10 の成功パターンの再現）

## 8. 教訓

1. **同じ結果が範囲内で収束したら、それはノイズでなく制約**。0.38±0.04 の5連続は
   「レシピを回す」フェーズの終了信号だった
2. **指標の非対称に注目する**: コーチが振れてアリーナが動かない＝コーチ側が暗記可能に
   なっていた（マーク特化の過適合）。ゲートを複数持つ設計が救った
3. **失敗した対策（乖離教師）も計器としては資産**: divergence_probe は候補の悪癖カタログを
   作れる唯一の道具として今後も使う（教師化は既定OFF＝`--out` 指定時のみ）
