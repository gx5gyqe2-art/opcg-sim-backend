# ドンの会計——**「余らせている」は計器の誤りだった。CPU はドンを使い切っている**

2026-09-14 実施・判定（ユーザ指示「進めてください」＝T17 の着手）。
**T17 に着手する前の下見で前提そのものが崩れた**ので、T17 は形を変え、**T10 が先に閉じた**。
同じ 300 局（seed 帯 9700〜9999・生成役 r3・`synth`・3,739 自席ターン）。
本報告は特定時点のスナップショット（追記・改変しない）。

## 結論を 3 行で

1. **`don_idle` は誤りだった**——`ATTACH_DON` は**選ばれた手として一度も現れない**
   （300 局 約 1.9 万手で 0 件）ので、`don − ATTACH_DON の行数 − PLAY のコスト` という再構成は
   **付与を丸ごと落としていた**。**真値は 0.51 個／ターン**で、再構成は **2.07**（4 倍）。
2. **CPU はドンを余らせていない**——**76.9% のターンでアクティブなドンを使い切っている**。
   波 32 で報告した「2.32 個余らせる・**77.1% のターン**」は、
   **偶然ちょうど裏返しの意味の数字**（真値は「0 個のターンが 76.9%」）。
3. **よって `δ` 過大請求の仮説は動機を失う**——ドンは余っておらず**希少**なので、
   `δ = 0.0277` を「平均的な限界価値」として使う根拠は弱まらない。
   **過払いの説明は「CPU が払い過ぎている」側に寄り、反事実の優先度が上がる**。

## 1. 何が起きていたか——**巨視手が中の原始手を隠す**（3 度目）

`attack_budget.py` の `don_idle = max(0, don − don_attached − don_plays)` の `don_attached` は
**`ATTACH_DON` の行数**だった。打たれた手の種類を数えると:

| 選ばれた手 | 件数 |
|---|---|
| **`DON_BOX`** | **10,540** |
| `TURN_END` | 3,439 |
| `PLAY` | 2,945 |
| `ACTIVATE_MAIN` | 932 |
| `RESOLVE_EFFECT_SELECTION` | 813 |
| `KEEP_HAND` / `MULLIGAN` | 336 / 264 |
| **`ATTACH_DON`** | **0** |

**`ATTACH_DON` は 1 件も無い**。付与は**全部 `DON_BOX`（巨視手）の中で起きる**ので、
引き算の項が常に 0 になり、**乗せたドンが「余らせたドン」として計上されていた**。

> **これは同じ罠の 3 度目**である:
> 1. **`ATTACK` も記録に無い**（攻撃は `DON_BOX` で届く）＝1b の数字が無効になった（§7.3）。
> 2. **`don_k` は `pol_k` に在った**のに「無い」と報告した（§7.3 訂正 1）。
> 3. **`ATTACH_DON` も記録に無い**（本件）。
>
> **教訓は毎回同じ**——`DON_BOX` は「k 個乗せてから T を殴る」を束ねた**巨視手**で、
> **中の原始手は行として現れない**。そして今回の直し方がいちばん確かである:
> **状態が答えを持っているものを、行動の再構成で出さない**。

## 4. 帰結——**`δ` は擁護され、疑いは CPU の側へ移る**

`2026-09-14_bodyless_and_power.md` は「`δ` の 13% 過大が過払いの正体」と書き、根拠は
**「CPU はドンを 2.32 個余らせている＝余っているなら 1 個の機会費用は平均より低い」**だった。
**この根拠は消えた**。ドンは 76.9% のターンで使い切られる**希少な資源**なので、
**`δ = 0.0277` を平均的な限界価値として請求することは擁護される**。

逆算した `δ`（上 2 帯で 0.0242／0.0245）**自体は依然として事実**だが、
**「なぜ低いのか」の説明が無くなった**＝**過払いの説明として残る候補は**:

| 候補 | 状態 |
|---|---|
| **CPU が払い過ぎている** | **最有力に昇格**（`δ` の説明が落ちたので） |
| `ν` が最弱帯で過小 | 開いたまま（実測 0.0690 は CI が 0 を含まない＝下限は立っている） |
| 登場時の利得の取り残し | **項を足す検定は反証力が無い**（同報告 §3） |
| `δ` が希少性で上がる（**逆向き**） | **新しく生まれた**——拘束条件なら影の価格は平均より**高い**。だとすると過払いは**さらに大きい** |

> **反事実の封鎖が解けた**。同報告は「反事実は `δ` を直した後」と書いたが、
> **`δ` を直す必要が無くなった**＝**反事実（理論が純損と言う手を禁じて勝率を見る）が最優先**。

## 限界

- **波 32 を再計算していない**（dump が残っていない）＝訂正の大きさは本 300 局の値。
  式が同じなので**誤りの向きは同じ**だが、波 32 の正しい値は不明。
- **`don_unaccounted` −0.08** の内訳は追っていない（ターン中のドン獲得と
  【起動メイン】のコストの差し引き）。
- **最後の main 行**を「ターンの終わり」と読んでいる。300 件（各局 1 件）は決着の攻撃で
  終わっており、そのターンは「余り」の意味が違う（もう次が無い）。
- ドンの余りが**少ない**ことは「攻めが上手い」ことを意味しない——
  `force_gap` は 4.83（`force_actual` 2.40 対 `force_max` 7.23）で、
  **殴っていないターンが 27.7%**・攻撃回数は 1.36/2.10。**取り逃がしは攻撃の側に在る**。
- 1 設定・1 ネット（r3）・生成時の探索（Dirichlet 雑音と温度が乗っている）。
