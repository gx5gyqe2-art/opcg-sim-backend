# T137b: 2 本の曲線の 3 指標——増分の一致・局面別の距離・終点の比（2026-09-23）

T137a（`two_curves.py`）が作った局×席の累積系列 `G(t)`／`R(t)` から、**曲線が重なっているか**を
実際に測る。器は `tests/scripts/two_curves_metrics.py`（新規）・`tests/test_two_curves_metrics.py`
（新規・11 本）。**記録は読まない**——T137a の `--dump` が書いた JSON を読むだけ。

**記録**: 実 = `w41`（300 局・600 席・行 3,847）／合成 = `w39 + w42`（900 局・1800 席・行 11,086）。

## 0. 結論（先に書く）

1. **増分の一致**（`ΔG_j` 対 `ΔR_j`・`j` は自席ターン番号）:

   | | 実 | 合成 |
   |---|---|---|
   | 相関（生） | **0.6419** | **0.6730** |
   | 相関（`j` の影を抜いた） | 0.3513 | 0.3748 |
   | 回帰の傾き | 0.4998 | 0.5811 |

   **予告は半分外れた**——「1 手ごとの相関（T84・0.535／0.554）とおおむね同じ水準になるはず」と
   書いたが、**生の相関はそれより高く**（0.64／0.67）、**`j` の影を抜くとそれより低くなる**
   （0.35／0.37）。**ターンにまとめると相関が上がるのはノイズの相殺**（1 ターンに複数の決定行が
   あれば個々の誤差が均される）が、**その上がり分の大半は「ターンが進むほど両方大きくなる」という
   共通のトレンドで説明できる**（`j` を抜くと元の水準を下回る）——**増分そのものの結びつきは
   1 手ごとの結びつきより弱い**、というのが正しい読み。
2. **局面別の距離が終盤ほど開く**（予告どおり）:

   | 帯 | 実 | 合成 |
   |---|---|---|
   | 0-2（序盤） | **0.1125** | **0.0823** |
   | 3-5（中盤） | 0.4822 | 0.2758 |
   | 6+（終盤） | **0.7764** | **0.4561** |

   **両記録とも単調に増える**——序盤の 7〜8 倍まで開く。T107（`A` の終盤の過大）と整合的。
3. **終点の比 `ΣG/ΣR` は理論が実現を上回る**（両記録・全四分位で 1 を超える）:

   | | 実 | 合成 |
   |---|---|---|
   | 平均 | **1.666** | **1.352** |
   | 中央値 | 1.597 | 1.306 |
   | 第 1 四分位 | 1.366 | 1.084 |
   | 第 3 四分位 | 1.876 | 1.558 |

   **方向・大きさとも T89（`A` は 1.20〜1.26 倍過大）と整合**。実の方が合成より過大の度合いが大きい
   （1.60 対 1.31・中央値）。
4. **型別の相関**（1 ターンぶんの `ΔG_族` を `ΔR` と突き合わせる）:

   | 族 | 実（n・相関） | 合成（n・相関） |
   |---|---|---|
   | **attack** | 3,170・**0.817** | 8,965・**0.813** |
   | play | 2,660・0.249 | 7,120・0.212 |
   | effect | 1,282・−0.098 | 2,354・0.016 |
   | end（常に 0） | 3,547・`None` | 10,186・`None` |
   | attach（帳簿でゼロ化・T85） | 1,802・`None` | 4,894・`None` |

   **T81（相関 0.36 の中身は型・攻撃が信号・効果は実デッキで逆相関）と一致**。**攻撃の理論値は実現と
   強く結びつく**（0.81〜0.82）が、**出す手（`play`）は弱く**（0.21〜0.25）、**効果はほぼ無相関**
   （−0.10〜+0.02）。

## 1. 上手くいったこと／いかなかったこと

**上手くいった**:
* **予告を書いてから測り、1 つ当たり 1 つ外れたのをその場で判定できた**——局面別の距離は的中、
  増分の相関は「ターンにまとめても情報は増えない」という予告の**理由付けの方**が外れていた
  （実際には増える。ただし増えた分の大半は交絡＝ターン数の共通トレンド）。
* **既存の道具（`rate_tracking.corr`／`demean_by`）をそのまま再利用**——新しい統計の式を作らずに
  T128 の道具で測れた（新定数ゼロの精神を統計処理にも及ぼした）。
* **型別の相関が T81 の結論と両記録で一致**——別の器（累積した曲線）で測り直しても、
  1 手ごとの器（T81）と同じ質的な順位（攻撃 > 出す手 > 効果）が出た＝**独立の追試として機能した**。
* **`end`／`attach` 族の相関が `None` になるのを「バグ」ではなく「設計どおり」と確認**——
  `TURN_END` は常に 0（`score_candidate` の定義）・`attach` は帳簿でゼロ化（T85）なので、
  定数列との相関は定義上取れない。事前にこの帰結を理解していたので、出力を見て慌てずに済んだ。

**いかなかった／自己批判**:
* **予告の理由付けが粗かった**——「1 手ごとの相関と同じ水準になるはず」の根拠を「情報は増えも
  減りもしない」とだけ書いたが、**ターン内の複数決定の和は分散を減らす（相関を上げうる）**という
  統計の基本を予告に織り込んでいなかった。**方向（相関が変わりうる）を先に書いておくべきだった。**
* **`increment_slope`（0.50／0.58）の読みをまだ書いていない**——傾き 1 からの乖離が何を意味するか
  （T89 の 1.2〜1.3 倍とどう関係するか）は次の T で扱う。本 T では算術の結果として出しただけ。
