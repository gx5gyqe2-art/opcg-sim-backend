## 1. 式（測る前に書いた）

### 1.1 問い

理論の守る側の計算（`defender.rs`）は、守り手が地平 `H`（平均 4〜5 段）の全部を見通して最善に守ると置く。最善の比べ方は
**防いだ本数（地平の全部の和）が多い → 切る札が少ない → 生き延びる段が長い → 段ごとの損害が小さい** の順（`better`）。
実際の守り手（CPU）がこれより**先を読まずに札を早く切る**なら、地平を生き延びると言う時計（`S` ≥ 1/2）に残る遅れ
（終わりの検算の主の組で差し引いた後 実 +0.94・合成 +1.19 ターン）は理論の誤りではなく守り手の打ち筋の写しのはず。

### 1.2 比べる 2 つの極（選び方の入らないもの）

- **(A) 今の理論**: 地平 `H` の全部を見通す最善（`defender.rs` そのまま）。
- **(B) 目先だけの最善**: **守り手は判断のたびに今のターン（段）だけを最善に守り、先の段は考えない**。
  比べ方は A と同じ（防いだ本数 → 切る札 → 生き延びる → 損害）を**今の段の中だけ**で読む＝**地平 1 の守る側の計算**。同じ値段・同じ入力・同じ偶然の分岐。
- **間の地平**: 「段 `t` の判断で、段 `t` から `k` 段だけ読む」守り手（`k` = 2, 3）。**記述として表に並べるだけで、判定には使わない**
  （記録から先読みの長さを選ぶと当てはめになる）。`k = 1` が B、`k ≥ H` が A。

### 1.3 先読み `k` の守り手の値（地平 `H` の全部を、その守り手が打つとして値付けする）

状態 `σ`（段 `t`・残りの攻撃・手札・ブロッカー・ドン・ライフ）で、`V*_c(σ)` を「地平 `c` 段までの最善の値」（A の動的計画を地平 `c` で解いた値・
比べ方は `better`）とする。先読み `k` の守り手の方策の値 `V^k(σ)` は:

- 攻撃 `x` に対する応え `r`（受ける〔偶然の分岐: 受けたライフの札〕／横取り／カウンターの札の組）の**選び方**:
  `r*(σ, x) = argbest_r  V*_{min(t+k, H)}( σ の r の後 )`（同じ比べ方・候補を試す順も `defender.rs` と同じ）。
- **値**: `V^k(σ, x) = V^k( σ の r* の後 )`（選んだ応えのその後も同じ守り手として、地平 `H` まで）。損害の足し方
  （受けた 1 本 `λ_net`・切った札 `μ`・倒されたブロッカー `ν`・とどめ `(λ − λ_net)·L0 + ν`）は A と同じ。
- **攻め手の順**: 攻め手は `V^k` を最小にする攻撃から宣言する（完全情報の攻め手は守り手の打ち筋を知っている。A と同じ比べ方）。
  守り手が先読みの中で想定する攻め手は最善の順（`V*` の中の攻め手）。
- 段の終わり（ブロッカーが戻る・ドンが満ちる・1 枚引く偶然の分岐）は A と同じ。
- 出力は A と同じ形: 段ごとの損害 `harms^k`・切る札の期待 `cut^k`・耐久 `θ^k = λ·L0 + μ·cut^k + ν_all`。

`k ≥ H` なら `V^k = V*_H`（**A とビットで同じ**であることを 10 局で確かめる）。**新定数ゼロ**（`k` は 2 つの極を名指すだけ）。

### 1.4 B の時計（守り手を B の札の使い方で読み替えた時計）

同じ計画（攻め手の出す札・付与・攻撃の並び・地平 `H`）のまま、守る側の計算だけを B で解き直す:

- 歩きの段の値: 地平の内の段 `j`（守る側の計算の段）では `sched^B_j = sched_j − harms^A_j + harms^B_j`（流入・効果・地平の外の `fb` は今のまま。
  `no_now` の計画の段 1 は今と同じく 0）。
- 耐久: `θ^B = θ − θ^A_DP + θ^B_DP`（`θ_DP` は守る側の計算の `λ·L0 + μ·cut + ν_all`。差は `μ·(cut^B − cut^A)`）。
- 時計 `τ^B` = 今の時計と同じ歩き（`m2probe::walk`＝`drv_cb::m2_clock` が `tau_walk` を出す歩き・上限 30）。

`τ^B` は**実際の攻撃を入れない**（予告として使える読み）。`k` = 2, 3 も同じ作り方（記述だけ）。

### 1.5 終わりの検算の物差し（`completion_check.py` の主の組と同じ）

勝った席の時計（自席ターンの頭の行・計画あり・ライフ 1 以上）について:

- 残る遅れ `r_int = max(1, ⌈min(τ, 30)⌉) − act`。
- 説明される遅れ `δ = E / s`: `E = (実際に窓の内で受けた本数 − 守り手のモデルが同じ窓・**実際の攻撃**で受ける本数) · λ`（窓 `W = min(H, act)`・とどめを含む）・
  `s` = 交点の段の歩きの段の値（床以下なら次の正の段・無ければ `θ/τ`）。
- 差し引いた後 `r'_int = max(1, ⌈min(τ − δ, 30)⌉) − act`。
- **A の組**: `τ = τ^A`（今の時計）・モデルの守り手 = A（`completion_check` の主の組そのもの。実 +0.937・合成 +1.192 を再現することを確かめる）。
- **B の組**: `τ = τ^B`・モデルの守り手 = B（実際の攻撃を入れて B で解いた窓の内の本数）・`s` は B の時計の段の値。

**後知恵**: `δ` は実際の攻撃を入れる（後知恵）ので「説明」には使えるが「予告」ではない。`τ^B` そのもの（差し引く前）は予告として読める。

### 1.6 打ち方の比べ（ターンごと）

自席ターンの頭の行ごと（攻め手の席・その行の守る側の計算の入力 `din`＝**その時の実際の盤面と守り手の手札**）に、**そのターンの実際の攻撃**
（リーダーへの攻撃の超過）を今の段の攻撃に入れて:

- A: 地平 `H` の守る側の計算の段 1 の「受けた本数（とどめを含む）」と「切った札」（`survival_split` の `now_act` と同じ作り方）。
- B: 地平 1 の守る側の計算の同じ 2 つ。`k` = 2, 3 は地平 `k`（記述だけ）。
- 実際: 受けた本数＝ライフの減り（決着したターンはライフ ＋ 1）・切った札＝**リーダーへの攻撃に対して出したカウンター**
  （`SELECT_COUNTER` の行を、そのターンの直前の攻撃の対象で振り分ける。守る側の計算はリーダーへの攻撃しか見ないので、
  キャラクターへの攻撃に切った札は比べない）。全部のカウンター（`completion_check` の数え方）も並べる。
- 対象のターン: 守り手のライフ 1 以上・命中する（超過 ≥ −ε）リーダーへの攻撃が 1 本以上・観測が揃う。ライフ 0 のターンは別に数だけ書く。
- 帯: その行の時計が地平を生き延びると言う（`S` ≥ 1/2）か否か。時計ごと（勝った席の時計の段 1..act の和）も並べる。

## 2. 合格の基準（測る前に書いた・**判定の閾であって式の定数ではない**——式には入らず、合否を読むためだけに使う）

1. **打ち方（先読みが浅いか）**: 両方の記録で、§1.6 のターンをまとめて
   (a) 切った札の平均の絶対差 `|実際 − B|` < `|実際 − A|`、かつ (b) 受けた本数の平均の絶対差 `|実際 − B|` ≤ `|実際 − A|`、かつ
   (c) `S` ≥ 1/2 の帯でも切った札の平均の絶対差が B < A。三つとも揃えば「先読みが浅い」。
2. **遅れの説明**: 両方の記録で、地平を生き延びると言う時計（`S` ≥ 1/2・A の時計で分けた同じ時計）の差し引いた後の残る遅れ `R` について
   (a) **消えた割合** `φ = (R_A − R_B) / R_A` ≥ 0.5、かつ (b) 勝った席の全部の時計の差し引いた後の偏りの絶対値が B で A より 0.1 を超えて悪くならない
   （遅れを別の時計へ移しただけでないこと）。
3. **結論の読み**: 1 と 2 が両方の記録で揃えば「残りの芯は守り手の先読みの浅さ＝理論の外（§8.5）」。揃わなければ、どれが外れたかと何が残るかを書く。
   `k` = 2, 3 の数は判定に使わない。

**予告**【推測・測る前】: B は今の段で防げるだけ防ぐので、切った札は A より多く、受けた本数は A より少ない（実際の守り手と同じ向き）＝1 の (a) は通る見込み。
ただし B は先の段の札を残さないので地平の内の損害が増え、時計は早くなる——`S` ≥ 1/2 の時計の遅れは縮むが、`S` < 1/2 の時計（今でも差し引くと
ほぼ 0〜やや早い）はさらに早くなる。よって 2 の (b) が外れる見込みが 5 割前後。
