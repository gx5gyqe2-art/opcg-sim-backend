## 3. 読み方

- **式の側の修正で実測に乗った**（ユーザの指摘どおり）。`ko_p` は 1 ターンの危険率なので打ち筋への依存は「生きたターン数」より弱い。
- **帳簿は両記録で同じ向きに改善**し、登場の価格の穴（0.62／0.66）が主にこれで埋まった。T59 で「KO は `ν` の穴」と読んだのも確認できた。
- **`ΔS` は元々無関係で、`geo` でも無関係**。向きが 2 記録で揃って下がるのは、`ν` を下げると行内の最善が「出す」から「殴る」へ寄り、
  記録の CPU が出している行を逸脱と数えるため。行内の順序に効かせるなら別の要因（T1〜T3 の `θ` 対 `Q`）で見る。
- 大きい体の重みが実測より高く残る（1.80 対 1.50）のは `ko_p_of` の山形（KO 効果だけ）と退場（戦闘を含む）の差＝次の穴の候補。
