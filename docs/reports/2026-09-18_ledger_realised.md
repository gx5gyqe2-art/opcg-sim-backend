## 1. 問い（T86 の結論）

守りの窓の `g` は「**理論の価格** − **実際の支払い**」という**2 つの別の物差しの差**なので、どちらの誤差も `g` に入る。
実測でも、両側の数え方を揃えてなお**価格は実際の支払いより 3〜5 割大きく、攻撃の本数とともに開いた**
（1 本 0.071 対 0.079 ≒ 釣り合う／5 本 0.289 対 0.224）。機構は T64（**守り手は手札の一番安い札から切る**）。

## 2. 式（新定数ゼロ）

```
LEDGER_HARM_MODE = realised
  攻めの行の g = realised_harm(この行, 同じ席の次の行)
               = attack_response.parts の {相手ライフ, 相手手札, 相手の体} の和
               = **crossing_bridge.harm_of と同じ式**（交点の橋が F を積むのに使っているもの）
  守りの窓の g = 0          （移転は攻め手の行に 1 回だけ・窓は `s`〔取りこぼし〕専任）
  決める価格 s = 理論の価格のまま（T58 の分離。`s` は「その局面で最善だったか」なので実現では書けない）
```

**ターン末で区間が閉じない行**（次の同席の行が次のターン）は 0 にして数だけ残す（`harm_unbracketed`）。

## 3. 予告した検算（測る前に書いた）

## 6. 読み方

- **上手くいった 1: 尺度がはっきり直った**。必要な `κ` は 0.509 → **0.782／0.877**、**接戦帯では 1.297／1.156**
  （1 を挟んだ）。`ΔG` の傾きも 0.186 → 0.296／0.255 → 0.354 で**これまでの最大**。
  **帳簿の膨らみ（T85 以来の「2 倍」）は、守りの窓を帳簿から外すことでほぼ解消した**。
- **上手くいった 2: 2 つの橋が同じ物を数えるようになった**（帳簿＝`F` の式）＝§0.1 が求める整合が 1 段進んだ。
- **上手くいった 3: 二重計上だけを止める形（守り 0）は相関を損なわない**（0.538 → 0.533／0.558 → 0.554）のに
  **尺度を 3 分の 1 直す**（0.509 → 0.602／0.508 → 0.597）＝**副作用のいちばん小さい直し**。
- **上手くいかなかった 1: 接戦帯の `ΔG` AUC が落ちる**（0.658 → 0.526（守り 0）→ 0.475（実現）・
  合成 0.568 → 0.508 → 0.503）。**守りの窓の `g` が接戦帯の順序付けを運んでいた**。
  ただし**それは価格ではなく「下手に守った量」**（`g_delta ≤ 0` の一方向の量＝**取りこぼしそのもの**）なので、
  **`s` に属する情報が `g` に混ざっていた**と読むのが素直。混ざっていたぶんが接戦帯の当たりだった。
- **上手くいかなかった 2: 実現で書くと効果の型が実デッキで強く逆相関になる**（−0.127 → **−0.487**・`κ` −1.571）。
  効果の行に**その後に起きたこと全部**が乗るので、**負けている席が効果を連打する**ぶんが素直に入る（選択交絡）。
  価格で書いていたときは −0.127 だったので、**この逆相関は実現側の属性**。次の T の材料。
- **予告 2 の外れが教えたこと**: **理論は攻撃 1 本を 2 割ほど過小に見ている**（実現 0.1403 対 価格 0.1158）。
  T61 の「価格／実現 1.19／1.34」は**集計（型ごとの和）の比**で、**行ごとの実効値では逆**だった＝
  どちらも事実で、**平均は価格が大きく、散らばりは実現が大きい**（トリガー・ブロックの有無で実現が振れる）。

## 7. 次（ユーザ判定）

1. **既定をどうするか**（本報告の判定事項）。3 つの形の性質:
   - **価格（旧既定）**: 相関は最良（0.538／0.558）・接戦帯の `ΔG` も最良（0.658／0.568）だが**尺度が半分**（`κ` 0.51）で、
     **守りの窓に二重計上が残る**（T86 で確認済み）。
   - **守り 0**（推し）: **相関はほぼ同じ**（0.533／0.554）・**尺度は 3 分の 1 直る**（`κ` 0.60）・
     **二重計上は消える**（`s` は従来どおり守りの取りこぼしを測る）。費用は接戦帯の `ΔG`（0.658 → 0.526）。
   - **実現**: 尺度は最良（`κ` 0.78／0.88・傾き 0.30／0.35）・**2 つの橋が同じ物**・合成の相関は最良だが
     **実の相関が落ち**、効果の型が実デッキで強く逆相関。
   **私の推しは `guard-g zero`**（正しさ＝二重計上を止める・相関を損なわない・尺度が改善）で、
   **実現は「橋の統合」として価値があるので切替として残す**。
2. **接戦帯の `ΔG` を取り戻す**——守りの取りこぼしは `s` に在るので、**接戦帯の順序付けは `s` 側で読む**か、
   `κ` の形（T80 の階段）で読み直す。
3. **効果の型**（実現で −0.487・価格で −0.127）を種類別に割る（T81 §5 の 2・まだ未着手）。
4. 速さ `A`（残り 3）。

## 限界

- 実現の損害は**その行と同じ席の次の行の差**で読む＝**ターン末の行は区間が閉じない**（1,780 行は 0 にした）。

- 効果の行の実現には**その後に起きたこと全部**が乗る（選択交絡・上記）。
- `s`（決める価格）は 3 つの規約すべてで理論の価格のまま＝**取りこぼしの測定は変えていない**。
- `κ` は `curve`（T75・既定）。**規約を変えると `κ` の分母 `w̄` も動く**（同じコミットで比較しているので条件は揃っている）。
- **観察であって因果ではない**。
