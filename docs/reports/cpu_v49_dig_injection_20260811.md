## 3. トリレンマ（本レポートの主結論）

50ペア・本体 value 微調整の枠内では:
1. **エネル掘りの獲得**（受け>無行動）— 買える（B/F・防御無傷）
2. **漏れ抑制**（見送りペアが必要）— 買うと防御較正が壊れる（C/D/G）
3. **ナミ逆裁定**（同カード逆ラベル対照）— さらに壊れる（E）

両立には (a) 教師の桁増し（他デッキの人間対局＝無料の正解ラベル。h1 一局の費用対効果は
実証済み）、または (b) 出口ヘッド型の較正分離（効果使用の判断を防御較正から物理的に
分ける）が必要。**シーソー干渉（v7）の再演**であり、裁定のたびにゲートへ点を足す運用
（今回 h1@2/h1@35 追加）で揺れを検出可能にしておく。

## 4. サトリ移植プローブ（ユーザ発案・裁定 2026-08-11）

ナミのデッキにサトリを移植した turn 1 合成盤面で「経済に紐づいたか」を検査する常設計器。
**ユーザ裁定: ドン再装填のないリーダーでは出さない（TURN_END）が正解**。

発見: **gen13 は元々順序が逆**（ナミ +0.12 で掘る / エネル +0.011 で掘らない）。B腕は
順序を修正（エネル +0.41 > ナミ +0.30）したが絶対水準はカード特徴経由で漏れる。v9 特徴の
アブレーション（ドンデッキ残をゼロ化してもマージン不変）で、**少データ注入はドン経済で
なく転移しやすいカード/文脈特徴に紐づく**ことを直接確認した。
