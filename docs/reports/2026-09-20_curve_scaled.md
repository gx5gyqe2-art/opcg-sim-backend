## 1. 式（新定数ゼロ・橋に既にあった形を 1 行の器へ）

**`curve_scaled` は交点の橋に前から在った**（`SLOPES` の変種）。1 行の器には入っていなかった:

```
τ = 輪郭 prof を Θ に届くまで積む。ただし 1 ターンの損害を **その席の速さで伸縮する**:
    h_k = prof[j+k] × scale        scale = A_seat / prof_th[j]
prof_th = **理論の速さの輪郭**（自席ターン j ごとの `slope_theory` の平均）
```

**新定数ゼロ**——`prof` と `prof_th` は**同じ run の同じ表**から書き写す（`harm_profile()` の 1 本目と 2 本目）。
**`cross` の規約も同じ**（測る記録と別のセットの表を使う・§0.1 条件 1）。

**予想（測る前に書いた）**: 輪郭は**比 `prof/prof_th`（無次元）**としてしか入らず**単位は `A` が持つ**ので、
**通貨の付け替えに対して不変になるはず**（T122 の P5 が `curve` で 96.2% 破れていた患部）。
**単一の局面では実際に不変だった**（通貨 ×3 で `D` が 2.05395 のまま）。**記録全体では破れた**（§3）。

## 3. 代償（採れない理由）

### 3.1 判別（未決着帯＝最後の自席ターンを外した帯）

| 腕 | 実 `curve` | 実 `curve_scaled` | 合成 `curve` | 合成 `curve_scaled` |
|---|---|---|---|---|
| `rel_flat` | **0.9384** | 0.6595 | **0.9462** | 0.8171 |
| `rel_K` | 0.7446 | 0.4804 | 0.8517 | 0.5784 |
| `abs_flat`（対照・読みに依らない） | 0.800 | 0.800 | 0.8628 | 0.8628 |

**`rel_K` は実で 0.48＝コインを下回る。** `abs_flat` が両方で同じなのは読みを使わない腕だから
（＝母数と物差しが同じであることの検算）。

### 3.2 較正（当てはめゼロ）

`sep`（理想 1.05）は **0.5652 → −0.1303**＝**符号が反転**した。
`ΔW` の帳簿として**向きごと壊れている**ので、較正の側でも採れない。

### 3.3 不変量

| | `curve` | `curve_scaled` |
|---|---|---|
| **P5**（通貨 ×3・打ち切り以外の破れ／19,803 行） | 19,051 | **6,429** |
| **P7**（両席の `A` ×1.3・同） | **0** | **17,940** |

**P5 は改善したが直っていない**（96.2% → 32.5%）。**P7 は自明に満たしていた状態から 90.6% の破れへ**。

**理由**: 輪郭は**絶対のターン番号で索引されている**。速さを c 倍すると**何ターンで届くかが変わる**ので、
**索引が指す値も変わる**——つまり伸縮と歩数は**可換でない**。
**`curve` で P7 が 0 だったのは満たしていたからではなく、`A` が時計に 1 度も入っていなかったから**。

### 3.4 端の欠陥（実在したが主因ではない）

`prof_th[0] = 0.0`——**`RATE_T1_MODE=on`（最初の自席ターンは 1 本も打てない規則）**なので、
**そこに「典型の速さ」は存在しない**。にもかかわらず分母に使っていたため床 `1e-3` で割ることになり:

* 倍率の分布: 中央 0.676・**99% 点 55.10・最大 55.1**（`j=0` の行が 4.3%）
* **時計が 200 ターンの打ち切りに貼り付いた行 5.0%**

**規則どおり「速さが定義される最初のターン」まで進めて割るよう直した**（新定数ゼロ）。
**が、AUC は 0.6587 → 0.6595 しか動かない**＝**端の欠陥は主因ではなかった**。

## 4. 何が分かったか（次の道）

**`curve_scaled` は `curve` と `clock` を連続につなぐ道**である——倍率が 1 に近ければ `curve`、
倍率が効くほど `Θ/(A·定数)` すなわち `clock` に近づく。**だから `clock` の弱さを引き継ぐ**。

**そして P5／P7 が直らない理由が、`curve` を良い時計にしている当のものだった**:

> **輪郭の加速は「絶対のターン番号の表」から来ている。** 表が良い時計を作るが、
> **表は状態を見ていない**ので速さの軸が無く、**索引が絶対なので尺度不変にもならない。**
> **この 2 つは同じ 1 つの性質の裏表で、伸縮では分離できない。**

**両方を得る道は 1 つしかない**——**加速を表からではなく状態から出す**。
**それは既に在る**: **T94 の「積み上がる歩き」**（`RATE_WALK_MODE=grow`・`R_j = 盤面 ＋ 在庫·[j≥2] ＋ 流入·(j−1)`）
で、**盤面が育つから速くなる**という形。これは `theory` の読みが使っていて、**`curve` は使っていない**。

**次の一手（推薦）: 1 行の器の読みを `theory`（積み上がる歩き）にして、同じ 4 つの物差しで測る。**
**`curve` の輪郭を捨てる**ことになるので、**T75 以来の「輪郭が最良の時計」という前提を測り直すことになる**。

## 5. 上手くいったこと／いかなかったこと

**上手くいった**:
* **橋に既に在った形を探してから作った**（`curve_scaled` は新発明ではない）。
* **測る前に「P5 が直るはず」と書き、単一局面で確かめてから記録全体で測った**ので、
  **どこで予想が外れたか**（単一局面では不変・記録全体では破れ）が特定できた。
* **端の欠陥を見つけて直し、それでも動かないことを確かめた**ので、
  **「端のせいではなく構造」と言い切れる**。
* **`abs_flat` が両読みで完全に同じ**＝母数と物差しが揃っていることの検算になった。

**いかなかった／自己批判**:
* **「無次元の比としてしか入らないから尺度不変になる」という論証が甘かった**。
  **輪郭が絶対のターン番号で索引されている**ことを式に入れていなかった。
  **単一の局面で確かめて満足し、記録全体で測る前に確信を書いた**。
* **T125 で「規則だから足していい とは限らない」と学んだ直後に、同じ型の早合点をした**
  （今回は「無次元だから不変」）。**不変量は 1 点ではなく母数で確かめる**。
* **`prof_th[0] = 0` を分母にした**のは設計時に気づけたはず（規則としてそこに速さが無いのは既知）。
