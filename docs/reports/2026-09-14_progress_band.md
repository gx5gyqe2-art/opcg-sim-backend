# 価格を縛るのは**デッキではなく進行**——ラベルを進行の変数で置き換えた

2026-09-14 実施・判定（ユーザ指摘「価格の考え方はデッキの中身でなくて進行により決まる。
デッキの進行方法がデッキにより特徴付けられているだけで、デッキ相性＝デッキの中身に
特徴付けられる進行という意味ではないのかな。デッキの中身はリーダー効果や色によって
縛られているので、それが出てくるのかな。こうすれば一般化できたりしない？」）。
**同日の `2026-09-14_real_decks.md` が残した疑いを、この指摘が解いた**。
合成 300 局・実デッキ 300 局。本報告は特定時点のスナップショット（追記・改変しない）。

## 結論を 3 行で

1. **指摘は正しく、実装より一段いい定式化だった**——同日の私の対処（デッキのラベルで帯を切る）は
   **一般化しない**（未見のデッキを値付けできない）うえ、**原因とラベルを取り違えていた**。
2. **進行の変数で置き換えると、デッキラベルの効果の大半が再現する**——
   実デッキの上 2 帯で **0.1112／0.1270 対 ラベルの 0.1143／0.1193**（ほぼ一致）。
   しかも**落ちる行が少ない**（14% 対 31%）。
3. **副産物が本報告で一番大きい**——**`ν` の実測に付いた疑いが晴れた**。
   合成側の「0.2112 → 0.1115」は**交絡の除去ではなく標本の脱落**だった。

## 1. 何が誤りだったか

同日 `real_decks.md` は、実デッキで弱い体の価格が **−0.0346**（CI が 0 を含まない）と出たのを
**デッキ相性の交絡**と診断し、**デッキの型（`deck_*` の argmax）を帯に足した**。

**診断は当たっていたが、対処が筋悪だった**:

- **一般化しない**——ラベルで縛ると、**未見のデッキには値段が付かない**。
- **原因とラベルの取り違え**——デッキが価格を決めているのではなく、
  **デッキが取りやすい進行**が決めている。デッキは**代理変数**にすぎない。

**そして本書 §17.1（通貨 → 時計 → 勝率）は既にそう言っていた**——
**進行とは 2 本の時計そのもの**である。**帯は進行の変数で切るべきだった。**

## 2. 進行の変数で置き換える

`progress_key = (相手の場の体数, 自分のドン, 自リーダーのパワー)` を粗く取った
（3 変数・24 セル）。**自分の場の体数は入れない**（説明変数なので帯に入れられない）。
自リーダーのパワーは**リーダー効果と色の代理**である。

### 2.1 進行はラベルを再現する（上 2 帯）

実デッキの上 2 帯で **`progress` は `deck` とほぼ同じ値**に着く（0.1112／0.1270 対 0.1143／0.1193）。
**落ちる行は 14% だけ**（ラベルは 31%）。
＝**デッキのラベルが持っていた情報は、進行の変数で取れる**。

**リーダー未満の帯でも負が消える**（−0.0346 → −0.0227・**CI が 0 を含むようになる**）。
ただし**ラベル（+0.0178）ほどは戻らない**——§4 参照。

### 2.2 **`ν` の実測に付いた疑いが晴れた**（本報告で一番重い）

`real_decks.md` は「**合成側でも飽和超えが 0.2112 → 0.1115 と CI 外まで動く**＝
同日の `ν` の実測（#39 の検算の土台）に疑いが付いた」と記録し、
**交絡の除去なのか標本の脱落なのか分離できない**として判定を保留した。

**進行で切ると分離できる**:

| 合成・飽和超え | 値 | 行数 |
|---|---|---|
| `state` | 0.2112 [0.175, 0.247] | 3,516 |
| `deck`（ラベル） | 0.1115 [0.053, 0.170] | 1,257（**−64%**） |
| **`progress`** | **0.2045** [0.164, 0.245] | 2,893（−18%） |

**進行で縛っても水準は動かない**（0.2112 → 0.2045・CI は大きく重なる）。
**ラベルのときだけ動いたのは、行が 64% 落ちたから**である。

> **＝合成の `ν`（0.0690／0.1503／0.2112）は進行の統制を通る。**
> **#39 の検算（飽和超えのずれが −0.0252 → +0.0074）の土台は保たれた。**

## 3. なぜこれが「一般化」なのか

進行の変数はデッキの中身を参照しない＝**未見のデッキにも同じ値付けが効く**。
`game_theory.md` §17.1 の枠と一致する:

```
price(X) = w(進行) · [ 時計の差分 ]
```

**`w` は進行の関数**であり、デッキの関数ではない。デッキは
**「取りやすい進行」を通じてしか価格に触れない**（リーダー効果と色が進行を縛る）。
**だから帯は進行で切るのが正しく、デッキで切るのは代理でしかない。**

## 4. 残ったこと——**弱い体の帯だけ、進行で取り切れない**

実デッキのリーダー未満で、`progress` は −0.0227・`deck` は +0.0178 と**まだ差がある**。
進行の 3 変数（相手の場・ドン・リーダーのパワー）が**この帯で取り逃がしている構造**が在る。

**候補**:

- **進行の変数が粗すぎる**（24 セル対ラベルの 36 セル）。
- **時計そのものを使っていない**——今の 3 変数は時計の**代理**であって、
  `T_me`／`T_opp` の推定値ではない。§17.1 の枠に忠実に作るなら**時計を直接推定して帯にする**べき。
- **弱い体の使い道がデッキで違う**（サーチャー／壁／捨て駒）＝
  「その後どうなるか」は今の状態変数に出ていない。

**＝次は進行の型を「2 本の時計の推定値」で作り直す**（§17.1 の `T_me`・`T_opp`）。

## 5. 判定

| 問い | 答え |
|---|---|
| 価格はデッキで決まるか、進行で決まるか | **進行**——ラベルの効果は進行の変数で再現する |
| デッキラベルで帯を切るのは正しいか | **代理としてのみ**。一般化しないので本筋ではない |
| 合成の `ν` の実測は信じてよいか | **よい**——進行で縛っても動かない（ラベルのときの移動は標本の脱落） |
| 実デッキの「弱い体は有害」は | **交絡**。進行で縛れば CI が 0 を含む |
| 進行で完全に取り切れたか | **いいえ**——弱い体の帯に残差。**時計を直接推定する**のが次 |

## 限界

- **進行の型は 3 変数の粗い代理**（相手の場・ドン・自リーダー）。§17.1 の時計そのものではない。
- **`deck_progress` は行が落ちすぎる**（合成 442 行）＝両方入れた読みは信用しない。
- **観察された傾きであって因果ではない**（全ての `ν` 実測と同じ）。
- 実デッキの生成役 r3 は**合成デッキで学習している**＝分布外の疑いは残る（未分離）。
- 各 300 局・1 設定。
