# T45——「ドンを付けて殴る」を `ν` の攻撃項に入れた: **リーダー未満の帯が合成で実測に届いた（0.97）**

2026-09-16 実施（ユーザ提案「ドンを振った場合に相手に与える圧力から使用コストを差し引いて計算する」・
方針変更「先に (2) を詰める」）。**新しい定数はゼロ**——`δ`（ドン 1 個の実測の価格 0.0277）を代替価値として引く。
本報告は特定時点のスナップショット。

## 式

```
攻撃 1 回（ドン付き） = max_k [ min( c(x + 1000k)·μ , Θ·μ ) − k·δ ]       k = 0 … 10・x = パワー − 相手リーダー
ν の攻撃の流量       = 上の値 × R                                          （`attack_stream` の `lead`・相手キャラ狙いも同じ形）
```

`δ` は「ドンを 1 個余分に持つと勝率がどれだけ上がるか」の実測＝**登場・他の体への付与を平均したドンの代替価値**。
盤面が判る文脈では T43 の貪欲配分（他の攻撃手との競合）がそのまま使える。`ATTACK_DON_MODE`（`don`／`bare`）で戻せる。

| 体（リーダー 5000） | 従来 | **ドン付き** |
|---|---|---|
| 4000（1000 低い） | 0 | **0.028**＝`c(0)·μ − δ`（1 枚付けて通す） |
| 3000（2000 低い） | 0 | 0（2 枚で `c(0)·μ − 2δ ≈ 0`） |
| 6000 以上 | `min(c(x)μ, Θμ)` | 同じ（素殴りが最善のまま） |

## 残り（中盤帯の 1.35 倍）

内訳は T44 のまま: 頭打ち ×1.10・率 ×1.12（**CPU の打ち筋＝式は動かさない・ユーザ決定**）・身代わりの上乗せ ×1.15。
**次はユーザ提案の後半＝相手キャラの価値（パワーの帯＋潜在効果）とブロックを `min` に入れる**——
リーダー攻撃の 1.5 倍（ブロック無し）とキャラ狙いの価値をまとめて扱う。

## 限界

- 帯の判定は「リーダー未満」を 1 つに束ねている——4000 と 3000 以下で式の値が 0.028 と 0 に分かれるので、
  帯の平均は体の分布に依る（合成 0.067・実デッキ 0.054 の差はそれ）。
- ドン付きの攻撃の率（毎ターン付けて殴るか）は率 1 のまま（(2) の方針どおり）。
- **観察であって因果ではない**。
