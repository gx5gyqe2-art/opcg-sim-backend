## 1. 問い（T94 の残り）

`grow` は **「出した体は死なない」**と数えていた（`R_j` が単調に増える）。実際は除去と戦闘で減る。
**`ko_p` は既に測ってある**（`theory_order.KO_P` = 0.289・T60 の `Σ(1−ko_p)^t` と同じ量）。

## 2. 式（新定数ゼロ）

```
R_j = リーダー                                     ← **KO されない**ので減衰しない（規則）
    + 盤面のキャラ·(1−ko_p)^(j−1)
    + 在庫·(1−ko_p)^(j−2)·[j ≥ 2]                  出したのは 1 ターン目＝j−2 ターン場に居た
    + 流入·Σ_{k=0}^{j−2} (1−ko_p)^k                i ターン目に引いた札は j で (j−1−i) ターンぶん減衰
```

**リーダーとキャラを分けたのが本 T の設計の要**（`theory_slope_parts`）——分けずに全部減衰させると
**速さが 0 に落ちる**が、規則上リーダーは必ず殴れる。流入の項は `流入 / ko_p` に**飽和**する
（盤面 5 枠という規則とも整合する）。

## 6. 読み方

- **いちばんの収穫は「向き」が確定したこと**。偏り +2.9 は**モデルが遅すぎる**という意味なので、
  **速さを下げる方向の手当ては全部逆効果**になる。**T95 は「やってみて逆だった」ではなく、
  「符号を考えれば先に分かったはず」の失敗**——次から**予告の符号を先に確かめる**。
- **残る偏りの容疑者は入れ替わる**。速さの側ではなく:
  1. **`Θ` が終盤に縮まない**（T89 で既に測っている——残りターンが 1〜2 の行でも τ は 5 ターン先を指す）。
     `Θ` の手札項・体の項が**終盤の実際の脆さ**を表していない。**こちらが第一容疑**。
  2. **効果の損害が速さに入っていない**（`A` は攻撃の価格だけ）。実測では効果の行も損害を出している。
- **`ko` で得たものはある**——**勝者の的中は両記録で微増**（0.6400 → 0.6451／0.6378 → 0.6397）し、
  **実の σ は 3.84 → 3.68**。**順序付け（どちらが勝つか）は良くなり、時刻は悪くなった**＝
  **減衰は「強さの比較」には効くが「いつ終わるか」には逆に効く**。
- **動く的（T91 の `deck`）と重ねると的中は実で 0.6580（歴代最良）**だが**偏りは +8.93**で、
  **合成では的中も 0.6206 に落ちる**＝**記録のセットで向きが割れるので採らない**。
- **既定は `off` 据え置き**。的中の +0.005／+0.002 は、偏り +0.84／+1.02 と MAE +23%／+29% の悪化に見合わない。

## 7. 次（ユーザ判定）

1. **`Θ` が終盤に縮まない件を直す**（最有力・T89 が測った穴・**速さではなく的の側**）——
   残りターンが 1〜2 の局面で `Θ` が過大なら、`τ` は必ず遠くを指す。**ライフが 1 枚のときの `Θ`**を

2. **効果の損害を速さに入れる**（1 と対）——`A` は攻撃の価格だけ。効果の行の実現は記録に在る。

## 限界

- **`ko_p` は 1 つの平均**（0.289）。パワー別の曲線（`KO_P_CURVE`・`ko_p_of`）は使っていない＝**体ごとの脆さの差は見ていない**。
- **`ko_p` は実測の量**（規則ではない）＝記録が変われば動きうる。ただし**既に測ってある量の再利用**で、
  本 T で新しく当てはめた数は無い。
- **在庫は「1 ターン目に全部出す」前提**（`(1−ko_p)^(j−2)`）。実際は何ターンかに分けて出す＝**減衰を過大に見る向き**。
- **リーダーが減衰しないのは規則どおり**だが、リーダーの攻撃価格そのものは相手の守りで変わる（T92 の限界のまま）。
- **`grow` ＋ `ko` は `theory` の読みだけを変える**。`curve`／`curve_scaled`／線形の橋は通らない。
