# P8-1/P8-2: 守る側の出来事は Rust を触らずに取れる——列の設計案（2026-09-24・実装前）

ユーザ指示「P8に行きましょうか」（T157 の後）。前回の絞り直し（`2026-09-24_p8_v5_design_update.md`）は
「守る側の枠ごとの被弾／ブロック／KO」を**Rust の変更**として残していた。実装前に取り場所を確かめた（P8-1）。

## P8-1 の結論: Rust は触らなくてよい

記録の台帳（`opcg_sim/loop/record_gen.py` の `_Recorder.post`）は、対局駆動（`driver.run_game`）が**適用した
全ての手**（守る側の `SELECT_BLOCKER`／`SELECT_COUNTER`／`PASS` を含む）と、**その直後の盤面**を 1 枚ずつ
積んでいる。守る側の出来事は全部ここから読める:

| 出来事 | 読み元（既に台帳に在る／1 行足す） |
|---|---|
| どの枠が狙われたか | 攻撃の手の `payload.target_ids`（`rules/legal.rs` の `ATTACK` の形）——**`step_record` が今は捨てている**ので 1 欄足す |
| どの枠がブロックしたか | 守る側の `SELECT_BLOCKER` の `card_uuid`（台帳の `uuid` に既に入っている） |
| カウンターを何枚切ったか | 守る側の `SELECT_COUNTER` の手の数（既に入っている） |
| 体が場から消えたか・いつ | `snapshot` の `field`（uuid の並び）を手ごとに比べる（既に入っている）——**uuid は対局中不変**なので枠 × カード番号の推定（`nu_stock` の限界）より正確 |
| 戦闘で落ちたか・効果で除かれたか | 消えた手が**その体を狙った攻撃の解決（守る側の `PASS`／カウンター）**なら戦闘、**相手の登場・起動・効果の対象選択**なら効果 |

エンジン（`rust/opcg_engine`）も パーサも触らない＝**`make audit-cross` は不要**・golden は動かない。
変わるのは `record_gen.py` の台帳と、npz に足す列だけ。

## P8-2: 列の案（`DUMP_VERSION = 5`）

`aux_tok`（相手の枠の攻撃活動）の**裏返し**として、行の視点席の**自分の 6 枠**（行の時点の自分のリーダー＋
場 5・並びは `aux_tok` と同じ流儀）を、**次の相手ターン**（`aux_tok` と同じ窓 A）について記録する:

```
aux_def [D, 6, 5]   列: targeted（狙われた回数）, blocked（ブロックに回った回数）,
                        life_lost（その枠が狙われた攻撃で失ったライフ・リーダー枠だけ非 0）,
                        ko_battle（戦闘で落ちた 0/1）, removed_effect（効果で場を離れた 0/1）
aux_def_row [D, 2]  列: counters_used（窓 A で自分が切ったカウンターの枚数）, blocks（ブロックの回数）
```

- **良し悪しは入れない**（`aux` と同じ規約・「起きたこと」だけ）。
- **訓練は読まない**——`dump_io` の読み込み列に足さない＝学習・ネット・生成の挙動は 1 bit も変わらない。
  理論の計器（`PL.iter_games` の `extra_fn`）だけが読む。
- **v4 の記録はそのまま読める**（列が無ければ `None`）。

### 検算（実装後に回す）

1. **同じ seed で打ち直した記録は、既存の列が 1 bit も変わらない**（生成は決定的＝w41 の 300 局を作り直して
   `tokens`・`pol_*`・`aux*` を突き合わせる）。変わったら台帳の変更が対局に漏れている。
2. **攻め側と守る側で同じ攻撃を両側から数えて合う**: 窓 A で相手の `aux_tok.attacked` の和 ≤ 自分の
   `aux_def.targeted` の和（1 枠が複数回攻撃すると `attacked` は 0/1 なので `≤`）・`aux_def.life_lost` の和 ≤
   `aux[:,0]`（ライフ回復で破れる既知の形と同じ向き）。
3. **消えた体は必ずどちらか 1 つ**（`ko_battle + removed_effect ≤ 1`）。

## 何に使うか（P8-7 で測る 3 つ）

- (a) T157 の大きい端: 在庫に**除去を引き受けた分**（相手が除去に払った札・ドン）を帰属させて在庫 ÷ `ν` を測り直す。
- (b) T139「全力で殴って負けた」行の守り手側の中身（ブロック・カウンターの枚数）。
- (c) 攻撃の行の残差 37.8%／38.9% を「相手の守りの答え」と「価格の誤り」に分ける。
