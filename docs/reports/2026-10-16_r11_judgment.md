## 0. まとめ（判定は書かない＝ユーザ判断）

4 条件のアリーナ（各 192 ペア＝384 局・void 0・重複 seed 0）で、**r11b も r11a も r3 に勝ち越した**。両候補とも主の CI 下限 > 0.50、副の CI 下限 ≥ 0.45【実行】。

| 候補 | 主（random × synth_roles・591000〜598000） | 副（固定ミラー・601000〜608000） |
|---|---|---|
| **r11b**（主候補・波 29／32 の全行に再分析を差し込み） | **0.573**（0.516〜0.629）・+51 Elo | **0.549**（0.502〜0.597）・+35 Elo |
| **r11a**（対照・再分析の 33,600 点だけ・方策の更新 4 倍） | **0.602**（0.546〜0.657）・+72 Elo | **0.563**（0.518〜0.607）・+44 Elo |

1. **予告との照合**:
   - 予告「r11b の主 0.52〜0.55・副 退行なし・r11a は r11b 以下」に対し、r11b の主は予告の上限を +0.023 上に外れた（0.573）。副は退行なしどころか勝ち越し（0.549）。
   - **r11a は r11b 以下の予告と向きが逆**（主 +0.029・副 +0.013 で r11a が上）。
   - ただし同じ seed のペアごとの差（r11a − r11b）は、主 +0.029（95% 区間 −0.023〜+0.081）・副 +0.013（−0.047〜+0.076）で、**どちらも 0 を跨ぐ**＝2 候補の差はこの局数では見分けられない【実行】。
2. **評価帯**（holdout・v_mse／方策の top1）: 波 30・32（r3 の訓練後の波）では、r11b・r11a とも r3 より良い。波 28（r3 の訓練範囲＝旧分布）では r3 より少し悪い（§2.3）。
3. **先例と比べると、1 回の 192 ペアは再現しないことがある**（r7 は +25 Elo → 高分解能で −4.5）。採否の前に、高分解能のアリーナで測り直すのが前例の手順（§3）。
4. **環境の注意**: 訓練に使った torch（2.14.1・CUDA 版の wheel・CPU で実行）では、torch と numpy の勾配の照合テストが落ちた（最大相対誤差 5.5e-3・許容 3.5e-3・§2.5）。

### 2.5 環境【実行】

- 訓練は torch 2.14.1（`+cu130`・CUDA 版の wheel を CPU で実行）。CPU 版の配布元がプロキシで拒否され（403）、既定の配布元の版が入った。
- この torch で `tests/test_n_rel_train_torch.py::test_grads_match_numpy` が落ちた。torch と numpy の勾配の最大相対誤差は 5.5e-3（摂動 1e-6）。許容（丸めの下限 7.0e-4 の 5 倍＝3.5e-3）をわずかに超える。
- このコンテナには以前 torch が無く、このテストは skip だった。訓練の後に torch を外し、`make test` は green（836 passed・12 skipped）。
- 誤差の大きさは小さいが、r11b・r11a はこの torch で訓練したネットである。

## 3. 読み【推測】

**r11a（深い教師だけ・33,600 点）が r11b（元の記録の π を 2 波ぶん混ぜた）より強く見える理由の候補**（断定しない・ペアの差は 0 を跨ぐ）:
- (a) **元の記録の π が薄めている**: r11b の方策点の大半（2 波の main 約 78 万点）は 160 sims の訪問で、深い教師の点は約 4%。深い教師の効き目が浅い教師に埋もれる。
- (b) **方策の更新量 4 倍の効果**: r11a は `--pi-steps-mult 4`。教師の中身ではなく、方策を何度も更新したことが効いている可能性。
- (c) value の差: r11a は value を 6 波（27〜32）で学び、波 29・32 の z も r11b より多い。評価帯の v_mse も r11a が少し良い。

(a) と (b) を分けるには、「r11b に `--pi-steps-mult` を付けた版」か「r11a を 1 倍で回した版」が要る。

**先例との比較**:
- r4q（同じ式・160 sims の教師）0.518（不採用）。
- r5 の高分解能アリーナ +3.5 Elo（2,798 ペア）。
- r7 は 192 ペアで +25 Elo、高分解能で −4.5 Elo＝**1 回の 192 ペアは再現しなかった前例**。
- r11 の +51／+72 Elo は先例より大きいが、1 回の 192 ペアであることは同じ。CLAUDE.md の規約（1 本の測定は昇格の証拠にならない）どおり、採否の前に再測定が要る。
