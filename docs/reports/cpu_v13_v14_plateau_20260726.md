# v13/v14 総括 — gen6 の踊り場は本物（容量・探索設定の否定）2026-07-26

v12 補遺（policy 微調整が犯人）の後、残る構造要因を**容量**と**探索設定**の2方向から潰した記録。
いずれも否定され、gen6 が現アーキテクチャ＋現教師ストリームでの到達点であることが確定した。
スナップショット（追記・改変しない）。

## 1. v13 容量実験 — 「ラベルへの当てはまり」と「実戦力」の非相関を実証

ネット容量は gen2 以来据え置き（hidden=256・23万パラメータ）だったため、蓄積コーパス
（root 16,426／子盤面 33,622）に対して器が小さい可能性を検証。

| 項目 | gen6 | scratch(hidden=512・39.6万) |
|---|---|---|
| held-out root MAE | 0.338 | **0.242**（−28%） |
| held-out corr | 0.823 | **0.881** |
| コーチゲート | 3.8 | 2.6 |
| **アリーナ80局** | — | **34/80 = 0.425** |

**予測精度を大幅に改善しても実戦は動かない**（0.425＝微調整族と同じ帯）。
訓練 mse 0.033 / val 0.145 と強く過適合しており、「狭い教師分布での精密化」が
探索の踏む分布での質に転化していないことを示す。**容量不足は棄却**。

## 2. v14 探索設定 A/B — 全つまみが無効

ネット固定（gen6）で serve の探索設定だけを変え、CRN ペア（同 seed・席入替）で対戦。
`LearnedEngine` に sims/c_puct/root_frac/root_gap のエンジン別上書きを追加（既定 None で挙動不変）。

| 条件 | 局数 | 勝率 | 95%CI |
|---|---|---|---|
| null（同一設定） | 12 | 0.500 | — （計器サニティ） |
| sims 320（思考2倍） | 60 | 0.533 | [0.407, 0.660] |
| root_gap=inf（Q乗り換え無効） | 60 | 0.500 | [0.373, 0.627] |
| c_puct 2.5 | 60 | 0.417 | [0.292, 0.541] |
| c_puct 1.0 | 60 | 0.550 | [0.424, 0.676] |
| c_puct 0.5 | 60 | 0.450 | [0.324, 0.576] |
| c_puct 0.75 | 60 | 0.567 | [0.441, 0.692] |
| **c_puct 0.75（確証・新帯）** | **120** | **0.458** | **[0.369, 0.547]** |

一次スイープで「c_puct 0.75〜1.0 に頂点の山型」が見え、独立2帯で再現したように見えたが、
**新帯120局の確証で 0.458**。プール（0.75 の全180局）= 89/180 = **0.494**＝実質 0.5。
小標本の多重比較によるノイズだった。**探索設定は棄却**（sims 倍増も有意差なし）。

## 4. 残る唯一の構造的説明 — 訓練分布のカバー範囲

- 教師は「採掘された決定点」1.6万点のみ。MCTS は探索中に**その外側の無数の葉**を評価する
- v12.1 で子盤面の順位を教えると順位正答は 0.45→0.63 に上がったが実戦は不変
  ＝**教えた場所では直るが、探索が踏む場所は相変わらず未較正**
- v13 の過適合はこれを補強（狭い分布の精密化 ≠ 広い分布での質）
