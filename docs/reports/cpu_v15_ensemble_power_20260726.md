# v15 総括 — アンサンブルの棄却と「アリーナ判定の検定力不足」の発見（2026-07-26）

v13/v14（容量・探索設定の否定）の後に残った安価な2手を検証し、いずれも棄却。
同時に**本セッションの判定手続き自体に検定力不足があった**ことを定量し、今後の測定方針を改める。
スナップショット（追記・改変しない）。

## 1. 検証した2手

### A. value アンサンブル（学習不要・`tests/scripts/ensemble_probe.py`）
gen6（実戦較正・held-out MAE 0.338）と scratch512（教師精密・MAE 0.250）の予測を重み平均して
葉評価に使う。診断で判明した弱点（**兄弟子盤面の順位判断が5割前後＝評価のばらつき**）に対し、
ばらつき低減の標準手段として機構的に的を射ている。policy prior・探索・root 読み出しは不変。

| 帯 | 局数 | 勝率 |
|---|---|---|
| 帯1（探索） | 60 | 0.533 |
| 帯2（確証） | 120 | 0.583 |
| 帯3（決着） | 120 | **0.442** |
| **通算** | **300** | **155/300 = 0.517 ± 0.029（CI [0.460, 0.573]）** |

**棄却**。帯2で 0.583 まで伸びて有望に見えたが、独立帯で 0.442。通算では 0.5 と区別できない。
（副次的観察: scratch512 単体は 0.367 と gen6 より明確に弱いのに混合すると 0.5 付近まで戻る＝
アンサンブル効果自体は働いているが、gen6 を**超える**には至らない。）

### B. 正則化（早期停止）スクラッチ
v13 の scratch は train mse 0.033 / val 0.145 と極端な過適合だったため、5エポック版
（train 0.096 / val 0.154・held-out MAE 0.250＝20ep 版とほぼ同等）で再判定。

**60局で 22/60 = 0.367**＝20ep 版（0.425）より悪い。**v13 の「容量は無効」結論は過適合が原因では
なく、訂正不要**と確定した。

## 2. 本セッション最大の方法論的発見 — 判定が検定力不足だった

アンサンブルの帯間ばらつき（0.442〜0.583）から、この対戦系の分散を踏まえた必要局数を計算すると:

    真の勝率 0.55 を 0.5 と区別（両側 α=0.05・検出力 80%）に必要な局数 ≈ 800 局/条件
    本セッションで実際に使った局数: 24〜120 局

**5pt 程度の差は 24〜120 局では原理的に判別できない**。これは本セッションで繰り返された
「60局で有望→確証で消える」現象（c_puct 0.567→0.458／アンサンブル 0.583→0.442）を完全に説明する。

### 結論の頑健性（同方向の結果を束ねると証拠量は足りる）
| 結論 | 束ねた証拠 | 判定 |
|---|---|---|
| policy 微調整は**有害** | 12候補すべて 0.33-0.49（通算数百局・v12 補遺の 1エポック 0.333 を含む） | 有意 |
| 容量拡大は**有害** | 0.425(80局)＋0.367(60局)＝通算 0.400/140局 | 有意 |
| 教師の量・種類は無効 | v9-v12.1 の全方式が 0.5 付近に散る | 無効と判断 |
| 探索設定は無効 | 全条件 0.46-0.55・c_puct は確証で崩壊 | 無効と判断 |
| アンサンブルは無効 | 0.517/300局 | 無効と判断 |

### 既存の昇格基準への含意
`promotion_gate` の stage2 基準（100局で勝率 ≥ 0.55）は、**真の差が 5pt のとき偽陽性/偽陰性が
ともに高い**。実際 gen6 の採用も 204局・0.564（CI 下限 0.496）というギリギリの証拠だった
（コーチゲートで 3.8 vs 3.0 の明確な改善があったため採用判断自体は妥当）。

## 3. 今後の測定方針（次に何かを試す前に直すべきこと）

1. **勝率を主軸にしない**。5pt 級の改善を勝率で確定するには 800局/条件＝現実的でない。
   コーチゲートのような**直接測定**（局面ごとの正解一致）や、ペア順位正答のような**低分散指標**を
   一次判定に使い、勝率は「大きく壊れていないこと」の確認に用いる
2. 勝率で判定するなら **300局以上を最低単位**とし、**必ず複数の独立シード帯**に分けて帯間ばらつきを見る
   （単一帯の 120 局は信用しない）
3. **探索段階で有望に見えた数字を報告しない**。確証（別帯・大サンプル）を通ってから報告する

## 4. 現状の結論

**gen6 が現アーキテクチャ＋現教師ストリームの到達点**であることは変わらない。
残る構造仮説は依然として**訓練分布のカバー範囲**（教師=採掘決定点 1.6万 vs 探索が踏む無数の葉）で、
次の柱は「探索が踏む分布での value 較正（TD/ブートストラップ）」＝要設計。
ただし着手前に §3 の測定方針を実装すること（さもなくば結果を判定できない）。

## 5. 教訓

1. **有望な数字が出たら、まず自分の測定の分解能を疑う**。今日は「確証で消える」を2回経験し、
   3回目にようやく分解能そのものを計算した。**先に検定力を計算しておけば、多くの実験は
   設計段階で「判定不能」と分かっていた**
2. **否定の質は証拠量で決まる**。単発 60 局の 0.42 は「悪い」と言えないが、同方向 12 回なら言える。
   結論を書くときは常に束ねた局数で語る
3. アンサンブルは機構的に正しく働いた（弱いメンバーを混ぜて 0.367→0.517）が、**機構が正しいことは
   目標達成を意味しない**
