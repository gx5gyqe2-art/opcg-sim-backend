# 方策の同一行比較（2026-09-12・a1／r3／r5／r6 × 波 28／30／32・`n_rel_band --policy`）

r6 の判定（`r6_judgment_20260911.md`）で「V は世代ごとに伸びるのにアリーナが動かない」乖離の原因候補として
挙げた **(1) 方策の劣化**を、同じ holdout 行で 4 本のネットを並べて確かめた。実行は r6 セットと同じ
作業セッション（教材・ネットが手元にあった）。成果物 `claude/band-policy-r6`（71161600・
`n1_results/band_policy_r6/band_policy_w{28,30,32}.json`＋log＋RESULT.json）。表はコーディネータが JSON から
組み直した（作業セッションの転記は使っていない）。判定はユーザ。

設計: 各波 w01＋w02・holdout（seed%7==0）の**方策点は全部**（`--policy-limit 0`）。各波の `visits` は
その時代の生成役の木が作った分布＝**r3 は波 28（a1 の木）・r5 は波 30（r3 の木）・r6 は波 32（r5 の木）が
「地元」**。波 28 は dump v2 で `pol_p` が無いので π' の P_net は当時の生成役 a1（`--pi-prior-net`）。
波 30／32 は v14 の `pol_p`。

## 結論（先に）

1. **方策は「現在の分布」では劣化していない**。波 32 では a1 → r3 → r5 → r6 で top1_visits・v_mse とも単調に
   改善。問い (a)「地元で見ても r6 の方策が低いか」は **no**——乖離の原因は方策の劣化ではない。
2. **その代わり、忘却が世代ごとに深くなっている**。波 28（2 世代前の分布）で r6 の top1_visits は **0.498**＝
   r3 の 0.631 から −0.133、**a1 の 0.585 をも下回る**。V も同じ向き（r3 0.559 → r6 0.587）。
3. **3 波を平均すると r6 は r5 より良くない**（v_mse +0.002・top1 −0.035）。r5 vs r3 は僅かに良い（v_mse −0.012・
   top1 +0.007）。**r3 vs a1 は 3 波すべてで V も方策も良い**（v_mse −0.034・top1 +0.048）。
   これを各世代のアリーナと並べると: r3 vs a1 は **+81 Elo**・r5 vs r3 は **+3.5 Elo**（高分解能）・
   r6 vs r5 は **+9／−18 Elo**（±38）。**候補が基準に勝った波の数（3／3・2／3・1／3）がアリーナの向きと一致**する。
4. つまり **これまでの評価帯（最新波だけを見る）は候補を地元で測っており、世代の改善を過大に見せていた**。
   2 つある列のうち、アリーナを当てたのは**古い波の列**であって最新波の列ではない。
5. 機構の仮説: **π の窓が「現 era のみ」（2026-08-28 決定）で、しかも era7・era8 は 1 era＝2 波**なので、
   各世代は直近 2 波の分布に特化しつつ、それ以外を忘れる。アリーナ（random × synth_roles・固定ミラー）は
   広い分布を測るので、特化と忘却が相殺して 0 になる。r6 の副条件（固定ミラー）が退行側に出たのはこの形。

## 読み

### 1. 方策は無罪、忘却が有罪

問いは「方策が劣化しているか」だった。**同じ行で見ると、現在の分布（波 32）では r6 が方策でも V でも最良**。
劣化していない。ところが 2 世代前の分布（波 28）では r6 の方策は a1 以下まで落ちている。**新しい世代ほど、
古い分布での方策精度が下がる**（r3 0.631 → r5 0.577 → r6 0.498）。V も同じ向きだが幅は小さい
（0.559 → 0.572 → 0.587）。**方策の方が V より忘れやすい**。

方策は探索の事前分布（P）なので、方策が忘れた分布の局面では木の探索が悪くなる。アリーナの
random × synth_roles は「自分の era の打ち筋」から外れた局面を大量に含む＝そこでは r6 の探索は r5 より悪い。
地元の局面では良い。合計すると 0 前後——**これが「V は伸びるのにアリーナが動かない」の正体**である可能性が高い。

### 2. 評価帯は地元だけを見ていた

これまでの評価帯は「最新波の holdout」だけを主として読み、古い波の悪化は「忘却」と脚注で片づけていた
（`r5_judgment_20260911.md` の波 28 の行）。CLAUDE.md の規約も「評価帯は世代交代のたびに更新する＝古い波は
新世代に構造的に不利」としている。**しかし今回の行列は、古い波の列こそがアリーナを当てていたことを示す**。
r3 だけが 3 波すべてで基準に勝ち、r3 だけがアリーナで勝った。

「古い波は新世代に不利」という読みは、新世代が本当に強いことを前提にしている。アリーナはその前提を
4 世代連続で否定した。**アリーナを主とするなら、評価帯も「全波の行列」で読むべき**で、最新波の 1 列で
世代の改善を語ってはいけない。

### 3. π の窓が細すぎる

era6（r3）は π＝波 25〜28 の **4 波**。era7（r5）は波 29〜30 の **2 波**、era8（r6）は波 31〜32 の **2 波**。
r3 だけが汎化し、r5・r6 は特化した。π の量が半分になったことと、era を切って古い π を捨てる規約
（2026-08-28「旧 era の π は方策を引き戻す毒」）の両方が効いている可能性がある。どちらが主かは
このデータでは分けられない（r3 の基準 a1 が未成熟だった分もある）。

### 4. 補足

- 木の訪問分布のエントロピーが世代ごとに上がっている（1.448 → 1.699）。木が決めきれない局面が増えている
  ことを意味し、それ自体が「V の改善が手に出ない」に関係している可能性がある（別の計測が要る）。
- r6 の副条件（固定ミラー）の退行は、忘却で説明がつく形。固定ミラーの局面は synth_roles の波 32 から遠い。

## 次の一手の候補（判定はユーザ・2 つの規約に触れる）

1. **π の窓を広げる**。現 era だけでなく直前 era の π も入れる（波 29〜32 の 4 波、あるいは重みを落として
   もっと前まで）。2026-08-28 の「旧 era の π は毒」を覆すことになるが、その決定は c 系（世代差 +100 Elo）の
   時代のもので、NRel（世代差 ±10 Elo）では前提が違う。**r7 は r6 と同じ warm-start・同じ z で、π だけ
   波 29〜32 にして訓練し、この行列とアリーナで比べる**のが最も直接的な検証。
2. **評価帯の読み方を変える**。世代判定には最新波の 1 列ではなく **3 波（地元・1 つ前・2 つ前）の行列**を
   出し、「候補が基準に勝った波の数」を先行指標にする。`n_rel_band` はそのまま使える。CLAUDE.md の
   「評価帯は世代交代のたびに更新する」に但し書きが要る。
3. r6 の高分解能アリーナは**不要**になった。この行列が乖離を説明したので、±10 Elo で 0 を確かめる価値は低い。

**やらない方がよいこと**: r6 を生成役に上げる（忘却をさらに進める）・符号化の列を増やす・π を現 era だけで
もう 1 波積む。
