  - **実側（手の差は直らない）とは判定が違う。**
- **【実行】ただし改善しない物差しがある**:
  - 差の平均は 1.03 → **1.45 μ** と上がり、1 μ 以上の行は 31.8% → 28.5%。

- **【実行】(v) 交点の橋は不変**（的中 .6682・偏り +0.324・1 桁まで同じ）。
- **【実行】不変量**:

## 3. 読み【推測】

- 橋の読みは、値段の読みの水準を交点の橋とほぼ同じにする（D の相関 0.89・勝率の読みの相関 0.92・傾き 0.79）。ここは実側と同じ。
- 合成では、それで記録の手との差の中央値と組の差の割合も下がる。理論の最善が攻撃に偏らなくなり（66% → 52%）、出す手を最善とする行が倍になる。合成の記録の CPU は攻撃以外の手を多く打つので、その分だけ近づく。
- 一方で、ターンを終える手の値段が大きく振れる（|値段| の中央値 0.41 → 1.43 μ）。差の平均が上がる（1.03 → 1.45 μ）のと、終える手の見込みと実際の中央値の悪化（1.70 → 1.98 μ）はここから来る。橋の相手の時計は「ターンの最後の行」で読む約束なので、ターンを終えた後続と打つ前の行の相手の時計の差が、値段に大きく出ると見る。
- 実側の判定（手の差は直らない・禁じる率の比は悪化）との違いは、比べる相手の違い（深い探索 対 記録の CPU）が大きい。採用の判断は、`syn_resolution` の深い探索との比べを待ってから行うのがよい。
