## 直したもの（変わった能力の数・状態なし／うち既定で使う）

| 名前 | 誤り | 規則どおりの値付け | 本数 |
|---|---|---|---|
| `draw_n` | 「N 枚引く」を 1 枚と数える | N 枚（「手札が N 枚になるように」は N − 今の手札・ドン N 枚のコストも N） | 193／134 |
| `either_side` | 「持ち主の〜」を自分の損と数える | 発動した側が選ぶ＝自分の体と相手の条件に合う体の良い方（「すべて」は両側の和・払えないコストは能力ごと 0） | 88／48 |
| `optional_block` | 「〜してもよい」を強制の損と数える | 任意の行動とそれに依る後続を 1 塊で max(0, 塊)・相手が選ぶ「払うか、しなかった場合」は安い方・「N 枚につき」は整数の段 | 47／19 |
| `base_power` | 「元々のパワーを X に」を発動した札のパワーとの差で読む | X − 対象の今のパワー（X は盤面から・読めなければ値なし） | 30／9 |
| `opp_subject` | 対象の書かれない「相手の〜」を自分の側と読む | 相手の側（18 動作） | 12／3 |
| `revealed_src` | 公開した札をデッキ下へを場の損と読む | 見た札の移動は無償（4 動作） | 4／2 |
| `choice_max` | 択一の選択肢を全部足す | 自分が選ぶなら最大・相手が選ぶなら最小 | 49／35 |

全部で 403 本（既定で使う 234 本）。探す効果の値段の分布（全カードの登場の値）も動く（平均 0.0406→0.0490）。
