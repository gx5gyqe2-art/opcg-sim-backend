## 1. 式・入る場所・不変量・予告・殺す基準（数を見る前に固定）

### 1.1 式（新定数ゼロ）

時計の行（攻める席のターンの先頭の行・行の持ち主＝攻める側、行の相手＝守る側）ごとに、守る側の【相手のアタック時】の能力を読む。

- **読む能力**: 効果の動作が全部パワーの上げ下げ（`BUFF`）のもの（第 1 版と同じ選び方）。
  - 持ち主: 守る側のリーダー（枠 1）と守る側の場のキャラ（相手の場の 5 枠）。
  - 条件: 【ターン1回】（そのターンに 1 回）と【ドン‼×n】（持ち主に**今の盤面で**付与中のドン ≥ n）だけ読む。それ以外の条件を持つ能力は 0。
  - 費用:
    - 「手札 1 枚を捨てる」（`DISCARD`・捨てる札に条件が無いものだけ）: 守る側の手札が 1 枚以上要る。払う札は 1 枚 1 役の価値が最小の札＝**手札にカウンター 0 の札が在ればそれ**（守りの札は減らない）、無ければ**カウンター値が最小のカウンター札**を守る側の手札の読みから外す。ターンに 1 回払う。
    - 「ドン‼−n」（`RETURN_DON`）: 守る側の場のドン ≥ n なら払える（第 1 版と同じ）。
    - 費用なし: そのまま。
    - それ以外の費用（自分をトラッシュ・捨てる札に条件あり など）は 0。
- **上げ幅 +X**（対象が自分のリーダー／キャラ）: その相手のターンの**守る側のリーダーのパワーを +X**（「このターン中」＝そのターンの全部の攻撃に効く）。複数あれば足す。
- **下げ幅 −X**（対象が相手のリーダー／キャラ・シャンクス OP09-001 −1000・OP12-008 −2000）: 攻める側の**一番大きい攻め手**（攻撃できるリーダー・キャラのうちパワー最大）のパワーをそのターン中 −X。複数あれば順に、そのときの一番大きい攻め手へ。
- 実デッキ（w41）で入るもの: ナミ OP11-041（【ドン‼×1】手札 1 枚を捨てて +2000）・シャンクス OP09-001（−1000・費用なし）・OP12-008（手札 1 枚を捨てて −2000）。OP16-048（【ブロッカー】を得る）は 0。

### 1.2 入る場所（固定）

- **時計の行の読みの入口 1 か所**（`drv_cb.rs::seat_row_body` の先頭）で、行を次のように直してから、その行の読みを全部行う:
  - 行の「相手のリーダーのパワー」（守る側のリーダーのパワー）に +X。**守る側のリーダーのパワーを読む場所はここから全部読む**: 攻撃の価格の守り側（`attack_value`〔攻め手の財布 `attacker_ctx` の中〕）・耐久 Θ（止める組の超過 x〔`rule_don_solve`〕）・ブロッカーの読み・速さの項。
  - 攻める側の一番大きい攻め手の札のパワー −X（行の札の欄だけ。次の自分のターンのリーダーのパワー〔守るときのパワー〕は触らない＝「このターン中」）。
  - 守る側の手札の読み（`g_def`）から、捨てる札の分を外す（カウンター 0 の札が在るなら外さない）。
- 守る側のリーダーの札の欄（守る側が次に攻めるときのパワー）は触らない＝「このターン中」。
- **守りの窓・手の値段の写し（`drv_tb.rs`・`theory_bridge`）には今回は入れない**。写しを作り直すとき（採否が出た後・§10）に同じ口を足す。時計・較正・的中・時計の側はここだけで測れる。
- エンジン本体は触らない。

## 7. 判断してほしいこと

### 判断 1: 【相手のアタック時】の効果を「その相手のターンのリーダーのパワー」として読む直しを、どう扱うか

1. **何を決めるか**: ナミの「このターン中 +2000」などを、その相手のターンの全部の攻撃にかかるリーダーのパワーとして読む直しを、既定にするか、切替で残すか。
2. **選択肢**:
   - (a) **既定にする（手の値段・守りの窓にも同じ口を足してから）**。ナミの読み違い 0.145 → 0.115（序盤 0.205 → 0.106）・的中 .7110 → .7310。手の値段と守りの窓は、足した後に測り直して報告に足す（§10）。
   - (b) **時計の行だけ既定にする**（今の形のまま）。時計・較正・的中は (a) と同じ。手の値段は古い読みのまま＝時計と値段で守る側のパワーの読みが食い違う。
   - (c) **既定にしない・切替で残す**。既定の数は変わらない。
3. **なぜこの問いが出てきたか**: 第 1 版（効果を仮想のカウンター札 1 枚と読む）はナミを悪化させて殺した（`2026-10-13_opp_attack.md`）。記録を数えると、ナミが守る相手のターンにはリーダーへの攻撃が平均 1.65 本来ていて、+2000 は 1 回の起動でその全部に効く（`2026-10-13_defence_gap.md` §8）。そこで「ターン中のリーダーのパワー」として読み直したら、序盤の外れが半分になった。
4. **推薦: (a)**。殺す基準に 1 つも当たらず、的中がこの一連で一番大きく上がった。ただし時計だけに入れた形では値段と食い違うので、写しの側にも足してから既定にする。
5. **決めないとどうなるか**: 切替は既定で切のまま（(c) と同じ）。
6. **留保**: ナミ全体は「効いた」の線（0.106）に 0.009 届かない。中盤（+0.176）は動かない。シャンクスの局の時計は遅く読む向きに広がった（+0.04 → +0.33 ターン）。手の値段の側では、序盤（1〜3 ターン目）の「理論どおりのターンが勝つ」差が +0.023 → −0.008 と気配で逆になった（区間は両方 0 をまたぐ・§10.1）。


## 9. 仕上げ: 守りの窓・手の値段の写しにも同じ口（2026-10-13・コード 8775e827）【実行】

司令塔の依頼（「守る側のリーダーのパワーを読む既存の場所全部」）で、§1.2 で後回しにした 2 か所にも同じ切替の中で口を足した（既定は旧のまま）。

- **手の値段の写し**（`drv_tb.rs` の `clock_read`・`kappa_of_row`、それぞれの鏡の行も）: 時計の行と同じ関数（`drv_cb::opp_attack_power_adjust`）で、攻める側の行と守る側の手札の読みを直してから読む。
- **守りの窓**（`drv_tb.rs` の `guard_step` の前）: 窓の行は**守る側の行で、誘発が解決した後**なので、記録には CPU が実際に使った分がもう入っている。
  - 上げ幅（ナミ +2000 など）は、守る側のリーダーの今のパワーが「印字 + X」未満（＝まだ使っていない）のときだけ、来る攻撃の超過から X を引き、捨てる札（カウンター 0 の枠が在ればそれ・無ければ手札の価値が最小の枠）を手札の読みから外す。
  - 下げ幅（シャンクス −1000 など）は、記録で使ったかを見分けられないので足さない。
- **「既に使った」の判定を時計の行の口にも入れた**（守る側のリーダーの今のパワー ≥ 印字 + X なら上げ幅を足さない）。時計の行は攻める側のターンの先頭なので、効かないはず。

**時計・較正・的中は入口 1 か所の版とファイルごと一致**（w41 300 局の時計の行 `clocks.json` が c0562ea2 の版と 1 バイトも違わない）。§2〜§5 の数はそのまま。合成も 2c28041f で測った数をそのまま使える。切替なしは 20 局の時計がファイルごと一致・golden を作り直す器で 0 行・`make test` green（cargo 474・pytest 622）。

- エネルの外れはどの役割でも 0.01〜0.02 縮んだ（エネルの対面のナミ・シャンクスの読みが変わった分）。他 3 デッキの「出す」の外れは 0 に近づいた。

### 10.3 守りの窓（`guardside`）

| 守る席 | 窓 前 → 後 | 止められると読んだ割合 前 → 後 | そのうち受けた割合 前 → 後 |
|---|---|---|---|
| ナミ（全体） | 676 → 634 | 0.611 → 0.655 | 0.334 → 0.354 |
| ナミ 4〜6 | 194 → 154 | 0.918 → 0.909 | 0.225 → 0.214 |
| ナミ 7〜 | 419 → 417 | 0.425 → 0.523 | 0.337 → 0.362 |
| シャンクス・エネル・ルフィ | 変わらない | 変わらない | 変わらない |

- ナミの窓が 42 減った（中盤）＝まだ使っていない +2000 を足すと、来る攻撃がリーダーのパワーを超えなくなり「来る攻撃なし」になる窓。終盤は「止められる」と読む窓が 0.43 → 0.52 に増えた。
- シャンクス等が変わらないのは、守りの窓では下げ幅を足さないため（§9）。

### 10.4 判断への影響

§7 の推薦（(a) 既定にする）は変わらない。値段の側（理論どおりの勝率差・役割の外れ）は悪化せず、守りの窓の読みも規則どおりに動いた。序盤のターン単位の差が気配で逆になった点は留保に足す。
