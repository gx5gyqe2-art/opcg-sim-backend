# D-6: 物差しの窓とコスト判定を既定に採用・基準線の取り直し（2026-09-25）

ユーザ決定「両方aでお願いします」（D-5 の 2 つの判断）を受けて既定を切り替え、新しい既定で基準線を取り直した。

* `DECISION_ROW_MODE`: `any` → **`main`**（`theory_bridge.py`・10 計器）——物差しの窓を効果の途中の選択の問いで
  閉じず、効果の解決後まで測る（`2026-09-25_d5_decision_rows.md`）。
* `COST_AFFORD_MODE`: `off` → **`check`**（`effect_value.py`）——登場時・イベントのコストを払えるかをエンジンと
  同じ規則で判定し、払えなければ効果 0（ドン‼️−N は場のドンの合計・レストにするコストは出す札のコストを
  払った後のアクティブ・`2026-09-25_d4_review.md`）。

旧の数字は `--decision-rows any --cost-afford off` で再現できる（CLI を持たない帳簿・遷移の器は
`theory_bridge.set_decision_row_mode("any")`・`effect_value.set_cost_afford_mode("off")` を先に呼ぶ）。

## 基準線（実 300 局 w41／合成 900 局 w39+w42・旧 → 新）

| play | 0.875 → **0.951** | 1.086 → 1.104 |

### 交点の橋（`crossing_bridge.py`）・2 本の曲線・遷移の残差

交点の橋は**不動**（`theory` 的中 0.7068／0.6515・偏り +0.357／+0.531・`curve` 偏り −0.352／−0.132・`σ_T`・
`within1`・MAE も 3 桁目まで同じ）。`two_curves --verify` は両記録で差 0.0。遷移の残差（`transition_ledger`）は
`priced_share` 0.400／0.446・`resid_share` 0.845／0.788 で不動・恒等式の誤差 0。

### 帳簿（`relative_ledger.py`）

主に読む `rel_K` は不動（AUC 0.7734／0.7637）。価格の絶対値の累積で読む `abs_flat` だけ動く（実 0.6997→0.7119・
合成 0.7732→0.7722）——コスト判定で登場の値段が変わる分。

## 読み

* 型ごとの値段と実現は実・合成とも今までで一番そろった（D-1 の 2 つの食い違いが消えた）。
* 線形の橋の本体は下がった。帳簿から抜けていた登場時の除去の損害（実で負けた側が 4.6 倍）が入った結果で、
  下がった分は打ち方の偏り。**#43（線形の橋の傾き→1）はこの採用で遠ざかった**。
* 交点の橋・曲線・遷移の残差・帳簿の主な読みは動かない＝両方の直しはそれらの前提を崩さない。
