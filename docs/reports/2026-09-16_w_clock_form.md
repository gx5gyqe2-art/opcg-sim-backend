# T49——価格を「傾き `w(状態)` × 時計の差分」で持つ。受ける費用の水準は直り、盤面の時計は `κ` に使えなかった

2026-09-16 実施（ユーザ決定「2 つ目かな」＝価格は `w(状態) × 時計の差分`・「今ある定数から定義できないか」）。
**新しい定数はゼロ**（全部が既存の実測の写し）。本報告は特定時点のスナップショット。

## 結論を 6 行で

1. **受ける費用の水準を実測の写しに置いた**——`Θ·μ = λ − h·μ`（`h` = ライフの札が手に入る割合 0.89・T48）⇒ **`Θ = λ/μ − h ≈ 1.58`**
   （旧 1.15 は「相手が受け始める切替点」＝費用ではなかった・罠 29・`THETA_SWITCH` に残す）。
2. **これだけで `ΔG` の説明力は上がる**——実デッキ AUC **0.656 → 0.697**（傾き 6.5 → 7.3）・合成 **0.600 → 0.641**（5.2 → 7.0）。
   五分位の実勝率は 35→72% から **25→75%** に広がった。リーダー攻撃の価格 対 実現は 1.48 → **1.29**。
3. **時計の形 `w(D)` は「平均が戻る」検算を通る**——`κ = w(D)/w̄` の平均 **1.11／0.99**（`w` の平均 0.135／0.120 対 `w̄` 0.121）。
4. **しかし盤面から機械的に出した `D` を局面の傾きに使うと説明力が落ちる**——AUC **0.697 → 0.576**（実）／**0.641 → 0.520**（合成）。
   原因は `D` の粗さ: 実勝率 `W(D)` は `D` が −3 → +3 で **0.20 → 0.65 しか動かない**（借りた `σ_D` = 1.4 ターンなら 0.02 → 0.98 のはず）。
   `σ` を 2〜4 に振っても `flat` に届かない（感度・合わせ込まない）。
5. **出荷既定**: `Θ` は新しい水準・**`κ` は `flat`（= 1・平均の傾き＝3 つ目の形を土台に）**。2 つ目が正本であることは変わらない。
   **足りないのは時計の推定器**——`σ` の出所（時間軸ヘッドの `T` 予測）で `D` を作るのが筋。
6. `ν` の在庫は `Θ` と一緒に上がり、飽和超えの帯で実測の 1.67 倍（流れ→在庫の換算 P1 の壁は前より高い）。

## 1. 形（ユーザ決定・`game_theory.md` §17.1.0）

```
手の価値 = W(後) − W(前)                          定義は 1 つ
        = (dG/dt) × ΔT = w(状態) × 時計の差分     2 つ目の形（傾き × 動いた時計の量）
w̄ = 0.5 / R                                      3 つ目＝経路で平均した傾き（積分条件・検算と土台）
```

| 量 | 出所（既存の実測） |
|---|---|
| `T_me = (相手ライフ + 相手手札/c̄ + 相手ブロッカー)/A_me`・`T_opp` はその鏡 | §17.1.5c・`c̄ = c_mean_all 1.514`・`A` は通る攻撃の本数（床 1） |
| `w(D) = φ(D/σ_D)/σ_D`・`D = T_opp − T_me` | `σ_D = √2 × 1.0` ターン（時間軸ヘッド r10 の決着ターン誤差） |
| `κ = w(D)/w̄` | `w̄ = 0.5/4.128 = 0.121` |
| 受ける費用 `w·(1 − h/c̄)/A = λ − h·μ` | `λ` 0.1362・`μ` 0.0551・`h` 0.89（T48） |

`κ` は同じ行の全候補に共通なので**順位（最善）は動かず**、橋の `ΔG` の行の重みだけが局面で変わる。
価格 対 実現の器（T41／T44／T48）は両辺に同じ `κ` が掛かるので比は不変＝平均の傾きで比べる。

## 2. 実測——橋 `ΔG`（1 手あたり・実デッキ 300 局／合成 900 局）

|---|---|---|---|---|---|
| 以前（T47） | 1.15 | 1 | 6.53 [3.8, 9.2] / 0.656 | 5.24 [3.1, 7.0] / 0.600 | 35→72% |
| **水準だけ** | **1.58** | 1 | **7.31 [5.2, 9.5] / 0.697** | **7.02 [5.2, 8.6] / 0.641** | **25→75%** |
| 水準＋時計（σ=1） | 1.58 | `w(D)/w̄` | 1.30 [0.0, 3.0] / 0.576 | 0.15 [−1.0, 1.2] / 0.520（`no_link`） | 47→68%（非単調） |

**`κ` の平均**: σ=1 で **1.114／0.993**（`w` の平均 0.135／0.120 対 `w̄` 0.121）＝**水準の検算は通る**。σ=2 で 0.80・σ=4 で 0.51（正規の峰が `w̄` を割る）。

**`D` の分布と実勝率**（当てはめない・攻めの行）:

| `D` の帯 | 実: 行数 / 勝率 | 合成: 行数 / 勝率 |
|---|---|---|
| `< −3` | 1,444 / **0.20** | 2,411 / 0.26 |
| −3〜−1 | 1,696 / 0.22 | 4,209 / 0.28 |
| −1〜1 | 7,155 / 0.40 | 15,192 / 0.45 |
| 1〜3 | 3,606 / 0.55 | 11,275 / 0.54 |
| `> 3` | 4,914 / **0.65** | 15,286 / 0.68 |

**`D` は勝敗を単調に順序付ける**（時計の向きは正しい）が、**`|D| > 3` が 34%／35% を占め、そこでも勝率は 0.2〜0.7**。
借りた `σ_D` = 1.4 なら `|D| > 3` は勝率 0.02／0.98 の「決着済み」で `κ ≈ 0` になる——**実際には決着していない行を 0 に潰していた**。
`D ≈ 0` の勝率が 0.40／0.45（0.5 でない）＝自席の判断点で読む時計は自分に甘い（自分の攻撃手は今・相手のは次のターン）。

## 4. 読み方

- **水準（Θ）は写しで直った**——費用は「失った資源の実測の和」から出す（罠 29）。切替点 1.15 は相手の打ち筋の観測だった。
- **2 つ目の形は「平均が戻る」までは通った**が、**局面の傾きに使える時計をまだ持っていない**。盤面から機械的に出す `D` は
  「今の盤面の 1 手番ぶん」（§17.1.5c の限界そのもの）で、±1 ターンの精度は無い。借りた `σ` は時間軸ヘッド（ネット）の
  予測の誤差であって、この推定器の誤差ではなかった（罠 29 の第 2 の形）。
- **`κ` を掛けて説明力が落ちる**のは「局面の傾きは要らない」ではなく「この `D` では傾きを間違える」。`W(D)` の帯は単調なので
  向きは正しい。
- **P1 は「式が無い」から「推定器が無い」に変わった**。

## 5. 次

1. **時計の推定器**——`σ` の出所と同じ時間軸ヘッド（r10 の `t_left`・両者のライフの先読み）で `D` を作り、同じ検算
   （`κ` の平均・`W(D)` の帯・`ΔG` の AUC）を回す。盤面の 1 手番近似を捨てる。
2. それまで `κ = 1`（平均の傾き）で `ΔG` を読む。
3. `ν` の在庫（流れ→在庫・P1 の残り半分）。

## 限界

- `σ_D` の正規は仮定。`W(D)` の帯で形を検算しただけで、分布の形は測っていない。
- `D` は自席の判断点から読むので自分に甘い（`D ≈ 0` で勝率 0.40〜0.45）。
- **観察であって因果ではない**。
