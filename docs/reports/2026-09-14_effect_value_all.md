## 2. 価格の出どころ——**全部既存の実測値からの導出**

| 系統 | 導出 | 使った実測値 | 値の例 |
|---|---|---|---|
| **テンポ** | **在庫 ÷ 残りターン**＝1 ターンぶんの流量 | `R = 4.128` | `REST_DON` = `δ/R` = 0.0067／`REST` = `ν/R` = 0.0263／`FREEZE` = 2 倍 |
| **選択**（サーチ） | **k 枚見て 1 枚選ぶ利得** `E[max_k W] − E[W]` | カード価値の分布（**つまみ無し**） | k=2 **0.0442**／k=3 **0.0647**／k=5 **0.0893**（= 0.80／1.17／1.62 `μ`） |
| **生存** | 体が消える確率 × 体 | `ko_p = 0.289` | `PREVENT_LEAVE` = 0.0314 |
| **キーワード** | ブロッカー＝実測の上乗せ／速攻＝攻撃 1 回／バニッシュ＝トリガー 1 回 | 0.035・`Θ·μ`・`τ_value` | ブロッカー 0.035／速攻 0.0634／バニッシュ 0.0082 |
| **能力の参照** | **同じカードなら再帰で解く**。判らなければ**能力 1 つ ≈ 札 1 枚** | `μ`（**暫定 P2-5**） | `NEGATE_EFFECT` = 0.0551 |
| **恒等式** | 勝利 = 0.5（Σλ = 0.5 から）／追加ターン = `0.5/R` | — | `VICTORY` 0.5／`EXTRA_TURN` 0.1211 |
| **常設で体の無い札**（ステージ） | **`ν` でも 0 でもなく「能力 1 つ」** | `μ` | `KO`(STAGE) = 0.0551 |

> **選択の利得につまみが無い理由**: `W`（カードの中身の価値）の分布を**同梱のカードと
> 既存の価格から計算する**ので、選ぶ余地が無い（1,710 枚で推定）。
> **能力ごとに 1 回だけ足す**——`LOOK(5)` → `MOVE_CARD(TEMP→HAND)` → `DECK_BOTTOM(TEMP)` は
> **1 つの選択**なので、動作ごとに足すと 3 重に数える。

> **ステージの扱いを変えた**（T16 の読み直し）——「ステージは体を持たない」は
> **`ν` を当てるなという意味で、価値 0 という意味ではない**。`ν` にすると体を数え、
> 0 にすると**ステージ除去が無料**になる。**常在効果 1 つぶん**として数えるのが筋が通る。

## 3. 桁の壊れ 3 つ（どれも上限で打ち切って直した）

| 症状 | 原因 | 直し方 |
|---|---|---|
| ある能力が **勝率 −5.4** | `count = 50`（「手札をすべて捨てる」の解析結果）を素通し | **帯の容量で打ち切る**（場 5・ライフ 5・ドン 10・**手札は実測 4.88**） |
| ある能力が **勝率 +21.7** | `パワー+792000` を `δ/1000` で線形に換算 | **1 体から引き出せる上限 `max(Θ·μ, ν)`**で打ち切る＝**理論自身の飽和** |
| ある能力が **勝率 +1.3** | 永続の速攻を 5 体に付与＝`Θ·μ × R × 5` | **速攻は 1 回きり**（`once`）と**攻撃ごと**（`turn`）を分けた |

**3 番目が一番危ない形**だった——**「期間を掛ける」という正しそうな規則を全部のキーワードに
当てた**ために、1 回しか得をしないものが R 倍になっていた。

> **`base = 99`（パーサの「上限なし」）も同じ形**——`ATTACH_DON` が 99·δ = 2.74 になっていた。
> **規則の上限 10 枚**で打ち切った。

## 4. 「出現から母数を作る」と何が起きるか（`measurement.md` へ）

**2 種類の欠陥が同じ原因から出た**:

- **実在しない名前が表に残る**——`COST_REDUCTION` は `ActionType` に無いので
  **その行は一生使われない**が、出現から作った表では**気付く手がかりが無い**
  （出現 0 と「名前が違う」が区別できない）。
- **実在する動作が表から漏れる**——`MOVE_TO_HAND`・`BP_BUFF`・`COST_BUFF`・
  `LIFE_MANIPULATE`・`SELECT_OPTION` 等は同梱カードに 0 件なので**見えなかった**。
  **カードプールが変わった日に黙って `None` が増える。**

**加えて分類そのものの誤りも 1 つ出た**——`DECK_BOTTOM` を丸ごと「情報・デッキ順」に
入れていたが、**80 件は `zone = FIELD`＝体を山札の下へ送る除去**だった。
**ゾーンを読まずに動作名だけで類を決めていた**ので見落としていた。

## 5. 橋（§0.5 の受け入れ基準）——**傾きは動かなかった**

実デッキ 300 局・`--silent exclude`・`Θ = 1.15`。**P2-1 の配線（イベント・起動メイン）後**と
**本作業（残り全部）後**を比べる:

| | P2-1 後 | **P2 全部後** |
|---|---|---|
| **無言の行**（攻め 18,815 行のうち） | 1,408 | **608（−57%）** |
| 値付けできない候補 | 起動メイン 1,452・登場/イベント 7,182 | **0**（残るのは効果の対象選択 1,924 だけ） |
| 1 手あたりの傾き（全体） | +4.27 [3.33, 5.40] | **+4.48 [3.49, 5.64]** |
| AUC（全体） | 0.701 | **0.710** |
| 接戦帯 | −1.68 [−3.27, +0.13] | **−1.66 [−3.24, +0.18]** |
| 接戦帯の攻め | +0.45 | **+0.48** |
| 決着帯 | +2.09 | **+2.14** |
| **守り** | −3.75 | **−3.75（不動）** |

**どれも CI が完全に重なる＝動いていない。** 母数が 4% 増えただけなので、**動かないのは
むしろ筋が通る**（無言の行 800 件は攻めの行の 4.3%）。

> **§0.4 の感度の規則がそのまま働く**——**結論が動かない穴は後回しでよい**。
> **P2-1（イベント・起動メイン）が信号を全部運んでいて、P2-2〜P2-4
> （情報・テンポ・能力付与）は被覆を上げるだけだった。**
> **これは「無駄だった」ではない**——被覆が上がったこと自体が、
> **カードプールが変わっても穴が開かない**という別の値打ちである。

## 限界

- **効果の値は条件を読んでいない**（`ab["condition"]`）＝**過大**の向き。**最大の残り穴。**
- **対象の `ν` を盤面の帯で渡していない**（カード単体の平均 0.1087 のまま）。
- **暫定値を 1 つ足した**（**P2-5**＝「能力 1 つ ≈ 札 1 枚」）。**中央値が `μ` に一致した**という
  実測に基づくが、**自分のコーパスから出した値**なので循環の気味がある。
  感度は `[0.5μ, 2μ]`（`ABILITY_UNKNOWN`）。
- **テンポの `÷R` は「在庫が一様に流れる」前提**＝終盤（`R` が小さい）ほど過小になる。
- **選択の利得は「引いた 1 枚が最良」**＝実際は色・コスト・盤面で選べる範囲が狭い＝**上限**。
- **`count_dynamic`（「トラッシュの枚数ぶん」）を読んでいない**＝固定個数で代表している。
- **`SWAP_POWER` 3 件は盤面が要る**ので値付けしない（0 にしない）。
