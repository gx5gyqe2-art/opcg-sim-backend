## 1. 問い（T101 の結論）

T101 で **`Θ` の終盤の過大は τ の偏りでは説明できない**（τ を揃えても 1.95／2.01）と判り、
**超過はちょうど手札の項 1 つ**（残り 1 ターン: `Θ` 0.3208 = ライフ 0.1357 ＋ **手札 0.1702** ＋ 体 0.0148 に対し
**要った損害 0.1643 ≒ ライフだけ**）。**逆に残り 6+ では手札の項が無いと足りない**（0.58）。

**＝大きすぎるのでも小さすぎるのでもなく、置き場所が違う。**

## 2. 式（**新しい量はゼロ**・規則だけ）

```
Θ        = λ·L + Σν(避けて通れない体)                       ← 手札は入らない
盾       = μ × 切れる枚数                                    ← **同じ量をそのまま移す**
盾の速さ = μ × Σ c(x_i)                                      ← 1 守備ターンに出せる上限
           （相手の攻撃のうち、ブロッカーが横取りする安い順 B 本を除き、`c(x_i) ≤ Θ` のものだけ）
歩き     : j ターン目の的 = Θ + min(盾, 盾の速さ × j)
```

**規則の根拠**（すべて `rules/battle.rs` と既測の量）:

| 規則 | 式のどこ |
|---|---|
| **カウンターは宣言された攻撃にしか切れない** | 上限が**攻撃の本数**で決まる（`own_attackers_of`／`opp_attackers_of`） |
| 攻撃は「パワー ≥ 対象のパワー」で命中＝**超過 `x` を止めるには `c(x)` 枚**（T61） | 1 本あたりの費用が `c(x_i)` |
| **アクティブなブロッカーは横取りできる**（`has_blocker` は `!is_rest` を要求） | **安い攻撃から** B 本を除く |
| **`c(x) > Θ` なら受けた方が安い**（T63 の守る規則・攻撃の価格が `min(Θ·μ, c(x)·μ)` なのと同じ判断） | その攻撃には札を出さない |
| **相手のターンが来ればレフレッシュで全部アクティブ** | 相手の攻撃は**場のキャラ全部 ＋ リーダー**（`can_attack` は自席のターンの旗なので使わない） |

**打ち筋は 1 つも入らない**——入力は**攻撃の本数とパワー・相手のライフ・ブロッカーの数・費用曲線 `c_of`** だけ。

## 7. 読み方

- **上手くいった（本命）: 理論の「これから要る損害」が実績と一致するようになった。**
  これは**新しい検算**であり、**本 T までどの T もこの形で測っていなかった**（`Θ`/要 を素で見ていた）。
  **`Θ` は在庫・要った損害は総量**という T101 の読み直しを式に通すと、
  **在庫 ＋ 補充 ＋ 盾**という 3 項が出て、**どれも先に測った量のまま**で 1 に並ぶ。
- **上手くいった: 2 つの穴が独立だと確かめられた**。序盤の不足＝**補充**（旧 `Θ` のままでも 6+ が 0.97／1.02 に戻る）、
  終盤の過大＝**手札の置き場所**（補充では動かない）。**別々に手当てできる**。
- **上手くいかなかった 1: 2 つの橋は小さく・記録のセットで割れる**。交点は両方で的中 −0.005／−0.002。
  帳簿は**実で落ち**（AUC 0.694 → 0.686）**合成で上がる**（0.730 → **0.736**・傾き 0.444 → **0.473**＝歴代最良）。
  **両方で落ちるのは恒等式の側だけ**（必要な `κ` 0.501 → 0.478／0.581 → 0.523・相関 0.386 → 0.347／0.501 → 0.404）。
  **機構は T97 と同じ型**——`Θ` に手札を入れておくと `D` が「手札の厚み」という勝敗の信号を拾うが、
  **それは耐久としてではなく、使える時間を無視した形で拾っていた**。**当たっていた理由が誤り**。
- **上手くいかなかった 2: 補充を歩きに入れると偏りが 2.5 倍に開く**（+2.53 → +6.37）。
  **勘定としては正しい（§4）のに歩きでは壊れる**理由は**積み上がる速さ `R_j` の序盤が `r` を下回る**から
  ——`grow` は `盤面 ＋ 在庫·[j≥2] ＋ 流入·(j−1)` で 1 ターン目は盤面だけ（`r = 0.040` と同程度）なので、
  **序盤の数ターンが実質ゼロ進行になり、そこで稼いだ遅れが全部残る**。
  **`r` の証拠は「読み方」（§4 の検算）に在って、「歩き」には入れられない**＝`RACE_MODE` は `static` のまま。
- **判定の材料**: **ユーザの 2 基準では `shield` が明確に上**（規則からしか作っておらず・打ち筋を 1 つも読まない）。
  **理論の検算（§4）は劇的に良くなり、2 つの橋の動きは 1% 前後で向きも割れる**（合成の帳簿は上がる）。
  **T97（`blockers`）と同じ構図**で、あのときはユーザ指示「理論的に正しいものにしたい」で採用した。
  **推しは `shield` を既定にすること**（採否はユーザ判定）。

## 限界

- **盾は「出せた分」を線形に積む**（`min(盾, 速さ × j)`）＝**毎ターン上限いっぱい使う前提**。
  実際の守り手は使わないターンもある（それは打ち筋なので式に入れない）。
- **盾の速さは今の盤面から測った 1 ターンぶん**で、**盤面が変わることを織り込んでいない**
  （`Θ` の体の項・`A` と同じ限界）。
- **`σ_T`・`w̄` の fixture は `stock` の条件で測った値**（T99・T100 と同じ限界）。
  **採用するなら両方測り直す**——本報告の `shield` の数字はその前の値。
- **`t_left − 1` を守備ターン数と置いている**（先手・後手や効果による追加ターンは見ていない）。
- **`要った損害` は勝った席の行だけ**。
- **観察であって因果ではない**。
