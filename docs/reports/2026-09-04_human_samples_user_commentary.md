# 見本棋譜へのユーザ解説（一次資料・2026-09-04）

棋譜（h1〜h6）の定性分析（`2026-09-04_human_samples_qualitative.md`・`_human_sample_roger.md`・
`_human_sample_doflamingo.md`）に対して、打った本人（ユーザ）が意図を補足した。棋譜からは
読み取れない「なぜその手か」であり、分析の誤読の訂正を含む。**設計の要件はこちらを優先する**。

## 1. エネル

- **序盤から相手の展開を考慮し、必要になる除去札を集める**ことを意識している。
- 放電は保護目的で使うこともあるが、今回は**手札を回して必要札を集めるために**使った。
  1 枚ドローが付くカードもサトリも同じ考え＝**ドローは「必要札を集める」手段**。
- 分析側の誤読: 放電を「主力の保護（コスト＋2）」と読んだが、主目的はドロー。型E の
  「保護」は副次。型A の組は「集めた結果」であり、**集める過程（相手の展開を見て何が要るかを
  決める）**が本体。

## 2. ロジャー

- **終盤の方がリーダーのパワーが上がる**（リーダー効果でドンフェイズのドンがリーダーに付く・
  キャラのロジャー P-107 の登場時 +2000・10c シャンクスの相手全体 −1000）ため、**カウンターは
  終盤に固めた方が手札効率が良い**。
- **リーダーパワーが上がるまでにどの程度手札が残っていれば良いか**を考えながら打っている。
- 分析側の読み「ライフは資源・守りは最後に集中」は結果として合っているが、理由は
  「守りの単価が終盤に下がる」という**時間で変わる手札効率**の計算。

## 3. ドフラミンゴ

- 対象変更は **KO 時効果を意識しているわけではない**。場合によっては**相手の攻撃よりパワーの
  高いキャラに誘導して手札を温存**する（ボディで受ける）。
- 10c ドフラミンゴをうまく使うために、**ドンを使いすぎないようリーダー効果を使わないターンが
  多かった**（ドン −1 の累積を避け、10 ドンを揃える）。
- 分析側の誤読: 「対象変更を KO 時効果持ちにだけ使う」は結果の一致であって意図ではない。
  意図は **手札とドンの温存**（受け先のパワーと、次の大型のためのドン予算）。

## 4. 共通

- **デッキにどんなカードが入っているか、どういう方針で打つべきかを意識しながら**打っている。
  ＝手は「そのデッキの計画」から出ている。

## 5. 設計への含意（`docs/n_attention_plan.md` へ反映）

1. **デッキ知識**: 自分のデッキ残の「役割別の枚数」（しきい値除去・減算・ロック・ドロー・
   カウンター・ブロッカー・大型）と、相手の見えたカード（場・トラッシュ・使われたカウンター）
   からの脅威見積もり。人間は「何が要るか」を相手の展開から決めて集めている。
2. **時間で変わる価値**: リーダーパワーの見込み（現在／最大ドン時）・10 ドンまでのターン数・
   次ターンのドン数・次ターンに出せる最大の札。守りの単価（カウンター 1 枚で守れる量）が
   時間で変わることを価値が持てるように。
3. **予算**: リーダー効果や 1c のドン −1 を「使わない」判断＝将来の大型のためのドン温存。
   「このターン使うと次ターンの大型が出せなくなる」を候補素性に。
4. **受け先の選択**: 対象変更・ブロックは「受け先のパワー ≥ 攻撃パワーなら手札を使わずに済む」
   が第一。KO 時効果は副次。相手 × 自の関係 R は「攻撃パワー − 受け先パワー」を主に。
5. **手札効率**: 守りに使える手札の総量と「残りの相手の攻撃回数×守りの単価」の見積もりを
   ライフと組で見る。
