## 1. 問い（T96・T98 が指した先）

`Θ` は**とどめのターンで実際に要った損害の 1.98 倍**（T96・`blockers` で）。残る膨らみは**手札の項**
（0.181 対 要った損害 0.169 とほぼ同額）。機構の見立ては「**切れる札が『必ず `μ` ずつ吸う』前提が終盤で破れている**」。

## 2. 式（新定数ゼロ）

```
Θ_hand = μ × c(x_max) × floor(切れる枚数 / c(x_max))
```

**規則**: 攻撃は「攻撃側のパワー **≥** 対象のパワー」で命中する＝**超過 `x` を止めるには `c(x)` 枚要る**（`c_of`・T61）。
よって切れる札は **`c(x)` 枚ひと組でしか働かず、1 回分に足りない端数は一生 `F` に入らない＝耐久ではない**。
`x_max` はその席が打てる**最大の攻撃の超過**。`c(x) ≤ 1`（超過 0）なら旧 `cuttable` と完全に一致する。

## 6. 読み方

- **上手くいった 1: 狙った場所にだけ効いた**。手札の項の減りが**残りターンに対して単調**（−52% → −1%）
  ＝**`c(x)` のひと組み化は終盤の形をそのまま説明している**。仮説が当たった。
- **上手くいった 2: 時刻が初めて正しい向きに動いた**。T90 以降、`Θ` や `A` をどう触っても偏りは開くばかりだったが、
  **手札の項を規則どおりに縮めたら 4 つの時刻の指標が同時に改善**した。
  とくに **`curve` の偏りが実でゼロを跨いだ**（+0.14 → −0.05）。
- **上手くいかなかった: 帳簿が大きく落ちる**（`ΔG` AUC −0.115／−0.065・傾き 0.458 → 0.187）。
  **しかも必要な `κ` まで 1 から遠ざかった**（0.559 → 0.458）＝**T97 のときと違い、`D` の広がりだけの話ではない**。
- **原因の見立ては形の粗さ**——**`x_max`（一番重い攻撃）で全部の札を割っている**。実際の守り手は
  **攻撃ごとに止めるかどうかを選ぶ**ので、軽い攻撃は安く止められる。`x_max` は `c` を最大に見積もるので
  **端数を捨てすぎ**、**`Θ` を小さくしすぎている**（`Θ`/要が 4〜6+ ターンで 0.88／0.77 と、もともと過小だった側をさらに削っている）。
- **つまり「向きは正しく、粗さが残っている」**。**規則としては `c(x)` ひと組みが正しい**が、
  **`x` を 1 つで代表させるのが乱暴**だった。

## 限界

- **`x_max` の 1 本で代表させている**（§6・§7 の 1）＝**端数を捨てすぎる向き**。
- **`σ_T`・`w̄` の fixture は `cuttable` の条件で測った値**。`cuttable_cx` の実測は σ_T 1.053／1.205 で
  fixture の 1.093／1.247 と 4% ずれる（`κ` の平均 0.847／1.129 は `cuttable` の 0.866／1.154 とほぼ同じなので、
  **帳簿の落ち込みはこのずれでは説明できない**）。**採用するなら両方測り直す**。
- **`c(x)` は平均の費用曲線**で、実際の手札のカウンター値の組み合わせではない（T64 の「一番安い札から切る」は別の器）。
- **端数を「捨てる」のは切り捨て**（`floor`）＝**確率的に届く場合を無視している**。
- **観察であって因果ではない**。
