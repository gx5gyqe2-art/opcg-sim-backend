# a1 採用報告（2026-09-05）— 出荷既定を N系 c10 から NRel a1 へ

**ユーザ決定（2026-09-05）**: 「R なし、相手デッキ知識は入れて進める（教材が増えれば効いてくるかも）」。
これは切り分け 3 本のうち **a1** の構成そのものなので、a1 を出荷既定に切り替え、以後の NRel は
この構成（`--ablate rel`）で訓練する。

## 何が変わるか

| 項目 | 旧（c10） | 新（a1） |
|---|---|---|
| ネット | N系 c（`n_eff.py`・カードを効果構造 64 で表し mean/max に畳む） | NRel Stage A（`n_rel.py`・22 枠の「効果構造 64＋今の状態 20＋ゾーン 5」トークン＋対の小ネット） |
| 符号化 | v12（94 列） | v13（94＋29 列・相手デッキ知識の要約を含む） |
| 関係 R | — | 遮断（`ablate={"rel"}`・serve は計算自体を省く） |
| 同梱 | `opcg_sim/data/learned/neff_c10.npz` | `opcg_sim/data/learned/nrel_a1.npz`（md5 96aafe0e…・514KB） |
| 正本 | `cpu_learned._DEFAULT_VALUE` | 同左（`_C10_VALUE` をロールバック先として追加） |
| vocab | gen15 系譜の vocab_ids | 同一（ネット付属） |

## 根拠

| 測定 | 結果 |
|---|---|
| r1 vs c10（分散 16 セッション・2 条件） | 主 0.557 [0.503,0.611]／副 0.591 [0.547,0.635]＝2 条件とも達成（`2026-09-05_r1_judgment.md`） |
| a1 vs r1（主条件 192 ペア） | 0.544 [0.487,0.601]＝R を外しても同等（`2026-09-05_r1_ablation.md`） |
| a2 vs r1（相手デッキ知識なし） | 0.503 [0.448,0.557]＝同等。ただしユーザ判断で**入れたまま**にする（教材が増えれば効く可能性） |
| c12 vs r1（c10＋同じ教材） | 0.430 [0.378,0.482]＝構造の寄与 |
| 評価帯（同じ holdout 38,164 行 v_mse） | c10 0.556／r1 0.531／a1 0.537 |
| 一致率 h1〜h6（317 点） | c10 0.322／r1 0.355／a1 0.345 |
| レイテンシ（sims 160・c10 比） | r1 1.83 倍／**a1 1.67 倍**（関門 1.3 倍は未達＝ユーザ受容） |

## 運用

- **生成役**は a1（era6・波25 以降・dump v2）。
- **訓練**は `n_rel_train.py --ablate rel` を既定（相手デッキ知識の列は入れる）。系譜の番号は r2, r3, … を続ける
  （r2 以降は「R なし」が既定の構成）。
- **ロールバック**: `_DEFAULT_VALUE` を `_C10_VALUE` に戻すだけ（`_is_neff`/`_is_nrel` が npz の鍵で判別＝配線変更不要）。
- 関門未達のレイテンシは次の改良対象（状態 S の条件評価の軽量化・ノード間の符号化共有）。
