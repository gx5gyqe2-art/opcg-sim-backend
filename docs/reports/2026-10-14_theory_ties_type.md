## 1. 問い・定義・予告（数を見る前に固定）

### 1.1 問い

理論が「探索の選ぶ手」を最善より損と読むのは、どの型の手で、どの帯で起きているか。攻撃の後続だけ戦闘を解決する上乗せで説明できるか。

### 1.2 点（記録だけ・新しい探索なし）

`theory_ties` の 2 つの群をそのまま使う:
- **(i)**: 記録と深い探索が一致し、理論の最善がその手を指さない点（586）。
- **(ii)**: 食い違った点で、理論の最善が第三の手を指した点（278）。
- **(iii) 対照**: 全部の点で「最善 − 記録の手」（1,692）。

差 ＝ 理論の最善の値段 − その手の値段（μ の倍数・値段の単位）。

### 1.3 手の型（記録の候補の鍵とカードの種類から）

| 型 | 中身 |
|---|---|
| 攻撃・リーダーへ | `ATTACK` と対象つきの `DON_BOX`（ドンを付けて攻撃）で、対象が相手のリーダー |
| 攻撃・キャラへ | 同じく、対象が相手のキャラ |
| 出す・キャラ／ステージ／イベント | `PLAY`（札の種類で 3 つに分ける） |
| ドンの付与・リーダーへ／キャラへ | 対象なしの `DON_BOX`・`ATTACH_DON` など、攻撃を伴わない付与（付与先で 2 つに分ける・付与先が読めなければ「付与・その他」） |
| 起動効果 | `ACTIVATE` 系（【起動メイン】） |
| パス | `TURN_END`・`PASS` |
| その他 | 上のどれでもない |

- 攻撃を伴う `DON_BOX` は攻撃に入れる（`theory_map.py` の `family_of` と同じ扱い）。
- 細かい型で点が少なすぎる組は、粗い型（攻撃／出す／付与／起動／パス／その他）でも表を出す。

### 1.4 量

- (1) 各点で、理論の最善の手の型と探索の手の型（(iii) では記録の手の型）を分類する。
- (2) 「最善の型 × 探索の手の型」の表で、点の数・差の中央値・**差の合計の占める割合**を出す。帯（1〜3／4〜6／7〜）でも割る。
- (3) **差の部品**:
  - 値段は「打った後の 2 本の時計の読み直し」（`p = (W(後) − W(前)) / κ`、勝率 W は自分の時計と相手の時計から読む）。
  - 各候補の後続で読んだ 2 本の時計と勝率に加えて、「**相手の時計だけを動かした勝率**」（自分の時計は打つ前のままにして読んだ W）を写しに書き足す。
    - 診断の切替 `OPCG_CLOCK_PARTS_DUMP=1` を足す。既定は切で、値は変えない。
    - 写しは取り直す（`theory_bridge.py` を同じ記録・同じ既定で回し直す）。
  - 最善 − 探索の手の勝率の差を、次の 2 つに分ける（勝率の差の和は全体と一致する）:
    - **相手の時計の部品** ＝ 相手の時計だけを動かした勝率の差。
    - **自分の時計の部品** ＝ 残り。
    - 分け方は「先に相手の時計、次に自分の時計を動かす」順の差（順で値が変わりうるので、逆の順でも合計だけ確かめる）。
  - **攻撃の後続の戦闘解決が占める分**: 攻撃の後続では戦闘を解決した局面（相手のライフ・キャラの減り）を読む。攻撃でない手の後続では戦闘は起きない。
    そこで、**最善が攻撃で、探索の手が攻撃でない組では、相手の時計の部品を「戦闘解決の分」の上限として読む**（相手の時計を動かすのは、その攻撃の戦闘で相手が失ったものだけ、という見立て）。
  - 「攻撃が最善で、探索は出す／付与」の組と、「出す／付与が最善で、探索は攻撃」の組を分けて見る。
- (4) 対照として、同じ表を (iii)「最善 − 記録の手」でも出す。

### 1.5 予告（司令塔が固定）

- **当たり（攻撃の上乗せ）**: 次の 2 つがそろう。
  1. (i)(ii) の差の合計のうち、「最善が攻撃で、探索の手が攻撃でない」組が **6 割以上**を占める。
  2. その組の差の部品で、攻撃の後続の戦闘解決（§1.4 の上限の読み）が**過半**。
- **外れ**: その組が **3 割未満**、または差が型をまたいで一様に出ている（**最大の組でも 3 割未満**）。
- その間は「どちらとも言えない」。
- 当たれば §6 に、攻撃の値段の読み方を規則から直す候補（上乗せを外す形・新定数ゼロ）を書く。式の候補だけで、まだ変えない。
- 式は変えない。新しい定数は入れない。

### 1.6 限界（先に書く）

- 「戦闘解決の分」は、相手の時計の部品で上から押さえる読み。攻撃でも戦闘以外（【アタック時】の効果など）で相手の時計が動く分が混ざる。
- 写しを取り直すのは部品を書き足すためで、値段は同じになるはず。取り直した写しの値段が前の写しと全行で一致するかを確かめ、数を書く。
- 深い探索は正解ではない（同じネット・古いエンジン）。理論は新しいエンジン。
- 道具は `theory_map.py` の副命令（1 回きり・テストなし）と、Rust の診断の切替（既定は切）。

## 7. 読み【推測】

1. 理論は「今リーダーを殴る」手を、キャラを出す・ドンを付ける手より高く読む。その差の 3/4 は**自分の時計**（自分が倒れるまでの読み）から来る。
   殴った後の局面の方が、自分が長く生き延びると読んでいる。
   - 候補 1: 攻撃の後続は戦闘（相手の守りの窓）まで解決するので、相手の手札のカウンターが減った局面を読む。その分、相手の次のターンの攻めが弱く読まれ、自分の時計が伸びる。
   - 候補 2: 出す・付与の後続では、手札や付与できるドンが減った局面を読む。それが自分の守り（手札のカウンター）の読みを下げる。
   - どちらも未確認。次に割るなら、自分の時計の部品を「相手の手札の減り」「自分の手札の減り」などで分ける。
2. エネルでは、この形が弱い（20%）。エネルの差は別の組に在る。
3. 「最善が攻撃で探索の手も攻撃」の組（18.5%・中央値 1.07 倍）は、どの攻め手で・何枚のドンで殴るかの読みの違い。
