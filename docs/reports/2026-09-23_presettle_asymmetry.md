# T146b/T146c: 決着前の較正の非対称（優勢側だけの過大評価）を測る（2026-09-23）

T146a（`2026-09-23_presettle_sigma.md`）は「σ を決着前の行だけから作り直す」仮説を外し、代わりに
**較正表が対称ではないこと**を見つけた——自分が劣勢と読む行は予測が実勝率より低く（過小評価）、
自分が優勢と読む行は予測が実勝率よりずっと高い（過大評価）。σ の対称な補正では直らない形である。
本 T はこの非対称を数字にし（T146b）、序盤〜終盤で割って機構を探る（T146c）。

**記録**: T145／T146a と同じ。実 = `w41`（300 局）／合成 = `w39 + w42`（900 局）。決着前の行だけ
（`--pre-settle on`）で測る。

---

## 0. 結論（先に書く）

**非対称は実在し、大きい。優勢側だけで見るとコインに大きく負け、劣勢側はコインにほぼ並ぶ。**
だが**序盤ほど大きいという予告は外れた**——**逆に終盤ほど大きくなる**。両記録で同じ向きに出た。

| | 実（決着前 3,212 行） | 合成（決着前 9,316 行） |
|---|---|---|
| 優勢側（`p>0.5`）の行数 | 1,919 | 5,886 |
| 優勢側の較正の差（符号つき） | **+0.177** | **+0.217** |
| 優勢側の対数損失 | 0.807 | 0.895 |
| 優勢側のコイン | 0.654 | 0.680 |
| 劣勢側（`p<0.5`）の行数 | 1,287 | 3,429 |
| 劣勢側の較正の差（符号つき） | **−0.026** | **−0.069** |
| 劣勢側の対数損失 | 0.556 | 0.682 |
| 劣勢側のコイン | 0.532 | 0.623 |

**優勢側は較正の差が劣勢側の 3〜7 倍大きく、対数損失がコインを 23%／32% 上回る**（大きく負ける）。
**劣勢側はコインとの差が 4%／9% とずっと小さい**（ほぼ並ぶ）。**T145 で見つけた「決着前の自信過剰」は、
ほぼ全部が優勢側の過大評価から来ている**。

| 序盤／中盤／終盤の較正の差（符号つき・優勢側） | 実 | 合成 |
|---|---|---|
| 序盤（自席 0〜1 ターン目） | +0.106 | +0.167 |
| 中盤（2〜3 ターン目） | +0.192 | +0.227 |
| 終盤（4 ターン目以降） | **+0.222** | **+0.252** |

**過大評価は序盤より終盤のほうが大きい**——「相手の速さが後から育つのを読めていない」（T118 が
最上位分位で見つけた機構）と同じ向きだと予想したが、**逆だった**。§4 で機構を考える。

## 1. 問い

T146a で見つけた較正表の非対称——**優勢側（自分が勝つと読む行）だけが大きく過大評価されている**の
ではないか。もしそうなら、σ を対称に広げる修正（T146a）が効かなかった理由も説明できる。

## 2. 式（新定数ゼロ・当てはめない）

新しい価格式は書かない。既存の `crossing_bridge.collect(pre_settle=True)` の行に対し、
`theory_order.prob_of_d` が計算する予測確率 `p`（既存の出荷読み `rel`・σ も既存の表から引く）を
**符号（`p>0.5`／`p<0.5`）で分けるだけ**（`tests/scripts/pre_settle_asymmetry.py` 新規）。
序盤／中盤／終盤の境目（自席ターン `j_me` の 0〜1／2〜3／4+）も新しい閾値ではなく、行の分布を
3 つに割る宣言である。

## 3. 予告と当否

`pre_settle_asymmetry.py` の docstring に測る前に書いた予告:

| # | 予告 | 結果 | 当否 |
|---|---|---|---|
| 1 | 優勢側の較正の差は劣勢側より大きい（符号は正・劣勢側は負かゼロに近い） | 実 +0.177 対 −0.026・合成 +0.217 対 −0.069 | **当たり** |
| 2 | 優勢側だけで対数損失を測るとコインに負ける幅が広がり、劣勢側だけならコインに近いか勝つ | 優勢側はコインとの差 23%／32%・劣勢側は 4%／9%（勝つまでは届かないが大きく近い） | **概ね当たり**（劣勢側も僅かに負けはする） |
| 3 | 優勢側の過大評価は序盤ほど大きい | **逆——終盤ほど大きい**（両記録で一貫） | **外れた** |

## 4. 予告 3 が外れた理由（考察・当てはめない）

T118 の機構（「相手の速さ `A_opp` が後から育つのを読めていない」）は**全行の最上位分位**（決着帯に
近い、はっきり優勢の行）で見つかったもので、**決着前の行全体**（本 T の母数）とは条件が違う。
本 T の結果は逆に「終盤ほど優勢側の過大評価が大きい」——2 つの候補を考えた（どちらも測っていない・
次の T に送る）:

1. **残りターンが長いほど不確実性が増えるのに、`σ_rel·s` の伸縮がそれを十分に織り込めていない**
   （`s = clock_scale(τ_me, τ_opp)` は τ の大きさで伸びるが、終盤の行ほど「これから何が起きるか」
   の分散が本当はもっと大きいかもしれない）。
2. **行は独立ではない**——1 局の中で「優勢」の評価が続けば、その局の終盤の行は全部同じ局から来る
   （1 局の見立てが外れれば、その局の終盤の行がまとめて外れる）。終盤帯は序盤帯より 1 局あたりの
   行数が多くなりやすく、**外れた局の影響が終盤帯に集中して出た可能性**がある（局単位で束ねた
   検算はしていない）。

## 5. 不変量

* `favorite`＋`underdog` の行数は全行数と一致する（`p == 0.5` の行だけが除かれる・実 3,212 = 1,919
  + 1,287 + 6・合成 9,316 = 5,886 + 3,429 + 1）。
* `stage_split` の 6 マス（優勢／劣勢 × 3 段）の合計も全行数と一致する（取りこぼしなし）。
* 実・合成の両方で符号・大小関係が一致する（優勢側 ≫ 劣勢側・終盤 > 序盤）——単一記録の偶然ではない。

## 6. 上手くいったこと／いかなかったこと

**上手くいった**:
* **T146a の較正表から見えた手がかり（非対称）を、そのまま数字にできた。** 新しい価格式を 1 つも
  書かずに、既存の予測確率を分けるだけで測れた。
* **予告 1・2 は当たり、「決着前の自信過剰はほぼ優勢側だけの問題」と言い切れる形になった。**
* **予告 3 が外れたことを隠さず報告し、外れた理由の候補を当てはめずに 2 つ挙げた。**

**いかなかった／自己批判**:
* **予告 3 の理由付けが、条件の違う T118 の機構をそのまま流用していた。** T142 の「T141 の全体比率を
  部分集合に流用した誤り」と同じ型の誤りを、今回は結果が出る前に予告の段階で犯していた。
* **局単位の束ね（1 局が終盤帯を支配していないか）を検算していない**——§4 の候補 2 は次の T に残る。
