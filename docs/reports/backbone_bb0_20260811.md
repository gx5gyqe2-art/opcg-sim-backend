# bb0 — 合成カード実現性スパイク（骨組み線 Phase 0）（2026-08-11）

骨組み線（`docs/cpu_backbone_plan.md`・bb 系列＝現行線と分離）の最初のスパイク。
**問い**: 実カードから収穫した能力を再結合した「実在しないカード」のデッキ×バニラリーダーで、
エンジンは対局を構造的に無傷で完走できるか。

計器: `bb_card_factory.py`（能力収穫2963件・コスト予算 c±1/低確率±2・数値変異は既定OFF）
／`bb_selfplay_audit.py`（対局ごとに新デッキ生成・出荷既定エンジン sims32・構造不変条件＋内在品質基準）。

## 1. 結果（300局・seed 880000〜880299・台帳 /tmp/bb0_ledger.jsonl）

| 指標 | 値 | 基準 |
|---|---|---|
| 完走 | **295/300** | — |

（実カードでは稀にしか踏まれない経路を合成世界が高頻度で踏んだ）。修正後に再監査して
Phase 0 を確定する。

## 2. 発見したエンジン欠陥（決定論再現・seed 明記）

### 欠陥A: キャラ対象選択にリーダーが混入し、リーダー移動でカードが増える（CARD_LOSS 3件）
- 再現: seed 880007・step84。「相手のキャラ1枚までを効果無効…KO」（合成880007510・
  実カード由来の能力）の SEARCH_AND_SELECT 候補に**リーダー（BB-L002）が含まれ**、
  選択・解決後にそのプレイヤの総カード数が 51→52（リーダーがリーダー枠に残ったまま
  コピーがトラッシュ系ゾーンへ）。**二重の欠陥**: (a) 「キャラ」対象フィルタがリーダーを
  除外していない経路がある、(b) リーダーの KO/ゾーン移動が保存則を破る。
- 他: seed 880094・880148 も同型（loss −1＝+1枚増殖）。

### 欠陥B: 合法手列挙と declare_attack の不整合（APPLY_NONE 2件）
- 再現: seed 880014・step47。攻撃 `BB-880014003 → BB-L002` が **legal_actions に列挙**
  されるのに適用は `ValueError: このカードは効果によりレストにできないためアタックできません`。
  「レストにできない」拘束の検査が列挙側に無い＝列挙と検証の不整合（探索の
  例外手封印則により実害は「無駄な死枝」だが、規約違反＝dead_child 汚染源）。
- 他: seed 880083 も同型。

どちらも**現行線の共有資産（エンジン）の修正案件**＝現行線の規約（テスト追加・
`make test`・必要ならベースライン再生成）で直す。修正は本レポートの範囲外（追補しない・
修正後の再監査は bb0b として別レポート）。

## 3. 既知の設計課題（Phase 3 で対処・実行可能性には無害）

- 固有名条件の能力（「リーダーが『ウタ』の場合」等）は合成世界で死文＝効果分布を薄める。
  Phase 3 で固有名参照つき能力のフィルタ or 汎化書換えを入れる。
- 打ち手は現行 gen14（合成IDは vocab 外＝PAD 埋め込み）。「物理＋探索だけで打てる」ことの
  予告編として機能したが、対局品質の上限は骨組みネット（bb1 以降）で置き換える。
