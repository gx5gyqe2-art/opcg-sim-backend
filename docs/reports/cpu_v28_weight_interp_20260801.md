# v28 重み補間スイープ — 交換曲線の同定・昇格点なし（2026-08-01）

スナップショット（追記・改変しない）。v27 診断（`cpu_v27_tradeoff_diagnosis_20260801.md`）の
選択肢1の実行: v25 防御混合腕（コーチ PASS 6.1 / アリーナ 0.454）と gen8 の value を
重み空間で線形補間し、コーチ得点とアリーナの両立点を探した。

## TL;DR

- **補間直線上に昇格点（wr≥0.55・CI下限>0.50）は存在しない**。全 α でコーチ v3 は
  PASS のまま（4.7→5.6〜6.2 と α に応じて滑らかに増える）が、アリーナは
  parity をわずかに割る領域から出ない。
- **コーチ得点とアリーナ勝率は滑らかに交換される**＝v27 の診断（14点の正解軸＝抑制と、
  全分布の最適のねじれ）の直線上の追認。補間で「ねじれを解く」ことはできない
  ——両者は重み空間で分離不能に混ざっている。
- 唯一の意思決定点は **α=0.5**: コーチ 5.6（PASS・退行ゼロ）× アリーナ 0.475
  （320局・CI [0.426, 0.524]＝parity を棄却できないが優越もない）。
  「人間検証点の改善を取り、自己対戦で最大 ~2-3pp を払う」取引としてのみ成立する。

## 1. 交換曲線（すべて標準 seed 計画 71000・4帯・出荷 gen8 相手）

| α（候補側重み） | コーチ v3（16seed・14点） | アリーナ wr | 95%CI | 局数 |
|---|---|---|---|---|
| 0.00（=gen8） | 4.7（基準） | 0.500（定義上） | — | — |
| 0.50 | **5.6 PASS**・退行0・m4@8 bar超え | 0.475 | [0.426, 0.524] | 320 |
| 0.75 | **6.2 PASS**・退行0・m4@8/m5@7 bar超え | 0.444 | [0.396, 0.491] | 320 |
| 1.00（=v25防御混合腕） | 6.1 PASS・退行0 | 0.454 | [0.411, 0.497] | 480 |

補足: 40局スクリーンは今回も誤誘導した（α=0.75 が screen 0.600 → 本判定 0.444、
α=0.25 が screen 0.375）。**40局は方向すら当てにならない**——本判定の seed 計画で
320局以上を読むこと（v15 の検定力の教訓の再演）。

補間の実装: 両ネットは gen8 温スタート系で同構造・同 vocab_ids・同 EffF（assert 済み）。
浮動小数の重み配列のみ α:1−α で線形結合（メタ・EffF は同一性確認の上でそのまま）。
サニティ: 同一盤面の予測が α に対し単調（0.102 → −0.010）。

## 2. 読み

1. **昇格は不可能**。補間は存在しない強さを作れない（両端がともに parity 以下なので当然の
   帰結だが、α=0.75 のコーチ 6.2 が純候補の 6.1 を上回るなど、コーチ軸では非自明な
   山があった＝重み平均の正則化効果。アリーナ軸には山は無かった）。
2. **ねじれは重み空間で分離不能**。ドン付与の抑制（v27 §2）は特定の重み方向に
   局在しておらず、α を下げると14点の得点と一緒に薄まる。分離するには重み操作でなく
   **データ操作**（14点型の局面だけに効く教師＝条件付き対比。v26 原因分析 §3 の
   フォーク生成＋ペア順位学習が該当）が要る。
3. **採用判断はトレードオフの価値観の問題**になった: アリーナ（自己対戦 vs gen8）は
   CPU 同士の均衡での強さ、コーチ14点は人間がマークした失敗局面の正解率。ユーザの
   目的（人間が対戦して自然に感じる CPU）にどちらが近いかで α=0.5 採用/見送りが決まる。
   本レポートは判定材料の提供まで＝**昇格基準では FAIL、採用はユーザ判断**。
