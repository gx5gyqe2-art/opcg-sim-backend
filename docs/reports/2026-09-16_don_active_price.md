# T57——アクティブなドン 1 個の価格 `δ_A`。ターンの途中の使用権は `δ/R`（実）〜`2δ/R`（合成）、相手のターンに払える分は測れず

2026-09-16 実施（ユーザ指摘「ドンのアクティブかレストかの価値って今考慮されてない？」→「測ってみてください」）。
**回帰しない・当てはめない**（総在庫を固定した帯の中の傾き・局クラスタのブートストラップ）。本報告は特定時点のスナップショット。

## 結論を 5 行で

1. **総在庫を固定して「今アクティブなドン」の傾きを読むと、自席ターンの途中では `δ_A` = 0.0067 [0.0005, 0.0087]（実）／0.0142 [0.0112, 0.0154]（合成）**。
   在庫の価格 `δ` = 0.0277 の **0.24／0.51 倍**。
2. **理論の流れの規則 `δ/R` = 0.0067 に実デッキはぴたり**・合成は 2 倍（`2δ/R`）。T42 で「アクティブにする効果は在庫÷R」と置いたのは
   実測に支持された。**`δ×N`（在庫）は 2〜4 倍高い**。
3. **相手のターンに払える分（カウンターイベント・ブロッカー）は測れない**——相手のターン開始時に自分のアクティブなドンが残っている行が
   少なく（平均 0.28／0.40 個）、傾きは −0.023 [−0.085, 0.026]／+0.008 [−0.009, 0.025] で 0 を含む。
4. **したがって `ACTIVE_DON`（アクティブにする効果）の価格は今の `δ×N/R` のまま**（実測の写し・実デッキで一致）。
   「付けて殴る増分」の形は上限がこの `δ_A` で押さえられる。
5. 帳簿（`state_meas`）が総在庫で数えていること自体は正しい（在庫 δ）。使用権の価値は 1 ターン分の流れで、価格の側で持つ。

## 1. 器（`don_active_price.py`）

```
δ_A = ∂P(win) / ∂(アクティブなドン)
帯  = (総在庫, 自ライフ, 相手ライフ, ターン帯, 手札, 自場の体数)   説明変数（アクティブ数）は帯に入れない
```

| 場面 | 行 | 意味 |
|---|---|---|
| `mid` | 自席ターンの 2 番目以降の判断点（開始時は全部アクティブで傾きが無い） | このターンの残りの使用権 |
| `opp_turn` | 相手の最初の判断点から自分のドン（列 4/5）を読む・z は自分の側 | 相手のターンに払える価値 |

## 3. 読み方

- **使用権 1 ターン分 = 在庫 ÷ 残りターン**は実デッキで数字まで合った。合成の 2 倍は「合成デッキはドンを使い切る打ち回し」
  （T17: 76.9% のターンで使い切る）でアクティブが残る行が例外的なため、と読む（因果ではない）。
- **相手のターンの使用権は記録では見えない**（CPU が自分のターンに使い切る）。イベントカウンターの価値（§12 の二重通貨）は
  ここでは検められない。
- `mid` の行は決定の後の量で条件付けている（使った後にアクティブが少ない）——帯で総在庫と場の体数を固定して、使い道（登場）の
  分は落としてある。

## 4. 次

- `ACTIVE_DON` は据え置き（`δ×N/R`）。付与・バフ（T55/T56）と同じ「`ν` の増加」で持つなら、その値は `δ_A` を超えないことを検算に使う。

## 限界

- `mid` は決定後の量（選択の交絡は帯で全部は消えない）。
- `opp_turn` は標本が薄い（アクティブが残る行が 1 割未満）。
- **観察であって因果ではない**。
