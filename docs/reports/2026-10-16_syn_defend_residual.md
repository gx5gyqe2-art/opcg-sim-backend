## 1. 問い・腕・予告（数を見る前に固定）

### 1.1 問い

記録の守りの点（相手のリーダーへの攻撃 1 回ごと）で、実際の守りが理論の見込み（このターンの残りを全部ライフで受ける）と同じだった群と、違った群（札を切った・ブロックした）とで、「守る席の実際の勝敗 − 理論が守る前に読んだ守る席の勝率（1 − W0）」の残差はどう違うか。

### 1.2 写しと点

- 写し: `syn_opp_turn_split` の写し（既定の表・`OPCG_HAND_STOP=survive`・`OPCG_CLOCK_PARTS_DUMP=1`＋`OPCG_DEF_TRACE_DUMP=1`＋`OPCG_OPP_TURN_DUMP=1`・300 局）をそのまま使う。新しく回さない。相手のターンの欄は `defres` が読まない余分な欄。
- 点・群・残差・割り（帯・残りライフ・時計の差・W の区間〔接戦 0.3〜0.7〕・ターン単位の参考）は実側 §1.2〜§1.4 のとおり。**本体は「理論＝受ける・実際＝切った」群と「理論＝受ける・実際＝受けた」群の残差の差**（95% 区間は局ごとの復元抽出）。

### 1.3 不変量（実側 §1.6 のとおり）

- 群の点の和＝全点。全点の残差の平均＝W の較正の偏り（全点で実際の勝率 − W の平均）。
- 「リーダーへの攻撃」の点の数が、同じ記録の `defend` の数え方と矛盾しない。

### 1.4 予告（司令塔が固定）

- 「理論＝受ける・実際＝切った」群の残差が、「理論＝受ける・実際＝受けた」群より **+0.02〜+0.05** 高い。残りライフ 1〜2 で差が最大。
- 判定（実側と同じ線）:
  - 差の 95% 区間が 0 を上回る → 「探索の守り（切る）は理論の見込みより良く転ぶ＝理論の価値の比を直す候補へ」。
  - 区間が 0 を跨ぐか負 → 「理論の守りは実際より悪くない＝対局で決める」。

### 1.5 限界（先に書く）

- 実側 §1.7 と同じ（相関であって因果でない・W での条件づけは局面の差を一部しか吸収しない・点は局の中で相関する）。
- **合成の記録の守りは、生成時の CPU のもので深い探索ではない**。「実際に切った」は探索の判断ではなく、その CPU の判断。実側の「探索の守りが良い」という読みは、合成ではそのまま言えない。
- 合成の W の較正はデッキの色ごとにずれる（`syn_w39_deckcal`）。残差の平均の偏りにそれが入る。
- 記録は古いエンジン（a28ededa）、理論は新しいエンジン。
