# T156(a): 置き換え先を「付けろ」ではなく「価格を借りた攻撃そのもの」にする（2026-09-24）

ユーザ決定（2026-09-24「aでいきましょう」）。T18-why（`2026-09-24_t18_why.md`）が突き止めた負けの主因——
純付与の価格は「付けて→（同じターンの後で）殴る」という2手の計画の価値なのに、介入は1手目（`ATTACH_DON`）
だけを実行し殴りは次の決定点の探索に委ねるため、探索が別の手を選ぶと同じ攻撃の価値を決定点ごとに何度も
計上する連鎖が起きていた（介入826件中41%が付与への置き換え、うち89%が同じターンで再介入）——を、
**置き換え先を「価格を借りた攻撃候補そのもの」にする**ことで実行の側から断つ。パイロット
（`2026-09-24_t18_pilot.md`）と**同じ条件・同じ seed**（`synth_roles`・sims 64・`attack_any`・
`attach_static on`・32 ペア＝seed 帯 1300000／1300016）で理論・プラセボ両腕を打ち直した。

**器**: `shadow_forbid.seq_prices` が読み替えた候補に `src_index`（価格を借りた攻撃候補の index）を添え、
`shadow_row` が `cands` と同じ長さの `reread_src` を返す。`t18_arena.redirect_reread` が、置き換え先
（理論の `best_index` またはプラセボの無作為な引き）がこの `reread_src` を持てば、その index に差し替える
——1 手目は同じ `ATTACH_DON` でも `commit` の `sig` が攻撃の型（対象つき）になるので、`commit_step` が
残りを機械的に殴りまで進める。新定数ゼロ。**CRN で決定的**——選ぶ手・候補・順位づけは 1 ビットも変えていない
ので、両腕とも「どの候補を選ぶか」はパイロットと完全に同じで、変わるのは「選ばれた候補が読み替えられた純付与
だったときに何を実行するか」だけ。

## 0. 結論（先に書く）

| 腕 | パイロット（修正前） | **T156(a)（修正後）** |
|---|---|---|
| 理論の勝率 [95% CI] | 0.234 [0.147, 0.322] | **0.3125 [0.217, 0.408]** |
| プラセボの勝率 [95% CI] | 0.125 [0.049, 0.201] | **0.156 [0.075, 0.238]** |
| 対にした差（理論−プラセボ）[95% CI] | +0.109 [+0.037, +0.182] | **+0.156 [+0.031, +0.281]** |
| 1 局あたり介入した行 | 12.9／11.8（理論／プラセボ） | **9.3／10.8** |

**T18-why の機構診断は正しかった**——置き換え先を攻撃そのものにしただけで、付与への置き換えは 41% から
2.7% までほぼ消え、1 局あたりの介入数も 12.9 から 9.3 に減った。**理論の腕の勝率も上がり（+0.078）、
プラセボとの差も広がった（+0.109 → +0.156・CI は 0 を跨がない）**——「理論の指す先には信号がある」という
パイロットの結論を、より強い形で裏づけた。

**ただし、理論を方策として使うこと自体はまだ探索に勝てない**——新しい勝率の 95% CI 上限は 0.408 で、
0.5 にはまだ届かない。予告 P3（勝率が 0.322 を超える）は **僅かに届かなかった**（0.3125 < 0.322・差は
0.0095）。点推定は明確に上がり、区間は大きく 0.322 の上に広がっている（上限 0.408）ので、この閾値だけを
見て「機構の説明が外れた」とは読まない——他の指標（付与への置き換えの消失・介入数の減少・差の拡大）が
すべて同じ向きに揃っている。**32 ペアでは境界線上の判定しかできない規模**だったという以上の意味を持たせない。

## 3. 何を何に替えたか（理論の腕・上位）

| 打った手 → 置き換え先 | 件数（596 中） |
|---|---|
| 攻撃 → 攻撃 | 144（24.2%） |
| 出す → 攻撃 | 130（21.8%） |
| 出す → 出す | 72（12.1%） |
| 攻撃 → 出す | 44（7.4%） |
| 出す → 終了 | 42（7.0%） |
| 効果 → 終了 | 40（6.7%） |
| 効果 → 攻撃 | 27（4.5%） |
| **付与 → 攻撃**（折り返し） | **19（3.2%）** |
| 出す → 付与 | 16（2.7%） |
| **付与 → 出す** | **13（2.2%）** |

T18-why（パイロット・修正前）では「攻撃→付与」194 件（23.5%）・「出す→付与」131 件（15.9%）が上位 1・3 位
だった。**置き換え先が付与そのものの行は、`play → attach` の 16 件（2.7%）・`attach → play` 13 件（2.2%）・
`attach → attack` 19 件（3.2%）まで縮み、合計しても 596 件中 48 件（8.1%）**——ほとんどのケースで、以前なら
「付与」として記録されていた置き換えが「攻撃」（折り返し先）として記録されるようになった。残る少数の
`rep_family=="attach"` は、対応する攻撃候補が無い（殴れない札への静的な付与・`attach_static` の対象）行。

## 4. 読み

1. **T18-why の機構診断は的中した**——「付与への置き換えは1手しか実行されないので同じ価値を何度も計上する」
   という説明どおり、置き換え先を実際の攻撃に差し替えただけで付与への置き換えがほぼ消え、介入密度も下がった。
2. **勝率とプラセボとの差は両方とも改善した**——理論の腕が方策として「良くなった」ことと、「理論の指す先に
   信号がある」ことの両方が、パイロットより強い形で確認された。
3. **それでも理論はまだ探索に勝てない**——CI 上限 0.408 は 0.5 に届かない。残る介入（596 件・折り返しなし
   473 件）には、T18-why の副因（安い体の価格が負になる・大きい体の価格が高すぎる・§0.6 (4) 参照）や、
   T155 が「本物の対立」と確認した「付けて殴る vs 手札を出す」（`play↔attach` 29 件・依然として理論と
   探索が本当に割れる行）がまだ残っている。**主因（実行の連鎖）は塞いだが、価格そのものの誤り（副因・
   バックログ #43）は未着手**。
4. **介入密度が下がったのに勝率が上がった**——同じ 32 ペア・同じ決定点を歩いているので、これは「介入が
   減って探索に近づいたから勝率が上がった」だけではなく、**残った介入 1 件あたりの質**（実行される手が
   理論の意図どおりになった）も上がったことを示唆する。両方の効果は本器の記録だけでは分離できない。

## 5. 不変量

* 両腕とも異常終了 0・void 0（32 ペア×2）。
* 箱の完走率は理論・プラセボとも 100%（パイロットと同水準・退行なし）。
* コード変更は「選んだ候補が読み替えられた純付与だったときの置き換え先」だけ——`shadow_row` の
  `forbidden`／`best_index`／`chosen_index` の計算・プラセボの `rng` の引き方は 1 ビットも変えていない
  （テスト 11 本で固定・`test_shadow_forbid.py` 43 本・`test_t18_arena.py` 42 本・ゲート 429 Rust ＋
  1718 pytest green）。
