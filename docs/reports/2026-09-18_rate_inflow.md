## 1. 問い（T92 が指した先）

T92 で `A` を割ったところ、**盤面の項は実績の 0.773／0.754 倍で小さく、超過は全部手札の項**（`A` の 33.5%／33.4%）だった。
機構は **`playable_attack_price` が「今のドンで出せる体の総額」＝在庫**であること——**1 回しか出せない札を毎ターン出せることにしている**。
**T76 が `μ` について確かめた取り違え**（「`μ` は**流入**の値であって**在庫**の平均ではない」）が、**速さの側で再現していた**。

## 2. 式（新定数ゼロ・T91 の `r` と同じ形）

```
SLOPE_HAND_MODE = flow
  a = (1/N) Σ_{札 ∈ そのデッキ}  attack_value_don(パワー, 相手リーダー, リーダー狙い)
      体でない札（イベント・ステージ）は 0
      コスト > 今のドン の札も 0            （規則の枠。ドンは毎ターン +1・上限 10）
```

**打ち方は入らない**——「どの札を選ぶか」ではなく**山の平均**を取る。デッキは seed から決定論で作り直す（T91 と同じ経路）。
**在庫のほうは速さではなく「一度きりの上積み」**で、交点まで歩く形（`tau_net`・T90）が**既に 2 ターン目から 1 回だけ**足している。

## 6. 読み方

- **上手くいった（本 T の収穫）: 水準が直った**。T89 が見つけた「`A` は実測の 1.26／1.20 倍」は
  **手札の項を在庫で数えていたせい**で、**流入に替えるだけで 1.010／0.938 になる**。
  **当てはめではない**——`a` は**デッキの中身と攻撃の価格**だけから出ており、**1 を狙って作っていない**。
  T89 → T92 → T93 で、**「`A` が多い」の正体を 3 段階で特定して閉じた**ことになる。
- **上手くいった 2: `curve_scaled` が実で最良**（0.6078 → **0.6200**）。この読みは輪郭を `A` の比で伸縮するので、
  **`A` の水準が正しくなった効果がそのまま出る**。
- **上手くいかなかった: 一定の `A` の時刻は悪化**（偏り +3.54 → +4.98／+3.67 → +5.19）。
  **これは矛盾ではない**——**損害の輪郭は加速する**（0.001 → 0.25/ターン・T52）ので、
  **「平均の速さ」を局の開始から一定で当てると、必ず時刻を遅く言う**。水準を合わせるほどそうなる。
  **時刻を読むための形は `curve`（輪郭に沿って歩く）で、そこは設計上 `A` を使わない**。
  つまり **`A` は「水準の量」として正しくなり、時刻は輪郭が担う**という役割分担がはっきりした。
- **ブロッカー（T92 の `on`）は重ねない方がよい**——水準が合った状態で足すと **0.980／0.906 と 1 を割る**
  （`stock` のときは 1.262 → 1.232 で改善方向だった）。**T92 の「対で入れ直す」は成立しなかった**＝
  **ブロッカーの割引は、今の `A` の他の項が正しくなった時点で過大**になる。既定は `off` のまま。

## 7. 次（ユーザ判定）

1. **既定をどうするか**（本報告の判定事項）。**私の推しは `--slope-hand flow` を既定にする**——
   (1) **規則とデッキの中身だけ**で書けている（`stock` は在庫を毎ターン数える誤り）・
   (2) **水準が 1 に載った**（当てはめずに）・(3) **`curve`（既定の読み）と `F_end/Θ_start` は完全に不変**・
   (4) `curve_scaled` は実で改善。**費用は一定 `A` の偏り**だが、**そこは `curve` の担当**。
2. **`A` の「一度きりの上積み」を交点の歩きに入れる**（次の T）——手札の在庫は速さではないが**総量には効く**。
   `tau_net`／`tau_from_profile` は既に「2 ターン目から手札の体が入る」形を持っているので、
   **そこへ `stock`（在庫）を、毎ターンの `a`（流入）と分けて**渡す＝**在庫は 1 回・流入は毎ターン**。
   **予測: 一定 `A` の偏りが縮み、`curve` は不変のまま**。
3. 接戦帯を正しい価格から組み直す（T88 の結論）。4. 効果の型を種類別に割る（未着手）。

## 限界

- **`a` は「引いた 1 枚が体である期待値」だけ**——引いた札が**除去や探す効果**でも損害は増えるが、そこは数えていない
  （攻撃の価格しか見ていない）＝**流入の下限**。
- **ドンの枠は今の行のドン**で切っている。引いた札は**後のターンに出せる**ので、この絞りは**流入をやや小さく見積もる**。
- **デッキは seed から作り直している**（記録にデッキの列は無い）＝生成時と同じ決定論の経路を通る前提（T91 と同じ）。
- `a` は**局を通して一定**（山が減っても数え直さない）。7 ターン前後で 10 枚強しか引かないので分布はほとんど動かない（未測定）。
- **一定の `A` を使う読み（`theory`）の時刻は、輪郭が加速する限り原理的に合わない**。本 T は水準の話。
- **観察であって因果ではない**。
