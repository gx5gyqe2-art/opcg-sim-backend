## 1. 問い（§0.7 の 9 段・1 段目）

完全情報（§0.05）では同じ局面を両席から読んだ勝率は足して 1。交点の橋の行 `(w, t)` は `p = W(τ_opp − τ_me)` を
出すが、`τ_me` は **w のターン t 開始の盤面**、`τ_opp` は **相手の前ターン t−1 開始の盤面**から読んでいた
（私の耐久 `Θ_w` は相手の t−1 の攻撃で削られる前・相手の速さ `A_{1−w}` はそのターンに出した体を含まない＝
両方とも `τ_opp` を膨らませ、手番の席に甘い）。T120 が `race_alloc` で同じ古さ（「次ターンに殴る体を 0.8／0.7 体
落とす」）を見つけて直していたのに、`rows_out` の `τ_opp` だけ古いままだった。

## 2. 式（新定数ゼロ・新しい量ゼロ）

**(a) 同じ瞬間**（`OPP_CLOCK_MODE=mirror`・`crossing_bridge.mirror_view`＋`seat_row`）: 行 `(w, t)` の相手の役を、
**w のターン t の最後の行**（`turn_last`＝相手のターン t+1 に w が向き合う状態）を**相手の席から見た鏡**にして、
**同じ `seat_row`**（既存の per_seat の本体を関数に切り出しただけ・既定の道はビット一致）で `w := 1−w` として読む。
* w の側（新しい相手側）は**そのまま**——出した後の手札・殴ってレストしたブロッカーはレストのまま・切るドンは
  使い残し（`g_for(w, t)`＝`turn_last[(w,t)]`・T76／T110 の規約＝me 役が `Θ_opp` を読む規約の**鏡**）。
* 相手の側（新しい自分側）は**リフレッシュ後**（`rules/turn.rs` `refresh_all`／`reset_player_status`）——
  レスト 0・召喚酔い 0・`can_attack`＝ユニット・付与ドンが戻る・ドンデッキから +2（`next_turn_don` と同じ式）・
  ブロッカーは札の情報で立て直す（列 6 は「非レストのブロッカー」なので殴ったブロッカーは 0 になっている）。
* `j`＝相手の次の自席ターンの序数（`len(prev_o)`）。手札の枠は相手の直近の自席行から（手札の中身はその席の行にしか無い）。

**(b) 手番の半ターン**（`theory_order.W_MOVER_MODE=half`）: 2 本の時計は各席の**自席ターン**で数えるので、同じ段数
なら手番の私が先に届く。連続の時刻で `T_me = t + 2(τ_me−1)`・`T_opp = t + 1 + 2(τ_opp−1)`、私が先なのは
`τ_opp − τ_me > −1/2`。だから **`W` の中心は `D = −1/2`**＝`W(D + 1/2)`（`w_of_d` も同じだけずらす・`predict` の同点の
扱い〔`τ_me <= τ_opp` で勝ち〕とは元から整合）。**規則から出る値で、当てはめた定数ではない。**
従来（古い読み方）は `τ_opp` が約 1 段古いぶん `D` が約 +1 されていたので、**実質の中心は −1＝半ターン行き過ぎ**
（自席びいき）だった。

**対の恒等式**（`seat_pair_symmetry`）: 従来の読み方では行 `a=(w,t)` の `τ_me` と行 `b=(1−w,t+1)` の `τ_opp` が
**同じ `per_seat[(w,t)]` の写し**なので `d_a + d_b = τ_opp(a) − τ_me(b)`＝**対のずれは古さそのもの**（`shared_term_share`
1.000 で確認）。`mirror` ではこれが崩れ（0.006）、`d_a + d_b ≈ −1`（`identity_resid` 1.66／1.32）＝**半ターンを足して
初めて対が反対称になる**（`half` の `p(d) + p(−1−d) = 1` はテストで固定）。

## 3. 机上監査（T151-0・反証つき）

Workflow で読み手 4 本 → 統合 → 反証 3 本。**統合ノートの推薦（相手の役を w の `turn_start` から読む）は反証 3 本
とも棄却**し、修正版が本 T の式になった:
1. **`Θ_w` の正しい読み元は `turn_start` ではなく `turn_last[(w,t)]`**——w が t で殴ったブロッカーは相手の t+1 まで
   レストのまま・手札とドンは出した後・払った後（T110）。`turn_start` で読むと全ブロッカーがアクティブ・財布が満杯
   ＝`Θ_w` を過大に読む（自席びいきの別の形）。**me 役が `Θ_opp` を読む規約の鏡は `turn_last`**。
2. **手番の半ターン**——読み手の予告「切替で対の和 → 0」は導けない（`W(D)` は `D=0` で 0.5・切替後は `d_a+d_b=−1`）
   ＝**切替だけでは符号が反転する**と反証が予告し、**そのとおりになった**（`mirror/off` で −0.240／−0.211）。
3. **`sched` の第 1 段が全ての歩きで 0**（`seat_slope_sched` の `j <= 1 → 0`・`rate_at` は `sched` が在ると `j0` の規則を
   通らない）——実 5 局 65 本の歩きで `sched_j1_sum = 0.0`・`rate_at(j=1, j0=3, sched) = 0` を確認。**両席に対称**なので
   本 T の予告には効かないが、**全ての τ を約 1 ターン膨らませる**＝T146b の「τ の偏り +1.6」の候補。**別 T（T152）**。

**残る非対称（開示・直せない）**: 相手の体のパワーは w の行の列 0＝「相手の手番でないとき」の値（`YOUR_TURN` の
パッシブが載らず `OPPONENT_TURN` のパッシブが載る）。エンジンは手番側のパッシブしか計算しないので w の行からは
読めない。同じ札が `A_w` の在庫と `Θ_w` の守りに同時に入る T135 ⑤ は、どの行を選んでも消えない（従来も同じ）。

  アクティブ・財布が満杯）を入れていた。**手番の半ターン**は私が見落としていたもので、反証の予告（符号反転）が
  そのまま当たった。**測る前に器と式を確かめる**（T144／T147a／T150c／T150f-3 に続く 5 回目の教訓）が今回は守れた。

**いかなかった**:
* 前のチャットで立てた**主張 A（席ごとのフィルタが非対称の原因）は棄却**（効果は +0.03・P6 で数字でも確認）・
  **主張 B の機構（同じ費用の相殺）も誤り**（台帳で訂正）・**σ の系は符号から誤り**（劣勢側は p < z）。
  正しかったのは「作り方を疑え」という方向だけ。
* **実の対の和は −0.070 で ±0.03 に入らなかった**（合成は −0.007）——実は劣勢側へ少し寄る。原因は未特定
  （段別では中盤 −0.108 が最大）。当てはめない。
* **最上位分位の相手の τ の残差（≈7／≈4.5）は動かなかった**——古さとは別の欠陥（T152 の候補）。
* 合成の対数損失はまだコインに負ける（0.778 対 0.693）——優勢／劣勢とも LL がコインより悪い＝**幅（σ）の問題が残る**。
* **線形の橋に予告を立てずに測った**（§5e）——`half` で `dS` は両記録で改善したが κ 付きの `dG` は両記録で悪化し、
  予告が無いので「当たり／外れ」が言えない。交点の橋の 4 指標にだけ予告を書いた（P5）のは範囲の取り方の失敗。
* `pre_settle=off`（全行）では実の的中が 0.716→0.706 と 0.011 落ちる（決着前の行だけなら改善）——決着後の行
  （勝者の最後のターン）で `mirror` の読みが不利になる理由は未調査。

## 8. 見つけた別の欠陥（T152 候補・ユーザ判断）

`seat_slope_sched` は列の先頭 `R_1` を**無条件に** 0 にし（`j <= 1`）、`rate_at` は `sched` が在ると `j0` の規則
（局の最初の自席ターンだけ 0・T103）を通らず `sched[0]` を返す→**全ての歩きの第 1 段が 0**（既定 `RATE_DON_MODE=flow`）。
両席に対称なので本 T の予告には効かないが、**全ての τ を約 1 ターン膨らませる**（実 5 局 65 本の歩きで `sched_j1_sum=0`）。
直すなら `sched` の第 1 段にも `j0` の規則を通す（新定数ゼロ）。予告と両橋の再測定が要るので別 T。

## 9. ユーザ判断をお願いしたいこと

1. **`--opp-clock mirror` を既定にするか**（推薦: **採る**。理由は数字ではなく「同じ瞬間から読む」が規則だから。
   交点の橋の数字は全部それを支持し、線形の橋には効かない）。
1′. **`--w-mover half` を既定にするか**（推薦: **交点の橋の `W`（`rows_out` の p・`win_calib`／`pre_settle_asymmetry`／
   `seat_pair_symmetry`）には採る**——根拠は規則（ターンは交互）で、対の反対称・較正・対数損失がそれを支持する。
   **線形の橋の κ に対しては保留**——`dS` は改善するが `dG` が両記録で悪化し、予告が無い。今の実装は
   `prob_of_d`／`w_of_d` に共通に掛かるので、採るなら「交点の橋の p だけ」に絞る配線（`win_calib.probs_of` で
   掛ける）を先に書き、線形の橋の κ は `dG` の予告を立ててから別に判断する）。採るなら既定の切替と、§0.6・
   T41 以降の再基準化を同じコミットで。
2. **次の T**: 両側対称な幅（σ）の問題——T146a の手順（σ_rel を決着前の行から作り直す）を**対称化した行**で
   もう一度（当時は標本が非対称で測れなかった）。
3. **T152（歩きの第 1 段が 0）を立てるか**——最上位分位の残差と T146b の +1.6 の候補。
4. **T149d／T149e は閉じる**（「優勢側だけ」という問いの前提が消えた）。
