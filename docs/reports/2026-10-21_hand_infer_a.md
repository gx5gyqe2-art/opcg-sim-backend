# 相手の手札はどれだけ当てられるか（WP `hand-infer-a`・2026-10-21）

`docs/search_efficiency_plan.md` §7.12。台帳 2+315。計器 `tests/scripts/hand_infer_probe.py`（`claude/hand-infer-a`）。
両席 r13d・160 回・random × synth_roles・seed 3001000〜3002999 の 2,000 局・自分（先手）の MAIN の判断点 145,203 行・holdout は局で分ける。
正解＝相手の本当の手札。基準＝超幾何（相手のデッキの中身 − 公開済みの札、から一様）。

| 当て方 | 対数損失の改善（対 超幾何・holdout） |
|---|---|
| 超幾何＋**公開で明かされた札を固定する**だけ（効果で名前が出た札・学習なし） | **4.6%** |
| ロジスティック回帰（100 列・公開情報＋「打たなかった」の特徴） | 6.0% |
| 小さな MLP | 6.7% |
| ロジスティック回帰から「明かされた札」の特徴を抜く | 1.4% |
| ロジスティック回帰から「打たなかった」の特徴を抜く | 5.5% |

- ターン帯: 1〜2 ターン目は改善なし（−0.9〜0%）／3〜4 ターン目 4〜5%／5 ターン目以降 6.6〜7.2%。役割別: ブロッカー 8〜10%・カウンター 6.5%・除去 5%。
- **探索に効く量**: 相手の手札のカウンター合計（千単位・平均 3.7）の誤差は超幾何 1.20 → 学習 1.13（**6% 減**）。「カウンターを 1 枚以上持つ」の AUC は 0.897 → 0.924（陽性 95.5%＝ほぼ常に持つ）。「2000 カウンターを持つ」の AUC 0.80 → 0.83。
- 効いた特徴の上位: 超幾何の確率そのもの・**明かされて手札にあると分かっている札**（2 位・3 位）・カウンター属性・「このターン相手が使ったカウンター」との交互作用。「打たなかった」の特徴は単独で +0.5 pt、マリガンは効かない。

**読み**:
1. **公開情報から相手の手札を当てる余地は小さい**——予告の下限（5〜15%）に届く程度。相手のデッキが既知なので、超幾何がすでに情報の大半を持っている。「打てたのに打たなかった」はほとんど効かない。
2. 改善の **3 分の 2 は「効果で公開された札を固定する」だけで得られる**（4.6／6.7）。これは学習ではなく、世界の引き直しが公開済みの情報を捨てている穴。今の `determinize` は相手の手札を全部混ぜ直すので、名前が明かされた札も混ざる。**直すのは安い**（公開で分かった札の位置を固定して残りだけ混ぜる）。
3. 相手の手札を完全に当てたときの上限 +77（`2026-10-21_reveal_arena.md`）に対し、推定で届くのは**ごく一部**と見込む（対数損失 6% の改善が Elo にどう写るかは未測定）。「相手の手札」という天井は、推定では崩せない。

**次**: (a) 公開で明かされた札を固定する修正（安い・測る価値あり）。(b) 学習した推定を世界の重みに使う本格版は、上限が小さいので優先度を下げる。
