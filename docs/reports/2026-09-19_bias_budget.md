# T112——**終局の偏りを恒等式で 2 つに割った**。答えは **「74.7%／73.7% は `A` の軌跡の誤り、25.3%／26.3% が的（`Θ`）と要の差」**。さらに **偏りの 90.9%／85.7% は最初の 2 自席ターン（j ≤ 1）に住んでいる**（ユーザ指示 2026-09-19「T18以外で検証ができる範囲について検証をお願いします。」）

結論を先に:

* **偏りは 1 つの数ではなく、2 つの誤りの和である**——**当てはめゼロの恒等式**で割れる:

  ```
  τ_theory − t_left = ( τ_theory − τ_harm ) + ( τ_harm − t_left )
                        ^A の軌跡の誤り        ^的（Θ）と要の差
  ```

  **行ごとに厳密**（浮動小数の誤差 **1.8e-15／3.6e-15**）。
* **T95〜T111 の 17 個の改善で偏りが 1 度も縮まなかった理由が出た**——**大きい側（`A` の軌跡・74.7%）を 1 度も触っていない**。
  触ってきたのは `Θ`（的）の側＝**偏りの 1/4**。
* **居場所は位相で決まっている**（勝った席の自席ターン母数）: **j = 0 で +9.59／+9.89・j = 1 で +5.92／+4.44**、
  **j ≥ 2 は ±0.51 以内**。**j ≤ 1 の 2 つの位相だけで偏りの 102.5%／96.5%**（j ≥ 2 の寄与が負なので 100% を超える。
  判断行の母数では 90.9%／85.7%）。**そしてその 2 つはほぼ全部が `A` の軌跡**（j = 0 で 104.5%／100.8%）。
* **台帳の +2.56 には物差しの +1 が混じっている**（新発見）。判断行の母数では**負けた席の行が勝った席の行より
  厳密に +1**（同じ `τ` を 1 ターン短い残りと比べている）。**組になる 1,545／4,413 行で誤差 4.4e-16**。
  **位相の偏りが無い母数（勝った席の自席ターン）で読むと偏りは +2.27／+2.32**。
* **平均は裾の統計**: 中央値は **+0.81／+0.99**（自席ターン母数では **+0.37／+0.47**）、
  **上位 10% の行が総和の 45.6%／46.8%** を出している。

## 1. 問い——**どこを直せばよいのか**

交点の橋の終局の偏り（勝った席の `τ` − 実際の残りターン）は **+2.563／+2.601**。
T95 から T111 まで 17 個の改善（規則の取り込み・財布・レース）を入れたが、**この数は 1 度も縮まなかった**。
**原因は「場所が分からないまま項を足していた」こと**——偏りは `Θ`（的）と `A`（速さ）の**両方**から来るのに、
**1 つの数に潰れていてどちらか言わない**。

## 2. 式（**新定数ゼロ**・当てはめゼロ）

既定の構成では `tau_grow` の的は**定数 `Θ`**（`need = Θ + r·j + 盾 + 段差` の後ろ 3 項が 0）。
このとき**歩きの速さの列だけを差し替えた τ** が作れる:

* `τ_theory`＝理論の速さの列（`A` が `grow` で積み上がる）が `Θ` に届くまでのターン数
* **`τ_harm`＝実際にその席がそのターン与えた損害の列**が `Θ` に届くまでのターン数（**端数の配分は `tau_grow` と同一**）
* `t_left`＝その席が実際に使った残りターン数

引き算を 1 つ挟むだけ:

```
τ_theory − t_left = ( τ_theory − τ_harm ) + ( τ_harm − t_left )
```

**第 1 項は「的は同じで、歩きだけを実測に替えたら何ターン変わるか」**＝**`A` の軌跡の誤り**。
**第 2 項は `Σ_{i<t_left} harm_i = 要` なので `Θ`/要 のずれを時間の単位で書いたもの**＝T96 以来見てきた量。
**第 1 項はこれまで 1 度も分離されていなかった**。

**恒等式なので当てはめる自由度が無い**（残差を説明する係数を置いていない）。

## 3. 検算の予告（測る前に書いた）

1. **恒等式は行ごとに厳密**（誤差 < 1e-9）。← **当たり**（1.8e-15／3.6e-15）
2. **第 2 項（的）は既知の `Θ`/要 と整合**（残り 1 ターンで `Θ`/要 ≈ 2）。← **当たり**（勝った席の自席ターン母数・
   残り 1 ターンで 0.3538/0.1686 = **2.098**／0.2967/0.1381 = **2.148**＝T101 の値と一致。
   判断行の母数では 1.49／1.51 まで下がる——**相手席の行が別の位相を見ているため**で、
   **`Θ`/要 を読むのは自席ターン母数**）
3. **台帳の偏り（`summarise` の `bias`）を器が正確に再現する**。← **当たり**（+2.5632 対 **+2.563**／+2.6013 対 **+2.601**）

### 5.4 物差しの +1（台帳の偏りに混じっているぶん）

`summarise` は**負けた席の行**で `t_opp_act`（勝った席のそのターンを**除いた**残り）を読む。
**`τ` も `Θ` も同じ行から来る**ので、**同じターンを両側から見た行の差は厳密に 1**:

| | 自席の行 | 相手席の行 | 組になる行 | 差の平均 | 最大誤差 |
|---|---|---|---|---|---|
| 実 | 1,842 行・**+1.5703** | 1,705 行・**+3.6359** | 1,545 | **1.000000** | 4.4e-16 |
| 合成 | 5,313 行・**+1.5984** | 4,873 行・**+3.6948** | 4,413 | **1.000000** | 4.4e-16 |

**物差しの +1 は誤りではない**（負けた席から見ればそのターンは既に終わっている）が、
**理論の形を読むときは `turns` の母数を使う**（+2.27／+2.32）。

## 7. 上手くいったこと／いかなかったこと

**上手くいった**

* **場所が決まった**。17 回の改善で動かなかった理由が「大きい側を触っていなかった」ことだと**数で言える**。
* **恒等式なので判定に解釈の幅が無い**。次の改善は「**`A` の項が落ち、的の項が動かない**」という**形**で判定できる
  ——偏りの合計だけを見るより**遥かに強い検算**（T111 の「向きは当たったが偏りは縮まなかった」も、
  この分解があれば最初から `A` 側を触っていないと分かった）。
* **打ち消しの帯を見つけた**（§5.3）。**偏りが小さい帯を「合っている」と読んでいたのは誤り**だった。

**いかなかった**

* **偏りは 1 ミリも縮んでいない**。本 T は**計器**であり改善ではない（意図どおりだが、数は良くなっていない）。
* **`turns` と `rows` で `A`/的 の比率が変わる**（89.2% 対 74.7%）。**母数で解釈が動く**ので、
  **以後の判定では母数を必ず明記する**（本報告は両方を出した）。
* **的の項の中身（`Θ` のどの項が終盤に残るか）はまだ割っていない**——`th_life`/`th_hand`/`th_body` 別の分解は次段。

## 8. 次の 1 手（本 T が名指しした 1 か所）

**歩きの成長がドンを 1 度も読んでいない**（`crossing_bridge.py:1337-1374` の `rate_at`＝`flow·(j−1)`）。
規則は「毎ターン +2・席の総量（既定 10・OP15-058 は 6）で上限」なのに、理論は**一定の流入**と書いている。
批評側の測定（`docs/reports/2026-09-19_verify_seven.md` §8）:

* 実測 ΔA は flow の **2.14 倍／2.04 倍**（ドン換算では 1.52 倍／1.15 倍）
* **ドンは j=4 で止まる**（Δドン 0.400 → 0.004 → 0.012）のに **flow は伸び続ける**（0.032 → 0.037 → 0.041）＝**形が逆**
* **A/ドンは j でほぼ平坦**（0.0254 → 0.0358）＝1 ドンの値段はほぼ一定
* **行ごとの相関はどちらもほぼ 0**（実 −0.018／+0.072・合成 +0.018／+0.003）＝**平均で 2 倍でも行では説明していない**

**判定は偏りの合計ではなく形で行う**: (a) j 列（§5.2）の j ≤ 1 が平坦化するか、(b) 本分解の **`A` の項だけが落ち、
的の項が動かないか**、(c) **一律に速くするプラセボ**（`flow` を 2.14 倍する）では (a)(b) が再現しないこと。
