# r5 の判定（2026-09-11・era7 第 2 回・符号化 v14・規約上は非昇格）

r5 ＝ warm-start r3（v13 → v14 へ pad）・`--ablate rel`・π＝波 29＋30（era7・worlds 4 ＋ R2・synth_roles・
両方向 ε 3%・波 30 は `--eps-target 0.3`）・z＝波 30→29→28→27（OOM なし・全部載った）・補助教師 0.1・
lr 2e-4・epochs 2（best＝**ep1**・r 系譜で初めて ep0 を超えた）・visits 教師。成果物 `claude/train-r5`
（ea9f031d・`n1_results/nrel_r5.npz`・RESULT.json）。作業セッション 1 本（opus）で訓練 39 分・評価帯 25 分・
アリーナ 55 分＝**1 セット 2 時間**（波 29 の r4 は 3 セッションで 1 日）。判定はユーザ。

## 結論（先に）

1. **規約上は非昇格**。主（random × synth_roles・192 ペア）**0.5026 [0.4492, 0.5560]・+1.8 Elo**＝未達。
   副（固定ミラー・192 ペア）0.5365 [0.4952, 0.5777]・+25 Elo＝退行なし。void 0／0・dup 0。
2. **評価帯は r3 → r4b → r5 で単調改善**（波 30: 0.5131 → 0.5044 → **0.4981**／波 29: 0.5327 → 0.5198 → 0.5171）。
   除去直後（after_removal）も波 29・30 で r5 が最良（0.6146／0.5834）。波 28（r3 の π 教材）は r3 が最良
   ＝r4 と同じ忘却。
3. **era7 の 3 本（r4 0.5182・r4q 0.5182・r5 0.5026）はすべてアリーナの分解能の内側**。192 ペアの 95% CI は
   ±0.053＝**±37 Elo**。「+10〜20 Elo の改善」と「0」を区別できない物差しで 3 回測っている。
4. 層別（波 30・型 × 出所 × コスト帯）: r5 は **reduce／trash／KO の高コスト帯で大きく改善**（reduce:EVENT:c6+
   −0.208・trash:ACTIVATE_MAIN:c6+ −0.189・KO:EVENT:c6+ −0.119）、**lock（レスト）系で退行**（lock:OTHER:c3-5
   +0.148・波 29 の lock:ON_PLAY:c0-2 +0.135）。bounce は波 29 で最良（−0.400）・波 30 で退行（+0.137）＝
   n が 400〜1,000 の層は波でひっくり返る（読まない）。

## 読み

### 1. v14 の材料は V に届いている

波 30（v14 dump・r5 だけが新列を持つ）で r5 は全ターン帯・除去直後・除去でない行の全部で最良。波 29（v13
dump＝新列は 0 埋め）でも r4b を上回るので、改善は「新列があるから」だけではなく π 2 波の教材と ep1 まで
回ったことも効いている。r5 の val は ep0 0.5151 → ep1 0.5134 と下がり続けた（r2〜r4 は ep0 が最良）。
**教材が π 2 波で 81 万点・r3 の 4 波より小さく、まだ過学習に届いていない**。

### 2. アリーナは 3 回とも同じ幅の中

era7 の主条件（synth_roles）は r4 0.5182・r4q 0.5182・r5 0.5026。3 本を合わせても 576 ペアで CI ±0.03＝
[0.48, 0.54]。**「V の 3% 改善は打ち手に出ていない」と「+10〜20 Elo は出ているが見えない」を、今の物差しでは
分けられない**。前者なら符号化・容量・教材のどれを積んでも判定は変わらず、後者なら積むほど昇格に近づく。
どちらかを先に確かめないと次の一手の評価ができない。

192 ペアを 1 単位にしたのは c 系（+100 Elo 級の世代差）の時代の設計。NRel の世代差が 1 桁小さくなった今、
**判定に要る分解能は ±10 Elo（±0.014）＝約 2,800 ペア**。1 ペア ≈ 15 秒（4 ワーカー）なので 16 セッション ×
175 ペアで壁時計 1 時間＝1 セットのアリーナより短い。

### 3. lock の退行

レスト系（lock）は「相手の次のターンの攻撃を 1 回減らす」疑似除去で、価値が**相手ターンの進行**に依る。v14 の
`power_opp_turn` は自分の盤面の相手ターン中パワーであって、相手の攻撃回数の変化は補助教師（aux の攻撃回数）に
しか無い。r5 が lock で退行し KO／trash（盤面から消える＝状態 S に直接出る）で改善したのは、V が
「盤面にあるものの評価」は学べて「相手の手番で起きること」はまだ学べていない、という §20.8.9 の census の読み
（除去を打った後の展開を CPU が実現できない）と整合する。次の符号化を考えるならここ（相手の攻撃可能体数・
レスト状態の相手キャラの攻撃力）。

## 提案（判定はユーザ）

1. **高分解能アリーナ**（新規・`arena-hires`）: r5 vs r3・主条件 random × synth_roles・**2,800 ペア**（16 セッション ×
   175 ペア・帯 551000〜566000）・両席 serve 既定。±10 Elo で「era7 の改善が 0 か +15 か」を確定する。
   1 時間で済む。**これが出るまで r6 のハイパーパラメータ（π 3 波・lr・epochs）は動かさない**（作業セッションの
   問いへの答え）。
2. 結果が +10 Elo 以上（CI 下限 > 0.50）なら: 規約の主条件「wr ≥ 0.55」は c 系の物差しなので、NRel では
   「CI 下限 > 0.50 かつ副 退行なし」への読み替えをユーザに諮る（世代ごとに +10〜15 Elo を積む運用）。
   r5 を生成役に（era8・波 31）。
3. 結果が 0 なら: V の改善が打ち手に出ない構造を疑う＝serve の探索（sims 160・worlds 1・visits）で V の差が
   手の差になる前に P（方策）が手を決めている可能性。方策側の教師（π）の質を上げる話に戻る（Q 補正 π' は
   不採用だったが、「V が良くなった r5 の Q」で作り直した π' は別物）。
