2. **準備箱は「除去 → 攻撃」と「KO 対象の選択」に効く**（ガンマナイフ 5/8・神の裁きの KO 5/8〔R2 と
   組んだとき〕）が、**worlds と組むと神の裁き → 攻撃の順が 0/8 に落ちる**（箱なし 5/8）。原因は

4. 4 つ全部を束ねた C_all のレイテンシは中位 **1.46 s**（既定の 7 倍・worlds 2 なら 0.69 s）。

## 読み

### 1. worlds 4 ＋ R2 で神の裁きが読まれる理由

エネル T9 の頭合わせ（`_keys.json` の `detail_enel_t9_kami_vs_oom`）:

| 条件 | 神の裁き（N, Q, P）| オーム攻撃（N, Q, P）|
|---|---|---|
| WP worlds 4・visits（s0）| 35, 0.842, 0.057 | 404, 0.958, 0.472 |
| C_w4_r2（s0）| **78, 0.879, 0.076** | 146, 0.849, 0.196 |
| C_w4_r2（s3）| 86, 0.991, 0.099 | 323, 1.000, 0.326 |

- worlds 4 で「相手の手札を知っているつもり」のオーム攻撃 Q が 1.000 → 0.85〜0.96 に落ち、
  平坦化（t=2）で神の裁きの P が 0.057 → 0.076 に上がって訪問が 78〜86 に届く（下限 80 前後）。
  `q_min_n` が Q 0.879 > 0.849 を拾う（s0）。s3 のように世界 4 本とも Q 1.000 の世界を引くと届かない。
- 決着 4/8 は分析 #5 の R2（640 sims）の 2/8 より多い。**世界を複数引くほうが sims を 4 倍にするより
  「止められる世界」を織り込む**＝§20.7.1 の見立てどおり。

### 2. 準備箱が効く場所と、worlds と組むと壊れる理由

- **効く場所**: ガンマナイフ（-5000 → 攻撃が通る）は箱の Q が深さ 1 で正に出る＝箱の有無で 0/8 → 5/8。
  神の裁きの KO 対象は箱の枝「KO する／しない」の Q 差で決まる＝R2 と組むと 5/8（打った run は全部 KO）。
- **壊れる場所**: 神の裁き → 攻撃の順。C_all の T9・action 0 の根は候補 53 本で、神の裁きは
  「素の PLAY × 2（P 0.0156）＋ 箱 8 本（P 0.0021）」に割れて **N 0**。箱なし（C_w4_r2）なら P 0.076・
  N 78。平坦化後の P はさらに薄まり（候補が 29 → 53 に増えるぶん）、`q_min_n` の下限 80 に 1 本も
  届かない → visits 規則に落ちてオーム攻撃。
- つまり**準備箱は「読ませたい手の訪問を分裂させる」副作用**を持つ。R2 単独（C_box_r2・K=1・下限 20）
  では割れても届く（4/8）が、K=4 で下限が 80 になると届かない。

### 3. 箱と素の手の取り合い（Q2 の判定材料）

| 条件 | 箱のある main 決定 | 箱を選んだ | 素の手を選んだ（箱あり）| 素 N > 箱 N 和（枚）| 箱 max N > 素 N |
|---|---|---|---|---|---|
| WP 準備箱・visits | 182 | 12 | 48 | 204 / 392 | 44 |
| C_box_r2 | 273 | 36 | 85 | 400 / 717 | 57 |
| C_all | 219 | 22 | 49 | 366 / 624 | 61 |

素の手が箱に勝つ構造は条件に依らない（P を等分された箱は PUCT で素の手に負ける）。
**箱を読ませるなら、素の手を落として枝を「攻撃しない」で代表させる**（配分箱と同じ扱い）か、
**枝に素の手の P をそのまま与える**（等分しない）かのどちらか。両方やると候補数の増加だけが残る。

### 4. レイテンシ

- worlds 4 ＋ R2 = 0.39 s（既定の 1.9 倍・WP の 2.3 倍より小さいのは局面の組み合わせ差）。
- 準備箱は木の全節で候補化するので 3.3 倍。worlds と掛け算で 7 倍（C_all 1.46 s）。
- serve の予算（分析 #5: 1.6 s まで）には C_all でも収まるが、生成（16 セッション × 960 局）は
  1 局 7 倍になる。

## 判定と提案

1. **アリーナの候補設定は「worlds 4 ＋ R2（sims 160）」**（`C_w4_r2`）。3 局面で最も人間の線に近く、
   決着 4/8、レイテンシ 1.9 倍。§20.5.3 `rs-search-arena` の候補をこれに差し替える（sims 640 の R2 から
   sims 160・worlds 4 へ＝実効 sims は同じ 640・壁時計は 1.6 s → 0.39 s）。
2. **準備箱は候補設定に入れない**（今回）。効く場所（除去 → 攻撃・KO 対象）は本物だが、訪問の分裂が
   worlds ＋ R2 の効きを消す。次の WP（`rs-setup-box-2`・§20.7.6）で (a) 箱があるときは素の手を落とす・
   (b) 箱の P は等分せず素の手の P をそのまま各枝に与える、の 2 つを入れて C_all を測り直す。
   直ったら候補設定に足してアリーナで再判定。
3. **生成（era7 波 29）**もアリーナの結果を待って同じ設定にする。1 局のコストは 2 倍弱。
4. `q_min_n` の訪問下限を K×sims で測る解釈（WP の問い (a)）は維持。ただし「同じカードの等価な手
   （同名 2 枚・箱の枝）を束ねてから下限を見る」案は、準備箱を入れるときに要る（`groups` は
   等価手マージを持っているので、選択規則を groups に対して適用する形）。

## 道具について
- `scenario_out_c/` の frames.json は 2 条件を並列に回したので `decide_ms` は膨らんでいる。レイテンシは
  `lat_*.json`（単独プロセス）を読むこと。
- 箱と素の手の取り合いは scratchpad の集計（`a6_bare_vs_box.py`）で数えた。次の WP で
  `rs_search_a_keys.py` に「箱の N 和 vs 素の N」の鍵として足す。
