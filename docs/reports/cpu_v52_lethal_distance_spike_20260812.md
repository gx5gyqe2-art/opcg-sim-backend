## 2. 読み

1. **乖離族の正体の再特定**（v1 の引分30が示した）: この族は「どちらが先に届くか」ではなく
   **相互リーサル状態で最初の詰め手を守り切れるか**の族。決め手は手番と**防御算術**
   （攻撃本数×打点マージン vs カウンター予算）——ユーザが当初エネルで言語化した
   「7000を作れるか・カウンター2枚を要求できるか」の一般形。
2. **忠実度を上げるほど説明力が単調に上がる**（−0.23 → +0.26 → +0.35）＝特徴ファミリーの
   方向は正しい。現行 v2 の残る不足は台本の忠実度: (a) ブロッカーを守りに使わない
   (b) イベントカウンター不使用（値が静的に読めない） (c) 攻め側がドン付与で打点しきい値を
   作らない（「7000ちょうど×複数本」の算術） (d) トリガー無視。
3. 1盤面あたり数十〜数百ms＝**葉評価に載せられる速度域**にある（v7 実測特徴の系譜）。
