## 1. 式（実装の前に書いた）

### 1.1 問い

前の候補（後の段で余ったドンを攻撃に付ける）は遅れの芯を縮めたが、計画の後の段の攻撃は実際の 1.2〜1.6 倍に越えた。元は掛け算で、
計画（`core/outer.rs::rules_steps`）は段 `j ≥ 2` で**盤面の体を毎段全部攻撃させる**（`S` < 1/2 の時計で計画 3.19／2.90 本 対 実際 1.90／1.83 本・
切り分け報告 §4・前の候補の §4.3）。本数を規則と既存の実測値だけで読み直し、そのうえで余ったドンを付けると、較正の改善を残したまま並べる力が戻るか。

### 1.2 本数を減らす根拠（一つずつ・使うものと使わないもの）

1. **使う: 体は相手のターンに倒される**（既存の実測値）。規則: 相手が攻撃できるのはレストの体だけ（攻撃した体はレストで相手のターンを迎える）・
   リーダーは倒されない。1 回レストで相手のターンを迎えた体が生き延びる確率は、**体の値段（`to.rs::nu_of`・`attack_stream`）が既に使っている
   生存の割引** `1 − ko_p(パワー)`（`leaves_to::ko_p_of`・T22 のパワー別の山形・既定）。新しい値ではなく、体の値段が「先の攻撃を何割に割り引くか」に
   使っているのと同じ物を、計画の攻撃の並びにも使う（値段と並びが同じ生存を見る）。
2. **使う: 攻撃できない状態**（規則）。出したターンは攻撃できない（速攻を除く・今の計画のまま）。段 1 で攻撃できない体（`S_CAN_ATTACK` が偽＝
   召喚酔いなど・今の `att1` に入っていない体）は段 1 でレストにならない＝段 1 の後の相手のターンには倒されない。`no_attack_now`（段 1 に攻撃しない計画）では
   段 1 に攻撃する体は無い。
3. **使わない: リーダーでなく体を狙う分**。既存の実測値に「攻撃のうち体を狙う割合」の定数が無い（`docs/` を探した・新しく測るとそれが新定数になる）。
   止めて報告する事項ではなく、今回の式に入れないだけ（§7 に残す）。
4. **使わない: 歩き（地平の外）の減衰 `RATE_DECAY_MODE=ko`**。地平の見積もり・流入・`fb` には触らない（司令塔の条件）。

### 1.3 式（段 `j ≥ 2` の守る側の計算に渡す攻撃の並びだけ・新定数ゼロ）

1. **さらされた回数** `e_i(j)`: 体 `i` が段 `j` より前の段で計画の中で攻撃した回数（＝レストで相手のターンを迎えた回数）。
   - 盤面の体（`later` のうちリーダー以外）: 段 1 に攻撃する体（`att1` の札の位置に在る・`no_attack_now` でない）は `j − 1`、それ以外は `j − 2`。
   - 段 `p` に出した体: 速攻なら `j − p`、そうでなければ `j − p − 1`（最初に攻撃できる段から数える）。
   - 生き残る確率 `s_i(j) = (1 − ko_p_of(x_i + 相手リーダーのパワー))^{e_i(j)}`（パワーは素の体のパワー・付与を含まない＝`nu_of` と同じ）。
   - 計画は「生き延びていれば毎段攻撃する」ままなので、`e_i(j)` は生き延びた場合の回数（期待値の並びの代表を作るため・倒れた後の分岐を作らない）。
2. **並べる本数**: 段 `j` の体の期待本数 `E_j = Σ_i s_i(j)`（リーダーは数えない）を、計画が段のドンの予算に使うのと同じ丸め（`nonneg_round`＝銀行丸め）で
   整数 `n_j` にする。
3. **どの体を並べるか**: `s_i(j)` の大きい順に `n_j` 体（同点は今の並びの順＝盤面の札の位置の順、次に出した順。今の財布の同点の割り切り「先に並んだもの」と同じ）。
   リーダーは毎段並ぶ（倒されない）。その段に出した速攻の体は `e = 0` で `s = 1`。
4. **余ったドン**（前の候補と組むとき）: 残り `L_j = round(d_j) − Σ cost(出す札) − Σ_{並べた体} k_i`（並べなかった体に値打ちで決めた付与 `k_i` は
   倒れた体には付けられない＝手元に戻る）を、前の候補の `leftover_attach`（`c̄` の増えを今の財布で配る・付与の上限 10）で**並べた攻め手（リーダー含む）にだけ**配る。
5. **守る側の計算に渡す段 `j` の攻撃**: `{ x_i + 1000·(k_i + e_i) : 並べた攻め手 }` ∪（その段に出した速攻の体）。

### 1.4 変えないもの

- 段 1（今のターン）・出す札・付与 `k_i` の選び方・払い `paid`（流入）・`fb`（地平の外の段の値）・`model_horizon`・値段の表・`KERNEL_FILES`。
  変えるのは `core/outer.rs::rules_steps` の `hits`（＝守る側の計算の `later_seq`）だけ。
- 既定（変数なし）では 1 ビットも変えない。

### 1.5 切替と新定数

- 環境変数 `OPCG_ATTACK_COUNT`（空でも `0` でもない値で入る・1 度だけ読む）。`OPCG_LEFTOVER_DON` と組み合わせて使う（単独でも動くが今回比べる腕は
  既定・余ったドンだけ・本数の直し＋余ったドンの 3 つ）。入れたときは攻め手の財布の dict に印（`attack_count`）を足す（計画のディスクの鍵に入る）。
- **新定数ゼロ・選び方ゼロ**: 使うのは規則（レストの体だけが攻撃される・リーダーは倒れない・出したターンは攻撃できない・速攻）・既存の `ko_p_of`（体の値段と同じ物）・
  今の丸め（`nonneg_round`）・今の同点の割り切り。結果を見て差し替える部品は無い。
- 試験 1 本（手で導ける値）: パワー 3,000（`ko_p` 0.2782）の盤面の体 2 体（どちらも段 1 に攻撃）・相手リーダー 5,000 では、
  `E_2 = 2 × 0.7218 = 1.44 → 1`・`E_3 = 2 × 0.5210 = 1.04 → 1`・`E_4 = 0.752 → 1`・`E_5 = 0.543 → 1`・`E_6 = 0.392 → 0`。
  段 1 に攻撃できない体は 1 段遅れて減る。

## 0. 結論（全記録の後に書いた）

1. **推薦は採らない**【実行】。殺す基準に両方の記録で当たった: 実で (c)（相対の腕の AUC .8076 → **.7990**）・(d)（的中 .7051 → **.7009**）、
   合成で (b)（`S` < 1/2 の観測 ÷ 予測 1.102 → **1.183**・上の境 1.15 を越える）・(c)（.7241 → **.7144**）・(d)（.6602 → **.6492**）。(a) 打ち切りは減った（実 9 → 0・合成 70 → 3）。
2. **問いへの答え: 本数を規則で読み直しても「付け過ぎ」は直らず、並べる力は戻らない**【実行】。計画の本数は実際に近づいた（`S` < 1/2 で実 3.19 → 2.65 対 実際 1.86・
   合成 2.90 → 2.31 対 1.78）が、**段 2 以降の計画の攻撃の超過の和は余ったドンだけの腕とほとんど同じ**（`S` < 1/2 で実 10,046 → 9,510 対 実際 7,138〔1.33 倍〕・
   合成 —（余ったドンだけ 9,806〔前の報告〕）→ 9,227 対 6,110〔1.51 倍〕）で、診断の印の 0.8〜1.2 倍に入らない。段のドンの総数は変わらないので、並べる体が減ると
   余りが残った体（とリーダー）に集まる。**付け過ぎの元は本数ではなく「後の段のドンを全部攻撃に回す」読みの側**（予告 §2.2 の見立てどおり）。
3. 並べる力は余ったドンだけの腕と比べて実で少し戻り（的中 .6964 → .7009・AUC .7969 → .7990）、合成ではさらに下がった（.6493 → .6492・AUC .7186 → .7144）。
   **どちらの記録でも既定には届かない**。
4. 較正の改善はおおむね残った: 実の `S` < 1/2 の観測 ÷ 予測 **0.989**（既定 0.927・余ったドンだけ 0.830）・打ち切り 0・σ_T 1.412 → 1.151。
   合成の σ_T 2.004 → **1.154**・打ち切り 70 → 3・絶対の腕の対数損失 .8639 → .6736。合成の `S` < 1/2 は逆に上へ越えた（1.183＝守り手が倒れる数を予測が言い落とす向き）。
   遅れの傾きは余ったドンだけの腕と同じだけ寝た（同じ時計で実 +0.60 → +0.25・合成 +0.31 → +0.13）。
5. `kappa_vector` はビットで不変（実・合成）。既定（変数なし）は 1 ビットも変わらない（既定の腕の全記録の数が前の報告と全部一致）。

## 7. 判断事項

### 判断 1: 後の段の攻撃の本数を倒される分で読み直したうえで余ったドンを付ける候補を採るか

1. **何を決めるか**: 守る側の計算に渡す攻め手の 2 ターン目以降の攻撃を、「体は相手のターンに倒されることがある」分だけ減らしてから、出す札に払った後の余りのドンを全部付けて読む式を既定にするか。
2. **選択肢**:
   (a) **採らない**（推薦）——測る前に決めた殺す基準に両方の記録で当たる。実: どちらが勝つかの的中 .705 → .701・決着前の勝率の並べる力 .808 → .799。
       合成: 的中 .660 → .649・並べる力 .724 → .714・地平を生き延びないと言う時計で倒れる数が予測の 1.18 倍（基準は 1.15 以下）。
   (b) 採る——時計の較正は前の候補と同じくらい良くなる（合成: 勝つ側の時計のばらつき 2.00 → 1.15 ターン・30 ターンで届かない時計 70 → 3 本・実: 倒れる数の予測の外れ 0.93 → 0.99）。
       並べる力と的中は両方の記録で下がる（実は前の候補より少し戻り、合成はさらに下がる）。
3. **なぜこの問いが出てきたか**: 前の候補（10-09・余りのドンを全部付ける）は遅れの芯を縮めたが、後のターンの攻撃が実際の 1.2〜1.6 倍に越えて並べる力を下げた。
   そのとき、計画は盤面の体を毎ターン全部攻撃させていて本数が実際の 1.6 倍だったので、ユーザ決定（10-10「(a) と T18 を同時に」）で本数を規則から直す候補を試した。
   本数は実際に近づいた（1.68 倍 → 1.42 倍／1.58 倍 → 1.30 倍）が、ドンの総数は同じなので残った攻撃に余りが集まり、攻撃の強さの和はほとんど減らなかった（1.42 倍 → 1.33 倍／1.60 倍 → 1.51 倍）。
4. **推薦とその理由**: (a)。測る前の基準に両方で当たり、問いの「並べる力が戻るか」に否と答えが出た。付け過ぎの元は本数ではなく「後のターンのドンを全部攻撃に回す」読みの側だと分かった。
5. **決めないとどうなるか**: 候補は切替のまま残る（既定は不変・golden も不変）。T18 の作業とは独立に進められる。
6. **留保**: 合成の線形の橋は 300 局だけで測った。採らない場合も、後のターンの攻撃を実際の半分の強さで読む穴（既定）は残る（遅れの芯の半分強）。

### 判断 2: 次に「後のターンのドンのうち攻撃に回る分」を規則と既存の値で読む候補を試すか

1. **何を決めるか**: 後のターンの攻撃に付けるドンの総数を、「全部付ける」でも「値打ちが費用を越えるときだけ」でもない読み方で決める候補を次に作るか。
2. **選択肢**:
   (a) **試す前に、選び方の入らない根拠があるかを先に調べる**（推薦）——実際の攻め手は後のターンで攻撃 1 本に 1.2〜1.5 枚付け、残りは出す札に払うか使わない。
       この「残り」を決める規則（例: 引いた札を出すのに払う分＝今の流入の読みと同じ物を先に引く）が既存の部品だけで書けるかを調べ、書けないなら止めて報告する。
   (b) 後のターンの付与はここで打ち切り、決めた順番（出口の再開・T18）へ進む。
3. **なぜこの問いが出てきたか**: 今回、本数を実際に寄せても攻撃の強さの和が実際の 1.3〜1.5 倍のまま残り、強さの付け過ぎが並べる力を崩すことが分かった。
   前の候補の報告 §1.4 に書いた「余りのドンを引いた体への払いと付与で 2 回使っている」重なりも、同じ向き（付け過ぎ）に効いている【推測】。
4. **推薦とその理由**: (a)。遅れの芯の半分強はここにあり、2 回の候補で「全部付ける」は越えると分かった。ただし「どれだけ付けるか」は選び方になりやすく、
   流入との順番（引く → 出す → 付ける）以外の根拠が見つからなければ (b) に倒す。
5. **決めないとどうなるか**: 後のターンの攻撃の強さの穴は既定のまま（実際の半分）残り、勝ちの時計の遅れの芯の半分強に手が付かない。
6. **留保**: 流入（引いた体）の払いを先に引く形は「流入には触らない」という今回の条件を外すことになる（流入の読み自体は変えず、余りの計算に使うだけでも、計画のディスクの鍵は変わる）。

判断 1 と 2 は独立（判断 1 を (a) にしても判断 2 は進められる）。表（`make theory-table`）は作り直していない（採らない推薦のため）。golden は既定が変わらないので動いていない。
