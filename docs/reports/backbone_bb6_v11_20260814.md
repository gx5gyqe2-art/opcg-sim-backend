## 2. 判定 — 弱い正

| 物差し | bb3(v10) | bb6(v11) |
|---|---|---|
| 域内 val MSE（同一対局A/B） | 0.708 | **0.643**（−9%） |
| 実L接戦帯 中間帯 n=49（ns2） | +0.117 | +0.147 |
| 　ハンニャバル帯 n=12 | +0.443 | **+0.598** |
| 　ナミ:シャンクス帯 n=31 | +0.098 | +0.184 |

| バニラL対照 中間帯 n=181（bb4b24・ベクトル全ゼロ） | +0.532 | **+0.582** |

- **特徴は機能**: 同一対局で域内 MSE −9%＝ネットは確かに使っている。バニラL対照の
  +0.05 は**脱交絡**（リーダー効果の帰属先ができ、共有物理特徴の混同が減る）＝設計どおり。
- 狙った対面は動いた（ハンニャバル +0.16・ナミ +0.09）が、**主指標は +0.03 で雑音圏**。
- ミル次元の悪影響懸念（ユーザ指摘: デッキ0勝利は OP03/P ナミ専用の超ニッチ）は
  **ゼロ入力封じ込め**で構造的に限定（能力を持たないリーダーでは全次元が厳密に0＝
  寄与不能）。対照帯の改善が無害性の実測でもある。

## 3. 機序の読みと次

- ナミ帯（49点中31点＝主指標の支配層）が小幅に留まる機序: ミルの**静的レート**だけでは
  「デッキ切れまで何ターン vs リーサルまで何ターン」の**レース計算**にならない。
  v52（Δ族）と同型の教訓＝レートではなく**距離の実測**が要る。
- 次の一手（v11.5/bb7 候補）: (a) **デッキアウト距離**（deck残÷mill率・リーサル距離と
  同じ /(MAX+1) 正規化・rule_flag との対で意味が立つ） (b) 条件充足の動的ゲート
  （ハンニャバル型の「今発火できるか」） (c) 合成カードへの trait 継承（発火不能32%の解消）。
- エネル帯（n=6）は不動＝特徴では動かない系譜的盲点の疑い（レフェリー方策自体の欠陥）。
  帯の増強（新規エネル対局）と合わせて別戦線。
- v11 の列定義はまだ確定させない（何にも採用されていない実験版・bb7 の結果を見て
  ミル等の弱い次元の整理も含めて確定する）。
