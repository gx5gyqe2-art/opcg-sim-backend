# T53——物差しをターン末まで広げても、効果と登場の価格は高いまま。物差しではなく価格の側

2026-09-16 実施（ユーザ指示「1 から着手」＝効果と登場の「実現」を次の判断点ではなくターン末まで挟んで測り直す）。
**式は触っていない・新定数ゼロ**（`price_realised.py` に列を足しただけ）。本報告は特定時点のスナップショット。

## 結論を 5 行で

1. **物差しは原因ではなかった**——「後で効く効果」（`ACTIVE_DON`・`GRANT_KEYWORD`・`BUFF`・`REST`・`ATTACH_DON`）を含むターンは、
   ターン単位の恒等式（Σ価格 対 ターン末までの実現）で **0.73**（実デッキ）・含まないターンは **0.88**。合成は 0.95 対 0.97。
   ターン末まで見ても、流れの効果を含むターンの方が**より**過大。
2. **登場の内訳**（実デッキ・キャラ 3,013 件）: 価格 = 体（ν − μ）0.124 + 登場時効果 0.061 − 機会費用 0.008。
   実現 = 自分の体 +0.138（帯の実測 ν）+ 手札 −0.041 + 相手側・ライフ +0.021。**体の式 ν は帯の実測の 1.3 倍・登場時効果は 1.7 倍**。
3. **効果の型ごと（実デッキ）**: `RAMP_DON` 0.084 対 0.054（0.65）・`GRANT_KEYWORD` 0.087 対 0（ターン末でも 0.038）・
   `ACTIVE_DON` 0.013 対 0（ターン末 0.081 は後の攻撃と重なる）・`DRAW` 0.027 対 −0.019。合成は `RAMP_DON` 1.03・`LOOK` 0.41・`MOVE_CARD` 0.59。
4. **行 → ターン末の実現は型の和に使えない**（後の行の実現と重なる: 攻撃 0.068 → 0.135・付与 0.001 → 0.098）。読むのは (1) のターン単位の分割だけ。
5. **次は価格の側**——(a) 体と KO の対象の ν（式 1.2〜1.3 倍 → 帯の実測に置くかは判定）・(b) `GRANT_KEYWORD`（速攻・ダブルアタックを
   `Θ·μ` で 1 回分と置いている）・(c) 登場時効果 1.7 倍・(d) `SET_BASE_POWER`（パーサ）。

## 2. 実測（実デッキ 300 局／合成 900 局）

### ターン単位の恒等式（Σ価格 対 実現）

| ターンの群 | 実: ターン数 / Σ価格 / 実現 / 比 | 合成 |
|---|---|---|
| 後で効く効果が在る | 598 / 0.392 / 0.288 / **0.73** | 1,245 / 0.240 / 0.227 / 0.95 |
| 無い | 2,934 / 0.272 / 0.240 / **0.88** | 8,953 / 0.216 / 0.210 / 0.97 |

流れの効果の価格が正しければ両群の比は同じになるはず。実デッキでは在る群の方が 0.15 低い＝**流れの効果の価格が高い**。
合成では両群とも 0.95 以上＝合成デッキの効果はほぼ合う（実デッキの効果が読みにくい）。

## 3. 読み方

- 「後で効く効果はターン末まで見れば合う」は**否定**された。ターン末まで見ても、その効果を含むターンは価格の方が高い。
- 登場の 0.62 は **体の ν（式が帯の 1.24〜1.30 倍）と登場時効果（1.7 倍）の 2 つ**で、機会費用はほぼ 0。
- 合成では効果も登場も 0.95 前後で閉じるので、**実デッキ固有の効果の読み（パーサ・キーワード）**が残る穴。
