## 4. 読み方

- **上手くいった 1: T81 が名指しした穴がふさがった**。「出す手は帳簿を動かすが勝率を動かさない」は
  **理論の欠陥ではなく器の食い違い**だった——時計が体を数えていなかっただけ。相関 0.06 → 0.47 は
  この一連の測定で単一の変更が出した最大の動き。
- **上手くいった 2: 予告どおりだった**。T81 §5 で「出す手の相関が上がり全体が 0.44 に寄る」と予告し、
  実測は 0.466／0.472 だった（§0.1 条件 3 の意味で当たった予言）。
- **上手くいった 3: 単位の検算が両記録で 1 に近づいた**（1.180 → 1.164／1.092 → 1.082）。
  `Θ` が過小だったことの独立な裏付け。
- **上手くいかなかった 1: 信号が型のあいだを移った**。全体の相関は上がったが、攻撃・守り・付与は下がった。
  つまり**「体を数える `D`」は出す手とよく合い、攻撃とは前より合わない**。ライフを削る手は `Θ` の
  ライフ項にしか映らないのに、`Θ` の体の項が大きくなって**相対的にライフの寄与が薄まった**のが素直な読み。
  次に割るべきはここ（型ごとに `Θ` のどの項が動いたかを見る）。
- **上手くいかなかった 2: 交点の時刻が伸びた**（偏り 2.96 → 4.07・τ 4.60 → 6.20）。`all` は
  **レストの体もブロッカーでない体も「耐久」として数える**が、**ブロックできない体は攻撃を止めない**。
  つまり**整合はしたが、共有する規約がどちらも正しいとは限らない**。
  **裏向きの選択肢（方向 B）は未測定**——`F` の側を `Θ` に合わせる（`side_nu_meas` を
  アクティブなブロッカーだけに絞る）。偏りの悪化はむしろ B が正しい可能性を示す。
  ただし B は `F` の攻撃価格（T61 などで検算済み）に触るので、別の T として測る。
- **`κ` の形はまだ先送り**（T80・T81 の読みのまま）。相関が 0.47 で止まっている段階で重みの形を決めない。

## 5. 次（ユーザ判定）

1. **既定を `all` にするか**（本報告の判定事項）。推す: 相関 0.357 → 0.472／0.405 → 0.464 は
   **恒等式そのものの改善**で、接戦帯は不動・単位の検算は 1 に近づく。**費用**: 交点の `theory` の
   正解率が 0.018／0.003 下がり偏りが 1.1 ターン悪化する（`curve` は 0.017／0.039 上がる）。
   **既定は変えずに置いてある**（`--theta-body all` で再現できる）。
2. **方向 B を測る**（`F` の体の項をアクティブなブロッカーだけに絞る）。整合の取り方は 2 通りあり、
   偏りの悪化は B 側を示唆する。どちらも新定数ゼロ。
3. **攻撃の型が下がった理由を割る**（`Θ` のライフ項と体の項の寄与を型別に見る）。
4. その後に効果の型を細かく割る（T81 §5 の 2・実デッキの −0.19）と `κ` の形。

## 限界

- `ΔW` は**理論自身の時計**から作った勝率で、真の勝率ではない（T80／T81 と同じ）。測っているのは内部整合。
- `side_nu_meas` は**付与ドンを外した素のパワー**で数える（`F` と同じ規約をそのまま借りている）。
- `Θ` の手札項は `cuttable`（T77 の既定）のまま・速さは `hand`（T78）のまま。
- 型の割り当てはその行で選ばれた手の型（`move_family`）で、候補の型は見ていない。
- `|g| < 0.005` の窓は落ちる（回帰には残る）。
- **観察であって因果ではない**。
