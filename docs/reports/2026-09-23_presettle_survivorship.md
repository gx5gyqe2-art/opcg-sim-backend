# T149c: 生存の選択（決め切れていない優勢側）を切り分ける（2026-09-23）

T149b は「経過そのもの」が過大評価を進める形を支持した。候補は「序盤から優勢のまま決め切れていない
局は、その時点で理論の見立てが外れていた局が多い」という生存の選択効果だった。本 T はこれを直接
測る（ユーザ指示「その10個をまとめてお願いします」の束 1・4 番目）。

**記録**: T146b/c・T149a/b と同じ。実 = `w41`（300 局）／合成 = `w39 + w42`（900 局）。

---

## 0. 結論（先に書く）

**混在した結果になり、単純な物語では説明し切れない。** 終盤の優勢側の行を「序盤から同じ席が優勢の
まま続いている（`persistent`）」と「終盤で新しく優勢になった（`flipped`）」に分けたところ、
**どちらが大きいかが記録によって逆転した**——実では `flipped` のほうがずっと大きく、合成では
`persistent` のほうがやや大きい。

| | 実 | 合成 |
|---|---|---|
| `persistent`（序盤から優勢） | n=361（233 局）・gap=**0.112** | n=1,043（636 局）・gap=**0.264** |
| `flipped`（終盤で新しく優勢） | n=242（156 局）・gap=**0.386** | n=672（465 局）・gap=**0.233** |

`no_early_data`（序盤の行が判定できない局）は両記録とも 0 件——`stage_of` の境目（`j_me≤1` を
序盤とする）で、決着前の行を持つ局はほぼ必ず序盤の行も持つ。

## 1. 式（新定数ゼロ・当てはめない）

新しい価格式は書かない。局ごとに**序盤で最初に優勢だった席**（`early_leader_of`——最初の序盤行の
`p` の符号から読む・自分の行の `p<0.5` ならもう片方の席が優勢）を求め、終盤の優勢側の行をその席と
比べて 2 群に分ける（`survivorship_split`）。

## 2. 実測が予告と違った理由（考察・当てはめない）

`flipped`（終盤で新しく優勢になった行）が実で突出して大きいのは、**逆の機構**を示唆する——序盤に
優勢だった側が終盤にひっくり返る局は、**その逆転自体が不安定**（まだ決着していない局面で、直近の
盤面の動きに引きずられて優勢の評価が変わりやすい）可能性がある。モデルは「今この瞬間の優勢」を
読むだけで、**その優勢がどれだけ安定しているか（何ターン続いているか）を割り引いていない**——
`persistent`（長く続いている優勢）より `flipped`（できたばかりの優勢）のほうが、本来はもっと
不確実なはずなのに、同じ読み方をしている。**ただしこの読みは実だけの形で、合成では逆**——
記録によって向きが違う時点で、単一の機構で説明することは本 T の実測だけでは正当化できない。

## 3. 不変量

* `persistent`＋`flipped`＋`no_early_data` の行数は、終盤の優勢側の行数の合計と一致する（実
  603 のうち優勢側の行数と付き合わせ済み・取りこぼしなし）。
* 局数（`n_games`）は行数以下（同じ局から複数の終盤行が出るため）——テストで確認済み。

## 4. 上手くいったこと／いかなかったこと

**上手くいった**:
* **新しい価格式を書かずに、既存の `p`／`who`／`stage` から生存の選択という候補を直接測れた。**
* **記録間で結果が食い違うことを隠さず報告した。** T147a の反省（外れた予告を正直に書く）を
  そのまま守った。

**いかなかった／自己批判**:
* **T149b が支持した「経過そのもの」という読みの、具体的な下位機構（生存の選択）は本 T では
  確定できなかった。** 実と合成で逆向きの結果になり、どちらの記録セットにも当てはまる単一の
  説明が無い。**T149d（式を書いて測る）に進むための根拠としては弱い。**
* **`flipped` の解釈（できたばかりの優勢は不安定）は、実の数字だけを見て後付けした考察**——
  合成で逆になった時点で、この考察自体を検証する新しい測定が要る（本 T の範囲外）。

## 5. ユーザ判断をお願いしたいこと

1. **T149（決着前の自信過剰の機構特定）は、ここで一旦保留することを推薦する。** T149a（局の束ね
   ではない）・T149b（経過そのものを支持）までは固い結論が出たが、T149c で具体的な下位機構の
   特定が記録間で割れた。**T149d（新定数ゼロの式を書いて測る）は、根拠が固まっていない状態で
   式を書くことになり、T147a と同じ失敗（不十分な根拠での修正）を繰り返す危険がある。**
2. **代わりに追える候補**（本 T では未着手）: 優勢の継続ターン数そのものを連続変数として `gap` と
   相関を見る（`persistent`／`flipped` の 2 値化ではなく）／局面の変動性（直近数ターンの `p` の
   変化幅）を軸にする。
3. **T150（ドンの機会費用）は T149 と独立なので、そのまま進めることを推薦する。**
