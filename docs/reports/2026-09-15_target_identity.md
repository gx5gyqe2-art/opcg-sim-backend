# 枠の素性を読んだ——**0.4% しか動かない。精緻化の利得が枯れてきた**

2026-09-15 実施。前作業の「次」の 1 番目＝**`card_idx` から枠の素性（特徴・色・名前）を引き、
特徴で絞る除去も盤面から対象を選べるようにする**。本報告は特定時点のスナップショット。

## 結論を 5 行で

1. **枠のカード ID から素性を引けた**（`card_idx` の並びはトークンと同じ＝
   0/1 リーダー・2〜6 自場・**7〜11 相場**）。特徴・色・カード名・属性・名前の除外を判定する。
2. **判定の可否を「静的な名前の一覧」から「渡されたデータ」に変えた**——
   **体の側にその素性が無ければ判定しない**。呼び出し側が素性を足せば自動で読めるようになり、
   足さなければ黙って誤判定しない（**これが設計上の一番の変更**）。
3. **動いた候補は 0.4%（186/43,263）**。変化は中央値 **+0.023**・**11 件が空振りの 0** に。
4. **橋は動かない**（全体 +4.325 → **+4.277**・CI が重なる。守りは不動）。
5. **3 段連続で「正しいが効く範囲が狭い」**——4.4% → 0.4% と**利得が 1 桁ずつ枯れている**。
   **効果の値付けはここで打ち切り、残る大物（P8）へ移るのが筋**。

## 1. 何ができるようになったか

| 効果の書き方 | 前 | **後** |
|---|---|---|
| 「特徴《ワノ国》を持つキャラ 1 枚を KO」 | 平均 0.1087 | **その特徴を持つ体のうち一番高い `ν`** |
| 「青のキャラ 1 枚を KO」 | 平均 0.1087 | **青の体の一番高い `ν`** |
| 「〈ガープ〉を KO」 | 平均 0.1087 | **その名前の体の `ν`** |
| **当てはまる体が居ない** | 平均 0.1087 | **0**（空振り・11 件） |
| **素性を渡していない呼び出し** | 平均 0.1087 | **平均 0.1087**（判定しない） |

**「〜または〜」は list で来る**ので**どれか 1 つ当たれば通す**。
**名前の除外**は 1 つでも当たれば落とす。

## 2. 設計の変更——**判定の可否をデータで決める**

**前**: 「読めない絞り込みの名前の一覧」（`OPAQUE_TARGET_KEYS`）に `traits` 等を入れ、
**1 つでも在ったら盤面を使わない**。

**後**: **絞り込み → それを判定するのに要る素性**の対応表を持ち、
**体の側にその素性が在るときだけ判定する**:

```python
FILTER_NEEDS = {"traits": "traits", "names": "names", "colors": "colors",
                "attributes": "attribute", "exclude_names": "names"}
```

> **なぜこの形が良いか**——**呼び出し側が素性を足した瞬間に読めるようになり、
> 足さなければ黙って誤判定しない**。静的な一覧だと**「一覧を更新し忘れる」という
> 罠が残る**（罠 25 と同じ形＝表と実装のずれ）。
>
> **どうやっても読めない絞り込みは一覧に残した**（`flags`・`is_vanilla`・`lacks_trigger`・
> `min_attached_don`・`power_sum_max` 等・**どれも出現 10 件未満**）。

## 3. 実測——**0.4% しか動かない**

実デッキ 300 局・登場と起動メインの候補 43,263 件（**素性を読む前と後**の比較）:

| | |
|---|---|
| **値が変わった候補** | **186（0.4%）** |
| 変化の平均 | +0.0126 |
| 変化の中央値 | **+0.0233** |
| p10 / p90 | −0.0308 / +0.0565 |
| **0 になった（空振り）** | **11** |

**向きは上**——素性を読むと**盤面の対象を選べるようになる**ので、
**平均に落ちていたものが「当てはまる中で一番高い体」に上がる**ことが多い。

> **効果の JSON には特徴 497 件・名前 172 件・色 68 件・除外名 120 件の絞り込みが在る**のに
> 動いたのが 186 候補なのは、**その札が手札に来て候補になる頻度**が低いから。
> **カードの表の件数と、実プレイで効く件数は別物**（罠 26 の親戚）。

## 4. 橋——**動かない**

| 帯 | 前段（素性なし） | **後（素性あり）** |
|---|---|---|
| **全体** | +4.325 [3.48, 5.23]・AUC 0.706 | **+4.277 [3.44, 5.20]・AUC 0.703** |
| 接戦 | −1.514 [−3.05, +0.25] | **−1.512 [−3.05, +0.22]** |
| 　攻め | +0.786 | **+0.781** |
| 中盤 | +1.313 [−0.28, 3.12] | +1.293 [−0.29, 3.10] |
| 決着 | +2.067 [1.43, 2.71] | +2.054 [1.41, 2.70] |
| **守り** | −3.754 | **−3.754（不動）** |

**小数第 2 位までほぼ同一。** 0.4% の候補が動いただけなので当然である。

## 5. 効果の値付けの利得が枯れた（打ち切りの判断）

| 段 | 何を直したか | **動いた候補** | 橋 |
|---|---|---|---|
| T33 | キャラの登場に効果を足す | （全キャラ） | **動いた**（中盤の判定が変わった・接戦の攻め +81%） |
| T34 | 効果の値を盤面の対象で決める | **4.4%** | 動かない |
| **T35**（本作業） | 枠の素性を読む | **0.4%** | 動かない |

**1 桁ずつ枯れている。** §0.4 の感度の規則に従えば、**効果の値付けの精緻化はここで止める**。
**残る穴で大きいのは P8（記録の穴＝守り側）**で、そこは価格では動かないと 6 段続けて出ている。

> **それでも T34・T35 を入れたのは、橋の分解能とは無関係に「カードの本文と食い違う値付け」
> だったから**（空振りに値段が付く・絞り込みを無視する）。
> **橋は「動いたか」の道具で、「正しいか」の唯一の道具ではない。**

## 限界

- **自分の場の体は素性を読んでいない**（`PLAY_CARD(SELF)` で出る体は手札の中身なので枠に無い）。
- **手札の枠（`card_idx` 12〜21）は使っていない**——「手札の〈ルフィ〉を捨てる」等は判定できる
  はずだが、**出現が少ないので触っていない**。
- **`is_vanilla`・`lacks_trigger`・`min_attached_don` 等はまだ読めない**（出現 10 件未満）。
- **「取れるうち一番高い体」は上限**（相手が守るので必ず最良は取れない）。
- **観察であって因果ではない**（§0.3 の限界はそのまま）。
