## 結論を 6 行で

1. **ブロックを入れた**——攻撃 1 回の損失 = `min( c(x)·μ, 受ける, min_B [ min( ν(B), c(P − P_B)·μ ) ] )`。
   「対象より大きく攻撃側より小さいブロッカーで受けてから札を切る」はこの `min` が拾う（8000 の攻撃 対 7000 の
   ブロッカー: 直接 2.25 枚 → ブロック後 1 枚 = 0.055）。観測できる量（アクティブなブロッカーとそのパワー）だけ。
2. **ただし記録ではほとんど効かない**——アクティブなブロッカーが居る攻撃の行は **9.6%**（40 局・996 攻撃）、
   価格が変わったリーダー攻撃は 29 件。**ブロックはリーダー攻撃の 1.5 倍の正体ではなかった**。
3. **正体は器**——`price_realised`／`nu_ledger` は「次の自分の行」で挟んでいたが、リーダー攻撃の **39% で次の行は
   `commit` 行**（`DON_BOX` マクロの消化＝**解決前の盤面**）。そこで挟むと攻撃の実現が消える。
   **次の判断点（`main` 行）で挟む**に直した。
4. **直すと攻撃の実現は 1.4〜1.6 倍に上がる**——攻撃 価格 0.052 対 実現 **0.074**（実デッキ）／0.056 対 **0.087**（合成）。
   リーダー 0.055 対 **0.074**・リーダー未満の体 0.024 対 **0.063**・飽和超え 0.075 対 **0.101**。
   **攻撃は安すぎる側**に転じた。登場 0.119 対 0.079（0.67）・効果 0.051 対 0.032（0.62）も実現が上がった。
5. **T44 の訂正**: 「(1) 攻撃 1 回の価値は合う」→ **合わない（実現の 0.6〜0.7 倍）**。「(3) 実測の因子の組み直しが
   中盤帯の実測 `ν` に届く」→ **届きすぎる**（合成 1.56 倍・全帯 1.3〜1.8 倍）＝**攻撃の流れの実測は、回帰で測った
   `ν`（在庫）より大きい**。流れ→在庫の換算（`R`・生存・回帰の収穫逓減＝P1）の壁は前より高い。
6. **局単位の実現の和は勝敗を AUC 0.87／0.79 で説明**（傾き 0.51／0.48）——器を直して説明力は上がった。

## 1. ブロック（式）

```
攻撃 1 回の損失 = min( c(P − P_T)·μ                        … 対象 T を直接カウンターで守る
                    , 受ける(T)                            … リーダーなら Θ·μ・キャラなら ν(T)
                    , min_B [ min( ν(B), c(P − P_B)·μ ) ] … ブロッカー B で受け、B を失うか B をカウンターで守るか
                                                            P < P_B なら B は無傷＝0 )
```

| 攻撃側 P（リーダー 5000・ブロッカー 7000・ν(B)=0.2） | 直接 | 受ける | ブロック→カウンター | 相手が選ぶ |
|---|---|---|---|---|
| 8000 | 2.25 枚 = 0.124 | 0.063 | **1 枚 = 0.055** | ブロックしてカウンター |
| 9000 | 2.78 枚 = 0.153 | **0.063** | 1.28 枚 = 0.070 | 受ける |
| 6000 | 1 枚 = 0.055 | 0.063 | **0**（無傷） | ブロック |

`score_candidate` は `ctx["opp_bodies"]` からアクティブなブロッカーを拾う（`blockers_of`）。対象そのものはその攻撃を
ブロックできないので外す。`attack_stream`（`ν` の在庫・分布モード含む）は盤面のブロッカーの旗で同じ `min` を掛ける。
**ブロッカーが居る盤面では「盤面の効果」（T46 の選択肢）が負にもなる**（リーダー狙いが止められる分）。

## 4. 読み方

- **ブロックは正しいが小さい**——この記録の CPU はブロッカーを少ししか使わない（体の 5〜10%）。実デッキで
  ブロッカーの多いデッキが入れば効く。式には残す。
- **攻撃の価格は安すぎる**（実現の 0.6〜0.7 倍）——T44 の「合う」は器の誤りだった。何が足りないかは次に測る:
  候補は (a) 命中時にライフの札が手に入る分を `Θ·μ` が織り込みすぎ（受ける費用 0.063 対 実現 `λ − μ` = 0.081）、
  (b) 倒した体の `ν_meas`（帯の実測 0.069）と式の `ν(T)`（小さい体で 0.02〜0.04）の差、(c) アタック時効果・トリガー。
- **攻撃の流れの実測は、回帰の `ν` を大きく超える**——流れ→在庫の換算（P1）が、`ν` の水準の主な壁。
- **`ΔG` は不動**（実 +6.0・合成 +4.7・両方成立）。

## 限界

- ブロックのテンポ（同じターンにもう 1 回ブロックできない）は 0 と置いた。
- 実現の側の `ν_meas` は帯の実測 3 値——小さい相手キャラを倒す実現は帯の平均で読んでいる。
- **観察であって因果ではない**。
