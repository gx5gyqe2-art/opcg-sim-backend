# C-5: 攻撃で自分の耐久が下がって見える理由——ブロッカーが攻めた行のレストだけで、席の視点を直すと他はゼロ(2026-09-25)

C-1(`2026-09-25_c1_attack_axis_by_result.md`)は「攻撃の残差は`th_me`(負)と`th_opp`(正)の2軸に乗り、
`th_me`は"nothing"(何も起きない結果)でも負」と読み、C-2/C-3(`2026-09-25_c2_c3_attack_rest.md`)で
候補(a)を実装・計測したが結果が割れた。ユーザ指示「元の問題がなぜ起きているのかは解明したい」
「どの式が正しいかも含めて検討したい」を受け、**残差ではなく耐久そのものを3つの項(ライフ・手札・体)に
割って、攻め手の種類(リーダー／ブロッカー／それ以外の体)ごとに数えた**(読み取り専用・新定数ゼロ)。

## C-1の読みの2つの誤り(本器で判明)

1. **`sh`は席0視点だった**——`transition_ledger`は席1の行を`_swap_state`で席0視点へ写してから
   シャープレイ配分を出す。席1が攻めた行では**`th_me`は守り手(席0)の耐久・`th_opp`は攻め手の耐久**で、
   符号も席0の勝率のもの。C-1はこれを全行「攻め手の耐久」として平均していた。本器は攻め手視点へ
   写し直す(`attack_detail`: 席1の行は軸を入れ替え・符号を反転)。
2. **「候補(c)は棄却(速さの軸に残差が乗らない)」は推論として無効**——状態の`A_me`/`A_opp`は
   **ターン開始の行で1度だけ**読まれ、同じターンの中では動かない(`rate_at[(w,t)]`)。攻撃の価格も
   `a_*`を動かさないので、同じターン内の遷移で`a_me`/`a_opp`/`j`の残差は**器の構造上0**であり、
   「既に正しく値付けされている」ことの証拠にはならない。

## 器

`transition_ledger.attack_detail`(dump行に添える): 攻め手視点の`sh_att`・両席の耐久の3項
(`crossing_bridge.threshold_of_me_parts`〔新設・`threshold_of_me`の内訳・和は厳密一致〕と
`threshold_parts`)・打った攻撃(枠・札id・ブロッカーか・リーダーか・パワー・的・付けたドン・価格`v`・
レストしたか)・行の基本量。`tests/scripts/attack_theta_parts.py`が結果×種類で束ねる。
`d_me`/`d_opp`＝行1−行0の3項、`unpriced_opp = Σd_opp + v`(0なら価格どおり・正なら相手の耐久は
価格より減っていない・負なら価格より減った)。テスト8本(`tests/test_attack_theta_parts.py`)。

## 実測(実局300局＝攻撃7,239遷移／合成900局＝18,252遷移・`curve`読み・既定)

### 1. 攻め手の種類で割る(攻め手視点)

| 種類 | 割合 実/合成 | `sh_att th_me` 実/合成 | `d_me` 体 実/合成 | `d_me` 手札 | `d_me` ライフ |
|---|---|---|---|---|---|
| リーダー | 40.5% / 45.6% | **+0.0002 / +0.0015** | −0.0018 / −0.0001 | +0.0024 / −0.0006 | 0 / +0.0021 |
| ブロッカーでない体 | 53.7% / 50.0% | **−0.0009 / −0.0025** | −0.0009 / −0.0028 | +0.0015 / +0.0002 | −0.0009 / +0.0001 |
| **ブロッカー** | **5.8% / 4.4%** | **−0.1261 / −0.1354** | **−0.1420 / −0.1575** | +0.0005 / +0.0001 | 0 / 0 |

**攻め手の耐久の負の残差は、ブロッカーが攻めた行にほぼ全部集中する**。リーダーとブロッカーでない体は
両記録でゼロ(±0.003)。ブロッカーの行では`d_me`の体の項がちょうど1体分の`ν_meas`(0.14〜0.16)落ちる
＝**攻撃でレストになり`THETA_BODY_MODE=blockers`の体の項から抜ける**(候補(a)の機構そのもの)。
C-1の「全行で−0.008」は 5.8%×(−0.126)＝−0.0073 という**薄まった平均**だった。「"nothing"でも負」も
同じ——nothing/ブロッカー −0.080(実)／−0.094(合成)、nothing/リーダー −0.001／+0.001、
nothing/それ以外 0.000／−0.001。

### 2. 相手の耐久(`unpriced_opp`・結果で割る・攻め手視点)

| 結果 | n 実/合成 | `v` 実/合成 | `Σd_opp` 実/合成 | `unpriced_opp` 実/合成 | 主に動いた項 |
|---|---|---|---|---|---|
| took | 2253 / 6449 | 0.081 / 0.080 | −0.120 / −0.117 | **−0.039 / −0.037** | ライフ −0.136(＝λ)・手札 +0.015/+0.020(ライフ札が手札へ) |
| countered | 2421 / 6563 | 0.071 / 0.072 | −0.080 / −0.074 | −0.009 / −0.002 | 手札 −0.070/−0.067(切った札) |
| took_and_countered | 110 / 379 | 0.086 / 0.086 | −0.201 / −0.206 | −0.115 / −0.119 | ライフ＋手札 |
| **blocker_died**(＝相手のキャラが1体減った) | 973 / 2798 | **0.087 / 0.091** | **−0.021 / −0.023** | **+0.067 / +0.067** | 体 −0.015/−0.016・手札 −0.006/−0.008 |
| **nothing** | 1482 / 2063 | **0.006 / 0.003** | **−0.024 / −0.022** | **−0.017 / −0.020** | 体 −0.011/−0.021・手札 −0.013/−0.002 |

種類で束ねると`unpriced_opp`は −0.018/−0.013(リーダー)・−0.007/−0.004(ブロッカーでない体)・
−0.007/−0.006(ブロッカー)＝**攻撃の価格は結果を平均すればおよそ合っている**(1〜2割の過小)。

**`blocker_died`の逆符号の正体**: `attack_response.classify`の`blocker_died`は相手の**キャラの数**
(`S_IS_CHAR`)が減った行＝**キャラをKOした攻撃**(ブロッカーとは限らない)。その価格は0.087〜0.091と
高いが、`Θ_opp`の体の項が失うのは`ν_meas`1体分の0.015〜0.016だけ——**「体をKOする価格」と
「耐久の体の項」が同じ体に対して6倍違う尺度で書かれている**。これは価格の型ごとの尺度の問題
(D系・バックログ#43)で、レストとは別の機構。

**`nothing`で相手の耐久が減る正体**: 相手のブロッカーが**ブロックしてレストになった**行(合成の
nothing/リーダーでは相手のブロッカー数が43%の行で動く)。ブロックは「ライフも手札もキャラ数も
変わらない」ので`nothing`に落ち、`Θ_opp`の体の項だけが落ちる(合成 −0.078)。価格は「通らない」と
読んでほぼ0(0.003〜0.011)なので、**この落ちも値付けされていない**——攻め手側(1.)と鏡像の同じ機構
(ブロッカーのレスト)。

## 結論

**元の問題の機構は1つ**——「ブロッカーがレストすると、`Θ`の体の項(アクティブなブロッカーだけを数える)
から`ν_meas`1体分が丸ごと消える」。それが (i) 攻め手のブロッカーが攻撃したとき(`th_me`・攻撃の
5.8%/4.4%)と (ii) 守り手のブロッカーがブロックしたとき(`th_opp`・`nothing`の行)の両側で起き、
どちらも攻撃の価格に入っていない。C-2の切替はこのうち(i)だけを、**「レストは在庫の永久の損失」という
今の状態の定義に価格を合わせる形**で足したもの。

C-3で「主に読む帯」の帳簿が悪化した理由はここから読める——**規則ではレストは次の自席ターンのリフレッシュで
戻る**(`rules/turn.rs`・T96)。決着が遠い行で1体分の`ν`を丸ごと引くのは規則より重い罰で、決着が近い行
(次の相手ターンにブロックできないことがそのまま効く)では正しい。とどめの帯で改善し決着前で悪化した
符号の割れは、**「永久」と「1ターン」の差**として説明がつく。

## 式の候補(C-5c・ユーザと検討)

| 候補 | 状態`Θ`の体の項 | 攻撃の価格 | 規則との対応 |
|---|---|---|---|
| F0(今) | アクティブなブロッカーだけ | 触らない | レスト＝永久の損失・価格は無視(残差として残る) |
| F1(C-2) | 同上 | ブロッカーが攻めたら`ν_meas`1体分を`th_me`から引く | 状態の定義に価格を合わせる(レスト＝永久) |
| F2 | **レスト中のブロッカーも数える**(札の原本から`blocker`を引く・`resting_blocker_term`と同じ読み) | 触らない | レスト＝損失なし(次のターンに戻る)・**次の相手ターンにブロックできない1回分を無視** |
| F3 | アクティブ＋レスト中を「次の自席ターンから戻る耐久」として時間の側へ(T96の`THETA_RETURN_MODE=untap`の設計) | 触らない | 規則どおり(1ターン遅れて戻る)・1行の器では`τ`が要る |

F2は両側(攻め手のレストも守り手のブロックも)に同時に効き、価格を触らない。F3が規則に最も忠実だが
1行の`Θ`に時間を持ち込む。**KOの価格と体の項の尺度差(6倍)は別の問い**(D系)。
