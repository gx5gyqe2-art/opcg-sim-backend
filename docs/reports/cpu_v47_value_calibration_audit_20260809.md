# v47 手順0 — 本体 value の較正一次監査: 本体は系統的に誤っている（2026-08-09）

「新たな指摘が出るたびにパッチを当てる前に、**本体 value が分布全体で正しいかをまず確認する**」
（ユーザ方針 2026-08-09）の第一歩。既存のレフェリーラベル済みコーパスだけを使い（生成ゼロ）、
gen13 本体の `predict()` と実測勝率を突き合わせた。計器は
`tests/scripts/value_calibration_audit.py`（新設・読み取り専用）。
本文書はこの時点のスナップショット（追記改変しない）。

## 0. 結論

**本体は正しくない。系統誤差が2つ、枝間マージン（0.02〜0.03）の10倍以上のスケールで実在する。**

1. **ライフ差の重みが過大**。ライフで劣勢の盤面を実測より悲観し（バイアス −0.45〜−0.19）、
   優勢の盤面を楽観する（+0.20）。単調で、戦闘出口分布では完全に単調。
2. **中間域の圧縮（自信不足）**。互角〜ややリードの盤面（予測 +0.1〜+0.6）の実測勝率は
   予測よりはるかに高い（予測 +0.20 → 実測 +0.66〜+0.76）。優勢側で特に強い。

## 3. 読み方の注意（正直な限界）

- ラベルは「当時のエンジン同士のロールアウト勝率」＝**自己整合基準**。両者が共有する誤解は
  この監査では見えない。それでも「自己対戦の勝率でさえ説明できない歪み」がこの規模で出た。
- B/C の盤面は**出口分布**（ターン末・戦闘後）であり、木の葉の全域ではない。ただし葉の68%は
  ターン境界近傍（v37 実測）なので大きくは外れない。
- A は204盤面で層あたりの検出力が弱い（±0.10〜0.30）。B/C の追認としてのみ使う。

## 4. 含意

- ライフ差 ±0.2〜0.45・圧縮 ±0.3〜0.5 のスケールは、枝間マージン 0.02〜0.03 の**10〜20倍**。
  この歪みの上で 0.03 の順位を競っているのが現状＝個別パッチが繰り返し必要になる構造的理由。
- 単調な歪みは**順位を保存する範囲では実害が出ない**（だからアリーナ中立が続いた）が、
  ライフと他資源を**交換する判断**（防御・ドン付与・展開）では順位そのものを反転させる。
  過去の指摘（m1@14・m2@44 系）がすべて交換判断に集中していたことと整合する。
- 直す場合の教師仕様が確定した: 「ライフ差の重みを下げ、中間域の自信を上げる」方向の
  較正で、対象分布は出口盤面。ただし本体を動かす以上、v40/v42 の教訓（アンカー/補間つき
  学習＋戦闘ヘッド再較正＋アリーナ検収）が前提条件。
