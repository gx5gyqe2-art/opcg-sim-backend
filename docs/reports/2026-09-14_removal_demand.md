# T27-b——**効果は盤面を狙っていない**。④は「見えない」のではなく「起きていない」

2026-09-14 実施・判定。合成 300 局（w39）・**実デッキ 300 局**（w41）。
`docs/game_theory.md` §14.1.2 の項④（除去要求）・`docs/cpu_theory_gap.md` の **T27-b**。
本報告は特定時点のスナップショット（追記・改変しない）。

## 結論を 5 行で

1. **uuid の持ち主の表は作れた**——ゲームの規則（自分のカードしか動かせない／相手のものしか
   殴れない）だけで、実デッキ 300 局で **4,848 枚**の持ち主が決まった。
2. **表は効いている**——`PLAY` した uuid の **62.6%**（合成 69.7%）が**後で行動している**
   ＝**uuid はゾーンを跨いでも変わらない**＝引き当てに使える。
3. **それでも被覆率は 0.0015**（合成 0.0058）——**効果が選んだカードのうち、
   盤面のカードは 1,000 枚に 1.5 枚しか無い**。
4. **＝④が「見えない」のではない。`RESOLVE_EFFECT_SELECTION` は手札・デッキ・
   トラッシュを選んでいて、盤面を狙っていない。**
5. **ただしこれは「実デッキに除去が無い」ではなく「CPU が除去を撃っていない」**
   かもしれない——**この 2 つは本器では分けられない**（§4）。

## 1. 前器の宿題と、鍵

`exit_ledger` は対象を**枠**（`pol_ti`）で追うので除去が見えず、
`removal_observable = false`（**0 を結果として読ませない**）を返していた。
本器は**uuid の持ち主を組み立てて**引き当てる:

| 手掛かり | なぜ持ち主が決まるか |
|---|---|
| 自席ターンの**行動主体**（`sig[1]`） | **自分のカードしか動かせない**（攻撃・付与・起動・登場） |
| 自分の**攻撃の対象**（`sig[2]`） | **相手のものしか殴れない** |

## 2. 表は効いている（**先に検算した**）

**被覆率 0 には 2 つの意味がある**——表が壊れているのか、選ばれたのが盤面のカードではないのか。
**混ぜると偽の発見が出る**ので、器に検算を持たせた:

```
map_validated = （`PLAY` した uuid が後で行動した割合）
```

高ければ **uuid はゾーンを跨いでも変わらない**＝表は引き当てに使える。

| | 合成 300 局 | **実デッキ 300 局** |
|---|---|---|
| 持ち主が決まった uuid | 3,711 | **4,848** |
| `PLAY` した uuid | 2,905 | 3,996 |
| **うち後で行動した** | **2,026（69.7%）** | **2,501（62.6%）** |

**表は使える。**

## 3. 実測——**効果は盤面を狙っていない**

| | 合成 300 局 | **実デッキ 300 局** |
|---|---|---|
| 効果の解決行 | 730 | **2,033** |
| 選ばれた uuid | 1,894 | 3,294 |
| **うち持ち主が判ったもの** | **11** | **5** |
| **被覆率** | **0.0058** | **0.0015** |
| `demand_per_turn` | 0.0003 | 0.0 |
| **判定** | `effects_do_not_target_the_board` | 同左 |

**選ばれた 3,294 枚のうち、盤面に居たことがあるカードは 5 枚。**
残りは**手札・デッキ・トラッシュ**のカードである（引く・捨てる・サーチする類の効果）。

> **前報の「実デッキは効果の解決が 1 局あたり 2.9 倍」は正しかったが、
> その効果は盤面を狙っていなかった。** 「見えていない項が実デッキで厚い」という
> 前報の読みは、**この測定で否定された**。

## 4. **ただし 2 つの説明が残る**（本器では分けられない）

| 説明 | 含み |
|---|---|
| **(a) 実デッキの構成に盤面除去が少ない** | ④は理論の項として小さい＝**`ν` の組み直しで④を省いてよい** |
| **(b) CPU が除去を撃っていない** | **④は理論の項としては要る**が、**記録が CPU の弱さを映している**＝
これは理論の話ではなく**打ち手の欠陥**（`cpu_theory_gap.md` §1 の「行動空間の被覆」の系） |

**(b) は実在しうる**——本シミュレータの CPU は実用水準に達していない（CLAUDE.md の前提）。
**分けるには「デッキに盤面除去のカードが何枚入っているか」を数える**必要があり、
それはパーサ側（効果 JSON）から出せる。**T27-c** として登録する。

> **どちらであっても、いま ④ に大きな値を置く根拠は無い。**
> **`ν` の組み直しは②（身代わり）と③（攻撃）で進めてよい**——ただし
> **(b) だった場合、この理論は「除去を撃たない CPU が作った棋譜」の上でしか検証されていない**
> ことになる（`measurement.md` §15 の自己対戦の限界がそのまま当てはまる）。

## 5. 体の同一性（挟み込みの解消）は**まだ片づいていない**

T27-b は「④の測定」と「体の同一性」を同じ鍵で開ける見込みだった。
**表は作れたが、盤面の枠と uuid を結ぶのは「選ばれた手」だけ**なので、
**行動しなかった体は追えない**。`2026-09-14_absorbed_power.md` の挟み込み
（合成 [0.135, 0.273]・実デッキ [0.108, 0.274]）は**そのまま残る**。

**解くには記録側の変更が要る**（枠ごとの uuid を毎行落とす＝dump v5）。**T27-d**。

## 限界

- **選ばれた＝除去されたとは限らない**（レスト・パワー下げ・移動も入る）＝
  本器が測るのは**「相手が自分の場に効果を向けた回数」の上限**。
  **その上限が 0 に近い**というのが結論なので、この向きの限界は結論を弱めない。
- **持ち主の表は「一度でも動いた／殴られたカード」だけ**を覆う。
  出してすぐ除去された体は表に載る（`PLAY` が主体を持つため）が、
  **手札から一度も出なかったカードは載らない**。
- 各 300 局・1 設定・生成役 r3。
