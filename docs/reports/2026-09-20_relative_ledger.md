## 0. 結論（先に書く）

1. **座標の取り方は当たった（P1）**——**価格を相対化（対数比の差）するだけで判別が跳ねる**。
   **勝敗がまだ決まっていない帯**（最後の自席ターンを外した帯）で
   **AUC 0.800 → 0.9384（実）／0.8628 → 0.9462（合成）**。
   **これは線形の橋の歴代最良を大きく更新する**（これまでの最良は 0.70 前後）。
2. **重み `K(r)` を足す形（法則そのもの）は判別を取り戻せなかった（P2 は不成立）**——
   `rel_K` は同じ帯で 0.7446／0.8517 で、**`κ = 1` の相対形（0.9384／0.9462）にも
   絶対額の `κ=1`（0.800／0.8628）にも負ける**。**較正は改善するが、判別と較正の衝突は解けていない**。
3. **その衝突は構造だと分かった**——**正しい `ΔW` は決着したら黙る**（`K → 0`・`r → 0` で `K ∝ r`）。
   ところが**局ごとの和を勝敗で採点する指標は、決着帯を大きく数える腕を機械的に有利にする**。
   **だから「正しい帳簿」と「よく当たる帳簿」は、telescoping が閉じない限り両立しない**
   ＝**`H`（引き・トリガー・相手の手の値付け）が予想ではなく論証で次の関門になった**。
4. **不変量は法則の側が正しく、出荷の `D` が破っていた（P5）**——
   `clock` の読み（`T = Θ/A`）では**通貨の一律付け替えで帳簿は 19,803 行のうち 15 行しか動かない**
   （その 15 行も打ち切り `RACE_CAP` に触れた行）。**`curve`（帳簿の正本）では 19,051 行が破れる**
   ——**輪郭 fixture が絶対量**なので、通貨を 3 倍すると時計が 3 倍にならない。
5. **共通の速さ誤差には強い（P7・確認）**——両席の `A` を 1.3 倍しても `clock` では 612 行中**打ち切り以外は 16 行**、
   `curve` では**厳密に 0 行**。T112 が言う「偏りの 74% は `A` の軌跡・その形は両席に共通」に対し、
   **比で読む形は設計どおり強い**。
6. **とどめの一撃は相対形だけが拾えた**——最後の自席ターンだけの帯では**ほぼ全部の腕が AUC < 0.5**
   （`abs_flat` 0.288／0.374・`abs_kappa` 0.219／0.306）なのに、**`rel_flat` だけ 0.678／0.626**。
   §17.9.4 の「絶対額では発散項が表せない」は**この帯で確認できた**。
7. **`κ` の物差しの齟齬（§17.9.6-1）は直したが、効果はほぼ無い**——`match` で
   AUC 0.6012 → 0.6052（実）／0.7213 → 0.7227（合成）。**正しさの修正であって利得ではない**。

**推薦**: **帳簿の価格を相対化する**（`Δlog` で書く）＋**`κ = 1` のまま**。採否はユーザ判断。
`K(r)` を掛けるのは**較正が要る用途（勝率の単位で読みたいとき）だけ**にして、既定にはしない。

## 1. 測ったもの（腕の組み方）

**「相対化」と「重み」のどちらが効くのかを分けるため 2×2 に組んだ**:

|  | 重み無し（`κ=1`） | 重み `K(r)` |
|---|---|---|
| **絶対額の価格** | `abs_flat`（T121 の勝者） | `plac_K` |
| **相対変化** | **`rel_flat`** | **`rel_K`（法則そのもの）** |

＋ `abs_kappa`（**出荷の帳簿** `κ = w(D)/w̄`）・`rel_exact`（`Φ(z')−Φ(z)`・一次近似なし）・
`plac_shift`（プラセボ: `K` を**前の局の同じ行番号**から取る＝重みと局面の結びつきだけ壊す）。

`Δlog(T_opp/T_me)` は**近道の `p/Θ` ではなく時計を作り直して引く**
（`curve` の読みでは `T = Θ/A` ではないので近道は成り立たない）。

### 判定に AUC を単独で使ってはいけない（本 T で気づいた）

**局ごとの帳簿の和を AUC で読むと、決着帯を増幅した腕が機械的に勝つ**——決着帯では勝敗が
もう決まっているので、そこを大きく数えるほど「当たる」。だから **3 つを並べて出す**:

1. 全帯の `auc`／`corr`（参考）
2. **`before`＝最後の自席ターンを外した帯**（**主に読む**）
3. **`sep`／`bias`＝当てはめゼロの較正**（`ΔW` の帳簿なら `Σ ≈ z − W₀` なので `sep → 1`・`bias → 0`）

`sep` の理想は厳密には `1 − w0_gap`（実 −0.05 ⇒ **1.05**／合成 +0.0444 ⇒ **0.956**）。

## 2. 実測（実／合成・`curve`＝帳簿の正本の読み）

### 2.1 判別（主に読む帯＝最後の自席ターンを外した）

| 腕 | 実 AUC | 実 corr | 合成 AUC | 合成 corr |
|---|---|---|---|---|
| **`rel_flat`** | **0.9384** | 0.5062 | **0.9462** | 0.4490 |
| `plac_shift`（プラセボ） | 0.7986 | 0.3883 | 0.8568 | 0.3827 |
| `abs_flat` | 0.8000 | **0.4916** | 0.8628 | **0.5935** |
| `rel_K`（法則） | 0.7446 | 0.3785 | 0.8517 | 0.5319 |
| `abs_kappa`（出荷） | 0.7012 | 0.3436 | 0.8144 | 0.5218 |
| `rel_exact` | 0.6348 | 0.2314 | 0.7523 | 0.4034 |
| `plac_K` | 0.6158 | 0.2135 | 0.7318 | 0.3951 |

**読み方**:
* **`rel_flat` が両記録で最良**（`abs_flat` に対し **+0.138／+0.083**）。**プラセボとの差も大きい**（+0.140／+0.089）。
* **相関では `abs_flat` が勝つ**（実は 0.5062 対 0.4916 でほぼ同じ・**合成は 0.4490 対 0.5935 で負け**）
  ——**対数形は裾が重い**（とどめで発散する）ので、**順位の指標（AUC）は跳ね、積の指標（相関）は裾に引かれる**。
  **「相対化は順位を直す・大きさは直さない」**と読む。
* **`K` を掛けると下がる**（`rel_flat` → `rel_K` で −0.194／−0.095）。

### 2.2 較正（当てはめゼロ・理想は `sep` 1.05／0.956・`bias` 0）

| 腕 | 実 `sep` | 実 `bias` | 合成 `sep` | 合成 `bias` |
|---|---|---|---|---|
| `rel_K`（法則） | **0.5652** | −0.1149 | 0.6399 | **−0.0114** |
| `abs_kappa`（出荷） | 0.3057 | −0.1815 | **0.7228** | −0.0531 |
| `abs_flat` | 0.3247 | −0.1045 | 0.4665 | −0.0439 |
| `rel_flat` | 3.0554 | −0.0811 | 2.9014 | −0.0641 |
| `rel_exact` | 0.0562 | −0.1336 | 0.2390 | −0.0174 |
| `plac_K` | 0.0387 | −0.0981 | 0.2050 | −0.0581 |
| `plac_shift`（プラセボ） | 1.3413 | −0.0056 | 0.8683 | −0.0061 |

* **理想から 2 倍以内に入る非プラセボの腕は `rel_K` だけ**（実 1.86 倍・合成 1.49 倍のずれ）。
  `abs_flat` は 3.2／2.0 倍・`abs_kappa` は 3.4／1.3 倍・`rel_flat` は **2.9／3.0 倍の行き過ぎ**。
* **だが `bias` ではプラセボ（`plac_shift`）が両記録で最良**（−0.0056／−0.0061）＝
  **`bias` 単独は判定に使えない**（重みを局面から切り離しても良く見える）。**`sep` と組で読む**。

### 2.3 とどめの帯（最後の自席ターンだけ）

| 腕 | 実 AUC | 合成 AUC |
|---|---|---|
| **`rel_flat`** | **0.6779** | **0.6264** |
| `plac_shift` | 0.5543 | 0.4674 |
| `rel_K` | 0.4133 | 0.4268 |
| `abs_flat` | 0.2882 | 0.3735 |
| `abs_kappa` | 0.2194 | 0.3057 |
| `plac_K` | 0.1750 | 0.2151 |

**ほぼ全部の腕が 0.5 を下回る**。これは **T107 が見つけた規則の帰結**——
**勝った席の最後の自席ターンは相手のライフが 0 になった時点で終わる**ので行数が構造的に少なく、
**負けた席は最後のターンをフルに使う**。だから「最後のターンの帳簿の和」は**負けた席の方が大きくなる**。
**その不利を押し返して 0.5 を超えるのは `rel_flat` だけ**＝**対数座標の発散項がとどめを拾っている**
（§17.9.4 の予言の、`rel_exact` ではなく `rel_flat` 経由での確認）。

**P3（`rel_exact` が最後のターンだけで勝つ）は反証された**——`rel_exact` は 0.3064／0.3363 で `rel_K` にも負ける。

## 3. 不変量（P5・P7・行ごとの厳密な検算）

**腕の AUC を run ごとに比べるのではなく、行ごとに `Δlog` と `K` の一致を見る**（`invariance`）。
**打ち切り（`RACE_CAP`）と床は絶対量**なので、**どちらの状態でも打ち切りに触れていない行だけ**を「破れ」と数える。

| 読み | P5（通貨 ×3） | P7（両席の `A` ×1.3） |
|---|---|---|
| **`clock`**（`T = Θ/A`） | 19,803 行中 破れ 9,851・**打ち切り以外は 15 行**（0.08%） | 破れ 612・**打ち切り以外は 16 行**（0.08%） |
| **`curve`**（帳簿の正本） | 19,803 行中 破れ 19,114・**打ち切り以外も 19,051 行**（96.2%） | 破れ **0 行**（厳密） |

**結論 2 つ**:
1. **法則は厳密に不変**（`clock` で 0.08% しか破れず、その全部が打ち切りか床）。
2. **`curve` の読みは通貨の付け替えで壊れる**——**輪郭 fixture（`harm_profile.json`）が絶対の損害率**なので、
   耐久と価格を同じだけ増やしても時計がその比で伸びない。**出荷の `D` は尺度不変ではない**。
   `curve` で P7 が厳密に 0 なのは**`A` が時計に 1 度も入らないから**（T121 の「速さの軸が無い」の裏返し）。

## 4. `κ` の物差しの齟齬を直した（§17.9.6-1）

`state_factor → w_of_d` は `σ_D = 1.4142` を使い、出荷の `W`（`prob_of_d`）は `σ_rel·s`（例で 2.7569）を使う
＝**T118 以降 `κ` は `W` の微分になっていなかった**。`KAPPA_SIGMA_MODE=match` で揃えた（**既定は据え置き `abs`**）。

| | 実 AUC | 実 corr | 実 `sep` | 合成 AUC | 合成 corr | 合成 `sep` |
|---|---|---|---|---|---|---|
| `abs_kappa`（`abs`＝現状） | 0.6012 | 0.1758 | 0.3057 | 0.7213 | 0.3800 | 0.7228 |
| `abs_kappa`（`match`） | 0.6052 | 0.1839 | 0.3153 | 0.7227 | 0.3821 | 0.7194 |

**効果はほぼ無い**（+0.004／+0.001 AUC）。**正しさの修正であって利得ではない**ので、そう書く。

**途中で床が必要になった**（踏んだ）——`κ` は**密度** `φ(z)/σ` なので `σ → 0` で発散し、
**両席の時計が同時に 0 へ行く行で `sep` が 21,065 に飛んだ**。`rel` の物差しは T118 の実測では `abs` より
**広い**ので、**狭くなる行は `rel` の測った範囲の外**として `abs` に留めた（新定数ゼロ・既存の `σ_D`）。
**法則の `K` にはこの病気が無い**（`K = φ(z)·g(r)/σ_rel` で `g(r) ≤ 1.06` の有界関数・`s` を含まない）
＝**対数座標の重みは有界・線形座標の重みは発散する**。

## 5. 判別と較正の衝突は構造である（本 T の一番の収穫）

**正しい `ΔW` は決着したら黙る**——`r → 0`（勝ち確）で `K ∝ r → 0`。これは**正しい振る舞い**
（決着した局で 1 手打っても勝率はもう動かない）。
ところが**局ごとの和を勝敗で採点する指標**は、**決着帯を大きく数える腕を機械的に有利にする**
（そこでは勝敗がもう決まっているので「当たる」のは情報ではない）。

    正しい帳簿 → 決着帯で静かになる → 局ごとの採点で不利
    よく当たる帳簿 → 決着帯で大きくなる → ΔW としては誤り

**この 2 つが両立するのは telescoping が閉じるときだけ**——`Σ ΔW = z − W₀` が厳密に成り立てば、
静かな帳簿でも局の合計は勝敗をちょうど当てる。**閉じない理由は分かっている**:
**自席の手以外の遷移（引き・トリガー・相手の手）に値段が付いていない**（`H`）。

> **だから `H` は「後回しの候補」から「次の関門」に格上げされた**。**予想ではなく論証で決まった**。

## 6. 上手くいったこと／いかなかったこと

**上手くいった**:
* **予告を先に書いてから測った**（§17.9.8 の P1〜P7）。**P1・P5・P7 が当たり・P2・P3 が外れ**と
  はっきり分かれたので、**当てはめの余地が無かった**。
* **2×2 に組んだので「相対化」と「重み」を分離できた**——利得は**全部相対化の側**（`rel_flat` 対 `plac_K`）。
* **不変量を「行ごとの一致」で測った**のが効いた。最初は run をまたいで AUC を比べていて、
  **`curve` で P7 が自明に通り・`clock` で打ち切りのせいで P5 が偽に破れる**という二重の誤読をした。
* **プラセボが 2 回働いた**——`plac_shift` が `bias` で最良になったので、**`bias` 単独では判定できない**と分かった。

**いかなかった／自己批判**:
* **`κ` の物差しを `match` に揃えたら密度が発散した**。§17.9 を書いた時点で
  「`K` は有界・`w/w̄` は発散する」と**気づけたはず**で、床を後付けで足すことになった。
* **P2 を「決め手」と予告したが外れた**。法則は座標について正しかったが、
  **「正しい形にすれば両立する」という期待が甘かった**——§5 の論証を**先にできていれば予告を変えられた**。
* **`rel_exact` が全帯で最下位付近**（0.5057／0.6050）。`Φ` で挟むと `[0,1]` に潰れるので、
  **和が飽和して局の差が出ない**。**「厳密な方が良い」も検証が必要な仮説だった**。
* **`dead_share` 0.6918／0.6773**——`curve` の読みでは速さを動かす手（45%）に加えて
  **`TURN_END` と価格 0 の行**も `Δlog = 0` になる。**器の母数の 7 割が 1 円も動かせていない**。
