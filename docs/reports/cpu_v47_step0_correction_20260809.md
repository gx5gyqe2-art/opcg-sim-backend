# v47 手順0 の訂正 — 「blend は保守側」は成り立たない（2026-08-09）

`cpu_v47_value_calibration_audit_20260809.md`（同日・手順0）の結論のうち**1点を訂正**する。
報告書は改変しない規約のため、正誤を本文書に残す（索引からは両方を辿れるようにする）。

## 訂正の対象

手順0 は §0 と §1 で次のように述べた。

> 混合ラベルのライフ差タイブレーク（w=0.25）は**ライフ差バイアスを打ち消す向き**に働くため、
> B/C の単調バイアスは**過小評価**（真値はより大きい）。

**これは支持されない。** 同じ手順0 の中にある純粋ラベル（データセット A・worlds=32・204盤面）で
ライフ差を層別すると、B/C で見えた劣勢側の大きな負バイアスは**消える**。

| ライフ差(自-相) | B: ターン末 w4混合 | C: 戦闘出口 w4混合 | **A: ターン末 w32 純粋** |
|---|---|---|---|
| ≤ −2 | −0.285 | −0.446 | **−0.001** |
| −1 | −0.184 | −0.261 | **−0.018** |
| 0 | −0.037 | +0.042 | +0.017 |
| +1 | +0.088 | +0.203 | +0.089 |
| ≥ +2 | −0.065 | +0.202 | **−0.280** |

## なぜ誤ったか

`margin_blend(z, ld) = z + 0.25·clip(ld/4)` は、**劣勢盤面のラベルを下げ、優勢盤面のラベルを
上げる**。これは同時に2つの見かけを作る。

1. ラベルのスケールが引き伸ばされる → ネットが**圧縮して見える**（較正曲線の歪み）
2. 劣勢のラベルが下がる → ネットが**劣勢で悲観して見える**（ライフ差層別の歪み）

手順0 は 1 だけを勘定し、2 を見落とした。「blend はライフ差バイアスを打ち消す向き」という
記述は、blend がライフ差**そのもの**をラベルへ足していることと矛盾している。

## 訂正後に残る所見

純粋ラベル（A）で残るのは次の2つ。どちらも 204盤面・56群（対局クラスタでは10対局）の
小標本なので、**大きさは確定していない**。

- **中間域の圧縮**: 予測 +0.178 の盤面の実測は +0.350、予測 −0.190 の実測は +0.003。
  等調回帰による単調変換で RMSE 0.412→0.375・平均バイアス −0.062→0.000。
- **ライフ優勢側（≥+2）の楽観 −0.280**（n=58・2SE ±0.19）。単調変換では −0.230 にしか
  下がらない＝**特徴依存**であり、出力の変換では消せない種類の誤り。

## 手続き上の教訓

- **較正（水準）の議論に順位学習用のラベルを使ってはいけない**。`margin_blend` は
  「拮抗枝の順位づけ」のために設計されたタイブレークで、水準を測る物差しではない。
- 同じ生成器のコーパスでも**ラベル式が違えば別の物差し**になる。今後の監査は
  `value_label_gen`（純粋 z）を正本とし、blend 込みコーパスは順位の検証にのみ使う。
- 手順0 の他の記述——中間域の圧縮の存在、m1@14 がその一般傾向の1標本である可能性、
  枝間マージン（0.02〜0.03）に対する誤差の桁——は本訂正の影響を受けない。
  ただし**大きさ**は B/C 由来の数値でなく A（および手順1 の純粋ラベル）で読むこと。
