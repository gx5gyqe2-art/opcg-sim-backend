# P2-1 の訂正——**対象の種別と場所を読んでいなかった**（ステージに `ν`・手札からの登場が無料）

2026-09-14 実施。ユーザ指摘「**動作の対象は配線で指定できるようになるよね？ 対象が自分か相手か、
またはキャラクターかイベントかステージかなどは大事**」への対応。
`2026-09-14_effect_value.md` の**同日中の訂正**（あちらは追記しない・こちらが新しい）。
本報告は特定時点のスナップショット（追記・改変しない）。

## 結論を 4 行で

1. **`target.player`（自分か相手か）は読んでいたが、`card_type`（種別）と `zone`（場所）は
   読んでいなかった**。**実害が 2 件出た。**
2. **実害 1: ステージへの `KO` を「体が消えた」と値付けしていた**
   ——T16 が「**ステージは体を持たない**」と明示しているのに `ν` を当てていた。
3. **実害 2: 手札から体を出す効果を「無料」で値付けしていた**
   ——**札 1 枚を失う**のに `+ν` だけ足していた。**トラッシュやデッキから出す場合と同じ扱い**だった。
4. **直した結果、被覆率は 51.8% → 52.27% に上がり、中央値は `μ` にぴったり合った**（0.0551）。

## 1. 実害 1——**ステージは体を持たない**

| 対象の種別 | 旧 | 新 |
|---|---|---|
| `CHARACTER` / `LEADER` | `ν` | `ν`（変更なし） |
| **`STAGE`** | **`ν`（誤り）** | **`None`（価格が無い）** |
| **`EVENT`** | **`ν`（誤り）** | **`None`** |

**ステージは場に残るが体を持たない**——`scalars` の場のキャラ数に入らないので、
`ν`（場のキャラ 1 体の価格）の勘定から外すのが正しい（T16・
`2026-09-14_bodyless_and_power.md` で**パワー 0 のステージ 124 枚が最弱帯に混ざっていた**のを
発見している）。**同じ誤りを効果の側で繰り返していた。**

> **ステージの価格は無い**（常在効果の価値＝§14.1.1 の項 10・11）。
> **`None` を返して保留する**——0 にすると「効果が無い」と混ざる。

## 2. 実害 2——**どこから出すかで札の損が付く**

```
旧:  PLAY_CARD → +ν                    どこから出しても同じ
新:  手札から   → +（ν − μ）            **札 1 枚を失う**
     トラッシュ・デッキ・見たカードから → +ν
```

実測で **`PLAY_CARD` の出どころは `HAND` 128・`TRASH` 54・`TEMP` 19**（`FIELD` 128 は
「このカードを登場させる」＝自分自身）。**手札からの 128 件を過大に評価していた。**

## 3. 併せて直したもの

**`TRASH` の `zone` が `LIFE`**（29 件）は **`λ`**（ライフの損）——`ν` でも `μ` でもない。
旧版は `None` を返していたので**誤りではなかったが、値付けできるものを保留していた**。

## 4. `card_type` が書かれていない動作の扱い

**全体の約 4 割は `card_type` が空**である。**書かれているときだけ除外に使う**
——書いていないものを弾くと、**値付けできる範囲が不当に狭まる**。

## 5. 配線のときは盤面の `ν` を渡せる（ご指摘への直接の答え）

カード単体の値付けでは **`ν` は平均 0.1087** を使うが、
**`action_value(..., nu=)` で上書きできる**ので、**配線する時点で対象のパワーの帯**
（0.0690／0.1503／0.2112）**を渡すのが正しい**。

```
弱い体を KO       → ν = 0.0690
飽和超えを KO     → ν = 0.2112     **3 倍違う**
```

**`pol_ti`（対象の枠）と `tgt_power` は記録に在る**ので、配線時に渡せる。テストで固定した。

## 6. 直した後の実測

| | 旧 | 新 |
|---|---|---|
| 被覆率 | 51.8% | **52.27%** |
| 値付けできた能力 | 1,754 | **1,770** |
| **中央値** | 0.0554 | **0.0551**（＝`μ` にぴったり） |
| 負の割合 | 11.9% | 12.8% |

**中央値が `μ = 0.0551` に一致**するのは合わせ込んでいない（写像表に自由なつまみが無い）ので、
**訂正後もこの独立の一致が保たれた**——むしろ近づいた。
