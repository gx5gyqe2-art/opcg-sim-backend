## 2. 式（新定数ゼロ・**打ち筋に依らない**）

```
G      = max(0, 攻撃の本数 − 相手のライフ − 相手のアクティブなブロッカー)   ← `board_theta` と同じ規則（§7）
c_eff  = 安い順に G 個の c(x) の平均                                       ← 1 回あたりの費用
Θ_hand = μ × c_eff × floor(切れる枚数 / c_eff)
G = 0 → 一番安い攻撃の c（守る義務が無いので削らない）
```

## 4. 読み方

- **上手くいった: T99 の削りすぎは直った**。帳簿の損は 3 分の 2 が戻り（`ΔG` AUC 0.579 → 0.657／0.665 → 0.703）、

  ＝**「守る義務が無いターンを削らない」という規則の 1 行が、帳簿の傷の正体だった**。
- **上手くいかなかった: 交点の利得も一緒に返した**。`Θ`/要（残り 1）は 1.43 → 1.73（`cuttable` 1.98）、
  偏りは +2.40 → +2.50（`cuttable` +2.53）。**`cuttable` に対して実質ほぼ中立**で、
  **`curve` の的中だけは実で下がる**（0.5861 → 0.5715）。
- **判定**: **規則としては T100 が正しい**（`G` は `board_theta` が既に使っている規則・入力は全部盤面）。
  **打ち筋にも依らない**。**しかし数値が動かない**ので、**既定は `cuttable` のまま据え置く**
  ——ユーザの基準は「正しさ」と「打ち筋に依らないこと」だが、**正しさが数値に現れない形を既定にしても検算にならない**。
  **切替として残し、下記の疑いを晴らしてから判定し直す**。

## 5. 測り方そのものへの疑い（本 T のいちばんの収穫）

**`Θ`/要 を「`Θ` の誤り」と読んでよいのか**を、ここで疑うべきだった。

- **`Θ` は在庫**＝「これから倒すのに要る量」。
- **`要った損害` は実績の総量**＝**実際にいつ終わったか**に依る。
- **攻め手が理論の τ より速く倒した局では、`Θ` > 要 になるのが当たり前**——`Θ` が間違っているのではなく、
  **その局が予測より早く終わった**だけ。

T96 で「残り 1 ターンで 4.07 倍」と読んだが、**残り 1 ターンの行は「予測より早く終わった局」に偏る**
（τ の偏りが +2.5 ターンなのだから、実際の終局はいつも予測より早い）。
**つまり `Θ`/要 の終盤の膨らみには、`Θ` の誤りと τ の偏りが混ざっている**。

**次にやるべきは切り分け**: **予測 τ と実際の残りターンが近い行だけ**で `Θ`/要 を測る。
そこで 1 に戻るなら**`Θ` は正しく、直すべきは速さ・時刻の側**。戻らないなら `Θ` の誤りが残っている。
**この切り分けをせずに `Θ` の形を足し引きしても、当てはめに近づくだけ**。
