**16 seed** で測り直し、v19 の点別主張がどこまで生き残るかを確定した。

## 2. 「測定ノイズでない」と言える差の下限

命中率は seeds 回のベルヌーイ試行＝SE ≤ 0.5/√n。2条件の差の SE は √2 倍なので **2σ ≈ 1.414/√n**:

| seeds | bar（この幅未満の増減は読まない） |
|---|---|
| 5 | **0.63** |
| 16 | **0.35** |
| 64 | 0.18 |

**5 seed の bar は 0.63＝点別増減はほぼ何も言えない水準**だった。純関数
`coach_gate.min_reliable_delta` として実装し、実行時に出力へ併記するようにした
（`tests/test_coach_gate.py` で数値を固定）。

## 3. v19 の点別主張の検証結果

| v19 の主張 | 16seed での判定 |
|---|---|
| m1@14 の無駄カウンターが完治（0→1.00） | **成立**（差 +1.00 ≫ bar） |
| m1@15 の無駄カウンターが完治（0.40→1.00） | **成立**（0.56→1.00・差 +0.44 > bar 0.35） |
| ガード m2@12 が反転（1.00→0.00） | **成立**（0.94→0.06・差 −0.88 ≫ bar）＝**本物の退行** |
| ガード m4@8 が退行（0.60→0.20） | **不成立・訂正**（16seed で **両者 0.38＝差ゼロ**。5seed の見かけ上の退行だった） |
| （v19 では気づかず） | **m5@7 が改善**（0.06→0.56・差 +0.50 > bar）＝gen8 の改善点がもう1つあった |

**gen8 の実像**: 明確な改善3点（m1@14・m1@15・m5@7）、明確な退行1点（m2@12）、残りは変化なし。
合計は 4.9 → **6.2** で、5 seed 測定（5.0→5.4）より**改善幅は大きかった**。
gen8 採用の判断（800局アリーナ主体）は変わらない。

## 4. 反映した運用変更

- `coach_gate.py` の既定 `--seeds` を **5 → 16**（5 は分散が大きすぎて点別議論に使えない）
- 実行時に bar と「bar を超えた点」を出力し、**bar 未満の増減を『治った/壊れた』と書かない**運用を
  計器側から強制する
- 16 seed でも bar は 0.35＝**±0.35 未満の点別差は依然として読めない**。点別の細かい増減を根拠に
  設計判断をしないこと（合否に使わない方針は v16 のまま）

## 5. 教訓

v15 で「勝率の検定力を先に計算する」を学んだが、**命中率という別の測定に同じ用心を適用していなかった**。
v20 の SEARCH_AVERSE 3点（3 seed）も v19 の m4@8（5 seed）も同じ穴を踏んでいる。
**新しい指標を導入したら、その指標の分散を最初に測る**——指標ごとに一度だけ払えばよいコストである。
