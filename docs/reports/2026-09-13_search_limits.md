# 探索は律速ではない——枝刈りは候補を落とさず、世界数を上げても勝率は動かない

2026-09-13 回収・判定。**問い**: CPU の弱さは**探索**の上限から来ているのか。
3 つの測定を同じ日に回した（台帳 `docs/n_loop_ops.md` §6・理論は `docs/game_theory.md` 第 II 部）。
本報告は特定時点のスナップショット（追記・改変しない）。

## 1. 行動空間の被覆——**枝予算は候補を 1 つも落としていない**（閉じた）

ユーザ指摘 2026-08-12「人間の付与が候補にすら無い」（当時 36%）の、現行エンジンでの測り直し。
記録では測れない（刈られた手は棋譜に現れない）ので、**同じ盤面・同じ seed・同じ sims で
`decide` を 2 通り**引いて根の候補集合を突き合わせた（腕 A＝既定の箱の枝予算／腕 B＝`budget: 0`＝無制限）。

| 量 | 実測（40 局・2,606 判断点・sims 160） |
|---|---|
| `coverage`（`|A∩B|/|B|`） | **1.000**（最小も 1.000） |
| `missing_any`（1 つでも落ちた判断点） | **0.000** |
| `best_not_in_a`（B の最善手が A に無い） | **0.000**（2,606 点すべて） |
| `exhausted_a_any`（枝予算が切れた） | **0.000** |
| `don_coverage`（DON_BOX 候補の被覆） | **1.000** |

ターン帯 3 つすべてで同じ（`T<=4`／`T5-8`／`T9+` いずれも 1.000・0.000）。
腕 B の追加費用は 800.9 秒のうち 397.6 秒＝**無制限にしても壊れず、結果も変わらない**。

**判定: 枝予算は上限を作っていない**。2026-08-12 の 36% は**当時の Python の列挙の話**で、
現行エンジンには当てはまらない（`critique_index.md` §4 の 3 を閉じる）。
**ただし閉じたのは「刈られたか」の半分**——「人間が打つ配分が列挙の**設計**に入っているか」は、
無制限の列挙を正とみなす以上この方法では測れない（宿題として残す）。

## 2. 世界数を上げる 2 腕——**どちらも勝率が動かない**（ただし分解能不足）

同じネット（r5）を両席に置き、候補席だけ世界数を上げた（既定は **`worlds = 1`**）。

| 腕 | ペア | 勝率 | 95% CI | Elo | void |
|---|---|---|---|---|---|
| `worlds = 4` | 275 | 0.5182 | [0.4711, 0.5652] | **+12.6** [−20.1, +45.6] | 0 |
| `worlds = 8` | 228 | 0.5044 | [0.4549, 0.5539] | **+3.0** [−31.4, +37.6] | 0 |

**事前登録した読み方は「CI 下限が 0.50 を超えれば世界数が律速」**で、どちらも 0.50 をまたいだ。
ただし**事前に想定した 1 腕 1,200 ペア（±14 Elo）に対し、実際は 250 ペア前後（±41〜45 Elo）**
＝**「効果なし」を示せる分解能に達していない**。正しく言えば

> **+20 Elo 級の効果は棄却できていない。分かったのは「+45 Elo 級の大きな効果は無い」こと。**

**用量反応は効果の存在を支持しない**（4 で +12.6・8 で +3.0＝世界数を増やして下がっている）。
シャードが極端に不均等だった（w03 260・w05 220・他は 0〜12 ペア）＝**`worlds>1` は重く、
`--workers 2` でも 8 セッションのうち 2 本しか実質進まなかった**。世界数を上げる案は
**費用（レイテンシ 4〜8 倍）に対して見返りの証拠が無い**ままなので、現状は採らない。

## 3. PIMC の診断——**壊れるのは接戦帯だけ**（理論の予測と一致）

`decide` の `per_world`（世界ごとの根の統計）から、束ねる前の各世界の結論を読んだ
（K=8・10 局・606 判断点・sims 160）。`game_theory.md` §5 の strategy fusion が
**実際に起きているか**の直接の観測。

| 帯（`|v0|`） | n | 世界の最善が割れる | **どの世界の最善でもない手を打った** | 選んだ手の Q の世界間の幅 |
|---|---|---|---|---|
| close（≤0.2） | 50 | **0.440** | **0.020** | **0.361** |
| mid | 128 | 0.336 | 0.016 | 0.273 |
| decided（>0.6） | 428 | 0.231 | 0.002 | 0.133 |
| 全体 | 606 | 0.271 | 0.007 | 0.182 |

`unmapped` は 0（世界間の候補の対応は付いている）。ターン帯では終盤（T9+）がやや悪い
（割れ 0.293・幅 0.200）。

**K=4 でも同じ形**（10 局・594 判断点）: 全体は割れ 0.177・融合 1.35%・幅 0.100、
接戦帯は **割れ 0.400・融合 4.0%・幅 0.212**＝**壊れる場所は K を変えても接戦帯**。

> **K をまたいだ数字の比較はできない**（機械的な偏りが 3 つとも入る）: 世界が多いほど
> 「どれか 2 つが違う」確率は上がる（`disagree` は上振れ）・min−max の幅も広がる（`q_spread` は上振れ）・
> **世界の最善の集合が大きくなるので `merged_novel` は下振れする**。
> したがって「K=8 の融合 0.66% < K=4 の 1.35%」は**世界数を増やせば融合が減る証拠にはならない**。
> 読めるのは「**どちらの K でも融合は数 % 以下で、接戦帯に集まっている**」まで。

**読み**: `merged_novel` が全体 0.7%・決着帯 0.2% で、**PIMC はほぼ自分の良い領域に居る**
（leaf correlation が高い＝どの世界でも同じ側が勝つ）。壊れるのは**接戦帯**で、
そこでは世界が 44% 割れ・Q が 0.36（勝率で 18 ポイント）ばらつき・2% は融合した選択になる。
**接戦帯は守りの判断が住んでいる帯**（`2026-09-13_time_plan_map.md` の t≤2）なので、
「守りが弱い」という観測と**同じ場所**を指している。

## 3 つを合わせた判定

- **列挙（枝予算）は律速ではない**——閉じた。
- **世界数は律速の証拠が無い**——費用に見合う効果は見えず、用量反応も逆向き。分解能不足は残る。
- **探索の構造的な弱点は接戦帯に限局している**——ただしその大きさ（2% の融合）は、
  今の弱さ（守りで +0.141 の差を取り逃がす）を説明できる量ではない。

→ **手当ての向きは探索ではなく評価・価格の側**（`game_theory.md` 第 III 部・第 VI 部）。
これは「探索を直しても伸びない」ではなく「**探索は今のところ上限を作っていない**」という意味。
