# bb1 — 情報量スパイク第1ラウンド＋ドメインギャップの分離（2026-08-12）

B系 Phase 1（`docs/cpu_backbone_plan.md`・最重要ゲート）の第1ラウンド。
計器: `bb_gen`（コーパス生成）/ `bb_train`（ID無し訓練）/ `bb_eval`（実盤面評価）/
`bb_isolation_probe`（ギャップ分離・ユーザの確認質問 2026-08-12 が設計動機）。

## 1. 設定

- 訓練: バニラリーダー×合成カード400局 → 8,652行（card_idx 全PAD＝ID情報を構造的に遮断・
  G系 ValueNet 実装をそのまま使用）。小ネット（d_emb8/hidden96/12ep）・val MSE 0.79（域内 r≈0.45）。
- 評価の正解基準: レフェリー勝率ラベル（教師正本 sims48×6世界）。**gen14 一致は判定に
  使わない**（固有性監査 #2）。ホールドアウトは実対局リプレイの中盤60盤面。

## 2. 結果

| 評価盤面 | 骨組み（ID無） | G14 参考線 | 読み |
|---|---|---|---|
| **実デッキ×実リーダー**（60点） | r=0.202・符号48% | r=0.417・符号60% | 第1回は届かず |
| **実デッキ×バニラリーダー**（60点・分離テスト） | **r=0.510・符号73%** | — | **回復＝主因が確定** |

## 3. 結論（Phase 1 第1ラウンドの答え）

1. **合成カード→実カードの転移は成立する**。実デッキの盤面でも、リーダー効果さえ無ければ
   骨組みは域内以上（r=0.51）に読める＝ドメインランダム化の核仮説（ユーザ提案）は**支持**。
   実カード分布とのずれは主因ではない。
2. **落差（0.51→0.20）の主因はリーダー効果**。バニラ世界で学んだ骨組みは、実リーダー
   （再装填・回復等）が支配する中盤の力学を原理的に知らない——設計どおりの盲点が
   定量化された。
3. 投資判断: 第2ラウンドは**リーダー能力のランダム合成（Phase 3 第2段の前倒し）**が
   正しい投資。データ増や予算モデル改善は主因に当たらない。
4. G系 v51 の負の結果（`cpu_v51_negative_20260812.md`＝乖離族は現行特徴で表現不能）と
   合わせ、**G系の較正欠陥と B系の設計が「測定ベースの特徴言語」という同じ解へ合流**した。
   Phase 2 の導出量（リーサル距離・実効ドン収入/回復量）が両系統の次の鍵。
