# T106——**相手の手札のブロッカーを耐久に入れた**（T96 以来の宿題・ブロックに召喚酔いは無い）。**規則としては正しく打ち筋にも依らないが、量が無く、わずかに悪い**——**出せるブロッカーが手札に在る行は 3%／11% だけ**（平均 0.0038／0.0079＝`Θ` の 0.5%／1%）で、勝者の的中は 0.6541 → **0.6552**（実）／0.6449 → **0.6406**（合成）と**記録のセットで割れ**、**偏りは両方で開く**（+2.53 → +2.59／+2.56 → +2.62）。**既定は `off` 据え置き**。**ついでに「効果の型を広げる」（T105 §6 の 2）を量から否定した**——**相手に捨てさせる効果は 0 枚／7 枚・直接ライフは 1 枚／0 枚**、**パワー減少はそもそも除去ではない**（このエンジンに「パワー 0 で KO」の規則は無い）

2026-09-18 実施（ユーザ指示「引き続き自走／論理的に正しいか・打ち筋に依らないか」＝T105 §6 の 2・T103 §8 の 4）。
**当てはめない・新定数ゼロ**。本報告は特定時点のスナップショット。
器は `crossing_bridge.THETA_HAND_BLOCKER_MODE`・`hand_blocker_nu`。

## 1. まず「効果の型を広げる」を量で否定した（T105 §6 の 2）

T105 は**除去だけ**を数えたので、次は**手札を捨てさせる・直接ライフ・パワー減少**を足す計画だった。
**作る前にデッキを数えたら、そこに量が無かった**:

| 効果の型 | 実デッキ（異なり 58 枚） | 合成デッキ（異なり 875 枚） |
|---|---|---|
| **除去**（T105 で実装済み） | **9 枚（16%）** | **85 枚（10%）** |
| 起動メインの除去（盤面から毎ターン） | 2 枚 | 16 枚 |
| **相手に捨てさせる** | **0 枚** | **7 枚（0.8%）** |
| **直接ライフ** | **1 枚** | **0 枚** |

**パワー減少は除去ではない**——「パワーが 0 になったら KO」という規則は**このエンジンに無い**
（`rules/` を検索して確認）。減った体は**戦闘で倒しやすくなるだけ**で、それは攻撃の値付けが既に持っている。
**`profile` の `red` を除去として数える計画は規則の誤読だった**ので取り下げる。

**＝T105 の除去で、効果の項の大部分は既に入っている。** 残りを足しても 1 に届かせるだけの量が無い。

## 2. 問い（T96 以来の宿題）

**ブロックに召喚酔いは無い**（ユーザ指摘 2026-09-18）——`rules/battle.rs` の `has_blocker` は
`!is_rest && KW_BLOCKER && !BLOCKER_DISABLED` だけを見て、**登場ターンかどうかを見ない**。
＝**出したブロッカーは相手の次のターンからもう横取りできる**。
よって**手札のブロッカーは「避けて通れない体」の予備**で、`Θ` の体の項と同じ意味を持つ。
**それが今まで `Θ` のどこにも入っていなかった**（盤面の体でも切れる札でもない）＝**欠落**。

## 3. 式（新定数ゼロ）

```
Θ_body += max_{手札のブロッカーのうち 次の自分のターンのドン（今 + 2・上限 10）で払える札} ν_meas(パワー)
```

**1 体だけ数える**——1 体は 1 ターンに 1 回しか横取りできず、2 体目を出すドンは体にも使えるので**過小側に倒す**
（`removal_harm` と同じ規約）。**完全情報で読む**（§0.05）——守る席の手札はその席の行に在るので、
`g_for`（T76 以来）と同じ経路で引く。

## 6. 読み方

- **上手くいった: 規則の欠落を 1 つ塞ぎ、量を確かめた**。**ブロックに召喚酔いが無い**以上、
  手札のブロッカーは耐久であり、**入れないのは誤り**。入れた上で**量が無いと判った**のが収穫。
- **上手くいった: 作る前に量を数えて、無駄な実装を 1 つ止めた**（§1）。
  **T103 の速攻（デッキの 1.55%）と同じ失敗を繰り返さなかった**——
  **「規則として正しい」と「数字が動く」は別**で、**先に量を数えれば順番を間違えない**。
- **上手くいかなかった: 数字は割れ、偏りは両方で開く**。実の的中だけ +0.0011、合成は −0.0043。
  **`curve` は両方で下がる**（−0.0022／−0.0081）。
- **判定**: **既定は `off` 据え置き**。**切替として残す**（`--theta-hand-blocker on`）。
  **規則としての正しさで採るなら、`RATE_T1_MODE` と同じ扱い**——どちらも「正しいが数字は下がる」。
  **ユーザが「正しさを優先」と決めるなら 2 つまとめて入れる**のが筋。

## 7. 次（ユーザ判定）

1. **`SLOPE_EFFECT_MODE=on` を既定にするか**（T105・**唯一、数字が一方的に良くなった項**）。
2. **「正しいが数字は下がる」3 つ**（`RATE_T1_MODE`・`RATE_RUSH_MODE`・`THETA_HAND_BLOCKER_MODE`）を
   **まとめて入れるか**。**理論の正しさを優先するなら入れる**——量はどれも小さい。
3. **7 ターン目以降の `A` 過大**を生存者バイアスと切り分ける（残りターンで条件づけて測り直す）。
   **これが済むまで `A` の後半はいじらない**。
4. **接戦帯の必要な `κ`**（0.559／0.627）——`Θ` の形はここまでで手を尽くした感がある。
   **次は `ΔW` のもう一方（`σ`）か、帳簿の側**。
5. **出口 T18**（理論が純損と言う手を禁じて勝率が動くか）。

## 限界

- **1 体だけ数える**（2 体目以降は無視）＝**過小側**。
- **コストは「次の自分のターンのドン」で見る**——それ以降に出せるブロッカーは数えない＝**過小側**。
- **条件（登場時の制約・色・特徴）を見ていない**＝**過大側**。
- **守る席の手札は「直近の自席ターン終わり」の値**（`g_for` と同じ規約）＝**1 ターンぶん古い**。
- **効果の型の数え（§1）は「異なりカード」の枚数**で、デッキ内の重み（同名 4 枚など）を見ていない。
- **観察であって因果ではない**。
