## 結論を 4 行で

1. **既定は `const`（1.15）のまま**。`board`（盤面から出す `Θ`）は**接戦帯で悪化する**ので、
   「`Θ` は 8 倍動くのだから定数は誤り」という前日の読みは**そのままでは採用できない**。
2. **`saturation_x` に 2 つのバグが在った**——**`x = 0` を候補にしていない**・
   **曲線の端（5000）で頭打ち**。**旧テストがその両方を固定していた**（今週 3 本目のバグ番人）。
3. **`Θ` には 2 つの経路が在り、帯レベルで食い違う**（恒等式 vs シャドー価格）。
   **平均は一致するが形が違う**＝**未解決**。だから定数を替えず**選べる形**にした。
4. **`board` は「より正確だがより無口」**——決着率が 0.539 → 0.445 に落ちる。
   `Θ < 1` の窓では**全ての通る攻撃が同値**になるからで、これは理論の**正しい帰結**である。

## 1. なぜ「盤面の `Θ` に差し替える」を素直にやらなかったか

前日の `2026-09-14_theta_price.md` は「`Θ` はライフで 8 倍動く（0.31〜2.64）」を出し、
「定数 1.15 が誤りの源」と書いた。着手前に**もう 1 つの経路と突き合わせた**ところ、
**帯レベルで一致しない**ことが判った:

| 自ライフ ℓ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **恒等式** `λ(ℓ)/μ − 1 − τ_value` | 0.90 | **2.81** | **2.30** | 0.27 |
| **シャドー価格** `c(x)` の `G` 番目 | **1.48** | 0.85 | 0.40 | 0.31 |

**平均はどちらも 1.325**（`τ_value` をそう決めたので当然）だが、
**盤面側はライフで単調に下がり、恒等式側は単調でない**。
`λ(ℓ)` の CI は ±0.07〜0.10 と広いので**食い違いが本物かも決着しない**。

> **2 つの推定のどちらが正しいか証拠が無いまま定数を替えるのは、
> 今週 2 度踏んだ「自分の推論を測定より先に置く」形そのもの**である。
> だから**既定を替えず、選べるようにして順序の一致率に決めさせた**。

## 2. 途中で見つけた `saturation_x` の 2 つのバグ

```
x* = min{ x : c(x) ≥ Θ }
```

| バグ | 症状 | 効く場面 |
|---|---|---|
| **`x = 0` を候補にしていない** | `c(0) = 1.00` なのに `Θ ≤ 1` で **1000** を返す（正しくは **0**） | **盤面の `Θ` は 1 を割ることが多い**（ライフ 3〜4 で 0.31〜0.40） |
| **曲線の端（5000）で頭打ち** | `c(x)` は 5000 より上も +0.66/1000 で伸びるのに 5000 を返す | `Θ > 3.63` の窓（リーサル圏） |

**既定 `Θ = 1.15` では両方とも露見しない**（`x* = 2000` のまま）＝
**定数で運用している限り見えないバグ**だった。

> **旧テストが両方を固定していた**（`saturation_x(0.8) == 1000` と `saturation_x(10.0) == 5000`）。
> **今週 3 本目の「バグを守るテスト」**（1 本目は `don_idle == 6 − 1 − 4`・
> 2 本目は `entry_gain` の要る額 0.0290）。書き直して、
> **定義そのもの**（返した `x` で足り、1000 手前では足りない）もラチェットした。

## 3. A/B の結果

### 3.1 順序の一致率（`theory_order.py`・全帯・10,946 行）

| mode | 決着したペアの精度 | **決着率** | **tie を 0.5 で採点** |
|---|---|---|---|
| `const` | 0.5253 | **0.5394** | 0.5136 |
| **`board`** | **0.5390** | **0.4450** | **0.5174** |

**素の精度だけ見ると `board` が +0.0137 勝つが、決着率が 9 ポイント落ちる**。
**これは「母数を結論で条件付ける」罠**（`measurement.md` §14-8）なので、
**tie を 0.5 で採点した列で読む**——差は **+0.0038** に縮む。
局ごとの平均の CI も重なる（`const` [0.5756, 0.5993] 対 `board` [0.5762, 0.6007]）。

**なぜ無口になるか**: `Θ < 1` の窓では `min(c(x), Θ) = Θ` が全ての通る攻撃で成り立つ＝
**どの攻撃も同値**。これは**理論の正しい帰結**（相手はどうせ受けるので超過パワーは無意味）
であって、器の欠陥ではない。**ただし方策の教師としては弱くなる**。

### 3.2 探索との突き合わせ（`theory_vs_search.py`・帯別）

| 帯 | `q_recovered` const → board | `th_recovered` const → board |
|---|---|---|
| **close**（接戦） | **0.3111 → 0.2708**（悪化） | **−0.0272 → −0.0549**（悪化） |
| mid | 0.3071 → 0.3135 | −0.0549 → −0.0463 |

**いちばん大事な接戦帯で `board` は両方とも悪化する**。
決着帯の `q_recovered` は上がるが、**決着帯は判断が易しい帯**である。

## 4. 判定

| 問い | 答え |
|---|---|
| `Θ` を盤面から出せるか | **出せる**（実装済み・`--theta-mode board`） |
| 既定を替えるべきか | **いいえ**——接戦帯で悪化し、公平に採点した差は +0.004 で CI が重なる |
| 「`Θ` は定数ではない」は誤りか | **誤りではない**（盤面の `Θ` は実際に 8 倍動く）。 **定数を替える根拠にならないだけ** |
| 何が分かったか | **2 つの経路が帯レベルで食い違う**＝どちらが `Θ` の正しい姿かは**未解決の理論問題** |

> **`board` が接戦帯で悪化する理由の候補**（本報告では分けられない）:
> (a) シャドー価格の経路が誤り、(b) `N`・`B` の見積もりが粗い（相手の追加の登場を数えていない）、
> (c) `Θ < 1` の窓で無口になる分、残ったペアの構成が偏る。

## 限界

- **A/B は 1 コーパス（300 局・r3・`synth`）**。
- **`th_recovered` は元々 0 付近**なので、その差（−0.027 対 −0.055）は小さな量の比較である。
- **tie を 0.5 で採点する**のは 1 つの採点規則にすぎない（他の重みなら順位が変わりうる）。
- `board` の `N` は「相手のリーダー＋相手のキャラ数」で、**相手が次のターンに出すキャラを数えていない**
  ＝`G` も `Θ` も過小側。ここを直すと結果が変わる可能性が残る。
- `x*` の平均は `saturation_x` の修正で **1406 → 1396** に動いた（分布の形と中央値 0 は不変）。

## 次

1. **`board` の `N` を良くする**（相手が次のターンに出せるキャラを手札とドンから見積もる）＝
   上の限界 (b) を潰してから A/B をやり直す。**これが最も安い次の一手**。
2. **2 つの経路の食い違い**は `λ(ℓ)` の CI が縮めば決まる＝**局数を増やす**（今は 300 局）。
3. **反事実（T18）は引き続き保留**——`Θ` の正しい姿が決まっていないので、
   「理論が純損と言う手」の集合がまだ安定しない。
