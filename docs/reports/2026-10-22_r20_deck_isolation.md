# 教材のデッキの切り分け——r20（実デッキで訓練）と r20s（合成デッキで訓練）（2026-10-22）

ユーザ決定（2026-10-22「一旦教材のデッキの切り分けとして教師の作成も訓練もやってしまいましょう」）。§7.34。
違いは教材のデッキだけ: 生成役 r13d・同じ設定・各 2 波（r20＝波 50＋49〔実デッキ 115 本〕・r20s＝波 50s＋48〔合成デッキ v2〕）・warm-start r11a・同じ更新量・どちらも best ep1。

## 読み

1. **実デッキで学ばせても、実デッキで強くならない**（r20 は real で −1.7・r20s と差なし）。一方、**実デッキで学ばせると合成デッキで大きく弱くなる**（−39）。教材のデッキは「狭くすると外で崩れる」方向にだけ効いた。
2. 評価帯の価値の誤差は、教材のデッキの帯で大きく良くなった（r20 は実の帯で 0.637 → 0.541）が、**対戦の強さには写らなかった**。価値の誤差の改善が強さに写らないのは r19（本番の深さで +3.6）と同じ形。
3. r19（波 49 だけの π・ep0）の 160 回 +12.4 は、r20（波 50＋49 の π・ep1）では −1.7 に消えた。教材を倍にしても伸びない。r19 の +12.4 は本番の深さでも消えていた（§7.33）ので、r19 の差そのものが小さい・揺らぎの内だった可能性が高い。
4. 合成デッキで学ばせた r20s は、ミラーで +13.3（下限 0.5073）と僅かに強い以外、r13d とほぼ同じ。
5. r17・r18・r19・r20・r20s の 5 世代続けて、主条件の強さが r13d から動いていない。教材のデッキ・量・分布を変えても動かない＝**ボトルネックは教材の側ではない可能性が高い**。
