# T43——登場の機会費用を状態で決めた: **`ΔG` が実デッキでも成立した（+6.4・AUC 0.64）**

2026-09-16 実施（目的の一致後の順序の残り 1＝登場の機会費用）。ユーザ決定「これは直しましょうか」。
**新しい定数はゼロ**——付与 1 枚の価値は攻撃の価格 `attack_value` の増分（理論の既存の規則）で、
掛ける枚数を判断点の状態（アクティブドン・攻撃できる体）で決めるだけ。本報告は特定時点のスナップショット。

## 結論を 6 行で

1. **直したもの**: 登場・イベントの価格から引く `コスト × 0.66μ`（無条件の定額）を、**機会費用**
   `V(アクティブドン) − V(アクティブドン − コスト)`（`V(n)`＝n 枚を攻撃手に貪欲に配ったときの攻撃の価値の増分の和）に。
   攻撃手が居ない・ドンが余る・飽和していれば 0。`PLAY_COST_MODE` で `flat` に戻せる（感度の切替）。
2. **機会費用は実測でほぼ 0**——1 回の登場あたり平均 **0.0026**（定額は 0.12）。理由は理論の側に在る:
   リーダーへの攻撃は `Θ·μ` で頭打ち＝**x ≥ 1000 で付与 1 枚の増分が 0 になる**ので、ドンに他の使い道が無い。
3. **登場の価格が正に戻った**——実デッキ −0.016 → **+0.101**（実現 0.055・比 0.55）・中央値 −0.021 → **+0.086**。
   合成 −0.034 → +0.097（実現 0.060）。**残る 1.8 倍は `ν` の水準**（T39・次の順序）。
4. **`ΔG` が実デッキで成立した**——**−6.5・AUC 0.39 → +6.4 [3.5, 9.5]・AUC 0.635・`bridge_holds`**。五分位の実勝率
   **40 → 40 → 55 → 60 → 72%**（単調）。攻め半分 +0.23 [0.11, 0.33]。**合成も成立**（+5.6・AUC 0.61・単調）。
   **＝同じ器・同じ式で 2 つの記録が同じ向き**（目的の一致の判定基準の後半）。
5. **T26（体を出す価値）**: 「出すのは得」の行が実デッキ 41% → **88%**・合成 41% → 79%・`μ_develop` 0.057 → 0.165。
   **行き過ぎの側**（`ν` の水準 1.8 倍がそのまま出る）＝次の順序で戻る見込み。
6. **`ΔS`（逸脱）は両記録で `no_link`**（実 −0.27・合成 +0.66 [−0.2, 1.6]）——**T42 で判った「逸脱の信号は価格の
   欠陥が運んでいた」が合成でも起きた**（定額の費用で最善が歪んでいた）。`ΔS` は主の判定ではないので結論は動かない。

## 1. 直した中身

```
登場の価格 = ν ＋ 登場時効果 − μ − 機会費用(状態)
機会費用   = V(D) − V(D − コスト)        D＝アクティブドン
V(n)       = ドン n 枚を攻撃手（リーダー＋今攻撃できる体）に貪欲に配ったときの
             Σ [attack_value(x + 1000·(k+1)) − attack_value(x + 1000·k)]   （リーダー狙い・Θ·μ で頭打ち）
```

- **攻撃手**＝枠 0（リーダー）＋自場で `is_char` かつ `can_attack_now`（トークン列 5）。
- 盤面を渡す呼び出し（橋・`price_realised`・`mu_branch`・`theory_order`・`theory_vs_search`）は全部 `attackers`・
  `don_active` を `ctx` に入れる。渡さなければ従来の定額（`flat`）。
- **機会費用が小さい理由は理論の攻撃の価格そのもの**——`c(x)` は x ≤ 1000 で 1 枚・x ≤ 2000 で 1.28 枚、
  `Θ = 1.15` なので**x ≥ 1000 の攻撃は既に頭打ち**（相手は受ける）＝付与しても増分 0。
  リーダーより 1000 低い体に 1 枚付けて通るようにする増分（`c(0)·μ = 0.055`）が最大の使い道。

## 限界

- **機会費用 ≈ 0 は理論の攻撃の価格（`Θ·μ` の頭打ち）の帰結**——付与の価値が本当にそこまで小さいかは
  T1 の「付与率が実測の 47%」と併せて疑いが残る。ただし T41 で攻撃の価格 対 実現は 0.91 なので、
  攻撃の側の水準は合っている。
- `ΔS` は両記録で `no_link` になった——逸脱の器は最善の価格に敏感で、いまの最善（登場が高い）が
  正しい保証は無い。判定は `ΔG` で行う（§0.1）。
- **観察であって因果ではない**。
