# 選んだ手の変化量 `ΔG` を累積した——**実デッキで反転し、逸脱 `ΔS` は保たれた**

2026-09-15 実施（T40）。ユーザの目的の確認「棋譜の選択による変化量を累積して、その棋譜の勝敗と
相関があるかをみたい」に対し、**橋（`theory_bridge.py`）に「選んだ手の理論値そのもの」の累積 `ΔG` を
足して**、従来の「最善からの逸脱」の累積 `ΔS` と並べた。本報告は特定時点のスナップショット。

## 結論を 6 行で

1. **`ΔG`（選んだ手の理論値の累積）は実デッキで強く反転する**——1 手あたりの傾き **−10.2** [−12.6, −7.7]・
   AUC **0.258**。五分位の実勝率は **87% → 67% → 50% → 32% → 32%**（`ΔG` が高いほど負ける）。
2. **合成デッキでは逆に成り立つ**——傾き **+9.1** [7.2, 10.6]・AUC 0.667・五分位 **32% → 71%** で単調。
   **同じ器・同じ式で記録を替えると符号が反転する**＝**`ΔG` は選択の質ではなく状態（とデッキ）を拾っている**。
3. **`ΔS`（逸脱）は両方で保たれる**（実 +4.36・AUC 0.703／合成 +1.24・AUC 0.555）——
   **同じ行の最善を引くことで水準（状態）が消える**から。
4. **反転の主役は効果の型**——実デッキで手の型ごとに割ると **攻撃 AUC 0.869（強く正）**・付与 0.753・
   登場 0.412・**効果 0.161（強く負）**。効果は手数の 7.4% だが局あたりの差の大きさは最大。
   合成では効果 0.514（中立）。**符号が反転するのは効果と登場だけ**。
5. **理屈は追える**——効果の値は T34 で「取れる対象の `ν`」になった＝**相手の場が強いほど高い**＝
   **負けている側ほど高い値の効果を打つ**。攻撃の値は `min(c(x)·μ, Θ·μ)` で頭打ちなので状態を拾いにくい。
6. **帰結**: 目的の「累積して勝敗と相関を見る」は**行の中で相対化した量（`ΔS`）で測る**のが正しく、
   **生の変化量の累積は勝敗の説明に使えない**（罠 27 として `measurement.md` に積む）。
   学習の教師に要るのは**行の中の順序**なので、`ΔS` の側が目的に直結している。

## 1. 器——2 つの累積を同じ実行で並べる

```
攻め側（自席ターン）:  s_t = v(打った手) − v(同じ行の最善) ≤ 0      g_t = v(打った手)
守り側（相手ターン）:  s_t = −max(0, 払った費用 − 最善の費用)        g_t = −(実際に払った費用)
                       払えなかった行は s = 0（誤りでない）          g は損をそのまま持つ（責任を問わない）
席の累積:  S = Σ s_t   G = Σ g_t     1 手あたり版は自分の手数で割る
差:        ΔS = S_自席 − S_相手席     ΔG = G_自席 − G_相手席
```

`v` は §14.1 の値付け（攻撃・登場＋登場時効果・効果 62 種・…）。**新しい定数はゼロ**。
**較正表**を足した——`ΔG_per_row`／`ΔS_per_row` を五分位に切って各分位の実勝率を並べる
（**回帰で係数は決めない**）。**手の型ごとの内訳**（攻撃／付与／登場／効果／終了）も出す。

## 2. 実測——`ΔG` は記録で符号が変わり、`ΔS` は変わらない

`pair`・`--silent exclude`。

| 量 | 実デッキ 300 局 | 合成 900 局 |
|---|---|---|
| **`ΔS_per_row`**（逸脱） | **+4.36** [3.52, 5.26]・AUC **0.703**・`bridge_holds` | +1.24 [0.34, 2.24]・AUC 0.555・`bridge_holds` |
| **`ΔG_per_row`**（変化量） | **−10.2** [−12.6, −7.7]・AUC **0.258**・`bridge_inverted` | **+9.1** [7.2, 10.6]・AUC 0.667・`bridge_holds` |
| 　攻め半分 `ΔG_atk` | −0.28・AUC 0.279 | +0.38・AUC 0.714 |
| 　守り半分 `ΔG_grd` | −0.89・AUC 0.250 | −0.64・AUC 0.362 |
| 五分位の実勝率（`ΔG`） | **87 / 67 / 50 / 32 / 32 %**（単調に下がる） | **32 / 43 / 50 / 60 / 71 %**（単調に上がる） |
| 五分位の実勝率（`ΔS`） | 23 / 52 / 62 / 45 / 85 %（非単調・幅 0.62） | 48 / 44 / 51 / 53 / 59 %（幅 0.11） |

`base` でも同じ（実 `ΔG` −9.8・合成 +9.4）＝**`ν` の形の話ではない**。

### 手の型ごとの内訳（`ΔG_atk` を型で割る・1 手あたり）

| 型 | 手数の割合（実） | **実デッキ AUC** | 合成 AUC | 局あたりの差の大きさ（実） |
|---|---|---|---|---|
| **攻撃** | 42.0% | **0.869** | 0.750 | 0.0095 |
| 付与 | 20.4% | 0.753 | 0.635 | 0.0004（無視できる） |
| 登場 | 22.0% | **0.412** | 0.568 | 0.0089 |
| **効果** | 7.4% | **0.161** | 0.514 | **0.0131（最大）** |
| 終了 | 8.1% | （値 0） | （値 0） | — |

**攻撃の型だけなら `ΔG` は両記録で強く勝敗を説明する**（0.87／0.75）。**合計が反転するのは効果の型が
逆向きで一番大きい**から。**回数だけでも同じ向き**——実デッキで「効果を打った割合の差」の AUC は 0.172・
「登場の割合の差」0.229・「攻撃の割合の差」**0.843**＝**負けている席が効果と登場を多く打ち、勝っている席が
攻撃を多く打つ**（状態の帰結であって選択の質ではない）。

## 3. 読み方——なぜ `ΔG` は状態を拾い、`ΔS` は拾わないか

- **`v(打った手)` の水準は「その行で何が取れるか」で決まる**——効果の値は取れる対象の `ν`（T34）で、
  **相手の体が強いほど高い**。登場の値は `ν − μ − 費用δ` で、体を出せる余裕が在るほど高い。
  **どちらも「今どういう状態か」を反映する**ので、累積すると状態の代理になる。
  実デッキ（除去・サーチが多い）でそれが表に出、合成（効果が薄い）では出なかった。
- **`ΔS` は同じ行の最善を引く**ので、その行で何が取れたかは消え、**「取れたものをどれだけ取ったか」だけ**が残る。
  だから記録を替えても符号が変わらない。
- **攻撃の型が両記録で正なのは、攻撃の値が頭打ち（`Θ·μ`）で状態を拾いにくく、かつ攻撃がライフに直結する**から。
  **これは理論の本体（攻撃の価格）が勝敗と結びついている証拠**として読める。

## 4. 目的への含意

「変化量が勝ちに向けて一番大きくなる手を探索が選べるように学ばせる」に要るのは、**行の中でどの手が
一番良いか**（順序）である。**生の変化量の累積は、その順序が正しくても状態に引きずられて反転しうる**
（本報告）。**よって**:

1. **勝敗との相関の検証は `ΔS`（相対化した累積）で行う**——既に `bridge_holds`（攻め側）。
2. **`ΔG` は「攻撃の型」に限れば勝敗の説明に使える**（AUC 0.87）——攻撃の価格の独立の検算として残す。
3. **効果・登場の値の水準は状態に依存する**ので、教師にするなら**行の中の相対値**として渡す
   （絶対値で渡すと「負けている側の手ほど高い」を学ぶ）。
4. **因果は T18**（理論の手を打たせて勝率が動くか）——本報告も観察であり、これは変わらない。

## 限界

- **実デッキ 300 局は対面がほぼ全て異なる**ので、同じ対面の中で `ΔG` を見る（デッキの交絡の除去）が
  できなかった（合成は 11 対面 22 局しか揃わず検出力が無い）。
- **帯の中の型別**は出していない（帯の集計は型を持たない）。接戦帯の `ΔG` も反転している
  （−4.4 [−5.8, −3.0]・守り半分が主）ので、帯で切っても消えない見込み。
- **守り半分の `ΔG` の負**は「守った（費用が高い）席が勝つ」＝手札が在る＝状態、の読みで
  攻め側と同じ形。**守り側の `ΔS` の反転（−0.82・7 段不動）は別の問題**（P8）で、本報告では触れていない。
- **観察であって因果ではない**。
