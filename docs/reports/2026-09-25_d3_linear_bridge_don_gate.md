# D-3: ドン!!コストの支払い判定（D-2）で線形の橋は動くか（2026-09-25）

D-2で足した`DON_COST_GATE_MODE=check`を、線形の橋（`theory_bridge.py`・`ΔG`＝数える価格の累積／
`ΔS`＝決める価格での最善からのずれの累積）に通して、実300局・合成900局（w41／w39+w42）で`off`と並べた。
読み取りだけ・新定数ゼロ・既定は変えていない。

## 結果

## 読み

1. **`ΔG`（線形の橋の本体）は両記録ともビット単位で不変。** 今の既定の帳簿は攻めの行を
   「実際に相手が失った額」で数える（`LEDGER_HARM_MODE=realised`・T87）ので、登場の値段は
   `ΔG`に入らない。D-2の直しは**構造上`ΔG`に届かない**——D-3が問う「線形の橋の傾き・符号の
   両記録一致」はこの直しでは動かない。`ΔG`の傾き・符号は直す前から実0.363／合成0.365で
   揃っている。
2. **効くのは`ΔS`（決める価格・最善からのずれ）だけで、実でだけ改善**: AUC 0.601→0.622・
   傾き 0.123→0.149・3帯すべてで上がる。払えないイベントを「候補の中の最善」に数えなくなった分、
   打った手の劣り具合の読みが勝敗と強く結びつく。合成は小数4桁目までしか動かない
   （OP15-074〜078を使うデッキが合成にほぼ無いため・D-2と同じ理由）。
3. **`ΔS`の両記録の食い違い（実0.62・合成0.47）はこの直しとは別の問題**——直す前から
   存在し（0.601対0.468）、直しの幅（+0.02）より一桁大きい。

## D-4への申し送り

* 採否の材料は「規則どおりの形か」と「`ΔS`（実）が上がり・どこも悪くならない」の2点。
  `ΔG`・合成・攻撃／付与／効果の型の値段は不変なので、既定に入れて失うものは見つかっていない。
* D系の当初の問い（#43「値段の型を直して`ΔG`の傾き→1・両記録で符号一致」）は、今の帳簿
  （実現額で数える）の下ではplay族の値段を直しても`ΔG`に届かないので、この道では閉じない。
