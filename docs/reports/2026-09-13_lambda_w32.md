# ライフ 1 枚は札 2.5 枚——予算モデルは自己整合、**ただし私の予測の当て方が誤っていた**

2026-09-13 実測・判定（`claude/lambda-w32` 39cdf948・コード差分なし）。
`docs/game_theory.md` §11.1 で定式化した `c̄ = λ/μ − 1 − τ_value` の**反証可能な予測の検査**。
計器は `tests/scripts/hand_value_slope.py --axis life`（同じ行で `--axis hand` を対照）。
波 32 の holdout **1,041 局**・ネットは出荷既定 r3・`--holdout-mod 7`。
本報告は特定時点のスナップショット（追記・改変しない）。

## 結果

単位は**勝率/枚**（`in_pwin`＝V の tanh 出力は半分にして揃えた）。

| 量 | 自席ターン | 相手ターン |
|---|---|---|
| **`λ` ライフ 1 枚（実測）** | **+0.1158** ±0.0042 | **+0.1362** ±0.0045 |
| `λ` V の観測の傾き | +0.1165 | +0.1321 |
| `λ` モデルの応答（`dv_count`） | +0.1189 | +0.1351 |
| **`μ` 手札 1 枚（実測）** | **+0.0433** ±0.0025 | **+0.0551** ±0.0026 |
| `μ` V の観測の傾き | +0.0453 | +0.0483 |

`sign_agrees.all = True`（両軸・両席）。`μ` は別の計測（`2026-09-13_readout_w32.md` §2）の
**+0.0433／+0.0551 と小数第 4 位まで一致**＝同じ holdout を独立に 2 回読んで同じ値が出た。

## 1. 予測の判定——**レンジには入った。しかし私の `c̄` の当て方が誤っていた**

事前登録は「`λ/μ` が 2.5〜4.5 なら自己整合」で、**自席 2.67 は範囲内・相手ターン 2.47 はわずかに下**。
しかし本来の検査は恒等式の方である:

```
c̄ + τ_value = λ/μ − 1 = 1.674（自席） / 1.473（相手ターン）
```

`τ_value ≥ 0` だから **`c̄ ≤ 1.67`**。ところが §11.1 では「`c̄(3000) ≈ 2.2`」を当てて
`λ/μ ≈ 3.4` を予測した。**この当て方だと `τ_value = −0.5` になり成立しない**。

**誤りは `c̄` を 1 つの x 帯に当てたこと**。`c̄` は「これから守る G 本の**平均**単価」で、
実際に飛んでくる x の分布で決まる。実測の分布は **`x≤0` が 38.5%・`x≥3k` は 24.5%**
（`2026-09-13_readout_w32.md` §6）＝**低い帯に偏っている**ので、平均の `c̄` は
曲線（1.00 / 1.31 / 2.22 / 2.64 / 3.85）の**下の方 ≈ 1.0〜1.3** になる。すると

```
τ_value = (λ/μ − 1) − c̄ ≈ 1.67 − (1.0〜1.3) = 0.37〜0.67 枚ぶん     （自席）
```

＝**トリガーの期待値は「札 0.4〜0.7 枚ぶん」**。密度 0.17（`deck_profile`）と比べて
「1 枚引くと 0.17 回トリガーが出て、その 1 回が札 2〜4 枚ぶんの働きをする」と読める大きさで、
**無理のない値**。よって**モデルは自己整合**と判定する。**失効したのは予測の当て方だけ**で、
`§11.1` の恒等式そのものは生き残る（当て方は本報告で訂正する）。

## 2. ここから出る**打ち回しの数字**（新しい）

`c̄ + τ_value ≈ 1.5` は「**無差別点が札 1.5 枚あたり**」を意味する。実測の `c̄` 曲線に当てると

| x | `c̄(x)` | 最適 |
|---|---|---|
| ≤2000 | 1.00〜1.31 | **守る**（単価が無差別点より安い） |
| 3000 | 2.22 | **受ける**（無差別点より高い） |
| 4000+ | 2.64〜3.85 | **受ける** |

＝**「2000 までは守り、3000 からは受ける」が平均的な最適**。実プレイは
**`c(x) < c̄` を 47.9% 受けている**（`2026-09-13_readout_w32.md` §4）＝**安い側で間違えている**。

## 3. ネットの内部の交換レートは**高すぎる**（新しい欠陥・小さいが系統的）

ネットの応答は `λ/μ = 3.60`（自席）／**4.69**（相手ターン）で、実測の 2.67／2.47 より
**35〜90% 高い**。原因は片側だけ:

- **`λ` は合っている**（応答 0.119 対 実測 0.116）。
- **`μ` が低い**（応答 0.033 対 実測 0.043＝**24% 過小**・相手ターンは 0.029 対 0.055＝**48% 過小**）。

＝**ネットは「ライフを失うこと」を正しく恐れ、「札を使うこと」を軽く見ている**。
これは `2026-09-13_readout_w32.md` §2 の「1 枚の価値を 25〜35% 過小に見ている」の内訳で、
**交換レートに直すと歪みが 1.4〜1.9 倍に拡大する**（比の分母が小さいので）。

**向きが重要**: この歪みは**守りすぎを生む**方向（ライフが高く札が安い＝守った方が得に見える）。
ところが実プレイは**守らなすぎ**（安い攻撃を 47.9% 受ける・`θ` は平ら）。
**価値の歪みと行動の誤りが逆を向いている**＝行動の誤りは価値から来ていない。
本日の結論（**壊れているのは方策の順序**）と整合し、それを別の角度から支持する。

## 4. 平均は 1 つの定数として使えない（§13 の再確認）

帯ごとの `λ` は **0.05〜0.18** と 3〜4 倍動く（`top_bands`・n≥30 の帯）。
相手ターンの `λ`（0.136）は自席（0.116）より **18% 高い**——受けるかを決めるのは相手ターンなので、
**判断に使うべきは高い方**。`λ/μ` を 1 つの定数として固定しきい値に使うのは、
§13（`θ` は状態の関数）の主張どおり**誤り**。

## 限界

- **`λ` の実測は逆因果に最も弱い量**。「ライフが低い＝既に負けている」という経路が在り、
  帯（手札・相手ライフ・ターン帯・自場）で固定しても**ライフがどう減ったかは制御していない**
  ＝`λ` は**過大評価側**の可能性がある。過大なら無差別点はさらに下がり、
  「2000 までは守る」の境目が 1000 台に寄る（結論の向きは変わらない）。
- モデルの応答（`dv_count`）は**scalars の 1 列を動かした反事実**で、手札の質（`counter_value`）や
  EXTRA の集約は据え置き＝`μ` 側は**過小評価の下限**（v6 の注釈と同じ制約）。
  したがって「ネットが `μ` を 24% 過小に見ている」は**上限としての主張**。
- 1 ネット（r3）・1 波（32）のみ。`τ_value` は**差から逆算した量**で直接測っていない
  （直接測るには「トリガーが出た／出なかった」の反事実が要る＝残る宿題）。
