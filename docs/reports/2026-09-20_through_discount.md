## 1. 入れた形（新定数ゼロ）

```
盤面の項 ← 盤面の項 × (通った本数 / 本数)
通った本数 = 本数 − 止めた本数 〔− ブロッカー〕
```

**無次元の比**なので**単位は変わらない**（P5 を壊さない）。
`止めた本数` は `hand_plan.attacks_stopped`＝**カウンター値が足りる組のうち出す価値の和が最小のものを、
受けるより安いときだけ切る**（ユーザ指摘の 2 要素の天秤・T130）。**打ち筋は入らない**
（記録の「実際に切ったか」ではなく**規則と相手の手札の中身**から解く）。

**モードを 2 つに分けた理由**: **`cut` はブロッカーを引かない**——
既定ではブロッカーは**耐久 `Θ` の体の項に在る**（`THETA_BODY_MODE=blockers`）ので、
**ここでも引くと同じ規則を 2 か所で数える**。`cut_block` は `--theta-body none` と**対でだけ**使う。

**渡し忘れで黙って 1.0 にならないようにした**——守る席の手札は**攻める席の行からは読めない**ので
`collect` が計算して渡すしかない。**`off` 以外で渡されなければ例外で落とす**
（**今日 2 度踏んだ事故**＝T128 の減衰・T129 のブロッカーの再発防止）。

## 2. 作る途中で見つけた単位の誤り

`counters_cut` は `n += len(idx)`＝**切った札の枚数**を返す。**止めた攻撃の本数ではない**。

```
カウンター 1000 が 2 枚・超過 1000 の攻撃 1 本 → 切った枚数 2・止めた本数 1
```

**本数から枚数を引いていた**ので、**平均の割引率が 0.36**（`A` が 1/3）まで落ちていた。
`attacks_stopped`（同じ規則・違う単位）を足して直し、**テストで 2 つの単位を固定した**。
**訂正後の平均の割引率は 0.407**（それでもまだ重い＝§3 の悪化の大きさと整合）。

**T130 の `d_through`（+0.256／+0.095）は枚数を引いた値**だった。§0-4 が訂正後の値。

## 4. なぜ効かないのか／何が残ったのか

**効かない理由は確定した**——**守りの判断は既に攻撃の価格の中に在る**:

```python
attack_value(...) = min(c(x)·μ,      # 守られたとき＝切られる札の費用
                        Θ·μ,          # 受けられたとき
                        ブロック)      # 横取りされたとき
```

**「相手は一番安い応答を選ぶ」**（`game_theory.md` §14.1）。
**割引はこれを 2 回目に適用している。**

**残った問い**: では**なぜ通った本数が `A` の外れと +0.282／+0.110 で動くのか**。

**最初の見立ては棄却した**（測る前に・既存の恒等式で）:

> 「受ける側の価格 `Θ·μ = 0.0872` がライフ 1 点の価値 `λ = 0.1362` より安い（1.56 倍）のでは」
> → **誤り**。**取られたライフは手札に入る**ので、正味は `λ − μ = 0.0811` で **`Θ·μ` と 7% しか違わない**
> （T11／T20 の恒等式 `Θ = λ/μ − 1 − τ` がそれを言っている）。**受ける側の価格は正しい。**

**機構は未特定**。**仮説を置かずに閉じる**——今日 3 度「もっともらしい機構を思いついて外した」ので、
**次は機構を当てにいかず、まず `min` の外側を測る**（1 ターンに複数本あるとき、
`min` は**本ごとに**取られるが、守り手の予算は**ターンで共有**される〔T86／T100〕＝
**本ごとの `min` の和は、ターン全体の最適応答より安くなりうる**）。**これは測れる**。

## 6. ユーザ判断をお願いしたいこと

1. **`RATE_THROUGH_MODE` は `off` のまま**（推薦）——**両記録・4 指標すべてで悪化**し、
   **理由もコードから確定している**（二重計上）。**切替は残す**（`cut_block` は `--theta-body none` と対で使える）。
