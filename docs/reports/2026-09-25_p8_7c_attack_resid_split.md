# P8-7(c): T123 の攻撃の行の残差 37.8%／38.9% を `aux_def` で割る——支持されなかった（2026-09-25）

T123（`2026-09-20_transition_ledger.md`）は、`transition_ledger.py` が値段の付いていない遷移の残差を
5 軸へシャープレイ値で配ったあと、**同じターンの中の残差**をさらに手の型で 3 等分し、そのうち攻撃の型の
直後に起きる分（実 37.8%／合成 38.9%）を「**相手の窓の答え**（ブロック・カウンター——攻撃の価格には
入っていない）と**価格そのものの誤り**が混ざる・P8 が開くまでこれが最良の分離」と注記していた。
`aux_def`（P8・dump v5）で守り手の実際の応答が読めるようになったので、この混合を割ってみた。

## 器

`tests/scripts/attack_resid_defender_split.py`（新規・読み取り専用）。`transition_ledger.collect(dirs,
dump=dump)` に `dump` を渡す 1 行の追記（既定の集計には触らない・診断用）で、攻撃の型の同じターン内
残差を **局×席×ターン**（攻め手の手番）ごとに束ね、`t139_defender_check.defender_actuals_by_turn` の
守り手の実際の応答（`blocks`・`counters_used`）と結びつける。

**器の設計を 1 度直した**——最初の素朴な設計（ターンの残差の和を応答の有無で 2 分）は、**応答した窓は
攻撃の遷移そのものが多いだけ**という交絡を含んでいた（実測: 応答した窓は平均 2.59 本／応答が無い窓は
1.92 本の攻撃遷移＝35% の差）。**遷移 1 本あたりに割った後の量**（`resid_per_transition`）を主指標に
直してから測った。

## 実測（実局 300 局・合成局 900 局・dump v5・同じ 2 本の記録を P8-7(a)(b) と共有）

| | 実（3,054 ターン） | 合成（8,813 ターン） |
|---|---|---|
| 攻撃の行の残差の割合（`transition_ledger` の `attack_rows`） | 0.3787 | 0.3838 |
| 応答した窓／応答が無い窓 | 2,047／1,007 | 5,862／2,951 |
| 攻撃の遷移の本数（平均・応答あり／なし） | 2.59／1.92 | 2.26／1.71 |
| 素朴なターンの残差の和（平均・応答あり／なし） | 0.182／0.132 | 0.142／0.112 |
| **遷移 1 本あたりの残差（平均・応答あり／なし）** | **0.0680／0.0696** | **0.0595／0.0640** |
| 応答の大きさ（カウンター＋ブロックの回数）と遷移あたり残差の相関 | 0.087 | 0.185 |

## 読み

**素朴な比較（ターンの和）は「応答した窓の残差が大きい」ように見えるが、それは交絡だった**——応答した
窓は単に攻撃の遷移が多い（それだけ和も大きくなる）。**遷移 1 本あたりに割ると、応答の有無で残差はほぼ
同じ**（実 0.0680 対 0.0696・合成 0.0595 対 0.0640）——**むしろ応答が無い窓の方がわずかに残差が大きい**。
応答の大きさ（カウンター＋ブロックの枚数）と遷移あたり残差の相関も弱い（実 0.087・合成 0.185）。

**「相手の窓の答え」が攻撃の行の残差を説明するという仮説は支持されなかった**。守り手が実際にブロック・
カウンターで応答したかどうかは、攻撃 1 回あたりの値段の当てはまりの悪さにほとんど影響していない。
攻撃の行の残差 37.8%／38.9% は、T123 が候補として挙げた 2 つの機構のうち、**少なくとも「ブロック・
カウンターという形の窓の答え」では説明できない**——出す・効果の行と同じ性質の**価格そのものの誤り**が
主因である可能性が高い（確定はしていない・他の応答の形——ライフの保護やパワーの一時的な上昇など、
P8-7(b) が合成の残る 3 行で示唆した未特定の防御手段——は本器の `blocks`／`counters_used` には出ない）。

## 結論

**T123 の「P8 が開くまでこれが最良の分離」という注記を、`aux_def` で検算した結果は否定的**——攻撃の行の
残差を「相手の応答」で説明する経路は、少なくともブロック・カウンターの形では支持されない。**残差の主因を
価格の誤りに絞ってよい**（バックログ #43 の対象を広げる方向の情報だが、#43 自体の着手可否はユーザ判断の
まま・新定数ゼロ・式は変えていない）。
