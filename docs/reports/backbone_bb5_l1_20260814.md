- 監査で懸念した「UNK 盲目の先生」は、**実害としては小さかった**。G14 は埋め込みが
  UNK でも scalars（物理特徴）＋探索で十分に打てており、教材の質は L1 と同等以上
  だった（bb4b24 中間帯で bb3 が bb5 を上回るのは、G14 側の探索の方が L1 の αβ より
  この世界で強い可能性すらある）。
- これで監査由来の3処方のうち **ラベル品質（bb4）・先生の質（bb5）の2つが実測で棄却**され、
  残るは**表現（リーダー物理要約特徴）のみ**。消去はしご（2.6σ）・特徴解剖（リーダー
  情報0ビット・重み直し天井 r=0.16）とも整合し、次の一手は特徴で確定的。
- L1 フラグ自体は残す（既定は learned のまま・採用なし）。合成世界のレフェリー役や
  「別系統の先生」としての将来価値（先生の多様化）はある。
