# T145: 決着前の較正が「悪化した」ように見えた理由（2026-09-23）

T138b（`2026-09-23_pre_settle_calibration.md`）は、決着後の行を除くと勝率の読み `W(D)` の較正が悪化し、
`relative_ledger` の `rel_K` は実記録で符号まで反転したと報告した。本 T はその理由を突き止める
（ユーザ指示「その 3 つを順に閉じてください」の 3 つ目）。

**記録**: T138b と同じ。実 = `w41`（300 局）／合成 = `w39 + w42`（900 局）。

---

## 0. 結論（先に書く）

**予測は 1 ビットも悪化していない。** T138b の「悪化」は 2 つの別々の理由で起きていた。

1. **`win_calib` の悪化は採点する行の入れ替わりである。** `W(D)` は行ごとに決まり、母数に依らない。
   除いた行は 96%／94% が勝者の行で、予測が高く当たりやすい行だった。その行を抜けば平均の損失は上がる。
   恒等式で確かめた（誤差 0）。
2. **`rel_K` の符号反転は、片方の席の最後のターンだけを抜いたことから来る。** 決着を宣言するのはほぼ勝者の
   とどめのターンなので、`--pre-settle on` は**勝者の最後のターンだけ**を局の和から抜き、**敗者の最後の
   ターン**を残していた。敗者の最後のターンは帳簿の上で大きく敗者側に積む。両方の最後のターンを抜けば
   AUC は 0.74／0.85 で高いまま、敗者の最後のターンだけを抜けば 0.89／0.94 まで上がる。

**残る本当の問題は 1 つ。** 決着前の行では `W(D)` は**勝者の順位づけはできる**（AUC 0.78／0.69）が、
**自信過剰**で、コイン（定数予測）に対数損失で勝てない。これは T138b が作り出した問題ではなく、決着後の行が
全体の数字を底上げして隠していた。出荷の読み（`rel`）でも同じだった。

## 1. `win_calib`：採点する行が変わっただけ

行の集合を「全」「残（決着前）」「除（決着後）」に分け、**同じ予測で**採点した（`tests/scripts/pre_settle_decomp.py`）。

| | 実・`abs` | 実・`rel`（出荷） | 合成・`abs` | 合成・`rel`（出荷） |
|---|---|---|---|---|
| 全・行数 | 3,547 | 3,547 | 10,186 | 10,186 |
| 全・対数損失 | 0.6784 | 0.6579 | 0.7763 | 0.7743 |
| 残・行数 | 3,212 | 3,212 | 9,316 | 9,316 |
| 残・対数損失 | **0.7246** | **0.7062** | **0.8209** | **0.8166** |
| 残・コインの損失 | 0.6917 | 0.6917 | 0.6926 | 0.6926 |
| 残・AUC | 0.7803 | 0.7784 | 0.6856 | 0.6896 |
| 除・行数 | 335 | 335 | 870 | 870 |
| 除・勝者の行の割合 | 0.961 | 0.961 | 0.937 | 0.937 |
| 除・予測の平均 | 0.841 | 0.930 | 0.819 | 0.903 |
| 除・対数損失 | **0.2351** | **0.1942** | **0.2997** | **0.3213** |
| 恒等式の誤差 | 0 | 1e-16 | 0 | 0 |

* **残の数字は T138b の `on` と完全に一致する**（実 3,212 行・0.7246／合成 9,316 行・0.8209）。同じ行・同じ予測である。
* **恒等式** `LL(全) = (n_残·LL(残) + n_除·LL(除)) / n_全` が丸め誤差まで成り立つ。除いた行の損失は全体の 3 分の 1 程度だった。
* **上位分位の過信の「拡大」も同じ効果である。** 除いた行は `abs` で最上位分位の 16%／19%、`rel` で 44%／48% を占めていた。
  抜けば、まだ決まっていない行が最上位分位に繰り上がる。

**本当の所見**: 残の行で、`W(D)` は 4 条件すべてでコインに負ける。T138b は「4 条件中 3 条件」と書いたが、それは
全の行の実・`abs` がコインに勝っていたのを数えたものである。T138b は出荷の読み（`rel`）を引いておらず、
`abs` だけを報告していた。`rel` は `abs` より少し良いが、残の行ではやはりコインに負ける。

## 2. `relative_ledger`：片方の席の最後のターンだけを抜いていた

`rel_K` の局ごとの和を「勝者の最後の自席ターン」「敗者の最後の自席ターン」「宣言した行」「それ以外」に割った
（`relative_ledger.py --parts`・新しい価格式は無い）。

| 勝者の視点で見た平均 | 実 | 合成 |
|---|---|---|
| 勝者の最後のターン | +0.42 | +0.41 |
| 敗者の最後のターン | **−0.32** | **−0.33** |
| 宣言した行（勝者） | +0.42 | +0.34 |
| 宣言した行（敗者） | −0.02 | −0.03 |
| それ以外 | +0.13 | +0.23 |

| 腕の AUC | 実 | 合成 |
|---|---|---|
| 全行 | 0.6508 | 0.7224 |
| 宣言した行を抜く（= T138b の `on`） | **0.3867** | **0.5367** |
| 勝者の最後のターンだけ抜く | 0.3715 | 0.4369 |
| 両席の最後のターンを抜く（= `before`） | 0.7446 | 0.8517 |
| **敗者の最後のターンだけ抜く** | **0.8944** | **0.9352** |

* **「宣言した行を抜く」は T138b の `on` の AUC を再現する**（0.3867／0.5367）。`before` も再現する（0.7446／0.8517）。
* 宣言した行はほぼ勝者の最後のターンである。**抜くと勝者の一番大きな積み（+0.42）が消え、敗者の最後の
  積み（−0.32）が残る**。これで和の符号がひっくり返る。
* **敗者の最後のターンは帳簿の上で大きく敗者側に積む。** 追い込まれた席が全力で殴るターンで、相手の時計が
  短いほど `Δlog` は同じ損害で大きくなる。帳簿は「追い上げた量」を正しく数えているが、その追い上げは勝敗を
  覆さない。
* **決着前の帳簿を読むには、時刻で両席を同じだけ切る必要がある。** 片方の席の行だけを抜くと、残った側に
  偏る。`before` は両席の最後のターンを抜くので偏らない。T138b の報告が「`before` は動かない」と書いたのは
  このためである。

## 3. 予告と当否

器の docstring に測る前に書いた予告:

| # | 予告 | 結果 | 当否 |
|---|---|---|---|
| 1 | 残の行数と予測は `--pre-settle on` と完全に一致する | 3,212／9,316 行・損失も一致 | **当たり** |
| 2 | 恒等式が丸め誤差まで成り立つ | 誤差 0〜1e-16 | **当たり** |
| 3 | 除いた行はほとんど勝者の行で、損失は全体よりずっと小さい | 勝者 96%／94%・損失 0.19〜0.32 | **当たり** |
| 4 | 上位分位の過信の拡大も同じ構成の効果 | 最上位分位の 16〜48% が除いた行 | **当たり** |
| 5 | 出荷の読み `rel` でも同じ効果が出て、`rel` は残の行でコインに近いか勝つ | 同じ効果は出た。だが `rel` も残の行でコインに負ける（0.7062 対 0.6917／0.8166 対 0.6926） | **半分外れ** |

`rel_K` の割り方は測った後に足した診断で、予告は書いていない。

## 4. 上手くいったこと／いかなかったこと

**上手くいった**:

* **T138b の数字を 2 つの器とも再現した上で割った。** 残の行・宣言した行を抜いた腕・`before` がすべて T138b と一致する。
  別の器で同じ数字が出たので、割り方の取り違えは無い。
* **2 つの「悪化」が別々の理由だと分けられた。** 較正は行の入れ替わり、帳簿は片側だけの切り取りである。

**いかなかった／自己批判**:

* **T138b は `abs` だけを引いていた。** 出荷の既定は `rel`（T118）で、報告の表題の条件と出荷の読みが食い違っていた。
  本 T で両方を出した。
* **T138b の「決着前を除くと較正が悪化した」「`Θ` の粗さは決着の前後を問わず残る」は、読みとして誤りだった。**
  予測は変わっていない。T138b の報告は書き換えず、訂正は本報告と台帳に置く。
* **決着前の自信過剰の原因は割っていない。** 候補は 2 つある。
  1. **`σ_rel` の母数。** `crossing_bridge.summarise` は `σ_rel` を `rows_out` の全行の残差の標準偏差から作る。
     輪郭の表は `--pre-settle off` で作ったので、決着後の行（残差が小さい）も混じっている。混じれば `σ` は小さく出る。
     決着前の行から作り直すのは当てはめではなく、同じ定義を正しい母数に当て直すことである。
  2. **τ の偏り。** 交点の橋の τ は平均で +1.6 ターン遅く言う（T128）。`σ` は残差の散らばりだけで、偏りを含まない。
     偏りがあれば、同じ `σ` でも予測は片側に寄る。

## 5. ユーザ判断をお願いしたいこと

1. **T138b の結論を本報告で差し替える**（推薦）。「較正が悪化した」ではなく「決着後の行が全体の数字を底上げして、
   決着前の自信過剰を隠していた」と読む。
2. **決着前の自信過剰を次に割るか。** 候補は `σ_rel` を決着前の行から作り直すことと、τ の偏りを分けること（§4）。T18 の前に要るかは判断が要る。
   T18 は `s`（手の比較）で縛るので、`W(D)` の較正には直接依らない。
3. **`relative_ledger --pre-settle on` の腕は使わない。** 決着前の帳簿は `before`（両席の最後のターンを抜く）で読む。
