# 中間ゲートの初回測定——**理論は中盤だけ一般化し、終盤は実デッキで消える**

2026-09-14 実施。フェーズの中間ゲート（`docs/cpu_theory_gap.md` §0.1・ユーザ決定
「理論の完成とは棋譜に対して勝敗が説明できるかどうか」を循環しない形に直したもの）の
**初回の定点**。組み上げ側＝合成 900 局（w39＋w42）・**ホールドアウト＝実デッキ 300 局**（w41）。
本報告は特定時点のスナップショット（追記・改変しない）。

## 結論を 5 行で

1. **理論は当たり前より上にいる**——実デッキで `position` **0.211** [0.050, 0.348]
   （0 = ライフ差しか言えていない・1 = ネットと同じだけ説明できている）。**CI は 0 を含まない**。
2. **中盤はそのまま一般化する**——合成 0.395 対 実デッキ 0.400。**ほぼ同じ**。
3. **終盤が実デッキで消える**——合成 0.471 → 実デッキ **−0.015**＝
   **ライフ差だけの評価に一切勝てない**。**これが最も鋭い所見**。
4. **手の順序は分布の外でほぼコインに落ちる**——局平均 0.589 → **0.519**（CI は重ならない）。
   判定は両方とも `price_does_not_teach`。
5. **器は 1 つも当てはめていない**（順位だけの指標・定数は凍結・重なりは実行前に拒否）。

## 1. 何を測ったか

| 予測子 | 中身 | 役割 |
|---|---|---|
| `base` | 自ライフ − 相手ライフ | **当たり前の下限** |
| `theory` | `λΔライフ + μΔ手札 + δΔドン + Σν(自場) − Σν(相手場)` | 凍結した理論 |
| `net` | `pol_v0`（ネットが見た根の価値） | **天井の目安** |

```
position = (AUC_theory − AUC_base) / (AUC_net − AUC_base)
```

**指標は AUC（順位のみ）**——較正も回帰もしないので、**ホールドアウトから値をもらう経路が無い**。
定数は `game_theory.md` §18 の値をそのまま凍結し、出力に刻んである。

## 2. 半 A——勝敗の説明

| | 合成 900 局（組み上げ側） | **実デッキ 300 局（ホールドアウト）** |
|---|---|---|
| 行 | 11,086 | 3,847 |
| `AUC base` | 0.6252 | 0.6145 |
| `AUC theory` | 0.7055 | 0.6678 |
| `AUC net` | 0.8456 | 0.8670 |
| **`position`** | **0.364** [0.266, 0.443] | **0.211** [0.050, 0.348] |

**ターン帯で割ると形が出る**（`position`）:

| 帯 | 合成 | 実デッキ | 読み |
|---|---|---|---|
| 序盤（1〜4） | 0.044 | 0.132 | **どちらも何も言えていない** |
| **中盤（5〜8）** | **0.395** | **0.400** | **そのまま一般化する** |
| **終盤（9〜）** | **0.471** | **−0.015** | **実デッキで消える** |

**終盤の実デッキ**は `base` 0.7754 に対し `theory` 0.7732——**ライフ差だけの評価に負けている**。
合成では 0.6748 → 0.7845 と明確に上回っていたので、**これは分布の外に出た瞬間に起きている**。

## 3. 半 B——手の順序

**勝敗だけ見ると「価値は当たるが順序は当たらない」を見落とす**ので同時に測る。

| | 合成 | **実デッキ** |
|---|---|---|
| 判断点 | 33,165 | 12,277 |
| `order_acc`（理論・ペア重み） | 0.5191 | **0.4657** |
| `order_acc`（方策の事前分布） | 0.4707 | 0.4480 |
| `gain`（理論 − 事前分布） | +0.0484 | +0.0177 |
| **局平均** | **0.589** [0.582, 0.596] | **0.519** [0.506, 0.531] |
| 理論が順位を付けられたペア | 55.0% | 49.2% |
| 判定（≥0.55 で `price_teaches`） | `price_does_not_teach` | `price_does_not_teach` |

**局平均の CI は重ならない**（0.582〜0.596 対 0.506〜0.531）＝**順序の能力は分布の外で
はっきり落ちる**。実デッキでは**ほぼコイン**である。

> **ペア重みと局平均が食い違う**（0.466 対 0.519）のは `theory_order` の docstring が
> 警告している既知の性質（ペア数が局で大きく違う）。**両方出す**——片方だけ読まない。

## 4. 判定と、そこから出る方針

| 問い | 答え |
|---|---|
| 理論は当たり前より説明できるか | **できる**（`position` 0.211・CI が 0 を含まない） |
| どこまで一般化するか | **中盤だけ**（0.395 → 0.400 でほぼ不変） |
| どこで壊れるか | **終盤**（0.471 → −0.015）と**順序全般**（0.589 → 0.519） |
| 完成したか | **していない**——ネットまでの 2 割・順序はコイン |

> **この数字は監視の定点であって、最適化の目標にしてはいけない**（§0.1 の条件 2）。
> 上げにいった瞬間に「残差を見て項を選ぶ」ことになり、循環が戻る。

### **ただし、ここで踏んではいけない線がある**

「終盤が弱いから終盤の項を足す」は**やってはいけない**——**残差を見て項を発明する**手続きで、
条件 2 そのものに反する。

**許されるのは、既に挙がっている 7 項目の中で順番を入れ替えること**だけである
（7 項目はこの測定より前に確定している）。そして**7 項目のうち 3 つは終盤に効く性質を
持っている**——身代わり・`ko_p` のパワー依存・`ν` の先読み（`R`／`A`）は、
いずれも**盤面が育ってから効く項**である。**新しく発明する必要は無い。**

## 限界

- **観察であって因果ではない**（因果はフェーズの出口 T18）。
- **`net` は上限ではなく目安**。ネットも最適ではないので `position = 1` が「完成」ではない。
- **実デッキ 300 局・1 設定・生成役 r3**。ホールドアウトは 1 本しか無い。
- **合成と実デッキの差は「分布の違い」であって、どちらが正しいかではない**。
- **序盤で `base` の AUC が実デッキだけ 0.4066**（ライフ差が**負に効く**）。
  合成は 0.6064 で符号が逆。**未説明**——先攻後攻の有利と絡む可能性があるが**未検証**。
  終盤の `base` が 0.775 と素直なので、席や `z` の取り違えではない。
- `position` は差の比なので、**`net − base` が小さい帯では不安定**（序盤がそれ）。
