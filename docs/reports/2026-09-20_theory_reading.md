## 0. 結論（先に書く）

2. **判別は戻らなかった**——未決着帯の AUC **0.9384 → 0.7316（実）／0.9462 → 0.8373（合成）**・
   較正 `sep` は **0.5652 → −0.193**。**`curve` が依然として大差で最良**。

   **実測でも通るのは `clock`（加速の無い読み）だけ**（破れ 16 行）。**単位の不変量は P5 の方**。
5. **どの読みも支配的でない**（§3 の表）。**`curve` は「使う目的（順序づけ・較正）」で最良だが構造的に誤り**、
   **`theory`／`clock` は構造的に正しいが順序づけで劣る**。

## 1. 副産物: **P5 の実装が誤っていた**（直した）

`_invariance` の P5 は **`Θ` と価格だけを c 倍し、`A` を倍にしていなかった**。
**`A` は「損害/ターン」なので、通貨の単位が変われば `A` も変わる**——倍にしないのは
**単位の変更ではなく物理の変更**（同じ速さで 3 倍の耐久＝3 倍の時間）である。

**`curve` の読みでは `A` が時計に入らないので無害だった**が、
**`A` が時計に入る読み（`curve_scaled`／`theory`）では測るものが違っていた**。

**訂正後の数字**（打ち切り以外の破れ／19,803 行）:

| 読み | 旧（誤った P5） | **訂正後** |
|---|---|---|
| `curve` | 19,051 | **19,051**（変わらず・結論も変わらず） |
| `curve_scaled` | 6,429 | **657**（3.3%＝**ほぼ通る**） |
| `theory` | — | **0**（厳密） |
| `clock` | — | **0**（厳密） |

**T122／T126 の P5 の数字は誤った定義で測ったもの**だが、**`curve` についての結論は変わらない**
（そこでは `A` が無関係なので同じ値）。**`curve_scaled` の評価だけ上がる**（6,429 → 657）。

## 2. 式（T94 の歩きを 1 行の器へ・新定数ゼロ）

```
R_k = リーダー ＋ 盤面·(1−ko_p)^{k−1} ＋ 在庫·[k≥2] ＋ 流入·(k−1)     （crossing_bridge.rate_at）
τ   = R_k を積んで Θ に届くまでのターン数                              （tau_grow）
```

**表を 1 つも使わない**——加速は**盤面が育つこと**から出る。だから**単位は `A` だけが持ち、P5 が設計から通る**。

**状態は `A` をスカラーで持つ**（軸は 4 本のまま）ので、席ごとの内訳
`(リーダー, 盤面, 在庫, 流入)` を**和 1 に正規化した割合**で持ち、歩きの各項は `割合 × A` で作る。
**`ΔA` は割合で配る**（＝歩きが `A` について 1 次同次に保たれる形）。
**代償**: 「出した体は次の自席ターンから」という T84 の遅れは**この形では表現していない**（一次の近似）。

## 4. P7 の撤回（要求として過剰だった）

**加速する時計は `A` について 1 次同次になれない。** `R_k = A·f(k)` のとき `τ` は
`A·Σ_{k≤τ} f(k) = Θ` の解なので、`A → cA` では `Σ_{k≤τ'} f = (1/c)Σ_{k≤τ} f`。
**`f` が一定なら `τ' = τ/c`・`f` が増えるなら `τ' > τ/c`。**

**テストで両方固定した**——一定の形（全部盤面）なら `D` は厳密に `1/1.3` 倍になり、
加速する形なら厳密にそれより大きい。**実測でも P7 を通すのは `clock` だけ**。

> **だから P7 は「満たすべき不変量」ではない**。**現実の対局が加速するなら、
> 片方が 1.3 倍速いことは「加速の日程に対していつ居るか」を本当に変える**ので、比が動くのが正しい。
> **`curve` で P7 の破れが 0 だったのも、満たしていたからではなく `A` が時計に入っていなかったから**（T126 で既に確認）。

**残る単位の不変量は P5 だけ**で、そちらは **`theory` が厳密に通し `curve` が 96% 破る**。

## 5. 何が確定したか

**`A` を時計に入れる 2 つの独立な道が、同じ約 0.2 の AUC を失った**:

| 道 | 加速の出どころ | 未決着帯 AUC（実） |
|---|---|---|
| `curve`（比較の基準） | **表**（両席共通の平均） | 0.9384 |
| `curve_scaled`（T126） | 表を**その席の `A`** で伸縮 | 0.6595 |
| **`theory`（本 T）** | **状態**（盤面が育つ） | 0.7316 |
| `clock` | 加速なし | 0.7682 |

**入れ方を変えても戻らない**＝**患部は `A` の推定そのもの**。
**T112 が「終局の偏りの 74.7%／73.7% は `A` の軌跡の誤り」と名指していたのと同じ結論**に、
**まったく別の経路（順序づけの指標）から着いた**。**2 本の独立な証拠が同じ場所を指している。**

**次の一手はもう「時計の形」ではない**——**`A` の推定を良くすること**。
`A` は今 `盤面の攻撃手 ＋ デッキからの流入` で、**T112 が「形（自席ターン番号の関数）の誤り」と
特定している**。**そこを直さない限り、どの読みも `curve`（平均）に勝てない。**
