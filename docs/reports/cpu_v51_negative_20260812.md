## 3. 解釈 — representation-bound（v24/v41 と同族・3例目）

乖離盤面が乖離する理由（その盤面固有の勝ち筋＝レース優位・止まらない布陣）を**現行の
特徴言語が表現できない**から value は外す。表現できないものは50点あっても汎化せず、
埋め込み等で暗記されるだけ——v49 の「勾配は転移しやすい特徴に逃げる」と同じ機構が、
今回は「逃げ先すら無い」形で現れた。**G系へのデータ追加パッチはこの欠陥族には効かない**。

## 4. 帰結

修正の本命は**特徴言語の拡張**＝B系 Phase 2 の導出量（**リーサル距離**＝双方があと
何ターンで詰むかをエンジンが仮実行で測る）。同日の B系分離テスト
（`backbone_bb1_20260812.md`）が「物理言語自体は実盤面で機能する」ことを示しており、
G系の較正欠陥と B系の設計が同じ解（測定ベースの特徴）へ合流した。
