## 1. 問い——「1 本にまとめた定数」とは何か

T109（速さ `A` の財布）と T110（耐久 `Θ` の予算）で**どちらもドンの金額は規則どおり**になったが、
**同じ席の `A` と `Θ` が互いを見ていない**。1 本のナップサックにまとめるなら
`価値 = A の分 + ρ × Θ の分` を最大化することになる。**その `ρ` は何か**。

**次元で半分わかる**:

* `A` は **[価格/ターン]**（毎ターン繰り返す流量）
* `Θ` は **[価格]**（一度しか使えない在庫）
* よって **`ρ` の次元は [1/ターン]** ＝ **率**

**`ρ = 1` と置くのは「耐久は 1 ターンで効く」と宣言するのと同じ**で、しかも**時間の単位を変えると値が変わる**
＝**そもそも well-defined ではない**。

## 2. 式（**新定数ゼロ・`ρ` は現れない**）

```
D = τ_opp − τ_me = Θ_me/A_opp − Θ_opp/A_me          （T90 の 2 つの時計）

∂D/∂Θ_me = 1/A_opp                 ← 耐久 1 単位が買う「ターン」
∂D/∂A_me = Θ_opp/A_me²             ← 速さ 1 単位が買う「ターン」

ρ = (∂D/∂Θ_me) ÷ (∂D/∂A_me) = A_me²/(A_opp·Θ_opp) = (1/τ_me) · (A_me/A_opp)
対称な局面（A_me = A_opp・Θ_me = Θ_opp）では  ρ = A/Θ = 1/τ
```

**`ρ` は「残りターン数の逆数」**。理由も 1 行で言える——**速さは毎ターン繰り返し、耐久は一度しか使えない**。
残り `τ` ターンあるなら速さ 1 単位は `τ` 回働き、耐久 1 単位は 1 回しか働かない。

実測の大きさ（`A` ≈ 0.20/ターン・`Θ_start` ≈ 0.86）: **`ρ` ≈ 0.23/ターン ≈ 1/4.3**。
**`ρ = 1` と置くと耐久を 4.3 倍に過大評価する**。

**そして `ρ` は置かない**——2 つの理由:

1. **`ρ` は局面の量**（どちらが速い側か・決め手がどれだけ近いか）。**定数に固めると
   「役割分担は関係ない」と宣言する**＝**打ち筋を式に入れる**（§0.05 で禁じた型）。
2. **`ρ` は微分＝線形近似**。財布の選択は**離散**（5 コストの体は「わずかな変化」ではない）。

**代わりの形**:

```
1. 財布の組（手札の札「出す／構える」＋ 場の攻め手への付与 k 枚）から、
   予算 P での (A の分, Θ の分) の **パレート境界** を出す          ← purse_pareto
2. 境界の各点で D を直に測り、最大の点を採る                       ← choose_by_race
```

**`D` は両軸で単調増**なので最適点は必ず境界上に在る＝**境界を出せば交換レートは要らない**。

### 財布に入る選択肢（規則が許すものだけ）

| 行き先 | 選択肢 | 値 | 規則 |
|---|---|---|---|
| 速さ | 手札の体を出す | 攻撃の価格（素殴り） | 召喚酔い（T84） |
| 速さ | 出した札の効果 | `removal_harm`（一度きり） | T105／T108 |
| 速さ | 場の攻め手に付与 `k` 枚 | `増分 − k·δ`（T45 のまま） | `ops.rs::attach_don` |
| 耐久 | 出せるブロッカー | `ν_meas` | ブロックに召喚酔いは無い（T106） |
| 耐久 | 構えるカウンター・イベント | `μ` | `apply_counter` が `pay_cost`（T110） |

**印字カウンターの札は無料**なので財布の外（`cuttable_share` が別に数える・二重にしない）。

## 5. 読み方——(b) が外れた理由は「記述」と「処方」の違い

**T109／T110 と本 T は種類が違う**:

* **T109・T110 は金額を直した**——「ドンは 4 ゾーンを動くだけ」「席ごとの合計はリーダーのルール」
  「次のターンに戻るのはレストも付与も」「カウンター・イベントは払う」。**どれも記録に在る事実**＝**記述**。
* **本 T は配分を直した**——「そのドンをどこに使うべきか」。**これは処方**であり、
  **記録を作った CPU はその配分で打っていない**。

**だから (b) が外れるのは驚きではない**——**両席に「模型どおりの最適配分」をさせると、
模型どおりに打っていない対局の勝敗は当てにくくなる**。**`D` を目的関数にも予測器にも使っている**ので、
**両席の `D` が上がり、差（＝予測の中身）はむしろ濁る**。

**(c) がその読みを支える**——**処方と打ち回しは無関係ではない**（1.3〜1.5 倍の差が両記録で出た）が、
**一致しているわけでもない**（理論の払い 4.75／4.43 対 実際 5.62／5.75）。

**判定: 既定にはしない。切替として残す。**
**判定の場は T18（出口）**——そこでは**理論が打ち回しに介入して勝率を測る**ので、
**処方の良さを処方として測れる**。今の 2 つの橋は**記述の器**なので、処方の評価には向かない。

## 6. 手続きへの自己批判（残す）

**(c) は (b) が外れた後に足した検算**である。**後から足した検算は当てはめに近い**ので、
弁護できる点を書いておく:

1. **(c) は配分と独立の量**（使い残しは配分の入力にも出力にも入っていない）。
2. **向きを先に決めてから測った**（「耐久を買えの行で残しが多いはず」）。
3. **それでも「外れた後に探した証拠」である**——**(c) だけで採否を決めない**（実際に採っていない）。

**もう 1 つの自己批判**: **`ρ` を「置かない」ことにしたが、`D` を目的関数に選んだこと自体は 1 つの選択**である。
`D` は T90 以来の理論の中心量なので新しく持ち込んだものではないが、**「勝率」ではなく「到達ターンの差」を
最大化する**という形は、**`W(D)` が単調なら同じ**という前提に乗っている（T75 の実測では単調・0.04 → 0.93）。

## 8. 限界

- **1 パス近似**（§7 の 2）。**両席が同時に配分を変える固定点は解いていない**。
- **`A_opp` はその席の行から読める分だけ**（相手の盤面の攻め手 ＋ デッキの流入）＝
  **相手の手札から出てくる体は入っていない**（自分側は入っている）＝**非対称**。
- **パレート境界は平均 1.5 点**（実）＝**過半の行では取り合いが起きていない**（予算が足りるか選択肢が無い）。
  **効いているのは 14.4% の行だけ**。
- **`D` を目的関数にも予測器にも使っている**（§5）＝**(b) の測り方そのものが処方に不利**。
- **観察であって因果ではない**。
