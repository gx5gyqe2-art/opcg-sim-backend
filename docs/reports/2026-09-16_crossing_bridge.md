# T52——交点の橋。価格の帳簿はしきい値と単位が合い、「いつ終わるか」は損害の輪郭で 1.1 ターンまで読めた。「どちらが勝つか」は 6 割のまま

2026-09-16 実施（ユーザ提案「足し上げた価値の関数と、しきい値の関数の交点が勝敗の橋になるんじゃないか」→「それで書いて検証してみてください」）。
**当てはめない・回帰しない・新定数ゼロ**（λ・μ・ν・c̄ の写し。損害の輪郭は自席ターン番号ごとの平均＝実測の表）。本報告は特定時点のスナップショット。

## 結論を 6 行で

1. **帳簿の単位はしきい値と合う**——勝った席が終局までに相手に与えた損害の累積 `F` は、開始時の相手の耐久 `Θ`（λ·ライフ + μ·手札 +
   ν·ブロッカー）の **1.14／1.05 倍**（実／合成）。**価格は損害の帳簿として一貫している**（2 つのセットの構造が成り立つ）。
2. 攻撃の価格の累積は実現した損害の **0.74／0.72**（効果・登場時除去は攻撃の価格に入っていない分）。
3. **損害は加速する**——自席ターン 1〜5 で 0.001 → 0.08 → 0.11 → 0.18 → 0.25（ドンが増えるぶん）。「今の傾きで直線に伸ばす」交点は
   6〜12 ターン先を指して外れる（偏り +7〜+13）。
4. **輪郭（ターン番号ごとの損害の平均）に沿って積むと、終局までのターン数は σ 1.08／1.29・偏り +0.5〜+0.8**——時間軸ヘッド（ネット）の
   誤差 1.0 と同じ水準に、**定義済みの量だけで届いた**。
5. **どちらが勝つかは 0.61〜0.64 のまま**（盤面の時計 T51 と同じ）。しきい値も輪郭も両席でほぼ同じ形なので、席の差（勝敗）はそこに無い。
6. **読み**: 交点の橋は「単位」と「時間」の橋としては成立した。「勝者」の橋には、耐久と輪郭に載っていない席の非対称（手札の中身・効果）が要る。
   **次の候補**: 輪郭の交点の近さ `|D|` を `κ` に使う（勝者の当否は要らない・W(D) は 0.20 → 0.97 と急）。

## 1. 器

席ごと・自席ターン開始ごとに:

```
F_w(t)   = 相手に与えた損害の累積（実現・λ×ライフ + μ×札 + ν_meas×倒した体・判断点で挟む）
Θ_w(t)   = λ·L_opp + μ·H_opp + Σν_meas(相手のアクティブなブロッカー)         相手を倒すのに残っている量
傾き     = hist: これまでの損害の平均／theory: 今の盤面の攻撃手の価格の和／curve: ターン番号ごとの損害の輪郭／
           curve_scaled: 輪郭 × (今の理論の傾き ÷ そのターン番号の理論の傾きの平均)
τ_w      = Θ_w に届くまでのターン数（輪郭なら積み上げて端数は比例配分）
勝者     = τ の小さい側（同数なら手番の自席）
```

測るもの: 勝者の的中率・倒した側の τ 対 実際の残りターン（偏り・σ_T・MAE）・`D = τ_opp − τ_me` の帯の実勝率・帳簿の検算。

## 3. 読み方

- **2 つのセットは成立する**——傾きのセット（価格）を足した帳簿は、しきい値のセット（耐久）と同じ単位で 1.05〜1.14 倍まで一致した。
  「価格の累積の傾きが 1 でない」のは欠陥ではなく、勝敗が帳簿の線形な関数ではなく交点だから。
- **時間は読める**——損害は 5 ターンかけて加速する（輪郭）。それを織り込むと終局のずれは 1.1〜1.3 ターンで、学習した時計と同じ。
  T50 の「体が居ると対局が早く終わる」も、この輪郭の後半（j ≥ 4 で 0.25/ターン）そのもの。
- **勝者は読めない**——耐久（両席で似る）と輪郭（共通）から出る `τ` は両席で近く、`D` の 7 割が −1〜1 に入る。席の差は
  帳簿の位置（実現した損害の差 `S`・AUC 0.88）には出ているが、**将来の損害の差**（手札の中身・効果・盤面の質）には
  定義済みの量で届いていない。

## 4. 次の候補（ユーザ判定）

1. **`κ` を輪郭の交点から**——`w(状態)` に要るのは「接戦か」（`|D|`）であって勝者の当否ではない。curve の `D` で `κ = w(D)/w̄` を作り
   橋（`theory_bridge`）で AUC を測る（`σ_D` は curve の σ_T から）。輪郭は `tests/fixtures` に置く（実測の表・新定数ゼロ）。
2. 席の非対称を耐久に入れる（手札の中身のカウンター値・`guard_afford` の予算）——勝者の的中がどこまで上がるか。

## 限界

- 損害の輪郭はこの記録（同じ CPU）の平均。輪郭を同じ記録で評価しているので時間の σ はわずかに有利（13 個の平均）。
- 損害は判断点で挟んだ実現の相手側の部品（ライフ・手札・体）。ドン・自席側は入れない。
- **観察であって因果ではない**。
