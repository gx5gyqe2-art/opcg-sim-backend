# v23 — VALUE_BLIND の原因分析: value は「勝者の相貌」を学んでおり、密ラベルはそれをエコーする（2026-07-29）

v20 が分離した VALUE_BLIND 4点（m2@64 / m2@66 / m4@2 / m4@8＝いずれも低コスト展開・付与の
過大評価）について、「**なぜ value が過大評価するのか**」を特徴設計に入る前に測定した
（`tests/scripts/value_blind_probe.py`・読み取り専用・net は現既定 gen8）。
スナップショット（追記・改変しない）。

## 1. 測り方（2部構成）

**A. 遮蔽帰属（occlusion attribution）**: 正着の子盤面（accept 最良）と誤着の子盤面
（非accept 最良）の符号化を**特徴グループ単位で入れ替え**、誤着側の value 優位
gap = v(誤着) − v(正着) がどの特徴群に乗っているかを両向き（fwd/rev）で測る。
グループは SCALARS_V5=55＋field＋card_idx の完全分割20群（`tests/test_value_blind_probe.py` が固定）。

**B. コーパス対照走査**: 密ラベルコーパス（v19 対面特化 24 シャード＝gen8 の教師そのもの、
v17 汎用 32 シャード）から「同リーダー・同ターン帯で当該カードが自場に在る行/無い行」を取り、
z（勝敗）と q_root（探索自己評価）の群間差 dz / dq と **echo = dq − dz**
（q_root が z の裏付け無く持ち上げている量）を測る。

## 2. 結果

### 2-1. 遮蔽帰属 — 押し上げているのは「勝者局面の見た目」の特徴群

| 点 | gap | 誤着（CPU側） | 正着 | 帰属上位（mean） |
|---|---|---|---|---|
| m4@2 | **+0.417** | PLAY ST30-004（turn1 イワンコフ出し） | TURN_END | **手札ID +0.165・自場特徴 +0.121・手札枚数 +0.084・召喚酔いフラグ +0.078** |
| m2@64 | +0.266 | ATTACH_DON EB03-055（クマシーへ付与） | ATTACK OP16-056 | **自場特徴 +0.174・能力使用済フラグ +0.114** |
| m4@8 | +0.113 | TURN_END（攻撃しない） | ATTACK OP09-001（リーダー攻撃） | **ターン/手番 +0.230**（gap 超・ドン −0.079 が引き戻し） |
| m2@66 | +0.088 | ACTIVATE_MAIN OP16-056 | ATTACK EB03-055 | **能力使用済フラグ +0.085・自場ID +0.068** |

読み取り:

1. **m4@2（最大 gap）**: 誤着を支えるのは「手札からカードが消えた」（手札ID/手札枚数 計+0.25）・
   「自場に体が並んだ」（自場特徴+場の枚数 計+0.17）・**「召喚酔いフラグが立った」（+0.078）**。
   召喚酔いは純粋なコスト標識なのに**正の寄与**＝ net は「酔いフラグ＝今出した＝勝者はよく出す」
   という**相関**を学んでいる。出したカードが何か（自場ID）は +0.010 とほぼ無寄与で、
   **イワンコフだから良い、ではなく「出すという行為の相貌」を良いと言っている**。
2. **m2@64**: ATTACK の子盤面は宣言直後＝**攻撃者レスト（コスト）だけが見え、打点は防御応答待ちで
   未実現**（復元盤面で確認: pending=CONFIRM_OPTIONAL・相手ライフ 3→3 不変・攻撃者 is_rest=True）。
   一方 ATTACH_DON の子盤面は「ドンが付いた」美点が即時に見える。**1手先比較は構造的に
   攻撃へ不利・展開/付与へ有利**で、value がその見た目の差をそのまま返している。
3. **m2@66**: 能力使用済フラグの**正の寄与**＝「能力を使った状態＝勝者の相貌」。使う内容の
   良し悪しではなくフラグ自体が報酬になっている（m4@2 の召喚酔いと同型）。
4. **m4@8 だけ別機序**: ターン/手番グループ単独で +0.230（gap +0.113 を超える）。TURN_END の
   子盤面は is_my_turn=0・turn+1 の**別レジーム**に跳び、そこの較正誤差が真の行動差を丸ごと
   飲み込む。訓練行の is_my_turn=0 は防御応答局面（平均 z=−0.10）に偏っており、
   「ターンを渡した直後の平常状態」の教師が薄い。
5. v5 で**この種の判断のために設計した「展開余力」特徴の寄与は全点でほぼゼロか負**
   （m4@2 で −0.031）。因果向けに設計した特徴は決定を運んでおらず、相関特徴が運んでいる。

### 2-2. コーパス対照 — z は支持しないのに q_root が持ち上げる（エコー）

| 点 | コーパス | 対象 | 在 n / 無 n | dz | dq | **echo** |
|---|---|---|---|---|---|---|
| m4@2 | v19（gen8の教師） | ST30-004 展開・turn≤2 | 780 / 2,966 | **+0.023** | **+0.145** | **+0.122** |
| m4@2 | v17（汎用） | 同上 | **1** / 100 | — | — | — |
| m2@64 | v19 | EB03-055 在場・turn≤11 | 15,146 / 28,575 | **+0.308** | +0.398 | +0.090 |
| m2@64 | v17 | 同上 | **0** / 2,007 | — | — | — |

読み取り:

1. **m4@2 はエコーの教科書例**: 勝敗 z は turn1 イワンコフ展開をほぼ支持しない（dz=+0.023）のに、
   q_root は +0.145 持ち上げる。q_root は**同じ value ネットが駆動する探索**の自己評価だから、
   これは旧癖の再生産。混合ラベル y=0.5·z+0.5·q の q 半分が毎周この癖を教え直すので、
   **密ラベルを何周しても符号が反転しない**（gen7・gen8 で実測どおり）。
2. **m2@64 は z 自体が交絡**: クマシー在場の行は勝敗でも +0.308 高い。「優勢だからキャラが並ぶ/
   生き残る」という**状態相関**であり、「この局面で付与するべきか」という行動の因果とは別物。
   状態価値学習は原理的にこの交絡を分離できない＝**同一局面での行動対照（反実仮想）を教師が
   持たない限り、z を増やしても直らない**。
3. **汎用コーパス（v17）には対照が事実上存在しない**（在 n=1 / 0）＝汎用周回はこれらの点を
   そもそも教えられない。v19（対面特化）で初めてデータが生じたが、上記1・2で中和された。

## 3. 結論 — なぜ過大評価するのか

**value ネットは「行動の因果的利得」ではなく「勝者局面の相貌」を学んでいる。**
1手先比較では (a) 展開/付与/能力は勝者の相貌（体が並ぶ・ドンが付く・フラグが立つ・手札が減る）を
**即時に**まとい、(b) 攻撃は**コスト（レスト）だけが先に見え利得（打点）は未実現**、
(c) TURN_END は較正の薄い別レジームへ跳ぶ。だから低コスト展開系が系統的に勝つ。

これが密ラベル2周で直らなかった理由も同じ測定内にある:
ラベルの q 半分は同じネットの探索自己評価で癖をエコーし（m4@2: echo=+0.122）、
z 半分も状態相関の交絡を含み（m2@64: dz=+0.308）、
反実仮想の対照はコーパスにほぼ無い（v17: 在 n≤1）。

## 4. 特徴設計（次の打ち手）への含意

1. **特徴の追加単独では反転しない見込みが高い**。遮蔽帰属が示すのは「情報が足りない」ではなく
   「既にある特徴を誤った符号で使っている」であり、専用に設計した展開余力特徴が寄与ゼロという
   実測がそれを補強する。ラベルが相貌を報酬にする限り、新特徴も同じ相関に吸収される。
2. 最有力は**反実仮想ペア教師**: 同一局面から「出す/出さない（付与する/しない）」を強制した
   CRN ペア対局を回し、**結果差分そのもの**をラベル化する。固定対面生成（v19）と
   子盤面ペア順位学習（v12.1）の機構は既にあり、組み合わせで実装可能。m4@2 型（エコー）にも
   m2@64 型（状態交絡）にも正面から効く。
3. 併せて安価な**エコー遮断**: 矯正対象局面（早期ターンの展開決定）だけ q 混合を切り z 純化する、
   または q 混合比 α を上げる。ただし m2@64 型の z 交絡には効かない＝単独では不足。
4. m4@8（ターン境界較正）は別問題として扱う。TURN_END 子盤面（is_my_turn=0 の平常状態）が
   教師分布にほぼ無いことが原因なので、反実仮想ペアが TURN_END を含めば同時に教師が生じる。

## 5. 計器としての注意

- 遮蔽帰属は非線形ネットでは加法的でない（fwd/rev の総和 ≠ gap）。両向きで大きい群のみを
  結論に使い、小さい群の符号は読まない（線形時の厳密加法性は `tests/test_value_blind_probe.py` で固定）。
- コーパス対照の「在/無」は**状態の対照**であって行動の対照ではない（attach 点では
  「そのキャラが場に居るか」を見ている）。dz はその粗さ込みで読むこと＝§2-2 の m2@64 は
  まさにこの粗さ（交絡）自体が発見。
- 対照走査の点別数値は n が大きく（780〜44k 行）、v22 の点別命中率とは違い分散の心配は小さいが、
  シャード＝対局単位の相関（同一対局から複数行）があるため、厳密な検定には対局単位の
  クラスタリングが要る。本報告は効果量（+0.12/+0.31）の桁で議論しており結論は揺れない。
