# v32 手札価値と評価方法の修正 — 測定器は直った・順位腕は不採用（2026-08-03）

スナップショット（追記・改変しない）。前提: `cpu_v31_option_ranking_20260802.md`（単手因果の壁）、
`gen10_adoption_20260802.md`。本サイクルはユーザの2指摘——「パワー2000以下のキャラの盤面価値は
低いはずだが使えていない」「手札は枚数もカウンター値も判断材料にすべき」——を起点に、
評価方法（レフェリーロールアウトの集約）そのものの欠陥を特定・修正した。

## TL;DR

- **評価方法の2欠陥を特定し修正（恒久資産）**: (1) argmax 防御ロールアウトは「手札を回して即出しする
  枝」に偽の優位を与える（温存カウンターが使われる世界が生成されない）。m4@2 実測で def_temp 0→0.7 に
  よりイワンコフ 18/32 → 11/32 と優位が消失。(2) 勝敗二値はマージンを捨てる（温存の利得は「際どい勝ちを
  安全な勝ちに」として現れる: 温存枝の勝ち時ライフ差 +2.29 vs 手札回し +1.60）。
  → `option_pair_gen` に **def_temp=0.7 既定**＋**margin_blend ラベル**（z + 0.25·clip(平均ライフ差/4)）。
- **本番 value の欠陥を数値で確定**: gen10 は (a) 効果不可視のバニラ2000追加に +0.063（6000体の 2/3）＝
  体の水増し加点、(b) カウンター2000札を失う痛み（−0.056）≦ カウンター0札（−0.068）＝**守りプレミアム
  ゼロ**、(c) m1@3 でウタの補充1枚を ≈0 円で評価（子盤面差 +0.011 でイワンコフ上）。
- **ゲートの標的を正しい位置へ**（ユーザ最終裁定 2026-08-03）: m4@2 は**発動する**イワンコフ（6000×2 で
  条件成立・手札 5→5）＝**出すのが正解**・非退行ガード化。「非発動イワンコフを咎める」の正しい標的は
  **m1@3**（6000×1・不成立・手札 6→5 のバニラ設置）＝ウタ accept で再採録（gen10 の行動欠陥
  イワンコフ 5/8 を実測）。コーチゲートは 14 点。
- **v32 順位学習腕は不採用**: 160局・296群・1328ペア（v8 符号化・def_temp・margin_blend）で
  順位正答 0.683→0.784 と一般改善するが、**m1@3 は動かず（0.50→0.50）**、防御 PASS 点が bar 超えで
  壊れる（m2@12 1.00→0.06・m2@58 1.00→0.25）＝コーチ 6.5→4.1 FAIL。96局弱学習でも同型
  （m2@58 退行）。**アンカー無し順位ヒンジは標的を動かす前に防御較正を壊す**（v31 と合わせ再現3回目）。
  gen10 維持。

## 1. 評価方法の修正（m4@2 3枝の反実仮想・32世界 CRN）

| 枝 | def_temp=0 | def_temp=0.7 | 勝ち時ライフ差 |
|---|---|---|---|
| イワンコフ出し | **18/32（+0.125）** | 11/32（−0.312） | +1.60 |
| A&S&L出し | 15/32 | 9/32（−0.438） | +1.75 |
| TURN_END | 15/32 | 11/32（−0.312） | **+2.29** |

def_temp（防御窓のみ訪問数比例サンプリング・攻め手順は不変・防御矯正フェーズ実績値 0.7）だけで
イワンコフの見かけ優位が消える＝**v31 までの単手ペアコーパスはこの盲点つきで生成されていた**。
マージン（残ライフ差）は CR.rollout が返していたのに集約が捨てていた。両修正を `option_pair_gen` に
恒久化（テスト: `test_option_pair_gen.py::test_margin_blend_is_bounded_tiebreak`）。

## 2. 本番 value の帳簿（gen10 反実仮想プローブ・実盤面）

- 自場スロットのパワー 2000→6000: Δv +0.104（方向は正・99.5%）／相手側 −0.142（対称）。
- **効果・ID不可視のバニラ2000ボディ追加: +0.063**（6000体 +0.095 の 2/3）＝「体があれば加点」。
  → 符号化 v8（自場集約の純対称化・66次元・しきい値特徴なし=ユーザ方針）で表現側を手当て。
- 手札からカウンター2000級を抜く: **−0.056（100%で低下）** vs カウンター0札 −0.068 ＝
  枚数の一般価値はあるが**守り札プレミアムはゼロ**（v6 特徴は見えているのに重みが無い）。
- m1@3 の子盤面対照: ウタ子（手札6のまま＋山札濾過）−0.291 vs 非発動イワンコフ子（手札5・dead−1）
  −0.280。遮蔽帰属: dead減少 +0.0025・場イワンコフID −0.0009 ＝どの単独特徴でもなく
  「補充1枚の価値 ≈ 0」が原因（ウタ vs 死にイワンコフの兄弟対照を教師が一度も含まないため）。

腕の設計限界であり、データ増や lr 調整では回避できない。

## 4. 次の一手（v33 候補・設計のみ）

   少量の標的ペアで届く公算が高い。
