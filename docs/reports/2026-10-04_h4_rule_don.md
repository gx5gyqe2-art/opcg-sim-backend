> 状態: **採用済み（ユーザ決定 2026-10-04）**。手札の項の既定は `rule_don`、鏡（自分の耐久も相手と同じ守る側の計算で読む）は既定で入れる。
> 旧の既定は `--theta-hand cuttable_forced`、鏡なしは `--mirror off`（または環境変数 `MIRROR=0`）、一律の値段は `--cut-price flat --cut-take mu`。

## 要約（採用の記録）

### 何を決めたか
守る側の手札の項を、簡易の見積もり（既定だった形）から、規則から導いた形（守る側が実際に切れる札の値と、攻め手がドンを付けて上げる分を数える形）に
切り替えること。あわせて、自分の耐久も相手と同じ守る側の計算で読む「鏡」を既定にすること。

### 選択肢
- (a) 付与まで入れた規則の形を既定にし、鏡も入れる（**採用**）。
- (b) 付与なしの規則の形だけ。実で当たり .665・偏り +2.05・ばらつき 5.93 で、旧の既定とほぼ同じ。改善の中身は付与の部分にある。
- (c) 据え置く。

### なぜこの問いが出てきたか
1. 手札の項は、守る側が手札から何枚切れるかを言う量で、旧の既定は簡易の見積もりだった。
2. 「正しい形で」というユーザ決定（2026-09-26）で、規則（カウンターの値・イベントのドン・ブロッカーの横取り・ライフの札が手札に入ること・
   攻め手のドン付与）から導く形を作った。
3. 独立レビューを H-4b から H-4g まで 6 回受け、式と数字の読み方を直した。最後に、状態数の予算で地平を縮めるかどうかを問題だけの関数にし、
   N-3（切らせた札の値段を平均の値段にする既定）と統合した。
4. 残りの測定（線形の橋・帳簿・遷移の帳簿）を 3 つの作業セッションに分けて測り、結果が揃ったところで、ユーザが両方の推薦（付与つきの形を既定に・鏡を既定に）を採った。

### 推薦とその理由（採用した内容）
- 交点の橋では実・合成とも偏りがほぼ消える（実 +1.94 から +0.05、合成 +2.37 から +0.37 ターン）。ばらつきは 5.9 から 1.4（合成 6.3 から 1.7）。
- 決着前の勝率の対数損失は、実・合成とも五分五分より悪かった旧の既定から、五分五分を上回る値になる（実 .681 から .527、合成 .777 から .606）。
- 相対の帳簿の順位づけは実で大きく良くなる（rel_K の AUC .717 から .902）。
- 鏡は、自分と相手を同じ式で読むという意味で規則に忠実。線形の橋の「打った手の値段の積み上げ」の AUC は、鏡ありのほうが鏡なしより低いが（実 .687 対 .805）、
  「状態の値」の AUC は鏡ありのほうが大幅に高い（実 .602 対 .370）。

### 決めないとどうなっていたか
旧の既定が残り、偏り +1.9〜+2.4 ターンと、五分五分より悪い勝率の較正が残る。

### 留保（悪くなった点・採用後の宿題）
測定で**悪くなった点を隠さず**残す。いずれも次の作業の候補:
1. **線形の橋・接戦帯**: 打った手の値段の積み上げ（実）の接戦帯 .446 から .380、中間帯 .460 から .412。合成は全体 .688 から .629。
   決着帯は実で .684 から .812 に上がる。
2. **線形の橋・決着帯の状態の値**: 実 .635 から .483（全体 .767 から .602）。合成は全体 .427 から .419 でほぼ同じ。
3. **遷移の帳簿**: 攻撃の行の「残差÷価格」が .884 から 1.128、残差の割合が .883 から .988。説明される割合は .315 から .308 でほぼ同じ。
4. **合成の rel_K の AUC は不変**（.681 から .679）。実は大きく改善。
5. **守る側の計算が予算で地平を縮める計画が約 1%**（実 1.1%・合成 1.4%）。結果は呼ぶ順に依らない。
6. **時間で読む器の速さが約 1.4 倍**（線形の橋は使わない）。
7. **鏡の時点の置き方**（下の 4 節）が未決。鏡ありで自分の耐久がちょうど 0 になる行が多く、局の合計が数局に支配される。

複数の宿題は互いに独立で、片方だけ先に進められる。

## 1. 何を作ったか（要点）
- `THETA_HAND_MODE` に `rule`（攻め手の付与なし）・`rule_don`（攻め手の財布を段ごとに持つ）・`rule_don_purse`（付け先を守る側の手札に対して選び直す）。
- 守る側の計算は期待値の動的計画法: 手札の札の種類ごとの枚数が状態。ライフの札は手札に入る（デッキ由来の分布）・毎ターン 1 枚引く・
  レスト中のブロッカーは次のターンに戻る・手札のブロッカーが次に出る。目的は（止めた損害 → 切った札の少なさ → 生き延びるターン → 損害を遅らせる）の順。
- 状態数の予算は 30 万。超えた計算は地平を縮めてやり直す。**縮めるかどうかは問題だけで決まる**（試行ごとに空の覚え書き・呼ぶ順に依らない）。
- 切った札の値段は損害の側と同じ 1 枚の値段で数える（一律の値段なら手札 1 枚ぶん、`joint` なら予約の平均の値段）。
- 鏡: 自分の耐久も相手と同じ守る側の計算で読む（`theory_bridge.MIRROR_ME`）。

### 鏡の診断（合成・60 局・3416 行）
- 鏡をつけると、合成の rel_K の相関が +0.34 から −0.17 に符号が反転する。**原因は鏡の行の組み立ての誤りではない**
  （相手の耐久と自分の速さは 2 つの走りでビットまで一致。1131 の攻撃の行のうち符号が食い違うのは 2 行）。
- 反転は **3 局**に集中する（鏡なしの 1 局の合計が ±0.1〜0.4 のところ、鏡ありで +17.3・−14.9・−8.3）。この 3 局を除くと
  相関は鏡ありで +0.43・鏡なしで +0.38。局ごとの合計の標準偏差は鏡ありで 3.16、なしで 0.39。60 局のブートストラップで
  相関の差は −0.50（95% 区間 −0.70 から +0.03）。**60 局の線形の相関は、決め手の一撃の数行に支配される指標として読まない。**
  並べ替えの指標である AUC は鏡あり・なしでほぼ同じか、最後を外した行・最後だけの行では鏡ありが良い。
- 仕組み（推定・切り分け未了）: 自分のライフが 0 の行 356 のうち、鏡ありでは自分の耐久がちょうど 0 になる行が **135**
  （鏡なしでは全 3416 行で 11）。相手のライフが 0 の行では 320 行中 31。鏡は「自分」を相手の次のターンの満了状態
  （ドンが戻り、全員が殴れる）で読み、「相手」は自分の今の途中のターンで読むため、自分だけが先に尽きたように見える行が増える。
  両席の耐久が同時に 0 になる行（6 行）では、時計が同じになるので重みが最大になり、決め手の一撃が局の合計を支配する。
- **未決の設計の選択**（ユーザの判断を要する種類ではなく、次の作業で決める）: 鏡で読む時点を揃える
  （(i) 相手も次のターンの満了状態で読む、(ii) 自分を今のターンで読む）か、鏡なしを既定のままにするか。
  どちらも新しい定数は要らない。決めるまで、鏡は `MIRROR_ME` で切り替えられる状態にしてある。
