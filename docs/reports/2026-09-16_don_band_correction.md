# 訂正——付けたドンが「実現」に暗黙に加算されていた（T47 の数字を直す）

2026-09-16・ユーザ指摘「DON box の後ろで測ったなら付けたドンが暗黙的に加算されているということはない？」。
**指摘どおりだった。** 本報告は特定時点のスナップショット（`2026-09-16_block_and_bracket.md` §3 の数字を置き換える）。

## 何が起きていたか

トークンの `power_now` は**所有者のターンには付与ドンを載せる**（`encode/tokens.rs`）。`DON_BOX` で体に付けた
1000·k は次の判断点まで残るので、`S_meas` の `Σν_meas(自分の体)` の帯が上がり（例: 4000 に 2 枚で 6000＝リーダー未満 →
中盤＝+0.08）、**付けたドンが攻撃の実現に化けていた**。リーダーのパワー（`scalars` 12/13）は付与を載せないので無関係。

**直し方**: 帯は素のパワー `power_now − 1000·付与ドン`（トークン列 2）で決める（`price_realised.side_nu_meas`）。

## 読み方

- **T47 の「攻撃は安すぎる側」は保つ**（1.2〜1.5 倍）が、幅は縮んだ。
- **付与の実現 0 は正しい**——付与そのものは在庫を動かさず、価値は攻撃の行に出る。
- **実デッキで組み直しが届く**のは、流れ→在庫の換算（P1）の壁が「思ったより低い」可能性を示す——合成の中盤帯だけが
  高い理由（率 0.89・毎ターン殴る帯）は次に読む。

## 限界

- 一時的なパワー上昇（バフ）は素のパワーに戻せない（トークンに元のパワーが無い）——同じ向きの偏りが残りうる。
- 相手の体の帯も同じ規則で外している（相手のターンでない自分の判断点では相手の付与ドンは載っていないはず）。
