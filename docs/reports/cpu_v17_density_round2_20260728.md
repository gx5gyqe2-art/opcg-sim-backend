# v17 — 密度2周目は逓減（800局 0.530・FAIL）と累積コーパス判定（2026-07-28）

gen7 採用（`docs/reports/gen7_adoption_20260727.md`）直後に、合意済みの追試「**密度ループの
再現性**」を実行した記録。スナップショット（追記・改変しない）。

## 1. 問い

v16 の +50 Elo は「密度→勝率」の**繰り返せるクランク**か、それとも1回きりの回収か。
事前宣言: gen7 で同じ工程（密2,048局→1ep→800局判定）を回し、
PASS（wr≥0.55 かつ CI下限>0.50）なら再現確定、wr<0.52 なら1回分で頭打ちと判定。

## 2. 工程（v16 と同一・計器も同一）

- 生成: gen7 自己対戦 **2,048局 → 231,662行**（113 行/局・q_root 有限率 1.00・seed帯 830000〜）
- 学習: gen7 + 1エポック（lr2e-4・train 0.096 / val 0.102＝v16 とほぼ同じ当てはまり）
- 判定: 較正済み `arena_gate`（対 出荷既定=gen7・seed帯 700000〜＝過去の判定と非重複）

## 3. 結果 — FAIL（グレーゾーン）

| 帯 | 局数 | 勝率 |
|---|---|---|
| band0 | 200 | 0.510 |
| band1 | 200 | 0.540 |
| band2 | 200 | 0.520 |
| band3 | 200 | 0.550 |
| **通算** | **800** | **424/800 = 0.530 · CI[0.499, 0.561] · Elo +21 → FAIL** |

事前基準との照合: **PASS でも撤退でもない**（0.52 ≤ 0.530 < 0.55）。CI下限 0.499＝
ゼロと区別できない。1周目（0.571 [0.540, 0.603]）との対比で**逓減は明確**。

## 4. 読み

1. **密度ループは +50 Elo の繰り返せるクランクではない**。1周目が「密レジーム不在」という
   ボトルネックを一度に回収し、2周目に残っていた余地は +20 Elo 程度（未確証）だった
2. 帯間差 0.040（0.51〜0.55）で1周目と同様に安定＝計器のばらつきではなく効果自体が小さい
3. 学習の当てはまり（val mse）は両周でほぼ同じ＝「学習が壊れた」のではなく「教える中身の
   限界効用が落ちた」

## 5. 追加判定（生成コストゼロ）: 累積コーパス

グレーゾーンの切り分けとして、既存データだけで作れる対照を判定に掛けた:
**gen6 + (v16∪v17)=468,049行 1エポック** vs gen7（=gen6+v16 のみで学習済み）。
- これが gen7 に**勝つ**なら: 量でまだ押せる（頭打ちは corpus 量の問題）
- **勝てない**なら: 1周分の密度でこの学習仕様の回収は完了（頭打ちは方式の限界）

→ **結果: 一次スクリーンで棄却**（45/96 = 0.469 < floor 0.48）。gen6 に倍量の密コーパスを
与えても gen7 に勝てない＝**頭打ちは corpus 量の問題ではなく、この学習仕様（1ep 追い学習）の
回収限界**。切り分けが付いた。

## 6. 現状の結論

- **gen7 は維持**（v16 の証拠は不変）。gen8 候補は無し
- **密度の追加周回は打ち切り**（2周目グレー＋累積スクリーン棄却の2点で確定）。
  v16 の正しい要約は「密度が**不足していた**ことが gen6 踊り場の主因の一つで、一度の回収で
  その分の伸び代は使い切った」
- 次の柱の候補は v15 §4 の残課題（探索が踏む分布での value 較正＝TD/ブートストラップ設計）か、
  実プレイからの新規マーク採取（コーチゲート標本の現代化＝gen4 期由来 7点の置き換え）
