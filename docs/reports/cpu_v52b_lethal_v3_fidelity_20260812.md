## 3. 読み — なぜ「賢くする」と壊れるか

1. **対称な強化は相殺する**: 攻守両方を賢くすると、相互リーサル盤面では「どちらも通せる／
   どちらも守り切る」へ再収束し引分が爆発（v2 の 16 → v3a の 34）。v1→v2 で引分が
   減った（30→16）のは**非対称**（守りだけ足した）からで、忠実度そのものの効用ではなかった。
2. **v2 は「立ち盤面の脅威の質」の代理量**: ドンを盛らずブロッカーも使わない粗いレースは
   「今の盤面が素で持つ圧力」を測る。実プレイ（レフェリーラベル）の EV はこの量と最も整合する。
   v3 は「全資源投入時の強制結果」という**別の量**で、実プレイの資源温存均衡から遠い。
3. 攻め/守りの分離（parts）でも両側とも単独で悪化＝単一バグではなく設計レベルの現象。
