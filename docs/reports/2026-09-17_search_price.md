## 結論を 5 行で

1. **価格の定義**: 探す能力（k 枚見て手札に加える）= `E[ max_{取れる札 ∈ k 枚} max(ΔH_play, ΔG_guard) ] − 費用`。取れる札＝**自分のデッキ**
   （記録の seed から復元・手札で検算 600/600 席）のうち絞り込み（特徴・名前・「名前かイベント」・カード種・コスト）に合う札。
   k 枚は非復元・合う札が無ければ 0・**探す札を出した後の手札とドン**で読む。`sel(k)`（山札全体の静的 `W` の最大）と手札 1 枚の μ は足さない。
2. **登場の `LOOK` の価格が実現に並んだ**: 実 0.179 → **0.122** 対 実現 0.123（比 0.69 → **1.00**）・合成 0.128 → **0.067** 対 0.074（0.58 → **1.12**）。

3. **見当違いの探しが高く評価されなくなった**: OP15-118（取れる札がデッキに無い探し・見つけた率 0）の効果 0.063 → **0.009**、ウタ OP09-002
   （出せない大物を探す・T66）0.131 → 0.019。プリン OP12-071 0.123 → 0.062 対 0.067（比 1.08）・ルフィ OP16-034 0.101 → 0.062 対 0.063（1.02）。

   0 にはならない）・来る攻撃が在ればカウンター札で `ΔG` が立つ。「それより後」の枠を `10 × max(1, R − 3)` にしたので最終盤（R ≤ 3）は先の枠が 1 ターンぶん。

## 3. 読み方

- **平均は合った**: 「探す能力の価格 ＝ 取れる札のうち今の手札に要る札の価値」で登場の `LOOK` の価格が実現の水準（比 1.0／1.1）に並んだ。
  旧価格の余り（`sel(k)`＝実現の 2.4〜3.4 倍・T59/T65）は、絞り込みと手札の状態を無視して「山札全体の最大」を足していたぶんだった。
- **見当違いの探しは 0 に近づく**: 取れる札がデッキに無い探し（OP15-118）は 0.009、出せない大物しか取れない探し（ウタ）は 0.019。
  CPU がこれらを打つ行は「体の価値だけ」で評価される＝理論の側は正しく評価している。CPU の探し方（ウタ型）の改善は別件（訓練の側）。
- **行ごとの相関の低下は物差しの側**: 次の判断点の盤面差は手札 +1 枚を μ で数える（罠 32）。価格は「その札が今の手札に要るか」で 0〜満額に
  散るので、行単位では合わない。合わせるには物差しに手札の質（`H_play + G_guard`）を入れる必要がある＝帳簿の側の置き換え（次）。
- **合成で価格の p10 が負**（−0.017）: 取れる札が無い／要らない探しは効果 0 で、体（`ν − μ`）より機会費用が高い札が負になる。旧価格では
  `sel(k)` が隠していた。
