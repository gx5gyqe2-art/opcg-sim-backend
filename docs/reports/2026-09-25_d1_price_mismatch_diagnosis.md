# D-1: 型ごとの値段の不整合——effect族のゲーム単位逆相関は交絡・playの"?"バケットの符号反転は分類と値付けの契機の食い違い(2026-09-25)

`price_realised.py`(T41)を今の既定(C-4採用後)で実局300局・合成局900局に対して回し直し、型ごとの
「値段 対 実現」の不整合を挙げた。基準線(`2026-09-25_baseline_current_defaults.md`)が保留していた
「effect族の実0.522・合成10.949の食い違い」の切り分けと、新たに見つかった2件を、ワークフロー
(診断2本×検証2本・独立4エージェント)で調べた。読み取りだけ・新定数ゼロ・式は変えていない。

## 器と測り方

```bash
OPCG_LOG_SILENT=1 python tests/scripts/price_realised.py --in <実 n_records dump v5> --out real.json
OPCG_LOG_SILENT=1 python tests/scripts/price_realised.py --in <合成 n_records ×2> --out syn.json
```

`price_realised.py`は6つの表を出す: `by_family`(型ごとの値段/実現)・`effect_by_action`/
`play_by_onplay_action`(効果・登場時効果を最初の動作の型で割る)・`turns_by_flow_effect`(ターン単位)・
`play_breakdown`(登場の内訳)・`by_family_games`(局ごとの値段差/実現差と勝敗のAUC・傾き)。
`C-4(THETA_RETURN_MODE=untap・ATTACK_REST_MODE=return)はこの器の値段そのものには影響しない`
——両席の耐久軸への配分（`kappa_vector.axis_of_move`）を変えるだけで、`score_candidate`が返す
生の価格`v`は変わらない。実測でも攻撃族の比は基準線と完全に一致した(実1.014・合成1.108)。

## 診断1: effect族のゲーム単位逆相関(実AUC 0.195)——**交絡・修正不要**

**結論(高確信)**: `RAMP_DON`(ドンを加速する効果)1種が効果族の48%(639/1331行)を占め、
**その使用は最終的に負けた側に強く偏っている**(639件中506件=79%が敗者側・独立検証で確認)。
除外すると残りの効果(ACTIVE_DON・GRANT_KEYWORD・DRAW・ATTACH_DON・BUFF)はほぼ無相関
(実AUC 0.459・合成の0.526と符号も水準も近い)——**行単位の値付けに欠陥はない**。

異常値駆動でもない(上位1/2/5/10/20局を落としてもAUC 0.195→0.218の範囲で動かない・300局に
広く分布)。頻度そのものが信号の主成分(`RAMP_DON`の使用回数だけのAUCも0.250でほぼ同じ)。

**機構は「劣勢だから使う」の反応的プレイか、席・デッキ単位の持続的傾向か**——中確信(独立検証で
補強): 瞬間のライフ劣勢で割ると382/257(劣勢/優勢)でAUC 0.242/0.359だが、**最終的な勝敗で割ると
506/133と大きく偏り**、しかもその506件の74%は「その瞬間はライフ劣勢ではない」行で起きている。
反応的プレイだけでは説明しきれない、席・デッキレベルの持続的傾向が主犯の可能性が高い。

**判断**: どちらの機構でも**価格式を直す理由にはならない**——これは「あるプレイスタイル・デッキが
弱い」という交絡であって、「ドン加速という手の値段が間違っている」ことの証拠ではない。D-2の対象
から外す。

## 診断2: playの"?"バケットの符号反転——**分類と値付けの契機の食い違い(修正対象)**

`play_by_onplay_action`の"?"(登場時効果なしと分類された行)は実で**符号が反転**する:

| 記録 | n | 割合 | price_mean | real_mean | ratio |
|---|---|---|---|---|---|
| 実(300局) | 1650 | 39% | +0.0106 | **-0.0102** | -0.957 |
| 合成(900局) | 3782 | 43% | +0.0270 | +0.0380 | 1.407 |

**原因(高確信・独立に2回確認)**: `effect_value.py`に2つの契機の集合がある——

```python
ON_PLAY_TRIGGERS = ("ON_PLAY", "ACTIVATE_MAIN", "MAIN", "RULE", "PASSIVE", None)   # 体なしカード用に広げてある
CHAR_ON_PLAY_TRIGGERS = ("ON_PLAY",)                                              # キャラはこれだけ
```

`price_realised.py`の**分類**(`primary_action(cid, EV.CHAR_ON_PLAY_TRIGGERS)`)は**狭い集合**しか
見ないので、`ON_PLAY`契機を持たないカードは全部"?"に落ちる。一方`theory_order.play_price_of`の
**値付け**(`_effect_value(cid, "on_play", ...)`)は**広い集合**(`ACTIVATE_MAIN`を含む)を通すので、
`ACTIVATE_MAIN`契機のカードの効果も登場の値段に足し込む。**"?"に分類されるのに値段には効果が
入っている**行が混ざる。

実測で"?"の69%(1136/1650)がイベント(コスト0の近縁5種・OP15-074〜078が982行)で、そのイベントの
`real_mean`は**理論値`-μ`(-0.0551)と5桁一致**——「手札を失った以外、何も実現していない」ことを
示す。合成側は"?"の68%が素のキャラ(登場時効果なしの体・値段と実現が同じ符号でratio 1.18-1.27と
健全)で、イベントは29%とシェアが小さく符号を反転させるまで至らない。実デッキがこの5種を多く
使ったことが実測だけで符号を反転させた。

**候補(a)(DONの機会費用の二重計上)は棄却**——`v`は`play_cost_term`(機会費用)を既に引いており、
`gross`(足し戻した額)で比べても"?"は依然として逆符号(`ratio_real_over_gross = -0.505`)。
**候補(c)(小標本のノイズ)も棄却**——`real_mean`のブートストラップ95%CIは`[-0.0161, -0.0030]`で
0を大きく外れる。構造的な効果。

**未確定点(D-2で先に潰す)**: OP15-074〜078はカードDB上`event=True`・トリガーは
`['ACTIVATE_MAIN', 'COUNTER']`(独自に確認)。イベントは1回使って捨て札へ行く札なので、
**「`ACTIVATE_MAIN`契機のイベントの本文は、プレイした瞬間に解決する」という値付け側の前提
(EB04-009の実測で採った広い集合の根拠・`effect_value.py`のコメント)がこの5種にも当てはまるはず
だが、実測はそれを裏切っている**。2つの可能性が残る: (i) 値付け側の前提がこの型のカードには
誤りで、分類だけでなく値付けの契機集合も直す必要がある、(ii) 値付けの前提は正しいのに**Rustの
エンジン側でこの効果が実際に発動していない**(理論の外の問題)。**D-2の最初の一歩は、この5枚が
どこか別の行で(例えば効果族のACTIVATE_MAIN発動として)実際に値を実現している形跡があるかを
記録で確かめること**——無ければ(ii)の疑いが強まり、理論のD-2では直せない。

## D-2への申し送り

* **対象は「playの"?"バケットの契機の食い違い」だけ**——effect族の逆相関は交絡と確定、式は
  変えない。
* D-2の最初の作業は上記「未確定点」の記録調査(読み取りだけ)。(i)なら分類・値付け双方の契機
  集合を型(イベント/キャラ/ステージ)で揃える式を書く。(ii)ならエンジン側の欠陥報告として別立てし、
  理論のD-2はここで一区切りにする。
* attach族は既知の型(T144/T155/T156)なのでD-2の対象にしない。
