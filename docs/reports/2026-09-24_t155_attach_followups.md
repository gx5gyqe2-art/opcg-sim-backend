# T155／T155b: 付与の 2 手読みの頭打ち（63%）を「同じターンの続き」で割る（2026-09-24）

ユーザ指示（2026-09-24）「②理論が 2 手先を読めるように直す → 9 割から 6 割までは下がったが、そこで頭打ち…を
もっと詰めてから考えましょう」。T144 は純付与（殴らずにドンを付けるだけの手）の価格を「それが準備する攻撃の
価格」に読み替え（枚数が同じか少ない攻撃候補の最大）、付与の禁じ率を 93%／91% → 63%／60% に下げた。それでも
攻撃自身の禁じ率（49%／40%）より高い。残りは「理論の正しい判定」か「物差しがまだ読めていない何か」か——
**式ではなく、同じターンで実際に打たれた続きで割る**（新定数ゼロ・判定は 1 ビットも変えない）。

**記録**: 実＝seed 50000〜50019（`--decks user`）／合成＝51000〜51019（`--decks synth`）・各 20 局・介入なし・
`--seq attack_le`。最初の 10 局は T144 と同じ seed。**既定は T151-6／T152 採用後**（`mirror`＋`half`＋`game`）。

---

## 0. 結論（先に書く）

**頭打ちの正体は 2 つに割れた。** 読み替えても禁じられた付与（実 112 行／合成 122 行）のうち:

| 中身 | 実 | 合成 | 読み |
|---|---|---|---|
| **順番の問題**——理論の最善（同じ型・同じ札）が**同じターンの後で実際に打たれた** | 47（42%） | 49（40%） | 物差しが 1 手ずつ見るせいの見かけ。CPU は理論の最善も打っている |
| うち理論の最善が「攻撃」 | 18／18＝**100%** | 22／22＝**100%** | 付けてから殴った＝箱を 2 手に分けただけ |
| うち理論の最善が「別の付与」 | 22／45（49%） | 27／42（64%） | 同じ札に枚数違いで付ける（31%／36% が同じ札） |
| **本物の対立**——理論の最善が「出す手」で、**その手はそのターンに打たれなかった** | 41／46（89%） | 58／58（**100%**） | 「付けて殴る」か「手札を出す」かの二者択一で CPU は前者を選んだ。理論と CPU の判定が本当に違う |
| その他（別の付与で打たれなかった・効果） | 24 | 15 | |

順番の行を数えなければ、付与の禁じ率は **60.1% → 41.5%（実）・57.7% → 40.2%（合成）**＝**攻撃自身の禁じ率
（48.9%／40.7%）と同じ水準**。**T144 で「攻撃の水準に届かない」と書いた分は、丸ごと順番の問題だった。**

**予告の当否**: 4 本のうち **3 本当たり・1 本は殺す基準が発火**（§3）。外れた 1 本が本 T でいちばん重要——
「出す手」を薦めた行は順番ではなく本物の対立で、**T18 で勝率を動かす候補はここ**（実 41・合成 58 行・
逸脱の大きさは手札 1 枚ぶんの価値の約 1.0〜1.2 倍）。

**読み替えられなかった付与**（静的価格のまま・57／56 行・禁じ率 70%）は **100% が「その札に攻撃候補が
1 つも無い」**（今のターンに殴れない札に 1 枚付ける・リーダー 0 件・【ドン!!×N】の条件を持つ札 0 件・
後で起動した行 5%／2%・ターン 8 以降に集中）——規則上の価値が無い手で、理論が代わりに薦めるのは「出す手」
（30／40 と 30／40）。**温度の手（序盤 4 ターンの探索ゆらぎ）ではない**（ターン 4 以下は 1／40・0／40）。

**T155b（順番の問題を読みで消す・§6）**: 順番の行の 31%／36% は**理論の最善が同じ札**（枚数違いの攻撃か付与）。
規則上ドンは 1 ターンに何度かに分けて付けられるので、「今 k 枚付ける」手の価値は「この札がこのターンに最終的に
何枚乗せて殴るか」で決まり、k 以下に限る理由が無い。第 4 の読み `attack_any`（同じ札の攻撃候補を枚数を問わず読む）を
足して同じ 20 局で測った——結果は §6。

## 1. 問い

T144 の読み替えの後に残る付与の禁じ（63%／60%）は、(a) 理論の正しい判定か、(b) 物差しが読めていない何かか。
式を足す前に、**同じターンの続き**（付けた札がその後殴ったか・理論の最善がその後打たれたか）で割る。

## 2. 器（新定数ゼロ・判定は不変）

`shadow_forbid.py`: 行に局・席・ターン・手番と選んだ手／最善の署名を添え（`sequence_columns`）、`collect` は
判定できない決定点も `trace` に残す。`turn_followups`＝付与の行ごとに同じターンの後の手を引く
（`atk_later`＝付けた札が後で殴った／`act_later`＝後で起動した／`best_later`＝理論の最善と同じ型・同じ札の手が
後で打たれた）。`followup_table`＝「読み替えた／静的」×「禁じた／禁じない」の 4 マス＋最善の型別。

## 6. T155b: `attack_any`（同じ札の攻撃候補を枚数を問わず読む）

**式（新定数ゼロ・規則から）**: 純付与（札 X・k 枚）の価格 ← X の攻撃候補の最大価格・**枚数を問わず**。
`attack_le`（k 以下）は「箱の生成器が付与と攻撃で違う枚数を出す」ことへの対処だったが、T155 で「同じ札に
枚数違い」の続きが実際に打たれていた＝ドンは 1 ターンに分けて付けられる（規則）ので、k で切る理由が無い。

**予告（`seq_prices` の docstring に測る前に書いた）**: (1) 付与の禁じ率は 60%／58% から**攻撃の禁じ率
（49%／41%）±5 ポイント**に下がる（殺す基準: 55% 超のまま）。(2) 最善が「出す手」の禁じ行（41／58）は動かない。
(3) 付与以外の型は 1 行も動かない。

**結果（同じ 20 局×2・打たれた局面は行ごとに同一）**:

| | 実 `attack_le` → `attack_any` | 合成 `attack_le` → `attack_any` | 予告 |
|---|---|---|---|
| 付与の禁じ率 | 0.601 → **0.447** | 0.577 → **0.409** | 攻撃（0.489／0.407）±5 ポイント → **当たり**（−4.2／+0.2） |
| 読み替えた付与の禁じ | 112／196 → **73／196** | 122／225 → **75／225** | |
| うち順番（最善が後で打たれた） | 47 → **10** | 49 → **7** | |
| うち最善が同じ札 | 35 → **1** | 44 → **0** | 消える |
| うち最善が「出す手」（本物の対立） | 41 → **41（同じ行）** | 58 → **58（同じ行）** | 動かない → **当たり** |
| 残りの内訳（最善の型） | 出す手 46・別の付与 21・攻撃 3・効果 3 | 出す手 58・別の付与 11・攻撃 6 | |
| 静的のままの付与の禁じ | 40／57（不変） | 40／56（不変） | |
| 付与以外の行 | 453／1,014 で**ビット一致** | 311／749 で**ビット一致** | **当たり** |
| 全体の禁じ率 | 0.478 → 0.447 | 0.459 → 0.414 | |

**予告 3 本とも当たり・殺す基準は発火せず。** 「同じ札に枚数違い」の見かけは読みで消え、付与の禁じ率は攻撃と
同じ水準に落ちた。**残った禁じの中心は「出す手」との本物の対立**（実 46／73・合成 58／75）で、これは読み方を
変えても動かない＝**T18 で試すべき介入はここ**。

**`attack_any` は T144 の `attack_le` の上位互換として推薦**（`attack_le` が対処した「箱の生成器の枚数の組が
違う」問題は `attack_any` が包含する・規則の根拠は上・新定数ゼロ）。既定は `off` のまま（ユーザ判断）。

## 7. 上手くいったこと／いかなかったこと

**上手くいった**: 式を足す前に「打たれた続き」で割ったので、**残りの禁じが 2 種類（順番／本物）に分かれ、
順番の分を除くと攻撃と同じ水準になる**ことを、新しい価格式を 1 つも足さずに言えた。T144 の「攻撃の水準に
届かない」の説明がついた。

**いかなかった**: 予告 1 は外れた（「出す手」は順番ではなかった）。外れた方が有益だったが、予告を書いた時点で
「出す手はドンを使わないので付与と両立しうる」と考えた根拠が浅かった——実際には付けて殴るとドンが無くなり、
出す手は打てない。**二者択一だと気づけたはずだった**。
