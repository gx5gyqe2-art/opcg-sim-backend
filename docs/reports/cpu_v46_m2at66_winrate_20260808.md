# v46 m2@66 の勝率測定 — 裁定は「より勝つ側」を不合格にしていた（2026-08-08）

v45（`cpu_v45_m2at66_root_cause_20260808.md`）で m2@66 の未達が「ply0 の初手選択」に還元されると
特定した。その §5 で「直しても勝率に効くとは限らない」と留保した点を、レフェリー32世界（CRN）で
実測した記録（この時点のスナップショット・追記改変しない）。

## 0. 結論

**裁定の基準（4件すべて消化）には勝率上の裏付けが無く、それどころか裁定が不合格にしている側の
初手のほうが勝率が高い。**

| 初手（強制）| 勝ち | ライフ差 | 判定 |
|---|---|---|---|
| Mr.3 起動 → 効果解決 → **リーダー攻撃** | **19/32** | +0.59 | ★ 最良 |
| Mr.3 起動 → 効果解決 → **ロビン攻撃** | 18/32 | +0.44 | ≈ 同価値 |
| ロビン攻撃（Mr.3 なし） | 14/32 | −0.34 | バンド外 |
| リーダー攻撃（Mr.3 なし） | 13/32 | −0.91 | バンド外 |

読み取れることは2つ。

1. **効くのは「Mr.3 の起動を攻撃より先に置くこと」**。攻撃を先にする2腕（13/14）に対し、
   Mr.3 を先に置く2腕（18/19）は **+4〜+6勝**。ライフ差も −0.91〜−0.34 から +0.44〜+0.59 へ
   一貫して反転する。レフェリーの対判定でも下2腕は同価値バンドの外。
2. **リーダーが先か他のキャラが先かは効かない**。Mr.3 有りで 19 vs 18、無しで 13 vs 14＝
   どちらも1勝差＝ノイズ。v45 で見つけた「リーダー先攻なら 11/11 で4件消化」という
   完全分離は事実だが、**その4件消化には勝率上の価値が無い**。

## 1. 裁定が逆を向いている

コーチゲートで**不合格**になる CPU の実際の手順は `Mr.3起動 → ロビン攻撃 → ナミ攻撃`（3/4 消化）で、
その初手は上表の **18/32（同価値バンド内・上位）**。一方、**合格**する 4/4 の筋は
リーダー攻撃から入る（v45 の分割表で 11/11）が、リーダー攻撃を先に置く腕は **13/32** で
バンド外まで落ちる。

**ゲートは、より勝つ手順を落として、より勝たない手順を通している。**

## 2. 計測上の落とし穴（今回踏んだ）

- **プランモードは攻撃を含む複数手順を表現できない**。1手適用するたびに手番が相手の防御窓へ
  移り、次の手順が `legal_actions` に現れず「不成立」になる。過去 m2@66 のレフェリー測定が
  「単発攻撃どうしの比較」だったのはこの制約による＝**「4件消化 vs 3件」を直接測る計器は
  そもそも存在しなかった**。裁定が「順序はほぼ等価」と判断した根拠もこの制約下の測定である。
- **プランを効果解決ダイアログの途中で終わらせると結果が壊れる**。単手順
  `ACTIVATE_MAIN:OP16-056` は **0/32** を返したが、`>RESOLVE_EFFECT_SELECTION>ATTACK:…` まで
  含めると 18〜19/32 になる。**約19勝ぶんの人工物**であり、0/32 を「Mr.3 起動は致命的」と
  読むのは誤り（本作業で一度そう誤読し、追試で反転させた）。
  → `--plans` の手順は**自分の対話が保留されない位置で終える**こと。
- 4腕は強制する手数が 1手 と 3手 で揃っていない（長い前置きはロールアウトの自由度を削る）。
  ただし Mr.3 の有無による差は攻撃の選び方に依らず同じ向き・同程度に出ており、
  レフェリーの対判定もバンド外と判定している。

## 3. 次にやるべきこと（ユーザ判断）

v45 §6 で挙げた「accept を ply0 のリーダー攻撃に絞る」案は**破棄**する（勝率が支持しない）。
残る選択肢は次の2つ。

1. **m2@66 を取り下げる**。m2@64 / m4@8 / m4@12 / m1@42 / m1@94 と同じ扱い＝
   「裁定の前提が実測と食い違い、確定できるまで検証済み集合から外す」。
   CPU は既に全 seed で Mr.3 を起動しており、勝率上の誤りは観測されていない。
2. **基準を「Mr.3 の起動を攻撃より先に置く」に立て直す**。上表がそのまま根拠になる。
   ただし CPU は失敗 seed でも成功 seed でも Mr.3 を起動しており、**先に置くか後に置くかで
   16seed 中どれだけ外すか**は未測定なので、立て直すなら先にその測定が要る。

いずれにせよ **v44 と同じ教訓が2例目として確認された**——ゲートの点を動かすこと自体には
価値が無く、**その点が勝率に効くかを先に測る**。v44 はプラン読み出し（7.44→7.50＝ノイズ）、
v46 は m2@66（満点にしても勝率は上がらず、むしろ下がりうる）。
