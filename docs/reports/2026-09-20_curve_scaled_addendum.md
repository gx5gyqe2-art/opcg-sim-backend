# T126 追記: 「速さを時計に入れるのは正しいのか」——判別の損失は**推定の尾**であって**軸の存在**ではない（2026-09-20）

ユーザの問い:

> 入れる入れないはどっちが正しいの？

**`2026-09-20_curve_scaled.md` は特定時点の記録なので改変しない。** ここが答えと追試。

---

## 0. 答え: **入れるのが正しい**

**2 つの別の問いが混ざっていた**ので分ける:

| 問い | 答え |
|---|---|
| **速さ `A` は時計に入るべきか** | **入るべき**（下の §1・理論の話・選択の余地は無い） |
| **今の `A` の推定は生で使えるか** | **使えない**（下の §2・実測・尾が判別を壊す） |

**前回の報告は 2 つを分けずに「採らない」と書いた**ので、
**「`A` を入れないのが正しい」と読めてしまう**。それは誤り。

---

## 1. 理論: `curve` は「`A` を入れていない模型」ではない

**輪郭は「平均の損害/ターン」＝平均の速さそのもの**である。だから `curve` は

> **`A` を見ていない模型**ではなく、**全員に平均の `A` を割り当てた模型**

である。**入れるか入れないかではなく、「その席の `A`」か「平均の `A`」かの選択**でしかない。

そして規則が決める事実——**出した体は次の自席ターンから毎ターン殴る**。
**平均を割り当てる模型は、体を出す手の効果を厳密に 0 と言う**（実測 `dead_share` 44.96%）。
**これは較正の違いではなく誤り**である。だから**入れるのが正しい**。

---

## 2. 実測: 判別の損失は**尾**であって**軸**ではない

**倍率 `A/prof_th[j]` の分布は中央 0.676 に対し 99% 点 55.1**（`j=0` の帯・打ち切りに貼り付く行 5.0%）。
**尾のせいなのか軸のせいなのかを切り分けるため、倍率を `[0.5, 2]` に締めて測った**
（**定数を 2 つ置くので理論には入れられない・診断専用**）:

| | `curve` | `curve_scaled` | **＋倍率の締め** |
|---|---|---|---|
| 実 未決着帯 `rel_flat` AUC | 0.9384 | 0.6595 | **0.8827** |
| 合成 同 | 0.9462 | 0.8171 | **0.8903** |
| 実 `sep`（較正・理想 1.05） | 0.5652 | **−0.1303** | **+0.0803**（符号が戻る） |
| 合成 `sep`（理想 0.956） | 0.6399 | 0.0690 | **0.2127** |
| `dead_share`（速さの軸が生きているか） | 0.6918 | 0.4192 | **0.4563**（生きたまま） |
| P5 の破れ／P7 の破れ | 19,051／0 | 6,429／17,940 | 8,013／18,510（**改善しない**） |

**読み**:

* **締めるだけで失った判別の 57〜80% が戻る**（実 0.6595 → 0.8827＝差 0.279 の 80%・合成 0.8171 → 0.8903＝57%）。
  **しかも速さの軸は生きたまま**。**＝損失の主因は `A` の推定の尾**。
* **較正の符号反転も戻る**（−0.1303 → +0.0803）。
* **残りは尾で説明できない**（締めても実 0.8827 < `curve` の 0.9384）＝**約 2 割は別の原因**。
* **P5／P7 は締めても直らない**＝**不変量の問題は尾とは別**で、前回書いた
  **「輪郭が絶対のターン番号で索引されている」**が原因のまま。

## 3. だから結論は 2 つに分かれる

| 欠陥 | 正体 | 直し方 |
|---|---|---|
| **判別を失う** | **`A` の推定が重い尾を持つ**（中央 0.676 対 99% 点 55.1） | **`A` をましな推定にする**＝**T94 の積み上がる歩き**（盤面が育つから速くなる・状態から出る） |
| **尺度不変でない（P5）・速さの共通誤差に弱い（P7）** | **輪郭が絶対のターン番号で索引されている** | **表を捨てる**（加速を状態から出す）＝同じ道 |

**2 つとも同じ次の一手を指している。**

**`curve_scaled` を既定にしないという判断は変わらない**（締めなしでは判別が崩れ、締めは定数を 2 つ置く）。
**変わるのは理由**——「`A` を入れるのが間違いだった」ではなく「**入れ方（平均の表を伸縮する形）と `A` の推定が足りない**」。
