## 1. 式（実装の前に書いた）

### 1.1 守り手が止められる量（パワーの単位・守る側の計算が既に持つ量だけ）

- 手札: `K₀ = max { Σ_{S} c : S ⊆ 手札のカウンターの札, Σ_{S} d ≤ D }`（`c` は札の止める量〔カウンター／カウンター・イベントの上げ幅〕・
  `d` はその札に払うドン・`D` は守り手のドン。守る側の計算の入力 `cards`・`don` そのもの）。
- 引く札: 1 ターンに 1 枚引く札の止める量の期待 `d̄ = Σ_t p_t · c_t`（守る側の計算の入力 `draw_types` の `(c, d, p)` のうち `d ≤ D`）。
- 攻め手の段 `j`（1＝今のターン）の量: `K₁ = K₀`、`K_{j+1} = max(0, K_j − U_j) + d̄`（`U_j` はその段で止めに使った量）。

### 1.2 そのターンの攻撃の並びの値段 `TV(xs, K)`

攻撃 `i` の超過 `x_i`（攻め手のパワー − 守り手のリーダーのパワー）。`x_i < −ε` は当たらない（0）。

- 止める値段 `g_i = c̄(x_i) · ḡ`（止めるのに要る札の枚数 × 守り手の 1 枚の値段——**今と同じ**）。
- 止めないときの値段 `a_i = min(λ_net, ブロッカーの値段)`（受ける＝ライフ 1 枚＝**守る側の計算と同じ `λ_net`**〔`cut_take_price`〕・
  ブロッカーは今と同じ `block_cost`）。
- 止めるのに要る量 `n_i = 1000 · ⌈(x_i + 1000 − ε) / 1000⌉`（規則: カウンターは 1000 単位・守り手のパワーが攻め手を上回る量）。
- `g_i < a_i` の攻撃を `n_i` の小さい順に、`Σ n ≤ K` の間は止める（値段 `g_i`・`U += n_i`）。残りは `a_i`。
  `TV = Σ_i（選んだ値段）`。（守り手は止める本数を最大にする——止めて得る差 `a_i − g_i` はほぼ一律なので。）

**今との違い**: 今は攻撃 1 本ずつに `min(g_i, take)` を付け、手札の量を見ない。しかも付与の値打ち（`_attach_gain`）の `take` は
`θ·ḡ + 0.89·(ḡ − tc)`（`μ` の場所に `ḡ` が入っている）で、`ḡ` が小さいと受ける値段まで 0 近くになる。新しい式では受ける値段は
守る側の計算と同じ `λ_net = θ·μ + 0.89·(μ − tc)`。

### 1.3 どこに使うか（攻め手側の静的な値段だけ・守る側の解き方には触らない）

| 場所 | 今 | 新 |
|---|---|---|
| `rules_steps` 段 `j ≥ 2` の付与の値打ち（体 `i` に `k` 枚） | `attack_value(x_i + 1000k) − attack_value(x_i) − kδ` | `TV(B_j with x_i+1000k, K_j) − TV(B_j, K_j) − kδ`（`B_j` は盤面の付与なしの並び） |
| `rules_steps` 段 `j ≥ 2` の出す札の値打ち | `atk + eff`（`atk`＝札 1 本の `attack_value`） | `TV(B_j ∪ {x_札}, K_j) − TV(B_j, K_j) + eff`（体でない札は今のまま） |
| 段の `fb`（地平の外の段の速さ） | 盤面の素の値段＋出した札の `atk`＋速攻＋付与の値打ちの和 | `TV(hits_j, K_j)`（その段の攻撃の並び全部）・`U_j` で `K` を減らす |
| 流入 `a_tab[l]`／`ar_tab[l]` | 山の体 1 枚の `attack_value` の平均（ブロッカーなし） | 山の体 1 枚を盤面の並び `L`（付与なし）に足した `TV(L ∪ {x}, K₂) − TV(L, K₂)` の平均（`K₂` は盤面だけで 1 段目を攻めた後の量） |
| `flow[l]` | `a_tab[l] + e_tab[l]` | 同じ（新しい `a_tab` で） |
| 地平の見積もり（`model_horizon`）の素の速さ `a0` | `lead_bare + chars_bare`（毎段同じ） | 段ごとに `TV(att1, K_j)`（`K_j` は同じ並びで減らす）＋流入 `× (j − 1)` |

**新定数: ゼロ**（`ḡ`・`λ_net`・`c̄`・`δ`・`ε` は既に在る・1000 と「1 ターンに 1 枚引く」は規則・`K₀`・`d̄` は守る側の計算の入力）。
`SOLVER_VERSION` を `rd-speed-7` に上げる（計画のディスクの鍵が古い計画を拾わないように）。

## 結論（§1・§2 の後に書いた）

1. **予告は主な点で外れた**【実行】。2 段の値段で打ち切りは**減らずに増えた**: 合成 70 → **197**（0 で止める版 189）・実 9 → **33**（24）。
   σ_T は合成 2.004 → **2.592**（2.460）・実 1.412 → **1.644**（1.608）。予告（合成 20〜40 本・σ_T 1.5〜1.75、実 0〜3 本）は外れ。
2. **類 A は減ったが、類 B に移った**【実行】: 合成の打ち切りの類は A 45 → 33・**B 25 → 162**（0 で止める版 154）。新しい類 B の時計は
   守る側の計算の段の数が中央値 9 → 18、耐久 `θ` が 1.95 → 2.59 に伸び、守り手の生存は中央値 16 ターン、30 ターンで `θ` の 78% までしか
   積めない。＝`syn_truncation` §4.4（候補だけを `μ` で）と**同じ失敗の形**——先の段に攻撃が並ぶと、守る側の計算が「安い札で毎ターン
   止め続ける」と言い、期待値の歩きは最後の枝が倒れるまで耐久に届かない（類 B の機構・①の芯と同じ）。
3. **打ち切りの外では少し良い**【実行】: 打ち切りを除いた勝った席の時計は、合成 偏り +0.331 → +0.275・ばらつき 1.611 → 1.578、
   地平の内の勝った席 +0.218 → +0.171（0 で止める版）。実はほぼ不変（+0.027 → +0.042・1.412 → 1.465）。
4. **殺す基準（実の偏り < −0.3）には当たらない**（実 +0.058）。ただし §0.7 の「悪化したら採用しない」に当たる——**推薦は不採用**
   （§7 の判断事項 1）。
5. **類 C（`λ_net` < 0）**: 2 段の値段は受ける値段に `λ_net` を使うので、`ḡ` > 0.153 の守り手で攻め手側の値段が負になる道を新しく開いた
   （流入が負の時計 実 6 → 32）。旧い付与の値打ちは受ける値段が `θ·ḡ`（`μ` の場所に `ḡ`）で負にならなかった。規則（攻撃の宣言は任意）から
   **攻め手側の 1 本の値段を 0 で止める**を別コミット（`be0bb677`）で入れた: 実の打ち切り 33 → 24・σ_T 1.644 → 1.608、合成 197 → 189・
   2.592 → 2.460。**守る側の計算の中の `λ_net`（類 C の本体）には触っていない**（`KERNEL_FILES` の入力の意味を変えるため・§7 の判断事項 2）。

## 7. 司令塔への判断事項

1. **2 段の値段を採るか**——推薦は**採らない**（`badd99df9` に戻す）。交点の橋の看板（打ち切り・σ_T）が両方の記録で悪化し、予告の主な点が外れた。
   打ち切りの外では少し良い（合成の地平の内の偏り +0.218 → +0.171）ので、**類 B（期待値の歩きが最後の枝でしか耐久に届かない）を
   ①の本体と一緒に直した後に、2 段の値段を測り直す**のが筋。課題②の主因（類 A）は直したが、その先の類 B が①の芯と同じ機構で、
   ②は①から独立に閉じない——`syn_truncation` §5 の「① と ② は同じ直しで動く」の読みは「② の値段の直しは ① の歩きの直しを前提にする」
   に改めるべき【推測】。①の小さな直し（倒れる時刻の真ん中で読む）は類 B にそのまま効く形なので、組で測る価値がある（今回は指示どおり入れていない）。
2. **類 C（`λ_net` < 0）**: 攻め手側だけを 0 で止めた（`be0bb677`・規則: 攻撃の宣言は任意）。守る側の計算の中の `λ_net`（受けた 1 本の損害が負）は、
   `KERNEL_FILES` には触らず入力 `lam_net` を 0 で止めれば直せるが、耐久の `(λ − λ_net)·L` の内訳も動くので今回は入れていない。入れるかは判断が要る。
   なお 2 段の値段を採らないなら `be0bb677` も一緒に外れる（攻め手側の 0 止めは旧い値付けでも同じ規則で言えるが、旧い付与の値打ちは負にならない）。
3. **残りの計測（`theory_bridge`・`relative_ledger`・`kappa_vector`・`win_calib --pre-settle on`）と表の作り直し（`make theory-table`）は回していない**。
   交点の橋が予告を外して悪化した時点で不採用の推薦になり、表は「採る式」の出力で作るもの（採らない式で作ると表と既定がずれる）だから。
   採る判断なら、表の作り直し（約 2 時間）→ 4 器の前後（約 4〜5 時間）を回す。
4. **流入の値段の量 `K₂`**（盤面だけで 1 段目を攻めた後の量）は 1 つの選び方で、遠い段の流入は在庫が減った後の量で値付けされるべき（静的な表なので段ごとに
   持てない）。これと、ブロッカーを流入にも入れた（旧い `a_of` はブロッカーを見ない）ことは、§4.2 の「地平の内の勝った席のばらつき 1.419 → 1.594（2 段）」の
   一因の見込み【推測】。
