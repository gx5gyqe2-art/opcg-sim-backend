## 4. 読み方——(a) は 2 つに割れる

- **(a1) 受ける費用の水準**——`Θ·μ` の Θ は **T2 で相手の切替点（どこから受け始めるか）から測った 1.15**。それは「相手が受け始める
  境界」であって「受けたときに失うもの」ではない。**受けたときに失うものは `λ − h·μ` = 0.086〜0.091**（実測の部品の和・Θ ≈ 1.6）。
  T47 の候補 (a)「`Θ·μ` がライフの札の分を織り込みすぎ」は**そのとおり**。恒等式から出していた 1.32（0.073）もまだ安い
  （`h` を 1 と置いていた分＝トリガーで札が手に入らない 1〜2 割を織り込むと 1.6 になる）。
- **(a2) 相手が `min` を選ばない**——0〜1000 で 3 割が受け・1000〜2000 で半分しか受けず・カウンターで 1.47 枚切る。
  これは**相手（同じ CPU）の打ち筋**。ユーザの原則（攻撃の率と同じ「打ち筋は式に入れない」）に従い**式には入れない**。
  診断値として残す（相手が強くなれば `min` に近づくはず＝価格の上限側に実現が寄る）。
- **(b) `ν(T)`** は `x > 2000` で合う。**(c) トリガー・アタック時効果**は受けた行の残差 −0.001〜−0.002＝ほぼ 0。

## 5. 提案（ユーザ判定待ち・式は触っていない）

受ける費用を **`Θ·μ` → `λ − h·μ`** に置く（`h` = ライフの札が手に入る割合の実測 0.82／0.89・**新定数ゼロ＝実測の写し**）。
`x ≥ 1000` のリーダー攻撃の価格が 0.063 → 0.086〜0.091 に上がり、リーダー攻撃の比 1.48 は 1.1 前後に寄る見込み（未測）。
**ただし `Θ` は守りの規則（`c(x) ≤ Θ` なら守る・P3）も駆動する**——受ける費用を 1.6 に上げると「`x` 1000〜2000 も守れ」に変わる。
攻撃の価格と守りの規則を同じ数で結ぶのが理論の形なので、**分けるか・両方動かすかはユーザの判定**。
