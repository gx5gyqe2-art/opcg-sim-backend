# T28 初回——**橋は架からなかった。しかも反転した**。原因は決着済みの局面

2026-09-14 実施・判定。**実デッキ 300 局**（w41・ホールドアウト）。
ユーザ提案「打った手による累積スコアを勝敗に紐づける」（`cpu_theory_gap.md` §0.3）の初回測定。
本報告は特定時点のスナップショット（追記・改変しない）。

## 結論を 5 行で

1. **`ΔS` は勝敗を予測した。ただし向きが逆**——**理論から外れた手を打った席の方が勝っている**
   （1 手あたりの傾き **−6.98** [−10.16, −3.66]・AUC **0.378**）。
2. **席順の交絡ではない**——手数の差が勝敗を予測する力はほぼ無い（AUC 0.5475）。
3. **反転は決着済みの帯に集中している**——**接戦帯の傾きは −0.008（ほぼ 0）**、
   決着帯は **−0.394**。**事前登録した交絡 #2（勝っている席は良い手を打つ余裕がある）そのもの。**
4. **`Θ` を 1.15／1.325／1.88 で振っても結論は動かない**＝**P3 はこの用途では効かない穴**
   （§0.4 の感度の規則が初めて仕事をした）。
5. **＝この形の累積スコアは橋にならない。** ただし**壊れ方が特定できた**ので直しようがある。

## 1. 測ったもの

```
攻め側: s_t = θ(打った手) − max_a θ(a)            候補の中の差
守り側: s_t = −( 実際に払った費用 − min(守る費用, 受ける費用) )
        守る費用 = c(x)·μ    受ける費用 = Θ·μ    **払えなかった行は 0**
S = Σ s_t（席ごと）        ΔS = S_自席 − S_相手席
```

**守り側は候補リストを使わない**（ユーザ指摘 2026-09-14）——記録に無いので、
**状態から理論の助言を出し、記録から実際の行動を出して**比べる。
**払えなかった行を誤りと数えない**のが要点（`measurement.md` §1）。

## 2. 実測（実デッキ 300 局・`Θ = 1.15`）

| 量 | AUC | 1 単位あたりの傾き | 95% CI |
|---|---|---|---|
| `ΔS`（生の和） | 0.351 | −0.257 | [−0.367, −0.150] |
| **`ΔS`（1 手あたり）** | **0.378** | **−6.98** | **[−10.16, −3.66]** |
| `ΔS` 攻め側だけ | 0.387 | −0.210 | [−0.321, −0.089] |
| `ΔS` 守り側だけ | 0.361 | −0.819 | [−1.236, −0.464] |
| **手数の差**（交絡の検査） | **0.5475** | — | — |

**AUC が 0.5 を大きく下回る**＝**理論に忠実な席の方が負けている**。
**攻め側・守り側の両方が同じ向き**（守り側の方が強い）。

**手数の差では説明できない**（AUC 0.5475）＝**先手・後手の非対称を拾ったのではない**。

## 3. **帯で切ると原因が見える**

| 帯 | n | 1 手あたりの傾き |
|---|---|---|
| **接戦（`mid`）** | 136 | **−0.008**（`Θ=1.325` で −0.018・`1.88` で −0.052） |
| **決着（`decided`）** | 162 | **−0.394**（同 −0.387・−0.370） |

**接戦帯では傾きがほぼ 0。反転は決着帯だけで起きている。**

これは**事前登録した落とし穴 #2 の署名そのもの**である:

> **勝っている席は「理論から外れた手」を打つ余裕がある。**
> 決着が付いた局面では最善手を打つ必要が無いので、**勝者ほど雑に打つ**。
> `s_t` を行内の差にしても、**「余裕」そのものは消えない**——そう書いておいた通りだった。

**そして接戦帯で 0 であることも、既知の診断と整合する**——接戦帯の `order_acc` はコイン水準
（`cpu_theory_gap.md` §1）。**決定に効く帯で、理論の順序は勝敗と結びついていない。**

## 4. 暫定値の感度（§0.4 の規則が初めて働いた）

| 穴 | 振った幅 | 結論は動いたか |
|---|---|---|
| **P3**（`Θ` の食い違い） | 1.15 / 1.325 / 1.88 | **動かない**——判定・帯の形とも同じ |

**＝P3 はこの用途では埋める優先度が低い。** 規則 2（感度を付ける）を置いた狙いどおり、
**「どの穴から埋めるか」を測定が答えた**。

> **P2（無言の行）は 3,568 行**——攻め側の行の相当部分で理論が値を付けられていない。
> こちらの感度はまだ測っていない（`--silent exclude` の実装は現状 `zero` と同じ扱い＝**宿題**）。

## 5. 判定と、直し方

| 問い | 答え |
|---|---|
| この形の累積スコアは橋になるか | **ならない**（反転する） |
| 原因は何か | **選択交絡**——決着帯で勝者が雑に打つ。**接戦帯では傾き 0** |
| 席順の交絡か | **違う**（手数の差の AUC 0.5475） |
| 理論が誤っているという証拠か | **そうは言えない**。**接戦帯が 0** なのは「結びついていない」であって「逆」ではない |

### 直し方（T28-b）

**局ごとに足してから帯で切ったのが誤り**だった。正しくは**行ごとに帯で切ってから足す**:

1. **接戦の行だけを足す**（`|v0|` が小さい行だけ `s_t` を累積）——決着後の雑さが入らない。
2. **行ごとに帯で層別した傾きを出す**（局単位ではなく行単位の推定）。
3. それでも 0 なら、**「理論の順序は決定に効く帯で勝敗と結びついていない」**が結論になり、
   それは**理論の側の所見**として重い（§1 の診断と一致する）。

## 限界

- **観察であって因果ではない**。反転の説明は選択交絡だが、**他の説明を排除していない**。
- **守りの窓はそのターン最初の 1 つだけ**・来る攻撃は**最大のもの**で近似。
- **P2（無言の行 3,568）を 0 と数えている**——`exclude` 版の感度は未測定。
- 実デッキ 300 局・1 設定・生成役 r3。合成では回していない。
- **接戦帯 n=136** は薄い。傾き 0 は「差が無い」ではなく「見えない」かもしれない。
