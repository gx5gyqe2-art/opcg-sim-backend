# T149a: 終盤の過大評価は局の束ねの見かけではない（2026-09-23）

T146b/c（`2026-09-23_presettle_asymmetry.md`）は、優勢側の過大評価が序盤より終盤で大きいという、
予告と逆の結果を見つけた。候補の 1 つは「1 局の中で優勢の評価が続けば、終盤の行がまとめて 1 つの
局の外れを反映する」という**局の束ね**だった。本 T はこれを局単位の重み付けとブートストラップで
検算する（ユーザ指示「両方とも追いましょうか」→「その10個をまとめてお願いします」の束 1・2 番目）。

**記録**: T146b/c と同じ。実 = `w41`（300 局）／合成 = `w39 + w42`（900 局）。

---

## 0. 結論（先に書く）

**局の束ねが見かけを作っていたのではない。終盤が大きいという差は、局単位に数えても、局を単位に
した復元抽出でも 0 を跨がずに残った。**

| 優勢側の較正の差 | 実 | 合成 |
|---|---|---|
| 行単位（T146b/c） | 0.177 | 0.217 |
| **局単位**（局 1 つ＝1 票） | 0.161 | 0.201 |
| late − early（行を局単位で束ねた点推定） | **+0.099** | **+0.055** |
| 95% 信頼区間（局の復元抽出 2,000 回） | **[0.046, 0.151]** | **[0.022, 0.086]** |
| 0 を跨ぐか | **跨がない** | **跨がない** |

劣勢側は逆に、late − early の信頼区間が両記録とも 0 を跨ぐ（実 [−0.107, 0.018]・合成
[−0.032, 0.045]）——**劣勢側の段による変化は、優勢側と違って統計的に言い切れない**。

## 1. 式（新定数ゼロ・当てはめない）

新しい価格式は書かない。既存の `p`（予測）／`z`（勝敗）を**局（`seed`）でまとめてから平均する**
（`per_game_gap`／`game_weighted_gap`）。**恒等式の検算**: `mean_gap`（`mean(p)-mean(z)`）は
`win_calib.score` の分位表から出す `gap_of`（分位の n 重み平均）と一致する（`calib_bins` の 4 桁
丸めの範囲内）——分位で切っても符号つきの差の合計は保たれるという既存の物差しの性質を、局単位の
版でも保つための検算。

**局単位のブートストラップ**（`bootstrap_stage_diff`）: 優勢側（または劣勢側）の行を局×段に束ね、
**局を単位に**復元抽出して `mean(late) − mean(early)` の分布を作る（2,000 回・固定 seed で再現可能）。
局が 5 未満なら測らない。

## 2. 検算の予告と当否

| # | 予告 | 結果 | 当否 |
|---|---|---|---|
| 1 | 局単位の較正の差は行単位と大きくは違わない（極端な外れ局に支配されていない） | 実 0.161 対 0.177・合成 0.201 対 0.217（10%未満の差） | **当たり** |
| 2 | late−early の差は局単位でも正で、信頼区間が 0 を跨がない | 両記録で跨がない（§0） | **当たり** |

## 3. 不変量

* `mean_gap` と `gap_of`（分位表）は丸め誤差 1e-3 の範囲で一致する（両記録・両側で確認）。
* 局数（`n_games`）は行の集合を局でユニーク化した数で、優勢側 300／299（実）・900／891（合成）——
  ほぼ全ての局が優勢側にも劣勢側にも行を持つ（1 局の中で優勢が入れ替わる局がある）。
* ブートストラップは固定 seed（既定 0）で完全に再現する（テストで確認）。

## 4. 上手くいったこと／いかなかったこと

**上手くいった**:
* **候補の 1 つ（局の束ねの見かけ）を、新しい価格式を 1 つも書かずに否定できた。** 既存の `p`／`z`
  を局単位でまとめるだけで検算が済んだ。
* **恒等式（`mean_gap` == `gap_of`）を先に固定し、局単位の版でも同じ性質が保たれることを確かめた
  上で頑健性を測った**——物差しそのものが局単位の集計で壊れていないことを先に確認する順序を守った。

**いかなかった**:
* **劣勢側の段による変化（負の方向）は統計的に言い切れないと分かった**——T146b/c の報告の
  「劣勢側も終盤にやや大きい」という記述は、本 T の基準では有意ではない。次の報告では劣勢側の
  段の差を強く主張しない。
