# gen13 採用報告 — 戦闘出口専用ヘッド × 裁定注入・低摂動版（2026-08-08）

gen13 = gen12 に**戦闘出口専用 value ヘッド**（`ValueNet.EXIT_HEADS` の "battle"・残差 MLP
hidden4）を載せ、人間裁定済み7点の注入順位ペアで**ヘッドのみ**を学習したもの（v43）。

## 1. 何を直したか

標的は m1@14 に代表される**防御の交換レート誤り**——「7000 攻撃に 1000+2000 の2枚で
リーダーを守る」をネットが得と評価するが、レフェリー（worlds16）と人間裁定は
「手札2枚 > ライフ1」で**素通し（PASS）が正**とする点。gen12 は深さ0の悲観的
continuation との誤り×誤りの相殺で偶然正解しており、箱の内部解決を実対局と同じ規約に
した v39（BOX_RESOLVE_DEPTH=1）でこの相殺が消えて 0.00 に落ちていた。

## 3. gen13 の設計（v43）

- **置き場所**: 戦闘出口専用ヘッド。胴体・本体 value は物理的に凍結（head-only 勾配）＝
  通常の葉評価・プラン評価は gen12 と bit 一致。較正が効くのは戦闘箱の枝順位づけ
  （防御窓の読み出し・木の箱化・ターン箱の中の戦闘窓）だけ。
- **教師**: `verified_inject_gen.py` の裁定7点注入（84ペア）。戦闘窓3点だけに限定する案は
  裁定がすべて防御側で守り偏りを生み m2@66 を壊した（0.75→0.00）ため、攻守を含む7点を採る。
- **摂動の最小化**: ヒンジ margin 0.2→**0.03**・hidden 32→**4**・学習後に残差ロジットを
  defcf 2,198盤面上で**中心化**（単調変換＝順位を厳密に保存して一律バイアスだけ除去）。
  一般の戦闘出口への摂動は**標準偏差 0.038**（v42 の約1/9・枝間マージンと同規模）。
  兄弟腕 margin0.05（std 0.058）は decide で m2@44 が 0.88→0.06 に崩壊＝絞ると正解マージンも
  細り探索の世界ノイズに負ける側の失敗も実在し、margin0.03 だけが両立した。

## 5. 運用メモ

- **ロールバックが過去世代より安全**: ヘッドを外せば（幅0）gen12 と bit 一致に戻る。
  重み補間もレシピ再現も不要。
- policy は gen12 と同一バイナリ（v12 確定＝policy 微調整は有害・符号化版 v8 一致）。
- 残る未取得はターン系（m2@44 0.75 / m2@66 0.69 / m5@7 系の完全化）で、これらは
  戦闘出口ヘッドの管轄外＝次はターン末ヘッド（v39 実装済み）の教師問題。v41 の結論
  「マージンを超える信号を持つ教師」がそのまま適用され、worlds 増強の教師再生成が
  戦闘・ターン両ヘッドの共通投資になる。
