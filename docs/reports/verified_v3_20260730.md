## 4. 計器上の注意

- 旧 v2 で立てた点別診断（v20 の分類・v21 の SEARCH_Q_BOUND・v22 の点別増減）は
  **v3 の accept で読み直すまで引用しない**。特に m4@12 と m2@12 は結論が反転した

  増減は bar 超でも慎重に読む（band 境界上にある可能性）
