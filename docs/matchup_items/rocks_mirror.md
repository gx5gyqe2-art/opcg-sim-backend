# 青ロックス ミラー（記事 a3）項目チェックリスト

## 1. 見出し
- 対面: 青ロックス ミラー。視点＝青ロックス（要塞型構築）。
- 投稿日: 2026-09-05（記事内で10月12日施行の緑ミホーク禁止に言及）。
- 記事の相性: ミラー（「仲間の夢」2枚入り）で先攻 五分／後攻 五分。先後選択は後攻。
- 大局観: 7シキを2枚以上盤面に絡めた側が有利。先に「仲間の夢」を打たされた側が押し込まれる。

## 3. 項目
1. **先後選択**: 後攻を選ぶ。後攻は後5で10ロックスを出して一気にライフを削るプランが有効。
2. **マリガン（先攻）**: 5リンリンは必須。次にA=7シキ、B=4グロリオーサか4カイドウ。後者は相手の後2のキャプテン・ジョンへの除去用。
3. **マリガン（後攻）**: 6ニューゲートは必須（後3に出す）。次にA=4キャプテン・ジョン、B=7シキ。2凶＋ジョンがあれば優位。
4. **先1〜先2**: 先1はシュトロイゼン（次ターンに5000で攻撃も可）。先2は2凶＋リーダーに1ドンで6000攻撃。3ステューシーを先2に置く手もあるが、後半の役割が大きいので温存気味。
5. **先3**: 通常は5リンリン（リーダー効果の前に出す＝ドローしたカードを切れる）。相手が後2にジョンを置いていたら4カイドウ（打点になるので優先）か4グロリオーサで除去。リンリンを出した場合、ジョンにリーダー攻撃を吸われるので旨味が薄い。
6. **先4**: 7シキを、速攻を使わずアクティブで返す。相手の後3ニューゲートと後4シキにレストを取られるため、攻撃できる対象があっても我慢する。先3のリンリンも相手がニューゲートを出していたらアクティブで返す。サブ案は6ニューゲート（シキが無いとき）。グロリオーサが相手に出ているときはパンプせず安く攻撃。
7. **先5**: 優先順に、(1)7シキ＋「仲間の夢」（先2で凶が出ている場合）、(2)7シキ＋アクティブ2ドンのブラフ（夢が手札に無い場合）、(3)3ステューシー＋6ニューゲート、(4)3ステューシー（登場＋起動）か5リンリン＋ジョン（3と4はシキが欠けたときの代替）。
8. **先6以降**: 10ロックスから7シキ、または3ステューシー＋6ニューゲートを展開。展開前に相手の後5攻撃でキャラ枚数を調整し、押し出しで捨てるくらいならブロックで使う。3本目のシキが置ければ相手のレストキャラを取り放題。耐久ならジョン＋夢には必ず凶を添える。夢が無ければジョン＋3ステューシーで2面止め。
9. **後攻の理想展開**: 後1 凶かシュトロイゼン→後2 キャプテン・ジョンをレストで返す（先攻はドンを全部キャラに使うため6000に届かず攻撃が不発）→後3 6ニューゲート（無ければ5リンリンかグロリオーサで除去）→後4 7シキ（相手の先4のシキがレストなら攻撃、アクティブならこちらもアクティブで返す）→後5 10ロックス（7シキか、6ニューゲート＋3ステューシー）で12000打点→後6 10ロックスか、ジョン＋夢か、3ステューシー＋起動→後7〜 リーサル。
10. **「仲間の夢」の使い方**: ジョンに打って要塞を作り1ターン凌ぐのが王道。ただし先に打った側（または欠いた側）が押し込まれるので、相手のリソースを削って先に打たせる。ジョン＋夢＋凶に対しては、自分の攻撃回数＋相手の手札枚数で突破できるか計算し、グロリオーサで相手の5コストを狙い凶に手札2枚を捨てさせる（攻撃2回分の価値）。ジョンを10ロックスから出すと夢が使えず壁止まり。単独で出し、亡者戯のケアのためアクティブドン4枚以上で返す。
11. **7シキの扱い**: 速攻で即レストにしない（次ターンの相手シキに取られる）。レストにしてよいのは先攻なら先5で夢を構えているとき、後攻なら10ロックスで多面展開したターン。序盤のグロリオーサ・ジョン・ステューシーで相手が固められているときは例外的にレスト可。
12. **攻撃値の読み**: 相手は2000が最低ラインと知っているので奇数ライン（5000、7000、9000）を狙い、システムキャラに合わせて5リンリンなら6000、ニューゲートやシキなら8000で2枚要求してくる。6000ブロッカーがいるならリンリン効果で+1000、またはバッキン切り。ニューゲートの3000はリーダー攻撃時だけで、レストキャラやニューゲート自身への攻撃には使えない。レストにしたら返しの相手の打点を計算してイベントを構える。
13. **ライフが少ないとき**: ライフ1以下ならリンリン＋ジョンでなく、ステューシーのロックやグロリオーサの除去＋ブロッカーなど防御寄りに。

## 4. 相手側
同じデッキ。先攻の理想は先2に2凶＋6000リーダー、先3にリンリンかグロリオーサ／カイドウ、先4にシキ、先5にシキ＋イベント、先6に10ロックス、先7にジョン＋イベントかステューシー＋起動、先8からリーサル。後攻側は戦力が早く揃うので強く攻撃してくる。

## 5. 負ける原因・注意
- 7シキの枚数負け。シキを即レストにして次のシキに取られる。
- 「仲間の夢」を先に打つ、または欠損する。
- リーダー効果の不発（デッキトップが非ロックス）。シュトロイゼンで対処する。
- 後攻3ターン目のニューゲートを欠く。レストのキャラへのリーダー攻撃は守りにくい。
- 10ロックス展開時にキャラが押し出される。
