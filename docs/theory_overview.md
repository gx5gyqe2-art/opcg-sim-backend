## 1. この理論は何か

- **目的**: CPU を変える前に「手の良し悪しを説明する理論」を組み上げる。理論が損と言う手を禁じて勝率が上がるか（出口 T18）で役立つかを確かめる。
- **前提**: **完全情報**で組む。両席の手札とデッキの中身が見えている前提で式を書き、まず勝敗の説明をつける。相手の手札が見えないことの扱いは後の層。
- **守る約束（4 つ）**: 当てはめた局で測らない／項は測る前に決める／各項は独立の量を言い当てる／**新しい定数を足さない**（規則・デッキ・既存の実測値だけで書く）。

## 2. 理論の部品

| 部品 | 何をするか |
|---|---|
| 通貨 | ドン 1 枚・手札 1 枚・ライフ 1 枚などを同じ単位に換算する（実測で固定・検算済み） |
| 攻めと守りの値段 | 攻撃を受ける費用・止める費用・ブロッカーの値打ち |
| 効果の値段 | 登場時・起動・付与・除去・条件つきの効果。コストを払えるかはエンジンと同じ規則で判定する |
| 手札の価値 | 手札の 1 枚ごとに「出す・カウンターに使う・持っておく」の最適な割り当てで測る |
| **手の値段**（2026-10-11 採用） | 候補の手を打った後の局面で 2 本の時計を読み直し、勝率がどれだけ動いたかを局面の傾きで割って値段にする。既定は山札とライフの並びを混ぜ直した複製で読む形（並びを知る形は切替・後知恵の上限） |
| 守る側の計算 | 守り手が先読みの範囲（平均 4〜5 ターン）で最善に守ると置いて、毎ターンどれだけ削られるかを解く |
| **交点の橋**（時計） | 両席について「相手を倒し切るまで何ターンかかるか」を出し、どちらが先に届くかで勝ち負けを言う |
| 線形の橋 | 打った手の値打ちの累積で勝敗を並べる |
| 手の値段 | 候補の手の値打ち。**既定（2026-10-11 採用・`2026-10-10_clock_value.md`）はその手を打った後の局面で 2 本の時計を読み直した勝率の動き**（`(W(打った後) − W(今)) / 局面の傾き`）。**既定の後続は並びを知らない形**（両席のライフと山札を行ごとに混ぜ直した複製＝理論の約束どおり中身は見えるが並びは見えない・同報告 §3.5 の列＝実 (i) .7533・(ii) .6482）。並びを知る形（真の盤面の複製・同報告の判定の列 .7577／.6610）は後知恵の上限として `OPCG_CLOCK_VALUE_ORDER=known` で残す。旧い「その 1 手だけの静的な値段」は `OPCG_CLOCK_VALUE=0` で戻せる |
| 局面の傾き | 2 本の時計の差から「その局面で 1 単位の得が勝率をどれだけ動かすか」を出す |
| 決着の定義 | 「相手が最善で守っても通る本数 ≥ 相手の残りライフ ＋ 1」なら、そのターンで決着（規則だけ） |
| 表（`tests/fixtures/harm_profile.json`） | 損害の輪郭・時計のばらつき・平均の傾きの実測値。`make theory-table` で作り直し、出所を点検する |

計算は全部 Rust（`rust/opcg_engine/src/theory/`）。Python は入口・記録の読み込み・集計だけ。正しさは cargo の記録の再生と golden で守る。

**段 (3) の判定を保留に戻した理由**（2026-10-09・独立レビューの指摘を司令塔が報告の式で確かめた）:
ユーザが測る前に決めた線は「残る遅れの群れを直した上限でも、的中と決着前の予測力の上がりがともに 0.01 未満なら完成」。
測った上限は群れの時計を**両席とも**同じ量（勝った席の平均の遅れ・1.50／1.62 ターン）だけ早める作りで、群れの 6〜7 割は負けた席の時計なので、
下がった（的中 −0.004／−0.013）のは作りの帰結であり「直しても良くならない」証拠にならない。「勝った席を完璧に当てる」副の天井も負けた席は早めたままだった。
**勝った席だけを直し負けた席は触らない天井は測っていない**（粗い見積もりでは +0.01〜+0.03 に届きうる・推測）。予告（+0.005〜+0.015）も符号ごと外れていた。
また判定は既定でない腕（絶対の腕）で下していた。→ **測り直した（`2026-10-09_ceiling_redo.md`）**: 勝った席だけ直す天井は 的中 +0.023／+0.036・決着前の予測力（相対の腕）+0.027／+0.053 で線を越えた＝**段 (3) は未完で、群れを追う**。ただし予測の側の特徴だけでは勝った席の多い帯を見分けられないので、時計の読み方ではなく計算の中身で直す必要がある。

## 5. 既知の限界

1. **手札の厚い守り手の生存を言い過ぎる時計の群れ**（時計の 10％／13％）。生き延びると言い、歩きが先読みの範囲の外で交わる勝った席の時計（105／462 本）は、整数ターンで +1.76／+2.47 遅い（打ち筋の分を差し引いて +1.14／+1.39）。
   作業担当は範囲の外の値付けを疑ったが、M-2 では範囲の外の値付けは中の値とほぼ同じだった。独立レビューの読みは「群れの時計は範囲の長さに貼りついていて、芯は範囲の内で後のターンの攻撃を実際の半分の強さ（計画の超過の和 3,338 対 実際 6,105）にしか読んでいないこと」（推測・未検証）。
   直したときの値打ちの天井は測り直し中（§3）。
2. **合成の記録の打ち切り**（30 ターンで時計が届かない 70 本）と、それによる**合成のばらつきの大きさ**（実戦の約 1.4 倍の 7 割はこの 21 本）。
3. **実際の守り手（CPU）は理論より 1 ターンに約 0.5 枚多く札を切る**。理論の最善と「目先だけの最善」の間にいる。ただし目先だけの守り手に置き換えても残る遅れは 15％ しか消えない＝遅れの大半は打ち筋では説明できない。打ち筋の課題として訓練の側の材料にする。
4. 線形の橋の行ごとの判定は、実戦で「逆向き」と出る（全体の並べる力は保たれている）。
5. 決着の定義は「1 ターンで詰む」まで。複数ターンの必勝は決着前の層に任せている。
