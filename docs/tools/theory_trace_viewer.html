理論と探索の棋譜

決定点の一覧
読み方
探索
CPU が実際に打った手。盤面では青緑の枠と矢印。
理論
同じ候補を理論で値付けして一番高い手。盤面では橙の枠と矢印。
介入
介入つきの局だけ。理論が損と読んだ手を、理論の最善に差し替えて実際に打った決定点。盤面の橙の矢印が実際に打った手、青緑の破線が探索が打とうとした手。
戦闘中
守りの窓など、攻撃の途中の決定点で攻撃側と対象を赤で結ぶ。
理論の値
単位は「手札 1 枚ぶんの価値」（枚）。差は打った手 − 理論の最善で、負なら理論はその手を損と読んでいる。
候補
行を押すと、その手を盤面に灰色の矢印で重ねる。カードを押すと拡大。
盤面
下が p1、上が p2。手番側の半分が明るい。完全情報なので両者の手札が見える。横向きはレスト、紫の数字は付与ドン。
