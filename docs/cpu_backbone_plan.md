# 骨組み価値ネット計画（リーダー非依存・合成カードによる基底事前学習）

> **種別: 計画（plan）**。実装完了後に SPEC / TEST_SPEC へ吸収し、文書としては残さない。
> 起案 2026-08-11（ユーザ提案）。前提となる実測: v49 トリレンマ（少数ペア注入は転移しやすい
> カード/文脈特徴に紐づく・サトリ移植で実証）・v24 representation-bound・
> gen14 採用時の限界（v9 物理特徴は与えても勾配が埋め込みの近道を選ぶ）。

## 0. 目的と設計原理

**目的**: 新しいリーダー・新しいカードを、カードごとの追加学習なしで妥当にプレイできる
価値関数の基盤を作る。

**原理**（2026-08-11 の設計議論の合意）:
1. **暗記（訓練時）から測定（推論時）へ**——エンジンは完全なシミュレータなので、決定時に
   測れる量（効果の資源差分・到達打点・リーサル距離）は測って渡し、学習は「測定が届かない
   長期の資源配置の価値」だけに使う。
2. **価値の言語は物理量とその差分**——カードID埋め込みを骨組みから排除する。効果の意味は
   パーサ導出（EffFeat 系）とエンジン実測（v7 型Δ特徴）で渡す。
3. **リーダー固有は生まれつきゼロの着脱残差**——共有骨組みはリーダー不可知。固有の判断は
   証拠（人間対局・レフェリー裁定）が入った分だけ残差モジュールに載る。
4. **ドメインランダム化**（本計画の核・ユーザ提案）——**リーダー効果なしのバニラリーダー**を
   据え、**デッキのカードに効果をランダム合成**した対局で骨組みを訓練する。同じカードIDが
   ゲームごとに違う効果を持つため、IDは何も予測せず、**埋め込み依存が構造的に不可能**になる。
   将来の実カードは「合成分布の1標本」＝分布内汎化になる。

## 1. フェーズ構成（各フェーズに Go/No-Go を置く）

### Phase 0: 合成カード実現性スパイク（安い・最初にやる）
- 効果予算モデルの素案: 実カード群から「コストn の効果強度」の分布を集計し、その予算内で
  効果（ドロー/除去/パンプ/ブロッカー付与…既存パーサ語彙の組合せ）をランダム合成する
  カードファクトリを作る。既存資産流用: `deckgen` / `condition_synth` / 効果カバレッジ系ハーネス。
- 合成デッキ同士で数百局の自己対戦を完走させ、**構造監査（EXCEPTION/CARD_LOSS/TEMP_LEAK=0）**
  と対局品質（ターン数・決着形の分布が実対局と大きく乖離しない）を確認。
- **Go/No-Go**: 監査ゼロ違反で完走し、退化対局（即決着・無限膠着）の棄却率が実用範囲
  （<20%目安）に収まるか。

### Phase 1: 情報量スパイク（理想形全体の当否を安く判定・最重要ゲート）
- 小さな骨組みネット（**card_idx なし**・物理スカラー＋field＋EffFeat/Δ特徴のみ）を
  ランダム世界の短時間訓練で作る。
- **評価＝実デッキのホールドアウト盤面**: 既存リプレイ（h1/e1/e2/m/g系）の決定点で、
  (a) レフェリー勝率ラベルへの較正、(b) 人間の手/gen14 の判断との順位一致を測る。
- **Go/No-Go**: 「ID埋め込みなしの物理言語で、実盤面の価値がどこまで説明できるか」。
  gen14 比で著しく劣るなら、物理言語の設計（Δ特徴）を拡充して再試行。2回で届かなければ
  埋め込み排除の程度を再検討（EffFeat のみ残す等）。

### Phase 2: 入力言語（符号化 v10）の確定
- Phase 1 の結果から骨組みの入力を確定する。候補:
  - **Δ特徴の全面化**（v7 の一般化）: 手札 PLAY・起動・リーダー能力を make/unmake で
    1手仮実行した資源差分（ドン/手札/ライフ/盤面火力）
  - **導出量**: 実効ドン収入/ターン・実効回復量/ターン・**リーサル距離**（双方の詰みまでの
    ターン数・A2 の恒久解）・到達可能打点（能力込み）
  - EffFeat（パーサ導出テーブル）は維持。card_idx は骨組みからは排除
- 恒等温スタートは使わない（言語が変わるため新規訓練）。既存 v1〜v9 経路は現行線のため維持。

### Phase 3: 骨組みの本訓練
- データ: 効果予算モデル下のランダム合成対局（バニラリーダー）**のみ**。品質フィルタ＋退化棄却。
- **実デッキは訓練に混ぜない**（ユーザ指摘 2026-08-11 で当初案から変更）: シナジーの価値は
  探索の未来の枝で発火し葉の物理量に現れる＝静的に教えれば ID/現行メタへの固有評価基準の
  再輸入になる。骨組みに card_idx は無いため実デッキ混合が教えるのは「現行カードプールの
  物理状態分布」だけ＝分布バイアス。実デッキの役割は**評価専用**（ホールドアウト）。
- 代わりに**被覆検査**を置く: ランダム世界の盤面特徴分布と実リプレイの盤面特徴分布を比較し、
  踏めていない物理領域（バフ横並び・早期大型等）は**合成側のつまみ**（効果合成率）で埋める。
- ラベル: 勝敗＋非飽和域のレフェリー勝率（v50 リーサル較正プローブの規約）。
- 一度きりの基底事前学習＝「新カードごとの大量試行はしない」制約と両立する。
- 段階2として**リーダー能力もランダム合成**した対局を混ぜ、「リーダー能力のΔを読む」
  ことまで骨組みに入れる（エネル型経済リーダーへの汎化）。

### Phase 4: リーダー残差モジュール
- `lead_slots`（設計済み・未使用）または出口ヘッド型残差で、リーダー固有の補正を
  着脱可能に。**新リーダーはゼロ初期化＝物理ベースラインから開始**。
- 教師は人間対局→裁定抽出パイプライン（v48/v49 で手動実証済みの流れの自動化）。

### Phase 5: 統合評価（三層）
- **ホールドアウト実カード**: 訓練にも EffFeat にも見せない実カード群でのプレイ品質＝
  「未来のカード」への汎化の直接測定（本計画で初めて可能になる評価）。
- **移植不変条件スイート**: サトリ移植型の合成検査を教訓ごとに自動生成（紐づけの検証）。
- 既存の**コーチゲート**（挙動）＋**アリーナ vs gen14**（全体）。骨組み線が gen14 に
  アリーナで劣る間は既定を替えない（現行線は無傷のまま並走）。

## 2. 現行線との関係

- 本計画は**並走する長期線**。現行線（gen14・A2=v50 リーサル較正・人間対局の裁定注入）は
  そのまま進める。v50 の計器（リーサル較正プローブ・レフェリーラベル）と符号化 v9 の
  物理特徴は、そのまま骨組み線の部品になる。
- 埋め込み排除で失われ得るもの（微細なカードシナジー）は、v24 の実測（埋め込みの線形和は
  カード間条件を表現できない）から損失は限定的と見込むが、**Phase 1 が定量する**。

## 3. リスクと対策

| リスク | 対策 |
|---|---|
| ランダム効果が歪んだゲームを作り歪んだ物理を学ぶ | 効果予算モデル（コスト↔強度）＋退化対局の棄却＋品質フィルタ |
| ランダム世界が実対局の物理状態を踏まない（被覆漏れ） | 被覆検査（盤面特徴分布の比較）→合成つまみで埋める。実デッキの訓練混合はしない（固有評価基準の再輸入・ユーザ指摘 2026-08-11） |
| 地平をまたぐ組み立て（数ターン先のコンボ成立）は未来の枝でも実現しない | 学習でなく測定で埋める: 手札×山札の関係Δ特徴（v7 の関係版）を Phase 2 候補に置く |
| 物理言語だけでは表現力不足 | Phase 1 の Go/No-Go で安く検出→Δ特徴拡充→それでも不足なら EffFeat 残し等の後退線 |
| 合成カードでエンジン/パーサが未踏経路を踏む | Phase 0 で構造監査ゼロ違反を先に確認（テスト資産の流用） |
| 骨組み線が長期化し現行線が停滞 | 完全並走・既定切替はアリーナ非劣位が条件・現行線の裁定/ゲート資産は全て骨組み線でも使う |

## 4. 着手順

1. Phase 0 スパイク（効果予算モデルの素案＋カードファクトリ＋監査つき数百局）
2. Phase 1 スパイク（骨組み小ネット＋ホールドアウト実盤面評価）
3. → Go なら Phase 2 以降を本計画に沿って詳細化（各フェーズ完了時にレポート化）
